# Key storyboard table rules

The harness schema is authoritative. These rules describe how creative fields should fit together; they do not define a competing data model.

## Source and purpose

- Every row must explain why the shot exists and which supplied source positions it realizes.
- One source action has one principal visual realization. Additional rows must contribute a supported receiver reaction, decisive detail, consequence, setup or payoff.
- Keep all cited sources inside the confirmed scene. Dialogue remains attached to its supplied speaker and performance context.

## Staging and time

- Composition should locate important subjects and objects using only the precision needed to make the frame unambiguous.
- Ordered action beats describe what changes during the shot, not simultaneous summaries that cannot be performed.
- Duration must accommodate spoken text, physical action, reaction, and meaningful travel. Use the supplied profile instead of sample-based cut lengths.
- A first frame contains only facts visible at the start. A last frame contains the achieved end state. Intermediate changes belong in action beats or keyframe notes.
- Dialogue, ambience, and sound effects must fit the visible action and source state. Sound must not imply an unsupported impact, movement, object, or off-screen event.

## Continuity and generation readiness

- The opening state must be compatible with the previous exit or explicitly identify a supported transition.
- The outgoing state should make direction, gaze, location zone, hand or prop ownership, continuing motion, light, and sound legible when those facts cross the cut.
- Cut within movement only when the following start state can continue that movement.
- Read the adjacent rows before changing a boundary. A local improvement is invalid when it makes the previous exit or next opening state contradictory.
- Camera movement should have a concrete attention or dramatic function; it is not required for visual interest.
- Bind supplied, confirmed scene, character, and prop identities when they are visibly required by the row. Asset references define identity, version, and state; creative staging cannot substitute a new identity or unsupported state.
- An insert or close-up must preserve the confirmed anchor features and current state of the depicted prop or larger asset instead of silently redesigning it.
