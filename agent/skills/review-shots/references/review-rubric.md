# Storyboard review rubric

The review complements deterministic gates. It does not replace source, duration, asset, hash, or coverage validators.

## Evidence threshold

An issue is supported only when the payload shows a specific mismatch between source intent, accepted plan, adjacent states, supplied profile, or candidate fields. Point to the smallest affected scope and the observed values. A general preference for more coverage, motion, variety, or drama is not evidence.

## Severity

- Use blocking severity only when the supplied policy identifies a violation that prevents a source-grounded, continuous, performable, or generation-ready candidate.
- Use warning severity for a supported weakness that can remain visible for human judgment without corrupting the fixed facts or downstream handoff.
- Never lower a deterministic blocker. When its evidence is also visible semantically, cite it and offer a bounded repair hint.

## Review lenses

- **Realization:** required information is visible; repeated source references contribute something distinct; no unsupported event is added.
- **Performance:** important dialogue has a readable speaker performance and consequential information has a readable receiver response when supported.
- **Space and continuity:** axis, screen direction, gaze, subject zone, entrances and exits, motion, light, sound, and prop ownership hand off coherently.
- **Temporal feasibility:** proposed duration can contain the spoken text, ordered action, reaction, and travel without collapsing them into an impossible instant.
- **Frame state:** first frames show only opening facts; last frames record achieved state; keyframe notes do not replace missing action beats.
- **Assets and production:** bindings use supplied identities, versions, and states; staging does not imply unavailable or contradictory assets.
- **Dramatic legibility:** a reveal, evidence insert, action consequence, scene transition, or hook is presented clearly enough to serve its accepted purpose.
- **Cut craft:** reaction, insert, motion match, and shot variation must each add supported information or continuity. Uniform coverage is a warning only when it makes an accepted purpose materially less readable.
