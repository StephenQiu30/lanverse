# 浮光页面接口设计

对应[页面总览](../requirement/浮光页面/index.md)与[数据设计](浮光页面数据设计.md)。基线 `2793f811`；本轮只读取 `backend/internal/app/public_api.go`、Handler/DTO和生成的 `backend/docs/swagger.json`，没有运行在线API验收。本文是页面消费需求及**拟新增合同**，不能替代在线Swagger，也不能据此手写前端请求或生成文件。

## 1. 公共约定与状态

- 现有公共业务API仅在local+回环地址装配，以Workspace身份取得当前actor；消费者认证尚未公开接入。下面认证后权限是目标设计，不是现网已有能力。
- REST路径 `/api`、资源复数、字段snake_case、UUID ID、UTC RFC3339、时长ms、金额bigint微元。新增业务动作统一斜杠（D-10）；不同时提供旧DES冒号写法别名。
- 新写命令带 `Idempotency-Key: UUID`；修改对象带 `expected_revision`。敏感认证例外见§3；同键同体回放安全结果，同键不同体 `422 idempotency_key_reused`。缺键400，未知字段/不合法枚举422；现有端点实际错误以DTO/Handler为准，不能为统一文档擅自改现有合同。
- 新普通列表默认limit50、最大200、不透明cursor，稳定排序 `(create_time DESC,id DESC)`；游标绑定作用域和筛选。素材库保留已实现的page/page_size/total，不套用cursor。
- 新增响应只包含页面所需安全字段。GET不触发生成或修复写入；异步命令202/201返回可查询的task/operation ID，不代表执行完成。
- 错误沿用 `application/problem+json` 与code、request_id、errors、meta；错误内容不含密码、凭据、签名或内部堆栈。HTTP标准基础为 [RFC 9457](https://www.rfc-editor.org/rfc/rfc9457.html)，业务code仍由本项目约定。

```json
{
  "type": "https://lanverse.local/errors/revision_conflict",
  "title": "内容已被修改",
  "status": 409,
  "code": "revision_conflict",
  "request_id": "request-id",
  "meta": { "current_revision": 8 },
  "errors": []
}
```

公共错误：401 unauthenticated；403 forbidden/password_change_required；404 not_found（不存在或不能披露的跨范围资源）；409 revision_conflict/state_conflict/in_use；422字段、模型、预算、引用或幂等错误；429 rate_limited附Retry-After；503 dependency_unavailable。UI依据code处理，不依据可变中文detail判断。

### 2.1 可复用请求示例

创建项目（现有）：

```http
POST /api/projects
Idempotency-Key: <uuid>
Content-Type: application/json

{"name":"验收项目","aspect_ratio":"9:16","style_type":"realistic","description":"合成验收数据"}
```

镜头生产不可用这个请求假装支持1:1。画布保存调用现有 `applyCanvasCommands` 的Command闭集；媒体元数据命令必须携带匹配的library/item/folder修订，不把一个revision混用到三种对象。

## 3. API-AUTH、API-ID、API-REG、API-PREF（规划/条件性）

延续DES-09应用用例；当前公开路由未装配，下表为评审后的接线目标。内部actor/org从可信服务端上下文取得。

| 方法与目标路径                                    | 权限                           | 请求字段 / 校验                                                                     | 成功返回                                                                               | 特有错误 / 语义                                                          |
| ------------------------------------------------- | ------------------------------ | ----------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------- | ------------------------------------------------------------------------ |
| POST `/api/auth/login`                            | 匿名，Origin+限速              | login_name、password必填；return_to仅站内且不直接信任                               | 200 `{user,must_change_password}`并设置HttpOnly会话Cookie                              | 不存在/禁用/错密统一401；锁定423；Redis故障503；不使用含密码通用幂等回执 |
| GET `/api/auth/me`                                | 会话；受限会话可读本人最低信息 | 无body                                                                              | id/login_name/display_name/role/status/revision/must_change_password、safe_preferences | 401时清客户端私有缓存；不返回hash/epoch/token                            |
| POST `/api/auth/logout`                           | 会话，重复登出可安全完成       | 专用会话撤销，不保存Cookie回执                                                      | 204清Cookie                                                                            | 撤销成功但审计故障需清Cookie并明确503/诊断，不重新启用会话               |
| POST `/api/auth/password`                         | 当前本人或强制改密会话         | current_password、new_password；强制模式依据服务器state；新密码10位含字母数字且不同 | 200 `{changed:true,user}`并轮换当前会话                                                | 422 password_policy；401旧密码失败；当前状态不匹配409                    |
| GET `/api/auth/sessions`                          | 本人                           | cursor/limit                                                                        | sessions[{id,label,created_at,last_seen,expires_at,current}]                           | 仅安全session ID，非令牌；Redis不可用503                                 |
| DELETE `/api/auth/sessions/{sid}`                 | 本人                           | 安全sid与Idempotency-Key                                                            | 204                                                                                    | 不能撤销他人会话；撤销当前会话按logout处理                               |
| POST `/api/auth/sessions/revoke-others`           | 本人                           | Idempotency-Key；确认目标为其他会话                                                 | 200 `{revoked_count,as_of}`                                                            | 创建竞态以epoch/时间截止规则明确；没有永久令牌回执                       |
| GET `/api/admin/users`                            | admin                          | search、role、status、cursor、limit                                                 | items安全账号、next_cursor                                                             | scope由当前org确定                                                       |
| POST `/api/admin/users`                           | admin                          | login_name、display_name、role、initial_password；敏感专用幂等摘要                  | 201 `{id,revision,must_change_password:true}`                                          | 409 already_exists；422 policy；事务内复核admin                          |
| PATCH `/api/admin/users/{id}`                     | admin                          | expected_revision、display_name/role                                                | 200 safe user                                                                          | 409 last_admin/state_conflict；不可改login_name                          |
| POST `/api/admin/users/{id}/disable` 或 `/enable` | admin                          | expected_revision                                                                   | 200 safe user/revision                                                                 | 最后管理员保护，epoch与状态同事务                                        |
| POST `/api/admin/users/{id}/reset-password`       | admin                          | expected_revision、new_password；不回显                                             | 200 `{revision,must_change_password:true}`                                             | 所有旧会话失效；强制本人改密                                             |
| PATCH `/api/auth/me`                              | 本人                           | expected_revision、display_name；不能传role/login_name                              | 200 safe user                                                                          | 非法字段422；冲突409                                                     |
| GET/PATCH `/api/auth/preferences`                 | 本人                           | PATCH: expected_revision、theme；avatar_asset_id可空；个人prompt字段待D-09          | 200 preference+revision                                                                | 头像归属/审核不合格422；跨库403                                          |
| POST `/api/registration-invitations/inspect`      | 持一次性token；D-01通过后      | token只在body，限速；不要GET中暴露token                                             | 200 `{workspace_label,login_name?,expires_at}`                                         | 无效/撤销/过期统一422 invitation_invalid                                 |
| POST `/api/registrations`                         | 有效邀请；条件性               | token、login_name、display_name、password；角色/组织拒绝客户端指定                  | 201 safe user或下一步登录指示                                                          | 邀请消费与用户创建同事务；重复token不重复建号                            |

API-ID指admin/users家族，API-PREF指本人资料/偏好家族，API-REG指邀请和注册家族。**没有公开注册或邮箱密码找回端点**。管理员签发/撤销邀请只在D-01通过后另以 `/api/admin/registration-invitations` POST、`/{id}/revoke` POST 接入，字段login_name可空、role、expires_at，令牌仅签发响应一次返回，审计只记邀请ID和范围。

会话和认证通用安全依据沿用现有DES-09，并参照[OWASP认证指南](https://cheatsheetseries.owasp.org/cheatsheets/Authentication_Cheat_Sheet.html)：统一失败提示、敏感操作重新核验身份、不在错误中泄露账户或凭据。具体会话时长沿用项目已记录12h/7d；“记住我”尚未得到扩大时长的授权。

| ----------------------------------------------------- | --------------------------------------------------------------- | -------------------------------------------------------------- | -------------------------------------------------------------- |
| GET `/api/projects/{pid}/episodes/{eid}/shots`        | scene_id、progress、stale、search、cursor、limit                | items ShotSummary、next_cursor、scene summaries                | scope/episode不匹配404；返回当前正式结构标识                   |

ShotSummary最小字段：id、scene_id、display_no、position、revision、version_no、description摘要、duration_ms、mode、progress、stale_reasons[]、missing_refs[]、selected_frame/take摘要、candidate_counts。ShotDetail补全camera、params、reference_items、line_keys、selected对象、current_operation_ids与allowed_actions。媒体URL短期授权获取，不能永久嵌入缓存对象。

```json
{
  "expected_revision": 7,
  "output_id": "<候选UUID>",
  "allow_stale": false
}
```

选定响应不是工作流指令：原子更改正式指针/选择日志/Outbox后成功；跨页缓存失效，lineage消费者后续标过期。任务完成只产生候选，不能偷偷调用选定接口。

### 5.3 授权材料

`POST /api/projects/{pid}/consents`：subject_label、kind、purposes、evidence_asset_id、valid_from、valid_until、declaration_version；返回201安全声明。`GET /api/projects/{pid}/consents/{id}` 返回范围与有效性、允许的材料读取入口；`POST …/{id}/revoke` 带expected_revision/reason返回撤销事实。授权证据不公开直链，材料访问/变更审计；无证据、范围不符、期限无效422。撤销后新报价拒绝，原任务按冻结合同评估并保留历史。

### 5.4 Agent与共享通知

API-AGT沿用DES-39规划：项目内session、messages、runs、proposals；run启动需当前scope及费用确认，消息流只传展示内容与状态，提案接受携带proposal_id/expected_revision，转为已有owning命令。工具白名单、取消、输出校验和不覆盖人工修改与GEN共用。没有运行实现证据前，不将“Agent建议已生成”的toast标为完成。

全局通知目标接口：GET `/api/notifications?cursor&limit&unread`；POST `/api/notifications/{id}/read`（同键安全）；只查询当前recipient。命令面板优先组合既有有权项目/对象查询；不把所有项目全量传浏览器。

## 6. API-ANA（规划）：仪表盘与统计口径

`GET /api/projects/{pid}/analytics?from=<UTC>&to=<UTC>&timezone=Asia/Shanghai&episode_id=<uuid?>`。from/to为半开区间，默认14天；timezone只决定显示桶边界，服务端将边界转换UTC；建议明细范围最多90天，“全部”使用汇总模式。每一子块返回 `available/error`，不能缺数补0。

```json
{
  "scope": { "project_id": "<uuid>", "episode_id": null },
  "range": {
    "from": "2026-09-24T16:00:00Z",
    "to": "2026-10-08T16:00:00Z",
    "timezone": "Asia/Shanghai"
  },
  "as_of": "2026-10-08T08:00:00Z",
  "metrics": {
    "shots_completed": { "numerator": 0, "denominator": 0, "ratio": null },
    "generation_success": { "numerator": 0, "denominator": 0, "ratio": null },
    "video_duration_ms": { "sample_count": 0, "mean": null, "p95": null }
  },
  "daily_tasks": [],
  "model_results": [],
  "episode_stages": [],
  "todos": [],
  "partial_errors": []
}
```

示例全零是无数据合同，不是实际项目数据。具体指标提案D-06：

| 字段               | 范围与分子/分母                                                                                                                           | 单位 / 边界                                                    |
| ------------------ | ----------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------- |
| shots_completed    | 当前active镜头已选ready且审核通过的视频 / 当前active镜头总数                                                                              | 当前快照，非时间窗口内新建镜头；若UI切时间仍保持快照需标“当前” |

## 7. API-AUDIT、API-HEALTH（规划）

| 端点                               | 请求                                                                     | 返回                                                                    | 限制与失败                                                                         |
| ---------------------------------- | ------------------------------------------------------------------------ | ----------------------------------------------------------------------- | ---------------------------------------------------------------------------------- |
| GET `/api/admin/audit-logs`        | from/to、actor_id/kind、action、object_type/id、project_id、cursor/limit | items安全摘要、next_cursor、as_of                                       | admin；org强制；默认最近7天、建议单次窗口≤90天                                     |
| GET `/api/admin/audit-logs/{id}`   | create_time（分区键精确定位）                                            | 脱敏before/after、actor、object、request/trace                          | 找不到404；不提供更新/删除                                                         |
| GET `/api/admin/audit-logs/export` | 同筛选；明确导出范围                                                     | CSV流，Content-Disposition；header说明导出范围                          | 建议上限10万行/50MB，超限422要求缩小；不静默截断；公式转义、权限中途复核、访问审计 |
| GET `/api/admin/health`            | 无任意PromQL；可force_refresh受限                                        | as_of、queues、operations、providers、outbox、kafka_lag、partial_errors | admin；30秒缓存；依赖故障显示null+原因，禁止返回秘密配置                           |

健康阈值沿用REQ-35；每块必须携带统计窗口和采集时间。外链Grafana/Temporal从运维配置白名单返回，禁止附带凭据。GET `/healthz`只是进程就绪，不能替代管理健康页；健康页面不得提供重启、清队列或修改任务终态。

## 8. 事件、缓存与前端接线

公开SSE当前仍为规划。沿用DES-03 `GET /api/projects/{pid}/events` 与 `/api/me/events`，Last-Event-ID重连；补发范围以其10分钟/5000条约定，过期发resync并重读。事件只含ID、revision、状态摘要，不传密钥或完整剧本。连接失效必须重新鉴权，不能保持撤权前数据流。

- Shot/参考/配音选定：失效对应详情、分镜、analytics与lineage；布局命令仅失效对应canvas。
- 模型/凭据变更：失效目录可用性，不改已冻结任务；报价冲突重取而不是自动确认更高价格。
- project变更：失效有权列表/详情；切project取消旧请求、隔离Query key；不跨用户共享私有缓存。
- 没有SSE时可对在途任务有界轮询，标签隐藏暂停，终态停止；轮询不是任务重试。

## 9. 合同测试与接入门槛

1. 生成Swagger路径/operationId/DTO必填字段与公开router一致；前端仅调用生成函数，禁止手写路径适配临时mock。
2. 同键同体重放100次效果一次；同键异体422；两次revision写入只能一次成功；跨项目/角色/撤权拒绝。
3. 表单非法值、超范围批量、缺引用、审核拒绝、预算不足、过期报价、取消与unknown分别有可判定错误。
4. 认证敏感输入不进入幂等回执、审计、日志、追踪或响应；会话/cookie/Origin测试与现有local模式分开。
5. 实际HTTP、PostgreSQL、Redis、对象存储、Temporal与供应商测试各留证。仅Swagger有路由不代表真实运行通过。

API-NONE用于两张规范画板，无读写业务接口；不能为页面覆盖数添加无意义端点。
