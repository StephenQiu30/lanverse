## 3. 接口

```http
POST /api/projects/{pid}/quotes
{ "items": [ { "target_type": "shot_take", "target_id": "<shot_id>", "capability": "video.generate", "mode": "omni_reference", "output_count": 2 } ] }
200 { "items": [ { "operation_id": "…", "quote_micros": 30000000, "inputs_preview": [
        { "seq": 1, "role": "subject", "label": "图1 李明 / 日常装 v1" }, { "seq": 2, "role": "subject", "label": "图2 王芳 / 默认 v2" },
        { "seq": 3, "role": "scene", "label": "图3 医院走廊 v1" }, { "seq": 4, "role": "camera", "label": "视频1 推镜参考" },
        { "seq": 5, "role": "audio", "label": "音频1 台词 3-12-1" } ],
      "prompt_preview": "图1 中的男子与图2 中的女子在图3 的走廊相遇，参考视频1 的推镜运动，按音频1 的节奏说话……" } ] }
```

Activity `provider.submit` 的 `inputs[]`（DES-03 §7.1）按 `seq_no` 传递 `role`、`media_url`、`media_type`、`duration_ms`、`label`。

## 故障约束与专项验证

- 专项验证：双角色、四类风格化、运镜与音频评测集；校验 Go 规则模板的指代编号与逐供应商输入顺序一致；故障注入超限、参考失效及供应商链接过期。

- P0 找不到同时支持全部参考且写实、风格化达标的模型：暂停全能参考上线与报价，继续评测适配器或调整方案，不删减已选输入（REQ-28 R1、R6）。
- 参考链接在供应商处理期间失效：按 REQ-30 R8 签发只读单对象供应商链接，有效期 min(预计处理时长 + 1 小时, 24 小时)，不返回前端并记入调用明细；可改为适配器上传。失败时保留状态与费用证据，修复后由用户重新报价。
