# 浮光正式前端替换验收

2026-10-08：当前设计页面已直接替换正式前端。首页为 `/`，其余页面使用下表地址；独立 `/preview` 目录、历史工作台及旧业务前端已删除。功能和数据继续使用 mock，刷新恢复，不代表真实业务完成。

## 已替换的实现

- App Router 正式入口加载 `frontend/src/components/fuguang/`。导航、账号菜单与页面跳转全部使用正式地址；不存在返回旧工作台或设计预览目录的入口。
- 删除旧项目、剧本、设定、素材、生成、任务、旧画布/时间线/导演台/深度等前端模块及对应旧测试；删除旧生成 API 客户端、请求层、上传代理与客户端生成配置。
- 删除旧 QueryClient provider、Next.js API rewrite、旧请求合同的 ESLint 限制，以及不再使用的编辑器、三维、请求/状态依赖与版本覆盖。CI 不再生成或比对已删除的旧前端客户端，后端自身检查保持独立。
- 共享 shadcn/Radix 组件只保留当前页面引用的组件；颜色使用 DESIGN 的语义 token。shadcn 配置移除不存在的旧 lib 入口，类名合并沿用官方 `cn` 包。
- 页面不显示站点底部 footer。素材分页仍为业务导航，使用独立可访问名称；侧栏底部的搜索、通知和账号入口保留。
- 正式前端不依赖旧后端的环境地址或健康状态。既有后端业务代码、数据库与文件数据本轮未删除；后端旧业务清理边界另行确认。
