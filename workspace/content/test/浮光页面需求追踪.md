# 浮光页面需求追踪

本表追踪18页139条功能行。它是验收计划，不是测试通过清单。每一行以页面文件中的业务规则和验收条件为准，关联到接口/数据设计组以及下方最小测试组合；实际实现时将自动化用例路径和结果补入“实施证据”，不得把mock测试标为真实业务完成。

## 测试组合

| 代码 | 必测内容                                                               |
| ---- | ---------------------------------------------------------------------- |
| R    | 读：合法/空/无匹配/权限/依赖错误/分页或筛选稳定；详情对象删除与过期    |
| W    | 写：成功刷新可见、同键重放、同键异体、版本冲突、撤权、校验、事务回滚   |
| G    | 生成：报价/确认/过期/预算/取消/unknown原键恢复/候选与选定分离          |
| S    | 敏感：秘密扫描、会话失效、角色隔离、最后管理员、邀请消费竞态（如适用） |
| M    | 媒体：真实内容、私有预览、就绪/审核/引用保护、清理与历史证据           |
| U    | 浏览器：主流程、键盘焦点、手机/桌面、错误保留、深链刷新                |
| V    | 视觉规范：token/variant一致、状态、长文/缩放、无多余业务写入           |

适用映射是最低测试集，不是对所有控件机械运行同一脚本。纯查询不执行写测试；纯布局不制造数据库测试；风险场景按功能规则增加。具体端到端步骤见[非功能与验收](../requirement/浮光页面非功能与验收.md)。
