# PG-14 模型注册表

依据：[浮光画板 17-2](https://www.figma.com/design/uLqmeRWuQuzfrp9xOYg6FT/?node-id=17-2)；对应新页面 `/models`，源码 `frontend/src/components/fuguang/admin-pages.tsx`。页面为本地 mock，字段和可见行为用于需求分析；固定样例值和成功提示不证明真实业务已实现。

## 展示字段与数据量

表中的存储名称是本轮新设计的逻辑表，未建表；建议分页量不是既有API合同。

| 区域       | 必须承载的字段                                               | 设计归属                                                              | 一次读取 / 保存的量                |
| ---------- | ------------------------------------------------------------ | --------------------------------------------------------------------- | ---------------------------------- |
| 模型列表   | 名称/key、供应商、能力、区域、支持模式、启停/发布状态        | model + current model_revision + provider                             | 按能力筛选建议20条；样例12不是上限 |
| 编辑与版本 | 默认时长/分辨率/固定镜头、参考上限、支持模式、JSON、版本差异 | model_revision的闭集param_schema/defaults/limits；草稿与published指针 | 一个模型一个编辑版本，历史按需     |
| 新建       | 名称/key/供应商/能力                                         | model首个草稿                                                         | 不从占位模型名猜实际供应商支持     |

## 功能与失败边界

| 当前动作           | 必须产生的结果                       | 边界与失败                                         |
| ------------------ | ------------------------------------ | -------------------------------------------------- |
| 表单 / JSON / 差异 | 同一版本的三种展示；参数由配置定义   | 不是三个配置副本，修改受revision保护               |
| 发布 / 启停        | 发布不可变版本；启停控制新任务可选性 | 旧任务仍可重现已冻结版本；现有接口形状不限制新参数 |

## 最小设计结论

模型定义与版本分离；当前没有价格管理页，不沿旧文档扩出价格平台。 物理字段与关系见[新数据设计](../../design/浮光页面数据设计.md)，请求/响应见[新接口设计](../../design/浮光页面接口设计.md)。

## 验收证据

- 逐项核上述字段与动作，包括空值、失败和权限；业务写入须刷新后保留，冲突不覆盖他人修改。静态/临时状态不套用持久化验收。
- 返回数据只服务当前显示或操作；统计需能复算；mock数值与真实值明确分开。
- 验收遵循[新页面验收](../浮光页面非功能与验收.md)。本轮只形成设计，没有宣称真实功能完成。
