# PG-08 登录

依据：[浮光画板 9-2](https://www.figma.com/design/uLqmeRWuQuzfrp9xOYg6FT/?node-id=9-2)；对应新页面 `/login`，源码 `frontend/src/components/fuguang/auth-pages.tsx`。页面为本地 mock，字段和可见行为用于需求分析；固定样例值和成功提示不证明真实业务已实现。

## 展示字段与数据量

表中的存储名称是本轮新设计的逻辑表，未建表；建议分页量不是既有API合同。

| 区域       | 必须承载的字段                                       | 设计归属                           | 一次读取 / 保存的量                     |
| ---------- | ---------------------------------------------------- | ---------------------------------- | --------------------------------------- |
| 认证输入   | 登录名、密码、保持登录                               | user_account密码hash；user_session | 提交一次，不把密码作为普通日志/幂等body |
| 反馈与导航 | 登录失败、5次错误锁15分钟、改密限制、注册/联系管理员 | 账号状态与会话认证结果             | 错误原因可安全归类，不暴露账号是否存在  |

## 功能与失败边界

| 当前动作        | 必须产生的结果                         | 边界与失败                                                      |
| --------------- | -------------------------------------- | --------------------------------------------------------------- |
| 登录            | 普通用户进首页；需改密用户只能进入改密 | 服务端验证，UI错误应按结果出现，不能永久写死                    |
| 保持登录 / 退出 | 决定会话Cookie持久性和有效期           | 账号页明确空闲12小时、绝对7天；未勾选用会话Cookie仍有服务端到期 |
| 注册 / 忘记密码 | 注册进入新页面；忘记密码提示联系管理员 | 不因为旧工作台本机身份而移除真实认证需求                        |

## 最小设计结论

账号与会话是新设计明确需要的业务能力。 物理字段与关系见[新数据设计](../../design/浮光页面数据设计.md)，请求/响应见[新接口设计](../../design/浮光页面接口设计.md)。

## 验收证据

- 逐项核上述字段与动作，包括空值、失败和权限；业务写入须刷新后保留，冲突不覆盖他人修改。静态/临时状态不套用持久化验收。
- 返回数据只服务当前显示或操作；统计需能复算；mock数值与真实值明确分开。
- 验收遵循[新页面验收](../浮光页面非功能与验收.md)。本轮只形成设计，没有宣称真实功能完成。
