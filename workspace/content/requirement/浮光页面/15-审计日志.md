# PG-15 审计日志

依据：[浮光画板 18-2](https://www.figma.com/design/uLqmeRWuQuzfrp9xOYg6FT/?node-id=18-2)；对应新页面 `/audit`，源码 `frontend/src/components/fuguang/admin-pages.tsx`。页面为本地 mock，字段和可见行为用于需求分析；固定样例值和成功提示不证明真实业务已实现。

## 展示字段与数据量

表中的存储名称是本轮新设计的逻辑表，未建表；建议分页量不是既有API合同。

| 区域       | 必须承载的字段                                     | 设计归属                         | 一次读取 / 保存的量                         |
| ---------- | -------------------------------------------------- | -------------------------------- | ------------------------------------------- |
| 筛选与日志 | 时间范围、操作人、项目、对象、动作；结果/时间/描述 | audit_event不可变事件            | 建议每页40；筛选先于分页，时间稳定排序      |
| 详情与CSV  | before/after、revision、对象ID、操作者、时间、结果 | 同一事件的脱敏快照；导出同一筛选 | 按需详情；导出建议最多1万条，超限提示缩范围 |

## 功能与失败边界

| 当前动作    | 必须产生的结果                        | 边界与失败                             |
| ----------- | ------------------------------------- | -------------------------------------- |
| 筛选 / 详情 | 显示真实事件；缺失字段显式为空        | 不得编辑审计；权限不因知道event_id绕过 |
| 导出        | 只输出授权和脱敏字段并处理CSV公式注入 | 无须为有限日志导出预建任务平台         |

## 最小设计结论

一份审计记录服务表格、详情和导出。 物理字段与关系见[新数据设计](../../design/浮光页面数据设计.md)，请求/响应见[新接口设计](../../design/浮光页面接口设计.md)。

## 验收证据

- 逐项核上述字段与动作，包括空值、失败和权限；业务写入须刷新后保留，冲突不覆盖他人修改。静态/临时状态不套用持久化验收。
- 返回数据只服务当前显示或操作；统计需能复算；mock数值与真实值明确分开。
- 验收遵循[新页面验收](../浮光页面非功能与验收.md)。本轮只形成设计，没有宣称真实功能完成。
