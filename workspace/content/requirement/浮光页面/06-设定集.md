# PG-06 设定集

依据：[浮光画板 7-2](https://www.figma.com/design/uLqmeRWuQuzfrp9xOYg6FT/?node-id=7-2)；对应新页面 `/bible`，源码 `frontend/src/components/fuguang/library-pages.tsx`。页面为本地 mock，字段和可见行为用于需求分析；固定样例值和成功提示不证明真实业务已实现。

## 展示字段与数据量

表中的存储名称是本轮新设计的逻辑表，未建表；建议分页量不是既有API合同。

| 区域       | 必须承载的字段                                                | 设计归属                                                | 一次读取 / 保存的量                     |
| ---------- | ------------------------------------------------------------- | ------------------------------------------------------- | --------------------------------------- |
| 设定列表   | 角色/场景/道具、名称/别名、出场集数、造型数、锁定/待定/未生成 | setting_entry + setting_revision；出场由场/镜头引用计算 | 当前类型列表建议20条；详情独立          |
| 造型与参考 | 造型名称/版本、正面半身/侧面/全身/表情组、锁定与缩略图        | setting_revision的有界looks + asset_reference           | 一次选中造型的4个槽位，不拉所有版本媒体 |
| 声音与授权 | 音色名称/试听音频、真人来源、声明状态/说明                    | setting_revision.voice及声明快照、media_asset           | 声明关联具体声音来源和提交人/时间       |

## 功能与失败边界

| 当前动作               | 必须产生的结果                                 | 边界与失败                                                           |
| ---------------------- | ---------------------------------------------- | -------------------------------------------------------------------- |
| 新增 / 名称别名 / 造型 | 生成对应设定新版本，锁定指针保持明确           | 同名不同对象不合并；合并别名不等同实体合并                           |
| 上传 / 生成参考        | 按槽位保存媒体或生成候选，明确锁定版本         | 不能把生成完成直接视为所有参考自动锁定                               |
| 声音试听 / 授权声明    | 播放真实音频；声明文本、主体、来源、时间持久化 | 页面要求未声明真人声音不得生成：该规则保留，不能因旧表没有支持而删除 |

## 最小设计结论

角色/场景/道具共享有限的设定结构；不先搭建通用授权审批平台。 物理字段与关系见[新数据设计](../../design/浮光页面数据设计.md)，请求/响应见[新接口设计](../../design/浮光页面接口设计.md)。

## 验收证据

- 逐项核上述字段与动作，包括空值、失败和权限；业务写入须刷新后保留，冲突不覆盖他人修改。静态/临时状态不套用持久化验收。
- 返回数据只服务当前显示或操作；统计需能复算；mock数值与真实值明确分开。
- 验收遵循[新页面验收](../浮光页面非功能与验收.md)。本轮只形成设计，没有宣称真实功能完成。
