# PG-01 首页与项目库

依据：[浮光画板 11-2](https://www.figma.com/design/uLqmeRWuQuzfrp9xOYg6FT/?node-id=11-2)；对应新页面 `/`，源码 `frontend/src/components/fuguang/home-page.tsx`。页面为本地 mock，字段和可见行为用于需求分析；固定样例值和成功提示不证明真实业务已实现。

## 展示字段与数据量

表中的存储名称是本轮新设计的逻辑表，未建表；建议分页量不是既有API合同。

| 区域     | 必须承载的字段                                          | 设计归属                                       | 一次读取 / 保存的量                                  |
| -------- | ------------------------------------------------------- | ---------------------------------------------- | ---------------------------------------------------- |
| 新建表单 | 名称≤50字、剧本文件、9:16/16:9/1:1、写实/动漫/国风/胶片 | project；script_document保存上传原件与解析结果 | 一次新建一个项目；文件流上传，不能在首页响应携带全文 |
| 项目卡片 | id、名称、封面、画幅、风格；最近更新排序键              | project + media_asset预览；updated_at用于排序  | 建议每页20条摘要；总数另计，样例项目数量不作容量     |
| 列表操作 | 名称搜索、最近更新/名称排序、网格/列表                  | 筛选/视图留URL或页面状态                       | 同一筛选下数据一致，打开项目才读详情                 |

## 功能与失败边界

| 当前动作        | 必须产生的结果                                              | 边界与失败                                                                        |
| --------------- | ----------------------------------------------------------- | --------------------------------------------------------------------------------- |
| 空白 / 剧本创建 | 支持全部当前画幅与风格；建项目后按上传剧本自动分集/抽取设定 | 文件文案支持txt/md/docx；input额外pdf是否保留是新页面自身歧义，不能沿旧接口裁掉md |
| 复制项目        | 生成新项目身份、独立可编辑内容及复制状态                    | 共享只读原件可引用，删除不能损坏副本；无需先建设通用复制平台                      |
| 打开项目 / 画布 | 进入同一project上下文的概览或画布                           | 没有数据、无匹配、失败分开；不追加旧工作台目录/归档功能                           |

## 最小设计结论

主页字段足以定义项目与导入；没有目录树、回收管理或独立剧本工作台的当前消费者。 物理字段与关系见[新数据设计](../../design/浮光页面数据设计.md)，请求/响应见[新接口设计](../../design/浮光页面接口设计.md)。

## 验收证据

- 逐项核上述字段与动作，包括空值、失败和权限；业务写入须刷新后保留，冲突不覆盖他人修改。静态/临时状态不套用持久化验收。
- 返回数据只服务当前显示或操作；统计需能复算；mock数值与真实值明确分开。
- 验收遵循[新页面验收](../浮光页面非功能与验收.md)。本轮只形成设计，没有宣称真实功能完成。
