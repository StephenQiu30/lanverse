# PG-05 数据分析

依据：[浮光画板 6-2](https://www.figma.com/design/uLqmeRWuQuzfrp9xOYg6FT/?node-id=6-2)；对应新页面 `/analytics`，源码 `frontend/src/components/fuguang/analytics-page.tsx`。页面为本地 mock，字段和可见行为用于需求分析；固定样例值和成功提示不证明真实业务已实现。

## 展示字段与数据量

表中的存储名称是本轮新设计的逻辑表，未建表；建议分页量不是既有API合同。

| 区域   | 必须承载的字段                                               | 设计归属                                          | 一次读取 / 保存的量                  |
| ------ | ------------------------------------------------------------ | ------------------------------------------------- | ------------------------------------ |
| 统计卡 | 完成镜头/总数、任务量/环比、成功率/失败/待核对、平均/P95耗时 | shot、generation_job查询计算                      | 固定卡片，均含as_of、窗口和样本数    |
| 图表   | 每日任务、按模型结果、分集阶段进度                           | 任务按时间桶/模型版本聚合；阶段由实际内容事实计算 | 7/14天或全时段有界桶，最多建议366点  |
| 待处理 | 原因、对象摘要、目标ID、数量                                 | 失败/未知任务和失效镜头查询                       | 首批建议10项，分页；无通知表前置依赖 |

## 功能与失败边界

| 当前动作          | 必须产生的结果                   | 边界与失败                                       |
| ----------------- | -------------------------------- | ------------------------------------------------ |
| 时间 / 分集切换   | 图表与卡片采用同一筛选口径       | 0分母、未知、依赖失败不显示为正常0               |
| 查看趋势 / 待处理 | 有界趋势下载或展开；跳转有权目标 | 图中样例不是数据事实；无明确定义的阶段显示未接入 |

## 最小设计结论

分析需要读模型与计算口径，不默认增加汇总库、计数表或新消息中间件。 物理字段与关系见[新数据设计](../../design/浮光页面数据设计.md)，请求/响应见[新接口设计](../../design/浮光页面接口设计.md)。

## 验收证据

- 逐项核上述字段与动作，包括空值、失败和权限；业务写入须刷新后保留，冲突不覆盖他人修改。静态/临时状态不套用持久化验收。
- 返回数据只服务当前显示或操作；统计需能复算；mock数值与真实值明确分开。
- 验收遵循[新页面验收](../浮光页面非功能与验收.md)。本轮只形成设计，没有宣称真实功能完成。
