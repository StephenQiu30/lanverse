# 当前页面术语

| 术语            | 本轮含义                                          |
| --------------- | ------------------------------------------------- |
| 项目            | 一份创作的规格、内容和媒体上下文                  |
| 设定/造型       | 角色、场景、道具及其外观版本                      |
| 镜头版本        | 一次不可变输入；不等于生成结果                    |
| 候选            | 任务输出；尚未必正式采用                          |
| 选定            | 用户明确采用的画面/视频输出                       |
| 失效            | 当前依赖与冻结版本不一致；不自动重新生成          |
| 收藏            | 当前用户对素材库条目的偏好                        |
| 未知/待人工核对 | 不能确认实际执行结果的任务，不能直接重提收费      |
| 历史实现        | 与本次浮光设计无默认约束关系的旧页面/接口/表/文档 |
