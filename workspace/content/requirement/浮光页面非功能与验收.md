# 浮光页面非功能与验收

与[REQ-02](02-非功能需求规格.md)共用既有指标，以下补充本次18页的适用场景、测量方法和失败判定；不把目标值写成已经达到的性能。新建议明确标注，待评审后进入正式门禁。安全与费用门槛优先于视觉成功态。

## 2. 测试环境与数据

| 数据集    | 最小内容                                                                                      | 用途                                       |
| --------- | --------------------------------------------------------------------------------------------- | ------------------------------------------ |
| 身份      | 2个组织隔离夹具；各有admin/producer/disabled；单独最后admin场景；受限改密会话                 | 正式MVP仍单org，跨org只用于安全负例        |
| 项目      | active/archived/recycled、无封面、不同风格/画幅、创建成功但导入失败                           | 首页、路由、恢复和只读                     |
| 分镜      | 150镜头/集；空场；重复/缺失台词；两个并发revision；不同模型合法时长                           | 详情、批量和场确认                         |
| 参考/媒体 | ready/pending/rejected/recycled、历史冻结引用、伪装类型、授权过期                             | 引用、选定、删除和私有预览                 |
| Operation | quoted/expired/confirmed/submitted/unknown/manual/failed/cancelled/completed/reused，迟到回执 | 无重复付费、统计、恢复                     |
| 分析      | 0样本、10完成6首次通过18生成、跨时区边界、模型停用、重复事件                                  | 按既有REQ-32及新增D-06分别复算，不能混口径 |
| 运维      | 队列101、unknown11、manual超24h、outbox1001、Prometheus不可用                                 | 阈值与缺失值                               |

所有数据合成，禁止将用户真实剧本、媒体、密码或供应商凭据复制进测试夹具。真实供应商测试另申请精确预算并记录结果；本轮没有执行。

## 3. 端到端验收场景

| 场景ID  | 前置                         | 操作                               | 预期与验收边界                                                |
| ------- | ---------------------------- | ---------------------------------- | ------------------------------------------------------------- |
| E2E-P01 | 有权制作者、合法TXT          | 创建项目→导入→刷新→进入集          | 同一project/job恢复，导入失败不丢项目；首屏成功不代表解析准确 |
| E2E-P02 | 同项目设定与可用私有图片     | 上传→绑定造型→确认→切到镜头引用    | 版本与摘要一致；回收/撤权不能成为新引用                       |
| E2E-P03 | 有合法镜头、模型价格和预算   | 报价→确认→供应商模拟完成→候选→选定 | 账本一次、候选独立、刷新/跨视图选定一致                       |
| E2E-P04 | 供应商已接收但客户端丢回执   | 刷新任务→unknown→原键核对          | 不创建第二笔付费；已存在结果接管完成                          |
| E2E-P05 | 两标签打开revision7          | A保存→B保存旧revision→B处理冲突    | A版本保留；B得到409并保留草稿，不能last-write-wins            |
| E2E-P06 | 20镜头其中2缺参考3生成失败   | 批量报价→仅合格确认→查看汇总       | 错误项不计费；失败/未知独立；重试需新报价                     |
| E2E-P07 | 2个账号会话                  | admin禁用producer→producer下一请求 | 拒绝访问，旧媒体/查询状态不继续暴露；启用不复活旧会话         |
| E2E-P08 | 有旧凭据及模型在途任务       | 替换→免费测试失败→查看原任务       | UI按保存后测试语义展示；原已提交任务不能自动换密钥重提        |
| E2E-P09 | 管理员与合成敏感值           | 发布模型/选定→查审计→CSV导出       | 动作/版本可追溯；导出无秘密，公式单元格安全转义               |
| E2E-P10 | analytics/health某块依赖故障 | 加载→刷新→恢复                     | null/过期明确，其他块可用；恢复数值能从明细复算               |
| E2E-P11 | 拟邀注册获D-01确认           | 并发消费同一邀请→登录→改密         | 一个用户一次消费；角色来自邀请；无token不能加入               |
| E2E-P12 | 全18页和长文/空态fixture     | 桌面/手机/键盘/读屏遍历            | 单一h1/main、焦点与错误正确、无整页横向溢出；性能独立测量     |

## 4. 完成定义与本轮验证界限

- 需求覆盖检查只证明页面、编号、引用和验收映射齐全；文档构建只证明可阅读。
- 上一轮845项前端测试和18页浏览器检查是mock/原前端证据，不证明本次规划端点、表、性能、授权或真实费用闭环已实现。
- 真实接入须逐行提供：后端合同/数据库测试、前端测试、浏览器结果、关键错误与恢复、适用NFR、公开契约无漂移；被跳过项保留未验收。
- 新产品决策和Schema/API提案在评审前不启用；本轮不执行SQL、账号写入或付费生成。
