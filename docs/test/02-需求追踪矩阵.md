## 1. 编号与规则

- **测试用例编号**：`TC-<功能文件号>-<序号>`，序号为该功能文件验收标准中的顺序，如 `TC-21-03` 表示 REQ-21 的第 3 条。验收标准增删时只追加新序号，不重排。
- **层级**：`集成`（后端 API 级自动化）、`E2E`（Playwright）、`人工`（需要人工判断，如画面一致性）。
- **状态**：`未执行` → `通过` / `失败` / `阻塞`；附最近一次执行的日期与证据链接。
- 本矩阵只覆盖首个版本（MVP）；V2 需求的验收用例在 V2 规划时登记。
