## 1. 评测对象与时机

| 对象 | 评测什么 | 时机 |
| --- | --- | --- |
| LLM Skill（`split_episodes`、`parse_episode`、`extract_bible`、`storyboard`、`compose_prompt`） | 结构化输出的准确性与完整性 | P0 选模型；Skill、提示词、模型版本任一变化（CI 门禁）；每周定时 |
| 生成模型：全能参考视频 | 一致性、参考遵循（动作、运镜、音频）、画质、失败率、耗时、成本 | P0；新模型接入前；每季度复测 |
| 生成模型：图生视频、带参考生图 | 一致性、构图遵循、画质 | 同上 |
| TTS / ASR | 可懂度、自然度、情绪、对齐精度 | 同上 |
| 内容审核 | 漏报与误报 | P0；审核服务变更 |
| V2 对话式 Agent | 任务完成率、提案正确率、提示注入抵抗 | V2 开发期间与每次模型 / 提示变更 |

## 2. 数据集

### 2.1 剧本评测集（LLM Skill）

| 项 | 要求 |
| --- | --- |
| 规模 | 10 部剧本（TST-01 §5）：竖屏短剧 6（含 ≥ 60 集 1 部）、中短片 3、单片 1；题材覆盖都市、古装、悬疑、甜宠、奇幻 |
| 边界样本 | 无集标记、多文件乱序、GBK 编码、长集（> 3 万字）、对白无引号、旁白与内心独白、同名不同人、一人多称呼 |
| 标注 | 分集边界（字符偏移）；场边界与标题；每句台词（偏移、说话人、类型、情绪）；角色与别名分组；造型阶段；场景与道具清单 |
| 标注流程 | 双人独立标注 → 差异仲裁 → 冻结为 `evals/datasets/scripts/v<N>`；每部剧先标注 3 集，全量标注 1 部 60 集剧 |
| 分镜参考 | 每题材 2 场由导演或有经验的制作者写“参考镜头表”，用于人工对比评分 |

### 2.2 生成评测集（视频 / 图片 / 声音）

| 维度 | 取值 |
| --- | --- |
| 风格 | 写实、日系动漫、国风 / 仙侠、3D 卡通、韩漫 / 条漫（5） |
| 镜头类型 | 单角色、双角色同框、动作参考、运镜参考、音频参考（5） |
| 每组合样本 | 4 个镜头设定 × 每个生成 2 个候选 |
| 资产 | 每种风格一套：2 个角色（各定妆照 + 三视图）、2 个场景、1 个道具；动作参考视频 4 段、运镜参考视频 4 段（推、拉、摇、跟）、台词音频 8 段（不同节奏与情绪） |
| TTS | 30 句覆盖多音字、数字、情绪、长句；5 个音色 |

资产与参考视频须有授权；真人素材仅用于写实组，且有授权声明（REQ-17）。

## 3. 指标

### 3.1 LLM Skill 自动指标

| Skill | 指标 | 计算 | 目标（REQ-02） |
| --- | --- | --- | --- |
| split_episodes | 分集边界准确率 | 预测边界与标注边界偏差 ≤ 20 字视为正确；正确数 / 标注边界数 | 100% |
| parse_episode | 台词召回率 | 与标注台词偏移重叠 ≥ 80% 的预测台词数 / 标注台词数 | ≥ 99%（AIQ-01） |
| | 台词精确率 | 匹配成功的预测数 / 预测台词数 | ≥ 98% |
| | 说话人准确率 | 匹配台词中说话人正确（按别名归一）/ 匹配台词数 | ≥ 95% |
| | 场边界 F1 | 场起点偏差 ≤ 50 字视为命中 | ≥ 0.90 |
| | 原文位置有效率 | 通过 `source_span` 校验的条目 / 全部条目（修复前） | 记录（观察修复负担） |
| extract_bible | 主要角色召回 | 出场 ≥ 3 集的标注角色被抽出的比例 | 100%（AIQ-02） |
| | 别名合并 F1 | 按“别名对是否同属一个角色”计算成对 P / R / F1 | ≥ 0.90 |
| storyboard | 台词分配完整率 | 场内台词恰好分配一次的场数 / 场数（修复后） | 100%（AIQ-03） |
| | 引用有效率 | 引用的设定 ID 均在输入中的镜头比例 | 100% |
| 全部 Skill | 首轮通过率、平均修复轮次、token、费用、耗时 | Trace 统计 | 记录，用于成本与模型选择 |

### 3.2 人工评分量表（1–5 分）

| 维度 | 1 分 | 3 分 | 5 分 |
| --- | --- | --- | --- |
| 角色一致性 | 明显不是同一人 / 换脸 | 可认出但发型、服装或五官有明显偏差 | 与锁定造型一致，细节稳定 |
| 多角色区分（双角色） | 两人外观互换或融合 | 可区分但一人有偏差 | 两人都与各自造型一致 |
| 场景一致性 | 与场景参考无关 | 大体相似 | 布局、色调、标志物一致 |
| 动作参考遵循 | 动作无关 | 动作类型相同，节奏或幅度偏差明显 | 动作与参考一致 |
| 运镜参考遵循 | 运镜无关或静止 | 方向正确，速度或幅度偏差 | 与参考运镜一致 |
| 音频节奏遵循 | 表演与音频无关 | 大致合拍，有明显不同步 | 节奏、情绪与音频一致 |
| 画质 | 严重崩坏、闪烁、畸形 | 有可接受的小瑕疵 | 可直接使用 |
| 分镜合理性（storyboard） | 镜头语言不合理、无法拍 | 可用但需较多修改 | 接近专业镜头表 |
| TTS 自然度 | 机械、错读多 | 可接受，个别错读 | 自然、情绪到位 |

**通过线**：某维度平均 ≥ 3.5 且 ≤ 10% 的样本 ≤ 2 分。一致性抽检通过率（REQ-02 AIQ-04）= 角色一致性 ≥ 4 分的样本比例，目标 ≥ 80%【P0 校准】。

### 3.3 自动辅助指标（参考，不单独决策）

| 指标 | 用于 |
| --- | --- |
| 人脸特征相似度（写实组，生成帧 vs 定妆照，逐帧取中位数） | 写实角色一致性的初筛与趋势监控 |
| 图像特征相似度（如 DINOv2 / CLIP 向量余弦，风格化组） | 风格化角色与场景一致性趋势 |
| 光流方向与幅度对比（生成 vs 运镜参考） | 运镜遵循的初筛 |
| 音频能量包络与画面口部 / 动作运动的相关性 | 音频节奏遵循的初筛 |
| 时长偏差、分辨率、帧率、黑帧 / 冻帧检测 | 技术质检 |

自动指标与人工评分的相关性在 P0 中计算；相关性 ≥ 0.6 的指标可用于后续回归的初筛，减少人工量。

### 3.4 运行指标

失败率（按错误码）、平均耗时与 P95、单镜成本、平均每镜重拍次数、审核拒绝率。

## 4. P0 模型选型评测

### 4.1 候选

| 能力 | 候选 |
| --- | --- |
| 全能参考视频 | 火山方舟 Seedance（2.x）、MiniMax 海螺 H3、OpenRouter 海外版 Seedance |
| 图生视频 | 同上 |
| 带参考生图 | Seedream、GPT Image（OpenRouter） |
| TTS | MiniMax Speech、豆包语音 |
| LLM（Skill） | 豆包、DeepSeek、通义（境内） |
| 审核 | 火山引擎内容安全（默认，DES-07 §11）；供应商内置审核 |

### 4.2 矩阵与样本量

全能参考：3 个模型 × 5 种风格 × 5 类镜头 × 4 个设定 × 2 个候选 = 600 段视频。按 5 秒、预估单价估算费用后，由产品负责人确认 P0 评测预算；预算不足时优先保证“双角色同框、音频参考”两类与写实 + 1 种风格化。

### 4.3 选型规则

1. **门槛**：全能参考在写实与 4 种风格化下，至少一家的“角色一致性、多角色区分、参考遵循”三项均通过（§3.2 通过线）。否则按 PLN-01 P0 退出标准暂停并重新评估方案。
2. **排序**：通过门槛的模型按加权得分排序：质量 50%（人工评分均值）、成本 25%（单镜有效成本 = 单价 × 平均重拍次数）、稳定性 15%（失败率、耗时 P95）、接口能力 10%（查询 / 取消 / 回调、幂等、参考上限）。
3. **结论**：每种风格确定主模型与备选模型，写入注册表初始配置（REQ-08）与 P0 报告。

## 5. 人工评分流程

1. 生成样本后去除模型标识，随机顺序呈现（盲评）。
2. 每个样本 2 名评分人独立评分；评分人先用 20 个锚定样本校准。
3. 计算评分人间一致性（加权 Cohen's κ）；κ < 0.6 的维度重新校准后复评。
4. 两人分差 ≥ 2 的样本由第三人仲裁。
5. 评分工具：内部简单页面（样本、参考、量表、备注），结果存 `evals/results/<日期>/scores.csv`。

## 6. 回归门禁

| 触发 | 运行 | 阻断条件 |
| --- | --- | --- |
| Skill 包变更（版本号提升） | 该 Skill 的自动指标（录制响应不可用时调用真实模型，费用计入评测预算） | 任一目标指标低于 REQ-02 目标，或比上一版本下降 > 3 个百分点（AIQ-06） |
| LLM 模型变更 | 全部 Skill 自动指标 | 同上 |
| 生成模型或适配器参数映射变更 | 该模型的精简评测集（每风格 × 每镜头类型 1 个设定）+ 人工评分 | 人工评分均值下降 > 0.3 或低于通过线 |
| 每周定时 | LLM Skill 全量自动指标 | 仅告警（供应商模型静默更新检测） |

门禁结果在 PR 中以评论形式展示；阻断须修复或由产品负责人书面豁免（记录在 PR）。

## 7. 成本与预算

- 每次评测记录模型调用费用，汇总到评测报告；P0 评测预算由产品负责人确认后执行（按 §4.2 估算）。
- CI 中的 LLM 回归优先使用录制响应；需要真实调用时，每次运行上限 ¥30，超出需人工触发。

## 8. 报告模板

```markdown
# 评测报告：<对象> <日期>
- 版本：Skill / 模型 / 适配器版本；数据集版本
- 自动指标：表格（本次、上次、目标）
- 人工评分：各维度均值、低分比例、κ
- 运行指标：失败率、耗时、单镜成本、重拍次数
- 典型样例：通过与失败各 5 例（链接）
- 结论与建议：是否通过门禁；选型或调整建议
```

报告存 `docs/acceptance/eval-<日期>-<对象>.md`（P0 报告为 `docs/acceptance/P0-评测报告.md`）。

## 9. V2 对话式 Agent 评测

| 指标 | 数据 | 目标 |
| --- | --- | --- |
| 任务完成率 | 40 条典型指令（调参数、拆分镜、写提示词、组织画布、准备批量生成） | ≥ 85% |
| 提案正确率 | 提案命令与期望命令一致（对象、字段、值） | ≥ 90% |
| 越权 / 注入抵抗 | 30 条注入样例（剧本、文件名、工具输出中嵌入指令） | 100% 不产生越权提案 |
| 首个流式片段延迟 | 全部样例 | P95 ≤ 3 秒（PERF-11） |
