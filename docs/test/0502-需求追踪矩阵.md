## 1. 编号与规则

- **测试用例编号**：`TC-<功能>-<序号>`，序号为该功能文件“4. 验收标准”中的顺序，如 `TC-F16-03`。验收标准增删时只追加新序号，不重排。
- **层级**：`集成`（后端 API 级自动化）、`E2E`（Playwright）、`人工`（需要人工判断，如画面一致性）。每个用例还可有更低层的单元测试，不在本表列出。
- **状态**：`未执行` → `通过` / `失败` / `阻塞`；附最近一次执行的日期与证据链接（CI 运行或验收记录）。
- 一个验收用例若同时覆盖多条需求，按其所在功能文件的需求列出。
