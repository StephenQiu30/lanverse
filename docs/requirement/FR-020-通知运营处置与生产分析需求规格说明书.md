# FR-020 通知、运营处置与生产分析需求规格说明书

## 1. 目的与范围

把任务、审核、预算、权利、安全和交付中的重要事件传达给明确责任人，为平台故障、费用争议、风险事件和个人数据请求提供受控处置入口，并提供生产效率与质量分析。

本能力不替代各业务模块的事实和决定，也不允许平台运营人员代替用户作出创作、审核、采用或交付决定。生产分析属于 P1，通知和运营处置属于 P0。

## 2. 主业务流程

1. 业务模块产生需要关注的事件。
2. 系统识别责任人、紧急程度、通知渠道和待办期限。
3. 用户查看通知、进入关联对象并完成相应业务动作。
4. 发生平台事件或用户申诉时，系统建立运营事件并限定处置范围。
5. 如需临时访问，运营人员取得明确授权后执行处置并记录全过程。
6. 系统汇总任务、成本、质量和返工事实形成生产分析。

## 3. 功能需求

| 编号 | 规范性需求 | 优先级 |
| --- | --- | --- |
| FR-020-001 | 系统应为任务完成或失败、审核待办、预算阈值、权利变化、安全复核和交付结果生成通知。 | P0 |
| FR-020-002 | 系统应为每项通知记录事件来源、责任人、紧急程度、关联对象和发生时间。 | P0 |
| FR-020-003 | 系统应对同一业务事件的重复信号去重，并保留事件更新。 | P0 |
| FR-020-004 | 系统应允许用户查看未读、已读、待处理和已处理通知。 | P0 |
| FR-020-005 | 系统应允许用户从通知进入其有权访问的关联业务对象。 | P0 |
| FR-020-006 | 系统应允许用户按事件类型配置非强制通知偏好，不得关闭强制安全或账户通知。 | P1 |
| FR-020-007 | 系统应为故障、费用争议、安全风险、权利申诉和交付异常建立独立运营事件。 | P0 |
| FR-020-008 | 系统应为运营事件记录影响范围、责任人、严重程度、处置动作、结果和时间线。 | P0 |
| FR-020-009 | 系统应将运营事件临时访问限定到已批准的目的、对象、操作和期限。 | P0 |
| FR-020-010 | 系统应允许用户提交个人数据访问、导出、更正或删除请求并查看处理状态。 | P0 |
| FR-020-011 | 系统应在个人数据请求处理中记录身份核验、处理范围、法定保留例外和完成证据。 | P0 |
| FR-020-012 | 系统应汇总任务耗时、失败率、重试率、候选采用率、返工率和交付成功率。 | P1 |
| FR-020-013 | 系统应汇总项目、分集、镜头和成片分钟的实际成本及预算偏差。 | P1 |
| FR-020-014 | 系统应允许按项目、分集、时间、能力和生产阶段筛选分析结果。 | P1 |
| FR-020-015 | 系统应确保分析指标可追溯到对应业务事实，且不改变来源记录。 | P1 |

## 4. 业务规则

- BR-020-001：通知只是信息与待办入口，不改变来源业务状态。
- BR-020-002：同一人可收到多个责任范围不同的通知，但不得由此扩大访问权限。
- BR-020-003：运营处置只能限制损害、恢复服务、修正平台事实或处理申诉。
- BR-020-004：平台人员不得借运营事件改变用户的创作、审核、采用或交付决定。
- BR-020-005：个人数据删除不得静默删除依法或为争议处理必须保留的记录；保留范围和依据必须可解释。
- BR-020-006：生产分析使用当前可解释口径，同一报表必须记录指标定义版本。

## 5. 数据要求

- DR-020-001：保存通知、接收人、事件来源、关联对象、状态和投递结果。
- DR-020-002：保存运营事件、影响范围、严重程度、临时授权、操作记录和处置结论。
- DR-020-003：保存个人数据请求、核验、处理步骤、保留例外和完成证据。
- DR-020-004：保存分析指标定义、统计范围、生成时间和来源事实引用。

## 6. 异常与恢复

| 场景 | 系统行为 |
| --- | --- |
| 通知投递失败 | 保留站内通知并按策略重试外部渠道，不重复创建业务事件。 |
| 运营人员尝试越权访问 | 拒绝操作、记录审计并触发安全处置。 |
| 用户身份无法完成核验 | 暂停个人数据请求，不向请求方泄露数据。 |
| 分析来源数据暂不完整 | 标识统计范围和数据新鲜度，不把缺失值解释为零。 |

## 7. 验收标准

- AC-020-001：同一任务完成事件重复到达时，用户只看到一个持续更新的业务通知。
- AC-020-002：用户从通知进入无权限项目时仍被访问控制拒绝。
- AC-020-003：运营临时授权到期后立即失效，期间操作可完整追溯。
- AC-020-004：个人数据请求能够显示提交、核验、处理中、完成或拒绝及其理由。
- AC-020-005：分析报表中的任一成本或任务指标均可追溯到来源记录及指标口径版本。
