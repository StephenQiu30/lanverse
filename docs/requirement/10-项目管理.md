## 1. 需求说明

### 1.1 背景与目标

项目是一部作品的生产容器，统一画幅、风格、预算与生成策略；所有生成与导出都遵循项目规格。概览让制作者一眼看到每集做到哪一步。

### 1.2 用户故事

- 作为**制作者**，我希望创建项目并设置画幅与风格，以便后续所有生成与导出遵循统一规格。
- 作为**制作者**，我希望看到所有项目，以及每个项目各集各阶段的进度与累计成本。
- 作为**制作者**，我希望归档已完成的项目，删除不需要的项目，并能在 30 天内恢复。
- 作为**制作者**，我希望设置默认模型，并决定本项目是否允许使用境外模型。

### 1.3 范围

- 包含：创建、修改（可修改字段）、列表、概览、归档 / 恢复、删除 / 恢复 / 到期清理、生成策略、AIGC 标识样式。
- 不包含：成员与角色、项目模板与快照、项目导出（见 REQ-34）。

## 2. 需求分析

### 2.1 业务流程

```text
创建（名称、画幅、风格类型、子风格、风格预设、描述）→ 自动创建预算（默认 0，需设置后才能生成，见 REQ-11）
→ 生产 → 概览跟踪 → 归档（只读）⇄ 恢复
删除 → 回收中（30 天）→ 恢复 | 到期彻底清理（数据库记录 + 对象存储）
```

### 2.2 业务规则

| # | 规则 | 理由 |
| --- | --- | --- |
| R1 | 名称 1–50 字，组织内可重名（以 ID 区分） | 内部使用，避免无谓限制 |
| R2 | 画幅（9:16 / 16:9）与风格类型（写实 / 风格化）创建后不可修改；风格化必须选子风格 | 已生成的素材与画幅、风格强绑定（P3、P12） |
| R3 | 输出分辨率固定 1080p | P12 |
| R4 | 可修改：名称、描述、风格预设、默认模型、是否允许境外模型、AIGC 标识样式 | — |
| R5 | 允许境外模型默认关闭；关闭时境外模型在该项目中不可选，报价返回 `overseas_not_allowed` | CMP-06 |
| R6 | 关闭境外开关不影响已确认的境外任务 | 不中断已付费任务 |
| R7 | 归档项目只读：所有写接口返回 `state_conflict`；可浏览、下载 | PRJ-06 |
| R8 | 有进行中任务（`confirmed` 至 `ingesting`、`unknown`、`reconciling`、`manual`）的项目不能删除或归档 | 避免任务结果无处落地 |
| R9 | 删除后 30 天内可恢复；到期由清理任务彻底删除项目数据与媒体对象，审计记录保留 | DAT-05、PRV-05 |
| R10 | 概览按集显示 6 个生产阶段的完成数 / 总数：场次确认、资产定稿、分镜、关键帧、视频、配音 | PRJ-02、REQ-03 §3 |

### 2.3 状态

项目状态：进行中 ⇄ 已归档；进行中或已归档 → 回收中（删除）→ 恢复为删除前的状态 | 30 天后彻底清理。回收中不改变原有的进行中 / 已归档状态，恢复后回到原状态。

### 2.4 异常与边界

- 大项目（100 集）的概览同样须在 2 秒内打开（PERF-01），进度变化 2 秒内可见（PERF-03）。
- 恢复时若同名项目存在不冲突（R1）。

### 2.5 前置与依赖

风格预设（组织级内置 5 套：写实 + 4 种风格化，P0 后由管理员维护）。

## 3. 验收标准

- Given 制作者创建 16:9、风格化 / 国风的项目，When 进入该项目的任意生成面板，Then 画幅默认且固定为 16:9，风格预设已带入。
- Given 已创建的项目，When 打开项目设置，Then 画幅与风格类型为只读；直接调用接口修改返回 `validation_failed`。
- Given 第 1 集 30 个镜头中 12 个已选定视频，When 打开项目概览，Then 第 1 集“视频”阶段显示 12/30，刷新后不变。
- Given 有进行中任务的项目，When 用户删除项目，Then 操作被拒绝并列出进行中的任务。
- Given 项目被删除 10 天，When 用户在回收列表中恢复，Then 项目及其媒体完整恢复。
- Given 项目未允许境外模型，When 制作者尝试通过接口对 OpenRouter 模型报价，Then 被拒绝并提示“本项目未允许使用境外模型”。
