# REQ-26 关键帧

| 项 | 内容 |
| --- | --- |
| 需求 | IMG-01 生成关键帧；IMG-02 上传关键帧 |
| 优先级 | MVP |
| 用例 | UC-11 |
| 页面 | 镜头详情、故事板 |
| 依赖功能 | REQ-15、REQ-18、REQ-21、REQ-22、REQ-30 |
| 状态 | 草案（2026-09-25） |

## 1. 需求说明

### 1.1 背景与目标

图生视频模式先确认静帧构图，再生成视频，适合构图要求精确的镜头（PRD-01 §7.2）。关键帧也可以由用户上传（如美术手绘或外部工具生成）。

### 1.2 用户故事

- 作为**制作者**，我希望为图生视频镜头生成首帧候选，或上传自己的图片，选定后作为视频首帧。

### 1.3 范围

包含：生成（单镜 / 批量）、上传、选定。不包含：局部重绘（V2，REQ-34）、尾帧（V2）。

## 2. 需求分析

### 2.1 业务规则

| # | 规则 | 理由 |
| --- | --- | --- |
| R1 | 生成输入：镜头画面描述、镜头语言参数、参考组合中的 subject / scene / prop / style（锁定版本）、项目风格预设、画幅 | IMG-01 |
| R2 | 生成画幅 = 项目画幅；分辨率 ≥ 1080p 的短边 | P12 |
| R3 | 上传图片审核通过后作为候选（`operation_output` 由系统操作 `origin = upload` 生成），与生成结果同等可选 | IMG-02 |
| R4 | 上传图片宽高比与项目画幅偏差 > 2% 时提示裁剪（提供裁剪框），分辨率低于 1080p 提示 | 输出质量 |
| R5 | 全能参考模式的镜头不需要关键帧，关键帧阶段跳过 | REQ-03 §3 |
| R6 | 关键帧改选 → 该镜头已生成的图生视频片段过期 | LIN-01 |

### 2.2 异常与边界

参考组合缺少必需参考时仍可生成（仅用描述），但提示一致性风险。

## 3. 实现所需

### 3.1 数据

`operation.operation`（`target_type = shot_frame`、`capability = image.generate`）；`operation_output`；`storyboard.shot.selected_frame_output_id`；上传关键帧：创建 `operation`（`capability = image.upload`、`status = completed`、费用 0）以统一候选模型。

### 3.2 接口

```http
POST /api/projects/{pid}/quotes { "items": [ { "target_type": "shot_frame", "target_id": "<shot_id>", "capability": "image.generate", "output_count": 4 } ] }
POST /api/shots/{id}/frames:upload   { "media_asset_id": "…", "crop": { "x": 0, "y": 120, "w": 1080, "h": 1920 } }
201 { "output_id": "…", "operation_id": "…" }
POST /api/shots/{id}:select-frame    { "output_id": "…", "expected_revision": 7 }
```

### 3.3 异步与工作流

生成：OperationWorkflow（图片同步或异步视供应商）；上传裁剪：`media` 队列 `CropImage` Activity。

### 3.4 事件与实时

同 REQ-22。

### 3.5 界面

镜头详情“关键帧”标签页：生成按钮（数量、模型、参数）、上传区（裁剪框）、候选对比、选定。

### 3.6 权限与审计

制作者；审计 `shot.frame_selected`。

### 3.7 非功能要求

PERF-09。

## 4. 验收标准

- Given 镜头引用造型 A v2 与场景 S v1，When 生成关键帧，Then 任务输入记录中包含 A v2 与 S v1。
- Given 上传一张 1920×1080 图片（16:9 项目），When 审核通过，Then 可作为该镜头关键帧选定。
- Given 已有图生视频片段，When 改选关键帧，Then 片段标记过期。

## 5. 测试要点

输入展开正确性；上传裁剪；审核拒绝路径。

## 6. 待确认

无。
