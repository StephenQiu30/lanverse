## 1. 需求说明

### 1.1 背景与目标

声音使用 AI 配音（TTS）。每句台词按角色音色独立生成、试听、选定，便于逐句返工。

### 1.2 用户故事

- 作为**制作者**，我希望按角色音色为每句台词生成配音，并可调整语速与情绪。

### 1.3 范围

包含：批量 TTS、逐句重生成、语速与情绪、发音修正、选定。不包含：真人音轨替换、口型同步、声音克隆、BGM（见 REQ-34）。

## 2. 需求分析

### 2.1 业务流程

```text
配音页：列出本集台词（按场）→ 批量报价（未配音 / 过期的台词）→ 确认 → 逐句 TTS → 候选
→ 试听 → 选定（line_audio_selection）
```

### 2.2 业务规则

| # | 规则 | 理由 |
| --- | --- | --- |
| R1 | 默认使用角色音色（REQ-16）与其默认参数；可逐句覆盖语速（0.5–2.0）与情绪（模型支持的枚举） | AUD-01 |
| R2 | 台词文本（`content_hash`）变化或角色音色变化 → TTS 音频过期 | LIN-01 |
| R3 | 选定以 `(episode_id, line_key)` 为键，跨结构版本有效 | 稳定键 |
| R4 | 台词显示其选定音频的时长，作为镜头时长参考 | SB-02 |

### 2.3 状态

台词配音状态：未配音 → 生成中 → 待选 → 已选；叠加“过期”。

### 2.4 异常与边界

- TTS 对特殊字符 / 多音字：支持在台词上设置“发音修正文本”（只影响 TTS 输入，不改台词），作为 TTS 参数。
- 台词为空或仅动作：不生成。

## 3. 验收标准

- Given 第 1 集 48 句台词，When 批量生成配音并选定，Then 每句台词都有选定音频，并显示选定音频的时长。
- Given 台词文本被修改，When 查看配音，Then 该句 TTS 音频标记过期。
