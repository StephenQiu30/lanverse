# M15 模板与集成接口需求

> Requirement ID：REQ-INT
> 状态：reviewed v1（ready_for_design，待产品负责人接受）
> 日期：2026-08-20
> 上游：[目标需求总览](./000-AI视频生产平台目标需求总览.md)
> 对应模块：M15 模板与集成接口

## 1. 需求结论

模板和外部集成只能复用已批准、可版本化的结构与能力，并必须经过与界面相同的权限、业务、资源和治理规则。模板升级不自动改写已运行项目；API、Webhook 或扩展不得获得数据库直连或跨模块写表能力。

公共工作流市场、任意可执行脚本和商业分成不在当前范围。

## 2. 用户结果与范围

组织可以把已批准的项目 Brief、实体结构、风格规则、镜头模式、质量规则和交付预设发布为内部模板；新项目预览后实例化并保留来源版本。受控客户端可以通过 API/Webhook 操作项目、镜头、计划、任务、候选、审阅和交付。

企业阶段可以注册私有模型或 LoRA 能力，但必须声明能力、数据范围、计量、健康和撤销路径。

## 4. 模板规则

TemplateRevision 发布后不可修改。模板可以引用组织已发布实体、规则和预设，不得包含源项目草稿、未授权媒体、凭据或当前任务状态。

实例化创建新项目对象身份并保存来源关系；模板后续升级不改变既有实例。迁移必须显示新增、删除、冲突、无法满足能力和下游影响，由用户逐项确认。

## 5. API 与 Webhook

API 客户端声明 Workspace、项目、允许动作、有效期和速率限制；高消耗、风险接受、主选和交付仍需要与界面相同的明确授权语义。

Webhook 事件只传递必要 ID、版本、状态和追踪信息，不复制完整剧本、Prompt、凭据或媒体。消费者重放同一事件不能产生重复业务动作；投递成功只表示通知送达，不代表对方业务完成。

## 6. 私有能力与扩展

私有能力至少声明媒体类型、模型/LoRA 版本、输入输出、参考限制、地域、数据处理、权利、计量单位、健康检查和回滚/撤销方式。它必须经过 M07 预检和 M08 耐久执行，不能形成旁路。

扩展 Manifest 声明所需查询和命令；未批准能力不可见。扩展不能安装任意运行时代码到核心进程、读取凭据或跨 Workspace 工作。

## 7. 失败与恢复

| 场景 | 用户可见结果 | 恢复动作 |
| --- | --- | --- |
| 模板依赖缺失 | 实例化前阻塞并列出依赖 | 安装/替换依赖或取消字段 |
| 模板版本不兼容 | 显示兼容范围和迁移风险 | 选择旧版或人工迁移 |
| API 重复请求 | 回读同一业务结果 | 使用原结果继续 |
| Webhook 目标失败 | 业务事实不回滚，投递进入重试/死信 | 修复目标后人工重放 |
| 私有能力健康异常 | 停止新路由并显示受影响计划 | 恢复、撤销或替代能力 |
| 集成凭据撤销 | 立即停止新调用 | 重新授权新连接 |

## 8. 非功能需求

| ID | 要求 |
| --- | --- |
| INT-NFR-001 | API 和事件契约版本化，并提供明确弃用窗口。 |
| INT-NFR-002 | Webhook 签名、防重放、投递和重试具有可执行验证。 |
| INT-NFR-003 | 集成凭据加密保存且不进入日志、事件或模板。 |
| INT-NFR-004 | 第三方限流、配额和故障不会拖垮核心交互路径。 |
| INT-NFR-005 | 模板和扩展隔离 Workspace，不能复制未发布项目事实。 |

## 9. 验收条件

| ID | 场景 |
| --- | --- |
| AC-INT-001 | 已批准模板实例化后形成新对象身份并保留模板来源版本。 |
| AC-INT-002 | 模板升级不改变已运行项目，只生成可审查迁移提案。 |
| AC-INT-003 | 相同操作通过 API 和界面得到一致权限、冲突和业务结果。 |
| AC-INT-004 | 重复 API 请求和 Webhook 重放不产生重复业务动作。 |
| AC-INT-005 | Webhook 目标失败不回滚已提交领域事实。 |
| AC-INT-006 | 私有能力不能绕过计划、资源、权利和执行治理。 |
| AC-INT-007 | 撤销集成连接后新调用立即停止，历史事件和审计保留。 |
| AC-INT-008 | 扩展无法直接写数据库、读取通配凭据或跨 Workspace 查询。 |

## 10. 指标与待确认项

指标包括模板实例化成功率、模板迁移冲突率、API 幂等命中、Webhook 成功/重试/死信、私有能力健康和扩展拒绝原因。待确认首批公开 API、Webhook 事件集合、模板可包含字段、企业私有能力优先级和契约弃用周期。
