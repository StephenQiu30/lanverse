# 故事板需求

## 目标与范围

制作者能在集场范围查看镜头，并对明确选中范围批量操作。

本模块范围：网格/表格同查询、筛选、选择范围、原子批量时长、逐镜头批量生成。

建议执行顺序为编号顺序；编号不代表排期或已批准实施。本文件按业务模块整体维护，内部功能在同一文档列出，不为每个按钮、接口或技术层建立单独需求文件。

## 功能与数据要求

<a id="req-f-04"></a>

### 分镜故事板

#### 字段与数据量

| 区域        | 必须承载的字段                                | 设计归属                                      | 一次读取 / 保存的量                        |
| ----------- | --------------------------------------------- | --------------------------------------------- | ------------------------------------------ |
| 页头与筛选  | 集、场名、镜头数量、状态、模式、视图          | episode/scene；镜头查询聚合                   | 当前集/场范围；建议一页40镜头，初版上限100 |
| 镜头卡 / 行 | 编号、描述、时长、模式、缩略图、画面/视频状态 | shot + current shot_revision + job/output摘要 | 不嵌套所有历史/候选                        |
| 批量状态    | 所选ID、统一时长、生成进度                    | 选择临时；写入shot_revision/任务              | 仅明确选中的镜头，不将全选暗含未加载项     |

#### 功能与失败边界

| 用户动作            | 必须产生的结果                             | 边界与失败                         |
| ------------------- | ------------------------------------------ | ---------------------------------- |
| 网格 / 表格 / 筛选  | 共享同一查询及排序；选中范围可见           | 无匹配与加载失败不同               |
| 批量改时长          | 校验全部镜头与模型限制，一次原子提交       | 一项冲突整批不写，返回具体冲突ID   |
| 批量生成 / 打开镜头 | 每镜头生成独立可追踪任务；进入同一shot详情 | 批量失败有逐项状态；不自动选定结果 |

## 范围边界

- 故事板是镜头列表视图，不另建一张故事板状态副本表。

## 依赖与待确认

依赖镜头；批量生成依赖14；不另存故事板状态副本。

待确认：批量读取上限仍为建议，需随实际数据消费评审。

以上缺口只是评审问题，不构成新增产品能力或架构决策。既有功能和约束不因旧接口支持不足而删除或降级。

## 模块验收

1. 本文列出的字段和功能由真实数据及操作结果承载，成功/失败/权限/未接入状态明确，mock不作为业务通过。
2. 需要持久化的写入可刷新恢复；版本冲突保留输入，重复副作用按幂等合同核对；只读/瞬时状态不强加持久化。
3. 当前用户/项目范围服务端验证；管理动作限管理员，秘密不进入响应、普通日志、审计明文或导出。
4. 实现时补与本模块风险匹配的成功、失败、冲突/重复、越权场景，分别记录自动化、真实持久化、浏览器及外部供应商证据，未执行不得报通过。

统一要求见[非功能规格](02-非功能需求规格.md)和[交互需求](05-界面与交互需求.md)；当前均待评审、未完成真实功能验收。本阶段不列Sprint、工时或固定用例数量。
