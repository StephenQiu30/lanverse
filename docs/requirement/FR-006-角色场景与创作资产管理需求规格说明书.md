# FR-006 角色、场景与创作资产管理需求规格说明书

## 1. 目的与范围

管理角色生产身份、服装造型、场景、道具、视觉风格和声音身份等可持续引用的创作资产，并形成可确认的视觉/声音生产基线。

分类依据是资产在短剧生产中的业务身份和用途，而不是文件格式。人物关系及角色、服装、道具和场景的剧情状态以 FR-005 为唯一叙事事实源，本模块只引用这些事实并管理其生产表现版本。

## 2. 资产类型

| 类型 | 业务含义 |
| --- | --- |
| 角色 | 生产中的稳定人物身份、别名、外观与声音识别特征 |
| 服装与造型 | 角色在剧情阶段、场次或镜头中的外观状态 |
| 场景 | 地点、空间结构、时间、环境和氛围基准 |
| 道具 | 需要跨镜头保持身份或状态的关键物件 |
| 风格 | 项目或局部范围的视觉、声音和表现约束 |
| 声音身份 | 角色声音身份及与授权、音色版本的关系 |
| 参考素材 | 用于表达创作意图或约束的文本、图片、音频和视频 |

## 3. 主业务流程

1. 从剧本或故事圣经识别资产需求。
2. 创建稳定资产身份，确认类别、归属和别名。
3. 导入或创建参考内容并关联来源和权利。
4. 确认项目级基准版本或局部使用版本。
5. 在场次、镜头和任务中引用明确版本。
6. 资产变化或停用时识别直接影响并交责任人处置。

## 4. 功能需求

| 编号 | 规范性需求 | 优先级 |
| --- | --- | --- |
| FR-006-001 | 系统应为每项角色、场景、服装、道具、风格和声音资产建立稳定业务标识。 | P0 |
| FR-006-002 | 系统应为资产指定唯一主类别并允许附加用途标签。 | P0 |
| FR-006-003 | 系统应支持角色维护别名、外观与声音识别特征以及未经确认不得改变的生产特征。 | P0 |
| FR-006-004 | 系统应允许资产引用故事圣经中明确版本的人物关系和剧情状态。 | P0 |
| FR-006-005 | 系统应支持场景的空间、时间、光线、天气和状态基准。 | P0 |
| FR-006-006 | 系统应支持服装、造型和关键道具的剧情阶段与使用范围。 | P0 |
| FR-006-007 | 系统应支持项目级和局部范围的视觉风格约束。 | P0 |
| FR-006-008 | 系统应检测名称、来源、媒体指纹或关系相似的疑似重复资产。 | P0 |
| FR-006-009 | 系统应允许用户合并、关联或保持疑似重复资产独立。 | P0 |
| FR-006-010 | 系统应允许镜头和任务引用明确的资产版本。 | P0 |
| FR-006-011 | 系统应支持从资产反查所有直接使用位置。 | P0 |
| FR-006-012 | 系统应阻止停用或强制受限资产产生未经批准的新引用。 | P0 |
| FR-006-013 | 系统应允许项目内复用同一资产身份而不复制失去来源的副本。 | P0 |
| FR-006-014 | 系统应在跨项目复用前重新校验访问和权利范围。 | P1 |
| FR-006-015 | 系统应允许按项目或指定局部范围建立包含明确角色、场景、造型、道具、风格和声音版本的视觉/声音基线。 | P0 |
| FR-006-016 | 系统应允许有权责任人确认一个范围内唯一当前视觉/声音基线，并保留历史基线。 | P0 |
| FR-006-017 | 系统应在当前视觉/声音基线变化后标识受影响的分镜、任务、候选、时间线和交付版本。 | P0 |

## 5. 业务规则

- BR-006-001：换装、年龄阶段、情绪或单张参考图不自动创建新角色。
- BR-006-002：角色叙事身份与角色视觉版本必须分离。
- BR-006-003：一个引用必须指向明确版本，不得只引用“最新版本”。
- BR-006-004：参考素材、生成候选和正式采用是三类不同事实。
- BR-006-005：资产停用不删除历史使用和交付证据。
- BR-006-006：视觉/声音基线是对明确资产版本的组合引用，不复制或改写故事圣经中的叙事事实。
- BR-006-007：同一项目和生效范围在任一时刻只能有一个当前视觉/声音基线。

## 6. 数据与权限要求

- DR-006-001：保存资产身份、类别、别名、描述、归属、状态和业务设定。
- DR-006-002：保存故事圣经事实引用、生产表现范围和直接使用引用。
- DR-006-003：保存疑似重复证据、合并决定、停用原因和影响清单。
- DR-006-004：保存视觉/声音基线、所含资产版本、生效范围、确认人、确认时间和历史版本。
- 创作者可登记和编辑；基准确认、合并和停用必须由相应资产责任人批准。

## 7. 异常与恢复

| 场景 | 系统行为 |
| --- | --- |
| 疑似重复但无法确认 | 保持独立或待确认，不自动合并。 |
| 删除已被使用的资产 | 禁止物理删除，改为停用并保留引用。 |
| 权利状态变为受限 | 阻止新使用，并标识已有任务、采用和交付影响。 |
| 文件暂不可访问 | 保留资产身份和引用，但阻止需要该媒体的生产。 |

## 8. 验收标准

- AC-006-001：同一人物以两个别名导入时，系统提示疑似重复且不自动合并。
- AC-006-002：角色换装不会创建新角色身份，而是形成关联造型版本。
- AC-006-003：从任一服装版本可查出使用它的单集、场次、镜头和任务。
- AC-006-004：停用已交付资产后，历史交付组成仍可还原。
- AC-006-005：任一已确认视觉/声音基线可还原其中全部资产版本及其故事事实引用。
- AC-006-006：修改当前基线中的主角版本后，使用旧基线的分镜和未交付结果显示待复核。
