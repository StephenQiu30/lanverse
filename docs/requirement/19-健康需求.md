# 健康需求

## 1. 需求概述

**需求目标：** 管理员能查看真实降级、执行风险及运行指标。

**使用者与价值：** 作为管理员，我希望看到真实降级、执行风险与监控可用性，找到对应处理入口。

**问题背景：** 现页刷新会改变演示状态，未证明指标来自实际部署或故障已经恢复。

| -------- | --------------------------------------------------------------------------- |
| 业务角色 | 管理员                                                                      |
| 文档状态 | 原始需求整理稿，待评审；不是已接受的设计或已验收功能                        |
| 范围来源 | 本文件第7、8节保留的原规格、现有页面代码，以及已整理的跨模块流程            |
| 完成依据 | 第3节功能结果、第4节质量条件、第5节验收场景；待确认项解决后才能验收相应能力 |

## 2. 范围与边界

本模块包含：固定窗口健康卡、供应商/队列/Worker摘要、30秒及手动刷新、去处理与配置监控链接。

查询实际运行摘要与处理/监控入口；不把页面标签当作部署某监控/队列技术栈的需求。

业务模块一份文档，内部需求编号仅用于追踪，不对应独立文件、接口、类或开发任务。编号不承诺排期。原资料中的存储名、组件名和分页建议不作为已接受架构。

## 5. 验收场景

下列是可执行的业务场景定义，尚未运行。实际测试按[生命周期方法](../软件生命周期与需求管理.md#测试与证据)记录环境、步骤、逐步预期与实际结果；功能行已给出独立验收条件，场景可联合验证多个相关功能。

| 场景         | 关联需求                   | 角色与初始条件                           | 操作顺序                                            | 预期结果                                                 |
| ------------ | -------------------------- | ---------------------------------------- | --------------------------------------------------- | -------------------------------------------------------- |
| AC-HEALTH-01 | FR-HEALTH-01、FR-HEALTH-02 | 有已知成功/失败/未知任务和固定运行指标集 | 打开健康→复算15分钟失败率及1小时供应商指标→核积压   | 值与口径一致；缺失指标显示不可用；样例阈值不作为达标承诺 |
| AC-HEALTH-02 | FR-HEALTH-01、FR-HEALTH-03 | 某供应商真实故障、某指标读取失败         | 手动/自动刷新→故障未修复再刷新→恢复指标数据源       | 刷新不虚报恢复；局部失败保留时间；恢复后显示新的真实结果 |
| AC-HEALTH-03 | FR-HEALTH-02、FR-HEALTH-04 | 管理员、制作者及未配置监控链接           | 跳凭据/风险任务→打开可用监控→试缺链接及普通用户访问 | 保持授权上下文，链接缺失明确；普通用户不能读运行信息     |

质量验收还需执行第4节的权限、故障、边界及数据量验证，并记录自动化、真实持久化、浏览器与外部条件各自的证据。静态数据、成功提示与文档检查不构成产品验收。

## 6. 依赖、假设与待确认

依赖实际任务与指标；未部署组件显示不可用，不据标签强制部署旧技术栈。

**原有待确认：** 实际部署指标来源、监控地址及可用设施需要按运行条件确认。

**本轮发现的需求缺口：** 失败率阈值与待人工核对超过24小时的告警是否沿用样例；统计事件时间、分母、指标过期时限及监控访问范围。

**质量目标待确认：** 本模块适用设备/浏览器/版本、典型与边界数据规模、网络/冷热缓存条件、响应P50/P95、交互/Web Vitals与内存目标，以及格式/大小/并发/批量/导出限额须明确后才能质量验收。运行环境、可用性/维护窗口、数据用途/地域/保留及观测口径/日志策略仍待确认；不臆造SLA或规模。

这些问题统一纳入[总表缺口登记](01-需求总览.md#需求缺口与确认)，由产品负责人确认业务政策，工程/测试负责人补验证条件。责任角色尚未落实到人员，未给出答复的范围维持待确认；不自动新增平台、渠道或旧页面能力。
