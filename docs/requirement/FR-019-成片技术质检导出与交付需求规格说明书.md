# FR-019 成片技术质检、导出与交付需求规格说明书

## 1. 目的与范围

对固定成片版本执行可重复的技术质检，依据目标规格生成视频、字幕、音频和制作清单，并在所有强制门禁通过后形成不可变的正式交付记录。

本能力负责生成和验证交付包，不负责将内容直接发布到外部渠道；多渠道规格和发行包属于 P1 范围。

## 2. 主业务流程

1. 用户选择固定成片版本和交付目标规格。
2. 系统执行画面、音频、字幕、音画同步和 AI 标识检查。
3. 系统区分阻断问题、需确认问题和提醒项。
4. 用户修复阻断问题并针对新成片版本重新质检。
5. 系统生成与固定版本对应的交付包并校验完整性。
6. 有权批准人确认交付，系统创建正式交付版本和交付记录。
7. 用户下载交付包或将其交给后续发行流程。

## 3. 功能需求

| 编号 | 规范性需求 | 优先级 |
| --- | --- | --- |
| FR-019-001 | 系统应允许用户为固定成片版本选择明确的交付目标规格。 | P0 |
| FR-019-002 | 系统应检查分辨率、画幅、帧率、时长、编码格式和文件可播放性。 | P0 |
| FR-019-003 | 系统应检查黑帧、异常静帧、画面缺失和不符合规则的空白区段。 | P0 |
| FR-019-004 | 系统应检查静音、削波、异常响度、音轨缺失和声道配置。 | P0 |
| FR-019-005 | 系统应检查音画同步、对白与口型同步以及字幕时间同步。 | P0 |
| FR-019-006 | 系统应检查字幕缺失、重叠、越出安全区和字符显示异常。 | P0 |
| FR-019-007 | 系统应检查适用的显式与机器可识别 AI 标识是否存在且可验证。 | P0 |
| FR-019-008 | 系统应将质检结果区分为阻断、需确认和提醒，并说明所依据的规则。 | P0 |
| FR-019-009 | 系统应支持生成视频主文件、字幕文件、音频分轨和封面等已配置交付物。 | P0 |
| FR-019-010 | 系统应支持生成脚本、镜头表、素材谱系、成本、审核和合规清单。 | P0 |
| FR-019-011 | 系统应为交付包中的每个文件记录大小、格式和完整性校验值。 | P0 |
| FR-019-012 | 系统应在全部强制门禁通过后允许有权用户创建正式交付版本。 | P0 |
| FR-019-013 | 系统应为每次正式交付记录交付人、时间、目标、内容版本、包版本和结果。 | P0 |
| FR-019-014 | 系统应允许对同一成片版本重试失败的导出，而不重复创建正式交付决定。 | P0 |
| FR-019-015 | 系统应支持按不同渠道规格生成相互独立的交付包。 | P1 |
| FR-019-016 | 系统应为交付版本建立门禁矩阵，并固定引用整集批准、技术质检、权利、安全、AI 标识及适用备案或许可的证据标识。 | P0 |
| FR-019-017 | 系统应在任一强制门禁证据缺失、未知、过期或待复核时阻止正式交付。 | P0 |

## 4. 业务规则

- BR-019-001：质检必须针对固定成片版本和固定规则版本。
- BR-019-002：导出文件生成成功不等于正式交付批准。
- BR-019-003：交付批准不等于外部渠道已经发布。
- BR-019-004：任一强制阻断未解决时不得创建正式交付版本。
- BR-019-005：已交付版本和交付包不得原位覆盖；重新交付必须形成新版本。
- BR-019-006：非强制例外必须记录批准人、理由、范围和有效期限。
- BR-019-007：交付门禁结论不得只引用模块当前状态，必须固定引用与该成片版本对应的证据版本。

## 5. 数据要求

- DR-019-001：保存成片版本、交付目标、质检规则版本、检查结果和例外决定。
- DR-019-002：保存交付包、文件清单、完整性校验值、生成状态和下载范围。
- DR-019-003：保存正式交付版本、批准人、交付目标、时间、门禁矩阵、逐项证据标识和上游追溯关系。

## 6. 异常与恢复

| 场景 | 系统行为 |
| --- | --- |
| 质检过程部分失败 | 将未完成检查标记为未知，不得按通过处理。 |
| 导出过程中断 | 保留固定输入和已完成结果，允许对失败步骤重试。 |
| 文件校验失败 | 标记交付包不可用并阻止正式交付。 |
| 已交付版本的上游内容变化 | 保留历史交付，新的交付申请必须使用新成片版本。 |
| 门禁证据与成片版本不匹配 | 标记证据无效并要求针对当前版本重新审核或检查。 |

## 7. 验收标准

- AC-019-001：包含阻断问题的成片不能创建正式交付版本。
- AC-019-002：导出失败后重试不会改变输入版本，也不会重复产生批准决定。
- AC-019-003：交付包下载后可使用记录的校验值验证文件完整性。
- AC-019-004：任一交付版本可追溯到成片、时间线、媒体、审核、成本和合规证据。
- AC-019-005：重新交付同一内容会创建新交付版本，旧包仍可按保留策略查询。
- AC-019-006：整集批准或合规结论已过期、待复核或指向其他成片版本时，正式交付不能创建。
