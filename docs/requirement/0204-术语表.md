## 1. 生产对象

| 中文术语 | 代码标识 | 定义 | 不要写成 |
| --- | --- | --- | --- |
| 项目 | Project | 一部作品的生产容器；含画幅、风格、预算、生成策略 | 工程、作品 |

| 风格类型 | style_type | 写实（realistic）或风格化（stylized） | 画风类型 |
| 子风格 | style_subtype | 风格化下的具体风格：日系动漫、国风 / 仙侠、3D 卡通、韩漫 / 条漫 | — |

| 剧本 | ScriptSource | 用户导入的原始文件及其来源信息 | — |
| 剧本版本 | ScriptVersion | 一次导入产生的规范化文本与内容指纹；不可变 | — |
| 集 | Episode | 剧本中的一集；逐集生产的单位 | 章节、分集（名词） |
| 场 | Scene | 同一时间、地点内连续的一段戏 | 场景（易与 Location 混淆） |
| 台词 | DialogueLine | 一句对白或旁白，含说话人、内容、情绪、原文位置 | 对白 |
| 原文位置 | source_span | 解析结果在剧本版本中的起止位置 | 锚点 |
| 设定集 | Bible | 全剧角色、造型、场景、道具的集合 | 资产库 |
| 角色 | Character | 剧中人物，可有多个别名 | 人物 |
| 别名 | alias | 同一角色在剧本中的不同称呼 | — |
| 造型 | Look | 角色在特定阶段的外观（服装、伤妆、年龄段），镜头引用的最小单位 | 形象、皮肤 |
| 场景 | Location | 拍摄地点的设定（如“医院走廊”） | 场（见“场”） |
| 道具 | Prop | 需要保持一致外观的物件 | — |
| 参考槽位 | ReferenceSlot | 造型、场景、道具下的一类参考图位置，如定妆照、三视图 | — |
| 锁定 | lock | 为参考槽位选定一个候选并形成不可变版本 | 定稿（动词可用“定稿”，状态用“已锁定”） |
| 角色音色 | VoiceProfile | 角色使用的 TTS 音色与默认参数 | 声线 |
| 镜头 | Shot | 分镜的最小单位；含画面描述、镜头语言参数、台词分配、生成模式、参考组合 | 分镜（“分镜”指整体） |
| 镜头表 | shot list | 一场或一集的镜头有序列表 | 分镜表 |
| 故事板 | storyboard view | 以缩略图网格展示镜头的视图 | — |
| 镜头语言参数 | shot language | 景别、机位角度、运镜方式、时长 | 镜头参数（可简称） |
| 生成模式 | generation_mode | 镜头的视频生成方式：图生视频或全能参考 | — |
| 图生视频 | image2video | 以选定关键帧为首帧生成视频的模式 | 图转视频 |
| 全能参考 | omni_reference | 以参考组合（多图、视频、音频）加描述直接生成视频的模式 | 多参考、全参考 |
| 参考组合 | ReferenceSet | 镜头用于全能参考的一组参考项 | 参考集 |
| 参考项 | ReferenceItem | 参考组合中的一项：被引用对象及版本 + 用途 | — |
| 用途 | role | 参考项或生成输入的作用：主体、场景、道具、风格、动作、运镜、音频、首帧、尾帧、源素材、提示词 | 角色（易与 Character 混淆） |
| 关键帧 | key frame | 图生视频的首帧图片 | 首图 |
| 片段 | take | 某镜头的一个视频生成结果 | 镜次、素材 |

| 字幕 | subtitle | 由台词与时码生成的文本轨 | — |
| 剪辑计划 | EditPlan | 片段、音频、字幕在时间线上的编排；每次保存一个版本 | 剪辑工程 |

| 成片 | Delivery | 一次渲染的结果，附清单；不可变 | 导出视频 |
| 成片清单 | manifest | 成片引用的全部对象版本、指纹与渲染参数 | — |

## 2. 生成与任务

| 中文术语 | 代码标识 | 定义 | 不要写成 |
| --- | --- | --- | --- |
| 生成操作 | Operation | 一次 AI 生成的完整记录：能力 + 模式 + 模型 + 参数 + 带用途的输入 → 候选；对用户展示为“任务” | — |
| 任务 | task（界面） | 生成操作在界面上的称呼 | 作业、Job |
| 能力 | capability | 生成的类别，如生图、改图、视频、TTS、结构化文本 | 功能 |
| 候选 | candidate / OperationOutput | 生成结果，选定前不被正式引用 | 草稿 |
| 选定 | select | 用户将某候选设为正式引用的显式操作 | 采用、应用 |
| 正式版本 | version | 被选定或确认后形成的不可变对象版本 | — |
| 报价 | quote | 生成前按注册表价格规则计算的费用，15 分钟有效 | 预估（界面可显示“预估费用”） |
| 二次确认 | confirm | 用户对报价的明确确认；付费生成的唯一放行方式 | 自动确认 |
| 批量生成 | batch | 对多个对象一次报价、一次确认、分别执行 | — |
| 输入指纹 | input_hash | 生成输入的摘要；相同指纹可复用结果 | — |
| 复用 | reuse | 相同输入已有成功结果时直接使用，不再收费 | 缓存命中（界面不用） |
| 结果未知 | unknown | 已发出付费请求但未得到明确响应的状态 | 超时失败 |
| 对账 | reconcile | 用原请求标识向供应商查询真实状态 | — |
| 待人工核对 | manual | 无法自动对账、需管理员处理的状态 | — |
| 过期 | stale | 上游产生新版本后，下游对象的标记；不自动重做 | 失效、脏数据 |
| 影响范围 | impact | 某次上游变化导致过期的全部下游对象 | — |
| 依赖 | dependency | 下游对象版本对上游对象版本的引用关系 | 血缘（代码中 lineage 可用） |

## 3. 模型与成本

| 中文术语 | 代码标识 | 定义 | 不要写成 |
| --- | --- | --- | --- |
| 供应商 | provider | 提供模型服务的公司或平台，如火山方舟、MiniMax、OpenRouter | 厂商、渠道 |
| 模型 | model / ModelProfile | 供应商提供的一个具体模型，在注册表中登记能力、上限、参数、价格 | — |
| 模型注册表 | catalog | 所有可用模型的声明式配置 | 模型库 |
| 参数表单 | param_schema | 注册表中定义的模型参数与界面组件 | — |
| 服务区域 | region | 模型服务所在地：境内（domestic）/ 境外（overseas） | — |
| 凭据 | credential | 调用供应商所需的密钥 | 密钥（可混用于技术文档） |
| 预算 | Budget | 项目可用于生成的金额上限 | 额度 |
| 预留 | Reservation | 确认时按报价冻结的预算 | 冻结 |
| 结算 | settle | 任务终态后按实际用量入账并释放多余预留 | — |
| 账本 | Ledger | 全部预留、结算、释放记录 | 流水 |
| 单分钟成本 | cost per minute | 某集全部模型费用 ÷ 成片分钟数 | — |

## 4. 界面与交互

| 中文术语 | 代码标识 | 定义 |
| --- | --- | --- |
| 流水线视图 | pipeline view | 按阶段组织的表格、列表、卡片界面；MVP 主界面 |
| 画布 | canvas | 无限画布界面，与流水线共享数据（V1） |
| 节点 | node | 画布上的元素，按类型（文本、图片、视频、音频、镜头表等）与动作（资源、生成、编辑）分类 |

| 提案 | proposal | Agent 给出的待确认修改（V1） |
| 任务中心 | task center | 查看全部生成任务的页面 |
| 影响清单 | impact list | 列出过期对象与重做预估费用的页面 |
