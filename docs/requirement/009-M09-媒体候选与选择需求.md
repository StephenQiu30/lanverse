# M09 媒体、候选与选择需求

> Requirement ID：REQ-MED
> 状态：reviewed v2（ready_for_design，待产品负责人接受）
> 日期：2026-08-22
> 上游：[目标需求总览](./000-AI视频生产平台目标需求总览.md)、[M08](./008-M08-提供商与耐久执行需求.md)
> 对应模块：M09 媒体、候选与选择

## 1. 需求结论

媒体文件事实、生成候选和人工选择是三种对象。每次成功结果形成不可变 Candidate，新结果、评分或预览高亮都不能自动覆盖当前主选；一个目标在一个装配上下文中最多一个当前 Selection，但可以暂时没有主选。

## 2. 用户结果与范围

用户可以安全上传、摄取、预览和比较媒体，查看每个候选的生成血缘、完整性、质量摘要和适用上下文，并做出采用、备选、拒绝或替代决定。上游变化保留历史候选和选择，但明确显示是否仍可用于当前上下文。

本模块不执行生成、不自动关闭质量问题、不决定正式审阅或交付，也不把对象存储路径当成业务选择。

## 4. 媒体与候选规则

MediaArtifact 至少有 `pending | verifying | ready | quarantined | missing | deleted` 完整性状态。Candidate 表示“针对当时目标和输入产生的历史输出”，即使当前上下文变化也不改成失败。

代理、缩略图、转码和抽帧都是派生媒体，必须能回到原媒体及处理版本。文件存在不等于 ready；哈希、长度、格式、解码和安全检查通过后才可用。

评分、排序和自动检查只能提供建议。Selection 必须记录目标上下文、Candidate、操作者、时间、理由和被替代决定；预览播放器当前显示项不能隐式写为主选。

M09 的完整性检查只回答“文件能否被安全存储、解码和读取”。面向镜头用途的时长/规格、黑帧/静音、语义、连续性和品牌质量属于 M10；M09 只展示 M10 的摘要和阻塞，不重复创建 QualityIssue。恶意文件或无法解码的媒体可以在 M09 隔离，但隔离记录不伪装成 M10 质量决议。

选择唯一键必须至少包含 `target_id + target_revision + selection_purpose + assembly_context`。分镜参考、首帧、尾帧、视频主选、音频主选和交付替代是不同 purpose，不能因为指向同一 Shot 而互相覆盖。

## 5. 并发、删除与复用

并发选择使用 expected revision；同一上下文两个选择只允许一个成为 current。删除已选或已交付媒体必须阻止、清除选择或按保留策略归档，不能自动改选最后一个候选。

上游变化后查询返回 `usable_for_context` 和原因。历史选择仍指向原 Candidate；复用到新上下文必须运行参考、权利、规格和质量预检并形成新决定。

## 6. 失败与恢复

| 场景 | 用户可见结果 | 恢复动作 |
| --- | --- | --- |
| 文件损坏/不完整 | 隔离并保留来源诊断 | 重新下载、上传或生成 |
| 代理生成失败 | 原媒体状态独立显示 | 重做代理，不重生成原媒体 |
| 并发选择冲突 | 显示当前主选和他人决定 | 刷新后重新选择 |
| 删除已选候选 | 显示全部引用并阻止静默删除 | 替换、清除选择或保留 |
| 上游变更 | 历史候选保留但当前适用性变化 | 显式复用或新生成 |
| 存储暂时不可用 | 不把 Candidate 标成生成失败 | 恢复存储并重新验证 |

## 8. 验收条件

| ID | 场景 |
| --- | --- |
| AC-MED-001 | 同一镜头三次成功生成形成三个独立 Candidate。 |
| AC-MED-002 | 新 Candidate 到达不会改变已有人工主选。 |
| AC-MED-003 | 预览高亮和收藏不会被导出当成 Selection。 |

| AC-MED-005 | 损坏媒体进入隔离，不显示为可选 ready 候选。 |
| AC-MED-006 | 上游人物状态变化保留旧候选并说明当前不可用原因。 |
| AC-MED-007 | 删除已选候选前显示审阅和交付引用且不自动替换。 |
| AC-MED-008 | 任一候选可回溯计划、Attempt、模型、输入和原媒体。 |
| AC-MED-009 | 显式复用产生新上下文决定，不改写历史 Candidate。 |

## 9. 指标与待确认项

指标包括首轮候选采用率、每镜候选数、选择周转时间、并发冲突、隔离率、媒体恢复率、复用率和不可用原因分布。待确认 shortlist 是否首期需要、媒体保留期限、用户上传与模型结果的默认权利标记及代理规格。
