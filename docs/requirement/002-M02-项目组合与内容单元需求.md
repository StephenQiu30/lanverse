# M02 项目组合与内容单元需求

> Requirement ID：REQ-PRJ
> 状态：proposed v1
> 日期：2026-08-20
> 上游：[目标需求总览](./000-AI视频生产平台目标需求总览.md)
> 对应模块：M02 项目组合与内容单元

## 1. 需求结论

Project 是平台的管理、记忆、权限和交付单元；ContentUnit 是剧集、广告版本、栏目期次等叙事与顺序规划单元。项目页面必须从真实业务对象计算进度、阻塞和下一动作，不能维护一套与事实脱节的“当前阶段”。

## 2. 用户结果与范围

用户需要建立项目简报、组织系列和内容单元、管理目标版本与变体、查看跨模块阻塞、归档或恢复项目，并在不复制另一项目草稿的前提下复用已发布资产。

本模块不拥有剧本内容、人物状态、镜头、任务或媒体，只保存项目组织、简报、内容单元、里程碑目标和跨模块查询结果。

| PRJ-FR-003 | 管理系列、季、内容单元和变体的稳定身份与顺序 | P0 |

## 4. 项目简报

Brief 至少包含项目目的、受众、内容形态、语言、画幅、目标时长、质量目标、禁止项、截止时间、资源上限和交付规格。字段允许 unknown，但进入生成计划前所需字段必须由下游 Readiness 明确指出。

批准后的 Brief 不可编辑；修改创建新 BriefRevision，并在提交前显示受影响的叙事、风格、镜头、计划和交付。项目“当前 Brief”是显式选择，不等于最新创建版本。

## 5. 内容单元与顺序

1. Project、Series、Season、ContentUnit 使用稳定 ID，显示编号和排序键可以改变。
2. 内容单元可以是集、广告版本、栏目期次或其他签认类型；不同类型不强制共享全部字段。
3. 重排内容单元不改变其身份，也不自动扩大人物状态或交付范围。
4. 变体必须声明来源内容单元和差异目的；不得用复制文件夹隐藏谱系。
5. 跨内容单元共享人物或资产由 M04 管理，本模块只显示引用状态。

## 6. 进度与状态规则

项目生命周期为 `draft → active → paused → completed | archived`。`completed` 需要满足签认交付目标；归档不代表完成。

项目概览分别显示：已开始、完成对象数/总数、运行中、失败、unknown、blocked、stale、待决定和可交付状态。任何一个汇总值都必须能下钻到构成对象，不能保存不可解释的总百分比。

## 7. 失败与恢复

| 场景 | 用户可见结果 | 恢复动作 |
| --- | --- | --- |
| Brief 并发修改 | 显示字段差异和当前版本 | 基于新版本重新提交 |
| 项目归档时仍有运行任务 | 显示任务与外部副作用范围 | 取消、等待或明确保留运行 |
| 项目复制部分失败 | 不发布半完成副本 | 从复制清单续做或撤销草稿 |
| 汇总投影延迟 | 显示数据时间和正在刷新 | 回源关键对象或重建投影 |
| 目标规格变更 | 先显示影响，不自动改写计划 | 新建 BriefRevision 并选择迁移 |

## 8. 权限与审计

- 创建、归档、恢复、复制和改变项目职责需要相应 Workspace 权限。
- Brief 批准和高影响目标变更记录操作者、基线、理由和影响确认。
- 项目概览不得向无权成员泄露来源正文、秘密人物字段或外部模型凭据。

## 9. 非功能需求

| ID | 要求 |
| --- | --- |
| PRJ-NFR-001 | 大型项目概览使用分页/聚合，不读取全部媒体正文。 |
| PRJ-NFR-002 | 汇总投影可重建，不能成为镜头、任务或交付唯一事实源。 |
| PRJ-NFR-003 | 重复创建和复制请求使用幂等键，不产生不可区分项目。 |
| PRJ-NFR-004 | 项目归档、恢复和职责变化具有完整审计。 |
| PRJ-NFR-005 | 具体项目、内容单元和并发规模由试点基线签认。 |

## 10. 验收条件

| ID | 场景 |
| --- | --- |
| AC-PRJ-001 | 用户从 Brief 建立一个项目和三个内容单元，重排后各内容单元引用不漂移。 |
| AC-PRJ-002 | Brief 修改形成新版本，已批准生成计划仍保留旧输入。 |
| AC-PRJ-003 | 项目概览中的失败、unknown 和缺主选数量都能定位具体对象。 |
| AC-PRJ-004 | 项目归档不删除来源、任务、候选、选择、审阅或交付历史。 |
| AC-PRJ-005 | 无权限用户无法通过项目概览获取其他项目敏感摘要。 |
| AC-PRJ-006 | 并发更新 Brief 时旧基线提交返回冲突而非覆盖。 |
| AC-PRJ-007 | 复制项目只复制用户确认的结构，生成新的业务身份并保留来源关系。 |
| AC-PRJ-008 | 投影重建后项目汇总与权威对象一致。 |

## 11. 指标与待确认项

指标包括活跃项目数、每周完成审阅或导出的多镜头项目数、阻塞平均持续时间、Brief 变更影响范围和项目归档恢复率。待确认内容单元类型最小集合、是否需要正式分支合并，以及项目级截止时间与镜头优先级的继承规则。
