# 功能需求总表

## 当前状态与使用方式

页面已实现，真实业务尚未逐项接入和验收。需求按业务模块独立维护，用户、项目、素材、模型等各一份完整文档，内部动作不再分别建文件。通用说明沿用01～05，业务模块按建议执行顺序从06连续编号；实施时选择一个模块先评审设计，再细化代码计划和验收。

编号只表达建议顺序，不是排期、工时或已批准开工。可以先实现模块内最小闭环，但需求阶段保持整份业务内容完整，不提前建立故事、接口或技术层任务。数据和接口文档仍为待评审提案，页面与mock不证明功能完成。

## 建议执行顺序

| 顺序 | 独立业务需求                      | 用户结果与范围                                                       |
| ---- | --------------------------------- | -------------------------------------------------------------------- |
| 01   | [06-用户需求](06-用户需求.md)     | 访客、制作者与管理员能按角色登录、维护自己账号并执行必要的账号管理。 |
| 02   | [07-项目需求](07-项目需求.md)     | 制作者能建立、查找、复制并打开同一创作项目。                         |
| 03   | [08-素材需求](08-素材需求.md)     | 制作者能上传、查看、收藏和在个人/项目范围复用素材。                  |
| 04   | [09-供应商需求](09-供应商需求.md) | 管理员能配置可用凭据，在更新失败时保留原配置。                       |

| 06   | [11-剧本需求](11-剧本需求.md)     | 制作者能将支持格式的剧本转成可追踪的项目内容。                       |

## 11. 待确认事项

下列事项仍为原始需求中的缺口，相关能力须在细化与验收前明确；本文不替用户决定。

| 问题              | 已确定部分                   | 仍需补充                                   |
| ----------------- | ---------------------------- | ------------------------------------------ |
| 剧本格式          | 文案txt/md/docx必须承载      | input额外pdf是否正式支持                   |
| 画布导出          | 当前有导出入口               | 导出画布图/选定媒体/包的具体格式与范围     |
| 素材容量          | 已用与总量卡片必须有真实来源 | 总量表示磁盘还是分配配额                   |
| 头像              | 更换与保存本人头像是需求     | 文件规格、裁切交互                         |
| 管理建号          | 建号/重置与首次改密保留      | 临时凭据的安全展示/交付方式                |
| 任务通知/全站搜索 | 入口保留                     | 点击后范围、列表与跳转细节                 |
| 真实付费生成      | 不允许mock成功掩盖收费       | 提交按钮前的价格提示、确认与费用不可知处理 |

各业务文档另记录解析规则、镜头来源、复制范围等细化问题；缺口须评审决定，不拿样例值补成已接受合同。

## 12. 通用验收与范围边界

逐项核对字段、动作、空值、失败与权限。业务写入须刷新后保留，冲突保留输入；统计可复算；生成不能替代人工选定。静态示例与临时交互状态不要求业务持久化。统一证据要求见[非功能需求规格](02-非功能需求规格.md#完成标准与证据层次)。

历史的组织/邀请/支付/协作角色、独立剧本工作台、导演台、时间轴、深度工具、素材包和永久清理不进入本次范围。旧页面、接口、表和技术拓扑不能反向裁剪本需求；历史资料和旧数据迁移仅在另行安排的任务中使用。本次仅整理文档，不修改前后端业务代码、数据库或用户数据。
