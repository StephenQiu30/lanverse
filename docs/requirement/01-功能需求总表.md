# 当前功能需求入口

功能按新页面维护于[页面总览](浮光页面/index.md)。每页包含“字段/数据量 → 功能/失败 → 数据与接口 → 验收”，覆盖页面内弹窗与控件。旧功能编号、旧路由及旧接口不作为本轮需求。

当前跨页链路见[业务流程](03-业务流程与用例模型.md)；新业务状态、权限与非功能要求见[页面验收](浮光页面非功能与验收.md)。新增表和接口必须有当前消费者，不预建未来目录或平台。
