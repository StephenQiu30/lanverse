## 0. 说明

### 0.1 需求格式

每条需求包含：

- **编号与名称**：`模块-两位序号`，编号不复用；删除的需求保留空号并注明。
- **优先级**：MVP / V1 / V2 / 待定。
- **关联**：PRD 决策（Pxx）与用例（UC-xx，见 0203）。
- **用户故事**：作为〈角色〉，我希望〈能力〉，以便〈价值〉。
- **业务规则**：必须满足的约束。
- **异常处理**：失败、边界与冲突时系统的行为。
- **验收标准**：Given / When / Then 场景；是判断需求完成的唯一依据，测试用例由此派生（见 0502 需求追踪矩阵）。

V2 与待定需求只写用户故事与关键规则，进入规划时再补全验收标准。

### 0.2 通用约定（适用于所有需求）

- **G1 命令幂等**：所有写操作携带幂等键；重复提交返回首次结果。
- **G2 版本冲突**：修改正式对象需携带期望版本；不一致时返回“内容已被修改”，界面提示刷新，不覆盖。
- **G3 候选与正式分离**：生成结果先是候选，选定后才被正式引用；历史版本可查。
- **G4 付费二次确认**：任何付费生成须经报价与用户确认（GEN-11）。
- **G5 依赖传播**：上游新版本使下游标记为“过期”，不自动重做（LIN-01）。
- **G6 审计**：选定、确认、预算、价格、凭据、注册表、账号变更均写审计记录。
- **G7 状态反馈**：所有异步操作在界面显示排队、进行中、成功、失败（附原因）、结果未知、已取消之一。

## 2. 账号与会话（ACC）

### ACC-01 管理员创建账号，用户以账号密码登录

- 优先级：MVP ｜ 关联：P17、UC-01、UC-02
- 用户故事：作为管理员，我希望为团队成员创建账号，以便只有授权人员能使用平台；作为制作者，我希望用账号密码登录。
- 业务规则：
  1. 不提供自助注册；账号只能由管理员创建。
  2. 账号字段：登录名（唯一）、显示名、角色（管理员 / 制作者）、状态（启用 / 禁用）。
  3. 初始密码由管理员设置，首次登录必须修改（ACC-05）。
  4. 密码至少 10 位，含字母与数字；服务端只保存加盐哈希。
  5. 未登录访问任何页面均跳转登录页，登录后返回原页面。
- 异常处理：连续 5 次密码错误，账号锁定 15 分钟并提示剩余时间；登录名不存在与密码错误给出相同提示，不暴露账号是否存在。
- 验收标准：
  - Given 管理员已登录，When 创建登录名为 `alice` 的制作者账号，Then 账号列表出现 `alice`，状态为启用，审计记录包含此操作。
  - Given `alice` 首次登录，When 输入正确的初始密码，Then 系统要求先修改密码才能进入。
  - Given 某账号连续输错 5 次密码，When 第 6 次尝试登录，Then 提示“账号已临时锁定，请 15 分钟后再试”，即使密码正确也不能登录。
  - Given 未登录用户，When 访问项目页面地址，Then 跳转登录页，登录成功后回到该项目页面。

### ACC-02 管理员配置模型供应商凭据

- 优先级：MVP ｜ 关联：P18、UC-03
- 用户故事：作为管理员，我希望配置火山方舟、MiniMax、OpenRouter 等供应商的凭据，以便平台能调用模型。
- 业务规则：
  1. 凭据加密存储；保存后界面只显示末 4 位与更新时间。
  2. 凭据可测试连通性；测试不产生付费调用。
  3. 删除或停用凭据后，依赖它的模型在注册表中显示“不可用”，新报价被拒绝；进行中的任务按原凭据完成或按供应商结果结算。
- 异常处理：连通性测试失败时显示供应商返回的错误类别（鉴权失败 / 网络不可达 / 超时）。
- 验收标准：
  - Given 管理员保存火山方舟凭据，When 再次打开配置页，Then 只显示凭据末 4 位，接口响应中不含明文。
  - Given 管理员停用 MiniMax 凭据，When 制作者对使用 MiniMax 模型的镜头请求报价，Then 报价失败并提示“该模型当前不可用”。

### ACC-03 会话管理与登出

- 优先级：MVP ｜ 关联：UC-01
- 用户故事：作为制作者，我希望可以主动登出，且长时间不操作后自动失效，以便账号安全。
- 业务规则：会话空闲 12 小时失效、绝对有效期 7 天；登出立即使会话失效；账号被禁用或密码被重置时，该账号所有会话立即失效。
- 验收标准：
  - Given 已登录用户，When 点击登出后使用浏览器后退，Then 无法访问受保护页面。
  - Given 管理员禁用某账号，When 该账号在另一浏览器继续操作，Then 下一次请求被拒绝并跳转登录页。

### ACC-04 管理员禁用账号、重置密码

- 优先级：MVP ｜ 关联：UC-02
- 用户故事：作为管理员，我希望禁用离职成员账号、为忘记密码的成员重置密码。
- 业务规则：不能禁用最后一个启用状态的管理员；重置密码后用户下次登录必须修改密码；禁用账号的历史操作记录保留。
- 验收标准：
  - Given 系统只剩 1 个启用的管理员，When 该管理员尝试禁用自己，Then 操作被拒绝并提示原因。
  - Given 管理员重置 `alice` 的密码，When `alice` 使用新密码登录，Then 系统要求修改密码。

### ACC-05 修改本人密码

- 优先级：MVP ｜ 关联：UC-01
- 用户故事：作为用户，我希望修改自己的密码。
- 业务规则：需验证当前密码；新密码满足 ACC-01 规则且不同于当前密码；修改后其他会话失效。
- 验收标准：Given 用户在两个浏览器登录，When 在其中一个修改密码，Then 另一个浏览器的会话失效。

## 3. 系统管理（ADM）

### ADM-01 模型注册表管理

- 优先级：MVP ｜ 关联：GEN-09、P18、UC-03
- 用户故事：作为管理员，我希望登记每个可用模型的能力、生成模式、参考上限、参数表单与价格，以便制作者在界面上按模型能力使用，并在报价时被正确校验。
- 业务规则：
  1. 每个模型记录：模型键、供应商、能力（生图 / 改图 / 视频 / TTS / LLM / 审核等）、支持的生成模式、各类参考的数量与时长上限、时长 / 画幅 / 分辨率范围、参数表单定义、价格规则、服务区域（境内 / 境外）、是否支持查询 / 取消 / 回调、状态（启用 / 停用）。
  2. 参数表单定义使用固定组件类型：输入框、单选、滑块、开关、按钮组、音色卡片（对齐 0102 §3.4）。
  3. 修改注册表产生新版本；已创建的生成操作使用创建时的版本。
  4. 停用模型不影响进行中的任务。
- 异常处理：保存时校验参数定义合法（字段名唯一、默认值在取值范围内）；不合法则拒绝保存并指出字段。
- 验收标准：
  - Given 管理员新增一个与已有模型同供应商的视频模型配置，When 保存并启用，Then 制作者在镜头生成面板中可以选择它，参数表单按定义渲染，无需发布新版本代码。
  - Given 某模型的参考图上限为 9，When 制作者为该模型配置 10 张参考图并请求报价，Then 报价被拒绝并提示“参考图最多 9 张”。
  - Given 已有进行中的任务使用模型 M，When 管理员停用 M，Then 该任务继续完成，新的报价请求被拒绝。

### ADM-02 审计日志查询

- 优先级：MVP ｜ 关联：G6、UC-23
- 用户故事：作为管理员，我希望查询关键操作的审计记录，以便追溯谁在何时做了什么。
- 业务规则：记录操作人、时间、对象、操作类型、前后值摘要；可按时间范围、操作人、对象类型、项目筛选；审计记录不可修改或删除；保留期见 0202 DAT-03。
- 验收标准：Given 制作者选定了镜头 3 的视频候选，When 管理员按项目与“选定”操作筛选审计日志，Then 能看到该记录，包含操作人、时间、镜头与候选标识。

### ADM-03 系统健康视图

- 优先级：V1 ｜ 关联：UC-17
- 用户故事：作为管理员，我希望看到各队列积压、失败率、结果未知数量与各供应商可用性，以便发现问题。
- 业务规则：数据来自监控系统，只读；异常超过阈值时高亮。

## 4. 项目（PRJ）

### PRJ-01 创建项目

- 优先级：MVP ｜ 关联：P3、P12、UC-04
- 用户故事：作为制作者，我希望创建项目并设置画幅与风格，以便后续所有生成与导出遵循统一规格。
- 业务规则：
  1. 字段：名称（必填，≤ 50 字）、画幅（9:16 / 16:9）、风格类型（写实 / 风格化）、子风格（风格化时必选：日系动漫、国风 / 仙侠、3D 卡通、韩漫 / 条漫）、风格预设（提示词与参考图组合，可选）、描述。
  2. 画幅与风格类型创建后不可修改；如需修改，新建项目。
  3. 输出分辨率固定为 1080p。
- 验收标准：
  - Given 制作者创建 16:9、风格化 / 国风的项目，When 进入该项目的任意生成面板，Then 画幅默认且固定为 16:9，风格预设已带入。
  - Given 已创建的项目，When 打开项目设置，Then 画幅与风格类型为只读。

### PRJ-02 项目列表与项目概览

- 优先级：MVP ｜ 关联：UC-04
- 用户故事：作为制作者，我希望看到所有项目，以及每个项目的集数、各阶段进度与累计成本。
- 业务规则：概览按集显示：场次确认、资产定稿、分镜、关键帧、视频、配音、剪辑、成片八个阶段的完成数 / 总数；累计成本与预算使用率。数据实时计算或在事件到达后 2 秒内更新（0202 PERF-03）。
- 验收标准：Given 第 1 集 30 个镜头中 12 个已选定视频，When 打开项目概览，Then 第 1 集“视频”阶段显示 12/30，刷新后不变。

### PRJ-03 项目预算

- 优先级：MVP ｜ 关联：P4、CST-03、UC-19
- 用户故事：作为管理员或制作者，我希望为项目设置预算上限，以便生成前自动拦截超支。
- 业务规则：预算为金额上限；可用余额 = 预算 − 已结算 − 已预留；报价金额超过可用余额时不可确认；预算可调高或调低（调低不得低于已结算 + 已预留）；预算变更写审计。
- 异常处理：可用余额低于预算的 20% 时在项目页提示（NTF-01）。
- 验收标准：
  - Given 可用余额 50 元，When 某批量生成报价 80 元，Then 确认按钮不可用，提示差额 30 元。
  - Given 已结算 300 元、已预留 50 元，When 将预算调为 320 元，Then 被拒绝并提示最低可设 350 元。

### PRJ-04 多成员协作与角色权限

- 优先级：V2 ｜ 用户故事：作为制片，我希望邀请编剧、美术、导演、剪辑加入项目并按角色授权。

### PRJ-05 项目快照与模板

- 优先级：V2 ｜ 关联：0102 D11 ｜ 用户故事：作为制作者，我希望把某个项目的某一时刻保存为模板，并基于模板创建新项目。

### PRJ-06 项目归档与删除

- 优先级：MVP ｜ 关联：UC-04
- 用户故事：作为制作者，我希望归档已完成的项目，并删除不需要的项目。
- 业务规则：归档后项目只读、可恢复；删除为软删除，进入回收状态保留 30 天后彻底清理（含媒体对象）；有进行中任务的项目不能删除。
- 验收标准：
  - Given 有进行中任务的项目，When 用户删除项目，Then 操作被拒绝并列出进行中的任务。
  - Given 项目被删除 10 天，When 用户在回收列表中恢复，Then 项目及其媒体完整恢复。

### PRJ-07 项目生成策略设置

- 优先级：MVP ｜ 关联：P18、CMP-06、UC-04
- 用户故事：作为制作者，我希望为项目设置默认模型，以及是否允许使用境外模型。
- 业务规则：默认值：允许境外模型 = 否；不允许时，境外模型在该项目的模型选择中隐藏，报价被拒绝；各能力可设默认模型。
- 验收标准：Given 项目未允许境外模型，When 制作者尝试通过接口对 OpenRouter 模型报价，Then 被拒绝并提示“本项目未允许使用境外模型”。

## 5. 剧本（SCR）

### SCR-01 导入整部剧

- 优先级：MVP ｜ 关联：P6、P7、UC-05
- 用户故事：作为制作者，我希望一次导入整部剧（单个文件或按集多个文件），以便平台掌握全剧信息。
- 业务规则：
  1. 支持 docx、txt（UTF-8 / GBK 自动识别）；单文件 ≤ 20 MB；总字数 ≤ 150 万字。
  2. 保存原始文件，可下载；生成规范化文本与内容指纹；内容指纹相同视为同一版本，不重复创建。
  3. 多文件导入时按文件名中的集号排序，用户可调整顺序。
- 异常处理：格式不支持、编码无法识别、文件损坏时逐文件报告原因，其余文件照常导入。
- 验收标准：
  - Given 一个 60 集的 docx 剧本，When 导入，Then 生成一个剧本版本，原文件可下载。
  - Given 再次导入内容完全相同的文件，When 导入完成，Then 系统提示“与已有版本相同”，不新增版本。
  - Given 同时导入 3 个文件，其中 1 个损坏，When 导入，Then 另外 2 个成功导入，损坏文件显示“文件无法解析”。

### SCR-02 分集识别与调整

- 优先级：MVP ｜ 关联：UC-05
- 用户故事：作为制作者，我希望系统自动识别集边界，并允许我合并、拆分、重命名集。
- 业务规则：识别结果为候选，需用户确认；每集显示起止原文位置；确认后生成正式的集列表。
- 异常处理：识别失败时允许用户手动按“集标记”规则（如“第 X 集”）重新分集。
- 验收标准：Given 系统将第 12、13 集识别为一集，When 用户在分界处拆分并确认，Then 集列表显示 61 集（原 60 + 1），拆分位置与原文一致。

### SCR-03 逐集结构解析

- 优先级：MVP ｜ 关联：UC-06
- 用户故事：作为制作者，我希望系统按集解析出场次、台词（说话人、内容、情绪）、动作描述、时间地点，以便后续拆分镜头。
- 业务规则：
  1. 每条解析结果携带原文位置，可点击定位并高亮原文。
  2. 原文中每一句台词被解析且只被解析一次；未归属的台词列为“待处理”。
  3. 解析结果为候选，按集确认。
- 验收标准：
  - Given 第 1 集原文有 48 句台词，When 解析完成，Then 台词列表共 48 条，每条可定位到原文，“待处理”为 0 或列出具体台词。
  - Given 某条台词，When 点击其原文位置，Then 原文面板滚动并高亮对应文字。

### SCR-04 解析结果人工修改

- 优先级：MVP ｜ 关联：UC-06
- 用户故事：作为制作者，我希望拆场、合场、修改说话人与台词、调整情绪标注。
- 业务规则：修改产生新版本，旧版本可查可对比；已被镜头引用的台词修改后，相关镜头标记过期（LIN-01）。

### SB-04 生成模式与参考组合

  4. 选择模型后，界面按模型能力显示各类参考的上限，超出时标红。
- 验收标准：
  - Given 全能参考镜头，When 添加两个角色造型、一个场景、一段运镜参考视频、一段台词音频，Then 参考组合显示 5 项及其用途。
  - Given 所选模型音频参考上限为 3，When 添加第 4 段音频，Then 该项标红并提示上限，报价被阻止。
  - Given 参考组合引用了一段仍在处理中的上传视频，When 请求报价，Then 被阻止并提示“素材尚未就绪”。

- 验收标准：Given 4 个视频候选，When 选定第 3 个，Then 镜头的选定视频指向候选 3；刷新后不变；另一个浏览器中基于旧版本改选时提示“内容已被修改”。

### GEN-03 批量生成

- 优先级：MVP ｜ 关联：UC-16
- 用户故事：作为制作者，我希望对整场或整集的镜头一次发起生成。
- 业务规则：批量报价列出每个镜头的费用与合计；可剔除个别镜头；确认后每个镜头独立执行；批量结果汇总成功、失败与未知数量。
- 验收标准：Given 整场 20 个镜头批量生成，其中 2 个失败，When 查看批次，Then 18 个成功、2 个失败各有原因，失败项可单独重试。

### GEN-04 任务中心

- 优先级：MVP ｜ 关联：G7、UC-17
- 用户故事：作为制作者，我希望在一个地方看到所有生成任务的状态。
- 业务规则：状态：排队、进行中、成功、失败（附原因）、结果未知、待人工核对、已取消；可按项目、集、类型、状态筛选；状态变化实时更新（0202 PERF-03）。
- 验收标准：Given 任务进行中时服务重启，When 服务恢复后刷新任务中心，Then 任务状态正确并继续推进。

### GEN-05 相同输入复用结果

- 优先级：MVP ｜ 关联：UC-16
- 用户故事：作为制作者，我希望重复提交完全相同的生成请求时不再重复付费。
- 业务规则：输入（模型、参数、参考版本、提示词）完全相同且已有成功结果时，报价为 0 并直接复用结果；用户可选择“强制重新生成”（按正常费用报价）。
- 验收标准：Given 镜头 3 已用相同输入生成成功，When 再次请求报价，Then 报价显示“复用已有结果，费用 0”。

### GEN-06 结果未知先对账

- 优先级：MVP ｜ 关联：UC-17
- 用户故事：作为制作者，我不希望因为网络问题被重复扣费。
- 业务规则：提交后未收到供应商明确响应时，任务进入“结果未知”，系统用原请求标识查询真实状态；供应商不支持查询时进入“待人工核对”，不自动重新提交。
- 验收标准：Given 模拟供应商提交超时但实际已受理，When 对账完成，Then 任务状态与供应商一致，账本只记录一次费用。

### GEN-07 取消任务

- 优先级：MVP ｜ 关联：UC-17
- 业务规则：排队中的任务可直接取消并释放预留；进行中的任务在供应商支持时同步取消，已产生费用按实际结算。
- 验收标准：Given 排队中的任务，When 取消，Then 状态为已取消，预留全部释放。

### GEN-08 切换供应商与模型

- 优先级：V1 ｜ 用户故事：作为制作者，我希望同一能力可以切换到其他供应商的模型，以便比较质量与价格。

### VID-04 全能参考生视频

- 优先级：MVP（必须） ｜ 关联：P10、UC-12
- 用户故事：作为制作者，我希望用镜头的参考组合（多角色造型图、场景图、道具图、动作 / 运镜参考视频、参考音频）加镜头参数与画面描述直接生成视频。
- 业务规则：生成输入为镜头当前版本参考组合展开后的全部项；片段记录所用参考版本；参考组合中任一项更新后，已生成片段标记过期。
- 验收标准：
  - Given 参考组合含角色 A v1、角色 B v1、场景 S v1，When 生成视频，Then 任务输入与片段记录均包含这 3 项及其版本。
  - Given 双角色同框镜头，When 生成完成，Then 人工抽检两人外观与各自锁定造型一致。
  - Given 参考组合含运镜参考视频，When 生成完成，Then 人工判断运镜与参考一致。

  - Given 写实与风格化项目，When 各执行上述场景，Then 均通过。

- 优先级：V1 ｜ 用户故事：作为制作者，我希望用上一镜的片段作为下一镜的参考，保持连续性。

- 优先级：MVP ｜ 关联：UC-15

- 验收标准：Given 1 个镜头未选定片段、1 个镜头素材过期，When 请求渲染，Then 渲染被阻止并列出未选定镜头；过期镜头只显示提示。

## 14. 媒体库（MED）

### MED-01 上传素材

- 优先级：MVP ｜ 关联：UC-20
- 用户故事：作为制作者，我希望上传图片、视频、音频作为参考或替换素材。
- 业务规则：图片（jpg / png / webp，≤ 20 MB）、视频（mp4 / mov，≤ 500 MB，≤ 60 秒）、音频（mp3 / wav / m4a，≤ 100 MB）；浏览器直传对象存储并显示进度；上传后自动探测元数据、生成缩略图、内容审核；全部通过后状态为“就绪”。
- 异常处理：格式或大小不符在选择文件时即提示；探测或审核失败显示原因，素材不可引用。
- 验收标准：Given 上传 300 MB 视频，When 上传完成，Then 显示时长、分辨率与缩略图，状态为就绪。

- 验收标准：Given 项目有 2,000 个媒体条目，When 按“视频、已被引用”筛选，Then 1 秒内返回结果并可预览。

### MED-03 删除素材

- 优先级：MVP ｜ 关联：UC-20
- 业务规则：被正式对象引用的素材不能删除，提示引用位置；未引用素材软删除，30 天后清理。
- 验收标准：Given 某视频被镜头 8 选定，When 删除，Then 被拒绝并提示“被第 1 集镜头 8 使用”。

### MED-04 来源与合规信息

- 优先级：MVP ｜ 关联：CMP-02、CMP-03、CMP-06
- 业务规则：每个素材显示来源（上传人 / 生成操作 / 供应商与模型 / 服务区域）、审核结果、授权声明、AIGC 标识状态。

## 16. 成本（CST）

### CST-04 价格表

- 优先级：MVP ｜ 业务规则：管理员维护各模型价格规则；价格变更产生新版本，只影响之后的报价；已确认的报价按原价格结算预留。
