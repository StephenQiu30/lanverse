## 1. 需求说明

### 1.1 背景与目标

声音以 AI 配音为主（P8）。同一角色全剧使用同一音色才有辨识度，因此音色是设定集的一部分，配音时默认使用。

### 1.2 用户故事

- 作为**制作者**，我希望为每个角色选择音色并试听，角色的所有台词默认使用该音色。

### 1.3 范围

- 包含：音色库浏览（按模型）、试听（付费确认）、设置默认语速与情绪、修改音色后的影响。
- 不包含：声音克隆、旁白音色的独立管理（旁白作为一个特殊“角色”处理）。

## 2. 需求分析

### 2.1 业务流程

```text
打开角色 → 选择 TTS 模型 → 音色库（名称、性别、年龄感、风格标签、官方示例音频）
→ 试听：用该角色的一句台词或固定示例文本生成（报价确认；复用规则避免重复收费）
→ 设为角色音色（可调默认语速、情绪）→ 保存
修改音色 → 该角色已生成的台词音频标记过期（REQ-31）
```

### 2.2 业务规则

| # | 规则 | 理由 |
| --- | --- | --- |
| R1 | 音色列表来自模型注册表中 `voice` 组件参数的枚举（含示例音频 URL） | 与模型解耦（REQ-08） |
| R2 | 官方示例音频免费播放；用角色台词试听属于付费生成，须确认 | GEN-11 |
| R3 | 相同文本、音色、参数的试听复用已有结果 | GEN-05 |
| R4 | 旁白作为系统内置角色“旁白”，同样设置音色 | 统一处理 |
| R5 | 音色变更（`voice_profile.revision` +1）使该角色 TTS 台词音频过期 | LIN-01 |

### 2.3 状态

无独立状态；`voice_profile.revision` 作为依赖版本。

### 2.4 异常与边界

注册表中音色被下架：角色音色显示“不可用”，配音报价返回 `model_unavailable`，提示更换。

### 2.5 前置与依赖

TTS 模型（MiniMax Speech 或豆包语音）已在注册表中启用。

## 3. 验收标准

- Given 角色 A 选择音色 X，When 为 A 的台词生成配音，Then 默认使用音色 X。
- Given A 已有 37 句 TTS 配音，When 更换音色，Then 37 句配音标记过期。
- Given 用同一句台词、同一音色试听两次，When 第二次报价，Then 显示复用、费用 0。
