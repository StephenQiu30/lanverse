# FR-016 协作审片、审核与批准需求规格说明书

## 1. 目的与范围

对剧本、创作资产、生成候选、镜头和整集成片建立统一的提交、评论、整改、批准和采用机制，使每个生产决定都对应明确对象、固定版本、责任人和时间记录。

本能力不负责修改被审核内容，也不以评论数量或播放行为推导审核结论。

## 2. 参与角色

- 提交人：提交固定版本并处理整改意见。
- 审核人：查看审核对象、发表评论并作出授权范围内的决定。
- 批准人：对关键基线、整集成片或交付门禁作出最终决定。
- 查看者：仅查看获授权内容和已公开评论。

## 3. 主业务流程

1. 提交人选择明确对象版本并提交审核。
2. 系统创建审核轮次并固定该轮审核范围。
3. 审核人针对整体、时间点或指定区域提出意见。
4. 提交人回复意见并提交新版本或说明无需修改的理由。
5. 审核人作出通过、要求修改、拒绝或终止决定。
6. 具备采用权限的人员将通过候选设为当前采用版本。
7. 系统保留轮次、意见、整改和决定的完整关系。

## 4. 功能需求

| 编号 | 规范性需求 | 优先级 |
| --- | --- | --- |
| FR-016-001 | 系统应允许授权用户提交明确且不可变的对象版本进入审核。 | P0 |
| FR-016-002 | 系统应为每次提交创建独立审核轮次并记录提交人、审核人、范围和截止时间。 | P0 |
| FR-016-003 | 系统应允许审核人对整体对象、文本范围、结构化字段、视频或音频时间点、字幕条目或画面区域发表评论。 | P0 |
| FR-016-004 | 系统应允许意见被回复、标记已处理或重新打开。 | P0 |
| FR-016-005 | 系统应区分普通评论、整改要求和阻断问题。 | P0 |
| FR-016-006 | 系统应允许有权审核人作出通过、要求修改、拒绝或终止决定。 | P0 |
| FR-016-007 | 系统应记录每项审核决定的决定人、时间、理由和所依据的对象版本。 | P0 |
| FR-016-008 | 系统应在要求修改后允许提交新版本进入新的审核轮次，并保留旧轮次。 | P0 |
| FR-016-009 | 系统应将审核通过与候选采用维护为两个独立业务事实。 | P0 |
| FR-016-010 | 系统应允许具备采用权限的人员在已通过候选中指定当前采用版本。 | P0 |
| FR-016-011 | 系统应在已通过或已采用对象的上游发生变化后将其标记为待复核。 | P0 |
| FR-016-012 | 系统应支持生成受限、限时且可撤销的外部审片访问。 | P1 |
| FR-016-013 | 系统应允许同一对象版本按审核目的、范围和审批阶段维护相互独立的审核决定。 | P0 |

## 5. 业务规则

- BR-016-001：未发表评论不等于审核通过。
- BR-016-002：任务执行完成不等于候选审核通过。
- BR-016-003：候选审核通过不等于当前采用，整集审核通过也不等于正式交付。
- BR-016-004：审核对象必须是固定版本；审核期间的新修改必须进入新版本。
- BR-016-005：评论、审核决定、采用决定和交付批准应分别授权。
- BR-016-006：同一对象版本、审核目的、范围和审批阶段的最终决定只能有一个当前有效结果，后续变化应形成新决定记录。

## 6. 数据要求

- DR-016-001：保存审核对象类型、对象标识、版本、审核轮次、参与人和截止时间。
- DR-016-002：保存评论位置、正文、回复、状态、整改关系和附件引用。
- DR-016-003：保存审核目的、范围、审批阶段、审核决定、采用关系、决定理由和完整历史。

## 7. 异常与恢复

| 场景 | 系统行为 |
| --- | --- |
| 审核对象版本失效 | 保留审核记录并标识对象不可继续决策，不转移到其他版本。 |
| 无决定权限用户尝试批准 | 拒绝操作并记录审计事件。 |
| 提交人在审核期间修改内容 | 创建新草稿，当前审核轮次继续指向原版本。 |
| 已采用候选被判定不可用 | 撤销当前采用关系并阻断依赖该版本的新交付，保留历史决定。 |

## 8. 验收标准

- AC-016-001：审核期间修改对象不会改变该审核轮次所查看的版本。
- AC-016-002：一个只发表评论但未作决定的审核轮次不得显示为通过。
- AC-016-003：要求修改后提交新版本会形成新轮次，旧意见和决定仍可查询。
- AC-016-004：无批准权限的用户不能作出通过决定，且被审核对象状态不改变。
- AC-016-005：任一当前采用镜头均可追溯采用人、采用时间、审核轮次和媒体版本。
- AC-016-006：同一成片版本的艺术审核与合规审核能够分别形成决定，且互不覆盖。
