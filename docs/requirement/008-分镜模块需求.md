# REQ-008 分镜模块需求

- 状态：待确认
- 输入：`001-平台总体需求概述.md`、`003-项目模块需求.md`、`005-审核治理模块需求.md`、`006-剧本模块需求.md`、`007-资产模块需求.md`
- 输出：Shot、ShotSpecVersion、镜头顺序、结构准备度和编辑命令需求
- 下游：REQ-009、REQ-010

## 1. 需求概述

分镜模块必须把剧本场景转化为可独立生成、审核、返工和计费的 Shot。每个 Shot 通过不可变 ShotSpecVersion 固定镜头语言、叙事内容和资产引用；readiness 由事实实时计算，不由用户勾选或前端猜测。

ShotSpec 是一个聚合整体。MVP 不为详情、对白、关键帧和资产关联分别暴露全套子表 CRUD，避免一次镜头编辑需要多组不一致请求。

## 2. 业务实体需求

| 编号 | 实体 | 需求 |
| --- | --- | --- |
| SBD-ENT-001 | Shot | 必须归属 Episode，保存稳定 ID、顺序、标题、Script Scene 引用、当前规格版本 ID 和生命周期状态。 |
| SBD-ENT-002 | ShotSpecVersion | 必须不可变，保存来源 ScriptVersion、景别/机位/运镜、构图/站位、动作节拍、对白/旁白、时长、情绪/光照和生成意图。 |
| SBD-ENT-003 | AssetReference | 必须作为 ShotSpecVersion 的组成部分引用固定 AssetVersion，并表达角色/场景/道具/服装/风格/声音用途。 |
| SBD-ENT-004 | Readiness | 必须是派生查询结果，包含 ready、阻塞原因、警告和下一动作，不作为可修改实体。 |

关键帧、视频、语音和音效候选属于 production/media；分镜模块只引用选用结果，不覆盖 ShotSpecVersion。

## 3. ShotSpec 最小内容要求

| 分类 | 最小内容 |
| --- | --- |
| 叙事 | 来源场景/片段、镜头目的、动作节拍、对白/旁白、预期时长 |
| 画面 | 景别、机位角度、运镜、主体站位、环境、构图、光照/情绪 |
| 一致性 | 固定角色/场景/道具/服装/风格 AssetVersion 引用 |
| 生成意图 | 文/图/参考生成类型、首尾/关键帧意图、允许模型能力类别 |
| 声音 | 说话主体、声音 AssetVersion、语速/情绪提示、环境音/音效意图 |

供应商专属参数不进入 ShotSpec；production 根据 ModelCapability 进行提交前适配和校验。

## 4. 功能性需求

| 编号 | 需求 |
| --- | --- |
| SBD-FR-001 | editor/owner 必须能在 Episode 内创建、列表、读取和修改 Shot 的标题等可变元数据。 |
| SBD-FR-002 | 用户必须能从剧本提取候选创建 Shot，或手工新增 Shot；重复候选决议不得重复创建。 |
| SBD-FR-003 | 用户必须能保存 ShotSpec 草稿为新 ShotSpecVersion，并查看历史和切换当前版本。 |
| SBD-FR-004 | 用户必须能原子重排 Episode 内 Shot，且序号连续、唯一并以服务端结果为准。 |
| SBD-FR-005 | 用户必须能复制、拆分和合并 Shot；操作只重组规格草稿，不自动复制媒体、任务或费用。 |
| SBD-FR-006 | 用户必须能显式把选定 Shot 的固定 AssetVersion 引用升级到新版本，并得到影响预检。 |
| SBD-FR-007 | 系统必须计算单 Shot 和批量 readiness，返回缺失规格、资产、授权、时长及下一动作。 |
| SBD-FR-008 | readiness 通过后用户才能进入生产预检；警告可以确认继续，阻塞项不得绕过。 |
| SBD-FR-009 | 用户必须能归档/恢复 Shot；只有无规格历史、任务、媒体、费用和审核引用的空草稿可删除。 |
| SBD-FR-010 | ScriptVersion 切换或 AssetVersion 失效时，系统必须指出受影响 Shot，不自动篡改既有规格。 |

## 5. 接口需求

| 编号 | 接口能力 | 输入 | 输出与错误 |
| --- | --- | --- | --- |
| SBD-IF-001 | Shot CRUD/归档 | ActorContext、Episode、允许元数据 | Shot；父级归档或存在删除阻塞时返回错误/清单 |
| SBD-IF-002 | 保存规格版本 | Shot ID、完整类型化规格、期望当前版本 | 新 ShotSpecVersion 与 readiness；并发变化返回版本冲突 |
| SBD-IF-003 | 版本列表/详情/切换 | Shot/Version ID、期望旧 ID | 历史或当前引用；跨 Shot 版本拒绝 |
| SBD-IF-004 | 重排镜头 | Episode ID、完整有序 Shot ID 列表 | 原子更新后的镜头摘要；缺失/重复/越权 ID 拒绝 |
| SBD-IF-005 | 复制/拆分/合并 | 源 Shot、切分点或相邻 Shot、目标顺序 | 新/变更 Shot 与规格草稿；不返回伪造媒体选择 |
| SBD-IF-006 | readiness 查询 | Shot/Episode ID、可选版本 | ready、blocking_reasons、warnings、next_actions |
| SBD-IF-007 | 资产引用升级 | Shot 列表、旧/新 AssetVersion、期望规格版本 | 每个目标的预检或新规格版本；默认冲突时整体失败 |
| SBD-IF-008 | 生产读取快照 | ShotSpecVersion ID | production 所需稳定 DTO 与 input hash 基础，不含供应商参数 |

## 6. 非功能性需求

| 编号 | 类别 | 需求 |
| --- | --- | --- |
| SBD-NFR-001 | 不可变 | ShotSpecVersion 只追加；切换当前版本、重排或归档不得改变历史规格内容。 |
| SBD-NFR-002 | 原子性 | 重排、拆分、合并和批量引用升级必须原子执行或返回逐项模式的明确结果，不留半更新顺序。 |
| SBD-NFR-003 | 可解释 | readiness 必须基于明确规则并返回字段/引用级证据，相同输入必须产生相同结果。 |
| SBD-NFR-004 | 可追溯 | ShotSpecVersion 必须关联来源 ScriptVersion、AssetVersion、创建人和由它产生的 GenerationRequest。 |
| SBD-NFR-005 | 并发 | 保存规格和切换版本必须使用期望当前版本防止静默覆盖；冲突时返回服务端最新版本。 |
| SBD-NFR-006 | 性能 | Episode 分镜列表、批量 readiness 和重排必须支持目标镜头规模；镜头上限与 P95 在 PRD 量化。 |
| SBD-NFR-007 | 可维护 | ShotSpec 子项以类型化聚合更新，不为每个子项机械建立 Router/Service/Repository 全套层。 |

## 7. 生命周期与失败路径

- Shot：`active ↔ archived`；生产/审核阶段由关联事实计算，不在 Shot 上任意 PATCH 状态。
- ShotSpecVersion：追加历史；当前版本指针可以切换，但已产生的 GenerationRequest 继续引用原版本。
- readiness 依赖变更后立即重新计算；曾经 ready 不代表永久 ready。
- 拆分/合并遇到已选媒体时必须明确提示媒体不会自动迁移，用户确认后才执行。
- 保存规格失败不得改变当前版本；并发冲突返回最新版本及重新应用修改所需信息。

## 8. 非目标与待确认

- 不做无限画布、专业镜头调度、复杂动画曲线或供应商参数编辑器。
- 不把生成状态、费用、媒体字节或审核决定写入 ShotSpec。
- 待确认单集镜头规模、ShotSpec 必填字段、默认时长范围、允许的警告绕过规则及拆分/合并交互语义。
