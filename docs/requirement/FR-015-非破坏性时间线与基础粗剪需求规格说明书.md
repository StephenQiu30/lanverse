# FR-015 非破坏性时间线与基础粗剪需求规格说明书

## 1. 目的与范围

以非破坏方式组织采用镜头、对白、字幕、音乐和音效，提供排序、替换、裁切、转场、基础速度和多轨编排，形成可完整播放的单集粗剪和成片快照。

本能力不替代完整专业级非线性编辑器、调色和复杂合成系统。

## 2. 主业务流程

1. 根据分镜顺序和当前采用候选创建自动粗剪草稿。
2. 剪辑人员调整顺序、入出点、替换、转场和多轨内容。
3. 系统检测缺失媒体、非法区间、异常空隙和重叠冲突。
4. 系统生成固定时间线版本对应的代理预览。
5. 剪辑人员创建不可变成片版本快照。
6. 成片版本进入整集审核和技术质检。

## 3. 功能需求

| 编号 | 规范性需求 | 优先级 |
| --- | --- | --- |
| FR-015-001 | 系统应允许时间线片段引用明确媒体版本而不修改源媒体。 | P0 |
| FR-015-002 | 系统应允许调整片段顺序、入点、出点和持续时长。 | P0 |
| FR-015-003 | 系统应允许替换片段来源并明确保持位置或重新适配结果。 | P0 |
| FR-015-004 | 系统应支持基础画面转场、速度调整和画幅适配。 | P0 |
| FR-015-005 | 系统应在独立轨道中组织对白、音乐、环境声、音效和字幕。 | P0 |
| FR-015-006 | 系统应记录每个片段与镜头、采用版本和源媒体的关系。 | P0 |
| FR-015-007 | 系统应检测缺失媒体、非法区间、异常空隙、重叠冲突和不可播放片段。 | P0 |
| FR-015-008 | 系统应支持生成与固定时间线版本对应的代理预览。 | P0 |
| FR-015-009 | 系统应允许创建不可变的成片版本快照。 | P0 |
| FR-015-010 | 系统应在上游内容或采用变化后标识受影响片段而不自动替换。 | P0 |
| FR-015-011 | 系统应保留被替换片段和历史成片版本的引用关系。 | P0 |
| FR-015-012 | 系统应支持导出基础可交换时间线或制作清单。 | P1 |

## 4. 业务规则

- BR-015-001：所有时间线编辑均为非破坏性。
- BR-015-002：自动粗剪只形成草稿。
- BR-015-003：预览完成不等于整集审核通过。
- BR-015-004：已审核或已交付时间线版本不得原位修改。
- BR-015-005：代理文件与高分辨率母版必须保持明确对应关系。

## 5. 数据要求

- DR-015-001：保存时间线版本、轨道、片段、源媒体、入出点、顺序、转场和速度。
- DR-015-002：保存代理与母版关系、预览和成片快照。
- DR-015-003：保存上游影响、片段替换和历史版本关系。

## 6. 异常与恢复

| 场景 | 系统行为 |
| --- | --- |
| 来源媒体失效 | 保留片段位置和引用，阻止生成完整预览。 |
| 已提交审核版本被编辑 | 创建新草稿版本，原审核对象不变。 |
| 代理与母版不一致 | 阻止正式输出并要求重建或校验。 |
| 上游采用版本变化 | 标识相关片段待复核，不自动替换。 |

## 7. 验收标准

- AC-015-001：裁切片段后，源媒体保持不变。
- AC-015-002：编辑已提交审核的版本会创建新草稿。
- AC-015-003：源媒体不可访问时，时间线保留位置并报告阻塞。
- AC-015-004：任一历史成片版本可还原所用视频、音频和字幕版本。
