# FR-010 AI 制作任务编排与异常恢复需求规格说明书

## 1. 目的与范围

把已经确认的制作目标组织为可追踪、可取消、可恢复、可核对成本的单项或批量任务，并管理输入基线、尝试、进度、错误和局部返工。

本能力不决定候选是否通过或采用。

## 2. 主业务流程

1. 系统汇总内容、资产、权限、能力、预算、权利和安全条件。
2. 返回“可开始”或带责任方和下一动作的“尚不可开始”。
3. 用户确认范围和预计用量后创建单项或批量任务。
4. 系统固定每次尝试的输入基线并执行。
5. 系统持续更新进度，形成结果、部分结果、失败或取消事实。
6. 用户按单项重试、补做、取消或根据审核意见局部返工。

## 3. 功能需求

| 编号 | 规范性需求 | 优先级 |
| --- | --- | --- |
| FR-010-001 | 系统应在启动前检查内容、资产、权限、能力、权利、安全、预算和额度条件。 | P0 |
| FR-010-002 | 系统应为每个阻塞指出对象、原因、责任方和下一动作。 | P0 |
| FR-010-003 | 系统应在启动前显示预计用量或说明无法准确估算。 | P0 |
| FR-010-004 | 系统应为一个明确资产或镜头目标建立独立任务。 | P0 |
| FR-010-005 | 系统应为任务记录责任人、优先级、依赖、预期结果和所属项目。 | P0 |
| FR-010-006 | 系统应允许把多个已就绪任务组织为批次，同时保留各子项独立状态。 | P0 |
| FR-010-007 | 系统应为首次执行、重试、补做、返工和外部补入分别建立独立尝试。 | P0 |
| FR-010-008 | 系统应为每次尝试固定内容、资产、参考和业务限制版本。 | P0 |
| FR-010-009 | 系统应区分排队、执行、后处理、成功、部分结果、失败、取消和状态未知。 | P0 |
| FR-010-010 | 系统应允许批次子项独立取消、重试、补做和提交审核。 | P0 |
| FR-010-011 | 系统应区分创作质量不合格与平台或供应执行故障。 | P0 |
| FR-010-012 | 系统应把局部返工关联到原候选、原问题和修改范围。 | P0 |
| FR-010-013 | 系统应在上游基线变化后标记运行任务和结果待复核，而不静默更换输入。 | P0 |
| FR-010-014 | 系统应保证重复请求、回调和重试不会重复创建任务或执行尝试。 | P0 |
| FR-010-015 | 系统应阻止前置依赖未达到所需状态的任务开始执行。 | P0 |
| FR-010-016 | 系统应在前置依赖达到所需状态后解锁后续任务。 | P0 |
| FR-010-017 | 系统应根据明确规则将前置任务失败或取消后的后续任务标记为阻断、跳过或待人工决定。 | P0 |
| FR-010-018 | 系统应检测并拒绝形成循环依赖的任务关系。 | P0 |
| FR-010-019 | 系统应在上游任务重做或结果失效后标识依赖的下游任务和结果待复核。 | P0 |

## 4. 业务规则

- BR-010-001：一个任务围绕一个可判断的结果目标。
- BR-010-002：批次是任务集合，不是不可分割的大任务。
- BR-010-003：等待用户、等待上游、等待平台和正常执行必须区分。
- BR-010-004：局部问题不得默认重做整批或整集。
- BR-010-005：任务执行完成不等于候选可用、审核通过或正式采用。
- BR-010-006：任务依赖必须指明所需前置状态，存在依赖不等于允许提前执行。

## 5. 数据要求

- DR-010-001：保存任务、批次、目标、责任人、优先级、依赖、状态和幂等标识。
- DR-010-002：保存每次尝试的输入快照、能力、供应请求、进度、结果和错误。
- DR-010-003：保存返工、原候选、问题范围、新尝试和用量引用。

## 6. 异常与恢复

| 场景 | 系统行为 |
| --- | --- |
| 批次部分失败 | 隔离失败子项，保留已完成结果并允许单独重试。 |
| 取消后结果迟到 | 隔离为迟到结果，未经人工确认不进入正常候选。 |
| 状态长期无更新 | 标记状态未知或需运营处理，不假装持续正常执行。 |
| 输入基线已变化 | 要求重新检查制作条件，不自动替换运行任务输入。 |
| 新依赖形成闭环 | 拒绝保存依赖关系并列出冲突任务。 |

## 7. 验收标准

- AC-010-001：批次中一个镜头失败不影响其他成功镜头。
- AC-010-002：重复启动请求返回已有任务，不创建重复消费。
- AC-010-003：任务运行期间资产更新，本次尝试仍保留原输入并显示待复核。
- AC-010-004：取消后迟到结果不会自动出现在正常候选列表。
- AC-010-005：前置任务未完成时后续任务不能启动，完成后按所需状态自动解锁。
- AC-010-006：形成循环依赖的任务关系不能被保存。
