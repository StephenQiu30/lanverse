本文定义**有哪些页面、每页放什么、关键交互如何表现**。视觉样式（颜色、字体、间距、无边框规则）以 DESIGN.md 为准，本文不重复。

## 1. 设计原则

1. **流程即导航**：流水线视图按 0203 §3 的十个阶段组织，用户随时知道“这一集做到哪一步、下一步是什么”。
2. **原文与结果并排**：解析、分镜等 AI 结果与其依据（原文、参考）同屏显示，可互相定位。
3. **候选对比优先**：所有生成结果以并排候选呈现，选定是明确的一次点击。
4. **费用始终可见**：任何会产生费用的按钮旁显示预估费用；确认弹窗显示报价与剩余预算。
5. **状态不隐藏**：异步状态、过期标记、缺失引用在列表、卡片、故事板上都直接可见。
6. **批量优先**：一集 20–150 个镜头，所有高频操作支持多选与批量。

## 2. 信息架构

```text
登录
└─ 应用外壳（顶栏：项目切换、任务中心入口、通知、用户菜单）
   ├─ 项目列表
   ├─ 项目（左侧导航）
   │  ├─ 概览
   │  ├─ 剧本（导入、分集、逐集解析）
   │  ├─ 设定集（角色 / 造型、场景、道具、音色）
   │  ├─ 集（选择一集后进入逐集生产）
   │  │  ├─ 资产定稿
   │  │  ├─ 分镜（镜头表 / 故事板）
   │  │  ├─ 镜头详情（关键帧、视频、参考组合）
   │  │  ├─ 配音与字幕
   │  │  ├─ 剪辑
   │  │  └─ 交付
   │  ├─ 画布（V1）
   │  ├─ 媒体库
   │  ├─ 影响清单
   │  ├─ 成本
   │  └─ 设置（基本信息、预算、生成策略、AIGC 标识样式）
   ├─ 任务中心（跨项目，可按项目筛选）
   ├─ Agent 面板（V1，项目内右侧抽屉，全局唤起）
   └─ 管理（仅管理员）
      ├─ 账号
      ├─ 供应商凭据
      ├─ 模型注册表与价格
      ├─ 审计日志
      └─ 系统健康（V1）
```

URL 需可直接访问与分享（同组织内），包括项目、集、镜头、任务、成片版本；刷新后停留在同一对象与同一视图状态（筛选、选中镜头）。

## 4. 关键交互

### 4.1 报价与二次确认（全局统一组件）

- 触发生成的按钮文案为“生成（约 ¥X）”；批量时为“批量生成 N 项（约 ¥X）”。
- 点击后弹出确认对话框：模型、数量、逐项费用（批量可展开）、合计、剩余预算、报价有效期倒计时、服务区域（境外时显示警示）。
- 预算不足时确认按钮禁用并显示差额；复用结果时显示“复用已有结果，¥0”并提供“强制重新生成”。
- 确认按钮不接受回车默认触发，需要点击或显式快捷键，防止误触。
- 所有入口（流水线、画布、Agent、批量）使用同一组件，不允许各自实现（0201 GEN-11）。

### 4.2 候选对比与选定

- 候选以网格显示（2–4 列），视频支持同步播放、逐帧步进、静音切换。
- 选定后候选角标显示“已选定”，其他候选保留；改选需确认（会触发下游过期时显示影响数量）。
- 版本冲突时 toast 提示“内容已被他人或其他页面修改”，并提供“刷新”。

### 4.3 状态标识

统一使用徽标（形状 + 文字，不只靠颜色）：

| 状态 | 文案 |
| --- | --- |
| 未生成 | 未生成 |
| 排队中 / 进行中 | 排队中 / 生成中（附进度或已用时长） |
| 待选 | 待选 N |
| 已选定 | 已选定 |
| 失败 | 失败（悬停显示原因） |
| 结果未知 / 待人工核对 | 核对中 / 待核对 |
| 过期 | 过期（悬停显示上游变化） |
| 缺失引用 | 缺失：〈对象名〉 |

### 4.4 参考组合编辑

- 参考项以卡片列表展示：缩略图、名称与版本、用途下拉、移除。
- 添加方式：从设定集选择锁定造型 / 场景 / 道具；从媒体库选择就绪素材；选择本镜台词音频；拖拽上传（先进媒体库）。
- 顶部显示所选模型的各类上限（如“图片 3/9、视频 1/3、音频 1/3”），超出标红。

### 4.5 原文定位

- 点击解析结果中的任一条目，原文面板滚动并高亮对应范围；反向在原文中选中文字，可高亮对应条目。

### 4.6 实时更新与离线

- 状态变化通过服务端推送实时更新，不需要手动刷新（0202 PERF-03）。
- 连接断开时顶栏显示“连接已断开，正在重连”；重连后自动补齐。

### 4.7 长操作与撤销

- 导入、批量操作在后台执行，页面可离开；完成后通知（NTF-01）。
- 非付费的编辑操作提供撤销（toast 内“撤销”，10 秒）；付费生成、选定、确认不提供撤销，只能改选或产生新版本。

### 4.8 画布（V1）

画布的节点、连线、布局、性能等设计在 0306 中定义；需求层约束：

- 画布与流水线任意一侧的修改，另一侧在 2 秒内可见。
- 节点可一键跳转到流水线中的对应对象，反之亦然。
- 画布上的生成使用 §4.1 的确认组件。

### 4.9 Agent 面板（V1）

- 右侧抽屉，项目内任意页面可唤起；显示流式回复、执行步骤、工具结果。
- 提案以差异卡片展示（对象、字段、旧值 → 新值），提供“应用”“拒绝”；付费草稿显示报价并使用 §4.1 组件确认。

## 5. 通用状态

每个列表与详情页须设计以下状态：

| 状态 | 要求 |
| --- | --- |
| 加载中 | 骨架屏，保持布局稳定 |
| 空 | 说明为何为空 + 下一步操作按钮（如“导入剧本”） |
| 错误 | 说明原因 + 重试；不显示堆栈或内部标识（可复制追踪 ID） |
| 无权限 | 说明并提供返回 |
| 部分失败 | 批量结果分组显示成功、失败、未知 |
| 只读 | 已归档项目、已锁定版本明确标注只读 |

## 6. 表单与校验

- 字段级即时校验，提交时汇总；错误信息说明如何修正。
- 不可修改的字段（画幅、风格类型）在编辑页以只读形式显示，并说明原因。
- 未保存修改离开页面时提示。

## 7. 快捷键

| 范围 | 快捷键 | 操作 |
| --- | --- | --- |
| 全局 | `Cmd/Ctrl + K` | 命令面板（跳转项目、集、镜头、页面） |
| 全局 | `?` | 快捷键帮助 |
| 全局（V1） | `Cmd/Ctrl + J` | 打开 / 关闭 Agent 面板 |
| 镜头表 / 故事板 | `↑ ↓` / `J K` | 上一 / 下一镜头 |
| 镜头表 / 故事板 | `Enter` | 打开镜头详情 |
| 候选对比 | `1`–`9` | 聚焦第 N 个候选 |
| 候选对比 | `S` | 选定当前候选 |
| 播放器 | `Space` / `← →` | 播放暂停 / 逐帧 |
| 画布（V1） | `Cmd/Ctrl + Z` / `Shift + Cmd/Ctrl + Z` | 撤销 / 重做 |
| 画布（V1） | `Cmd/Ctrl + C / V`、`Delete` | 复制、粘贴、删除节点 |

快捷键不得触发付费确认。

## 8. 响应式与设备

- 生产操作面向桌面，最小宽度 1280 px（0202 CPT-01）；1280–1440 px 时侧栏可折叠。
- 手机宽度仅保证登录、项目概览、任务中心可用（V1，0202 CPT-02）。

## 9. 无障碍与文案

- 遵循 0202 A11Y-01；状态不只用颜色表达；所有图标按钮有文字标签。
- 界面术语使用 0204 中文术语；金额显示到分，单位“¥”；时长显示为“秒”或“分:秒”。
