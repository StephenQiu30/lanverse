# REQ-29 台词配音与真人音轨

| 项 | 内容 |
| --- | --- |
| 需求 | AUD-01 台词配音；AUD-02 上传真人音轨替换 |
| 优先级 | MVP（AUD-01）；AUD-02 真人音轨替换为 V2（PRD-01 P26） |
| 用例 | UC-13 |
| 页面 | 配音与字幕 |
| 依赖功能 | REQ-13、REQ-16、REQ-21、REQ-22、REQ-30 |
| 设计 | [DES-32 台词配音与真人音轨](../design/32-台词配音与真人音轨.md) |
| 状态 | 草案（2026-09-25） |

## 1. 需求说明

### 1.1 背景与目标

声音以 AI 配音为主，可替换为上传的真人音轨（P8）。每句台词独立生成、试听、选定；真人录音可以按句或按整场上传后切分对齐。

### 1.2 用户故事

- 作为**制作者**，我希望按角色音色为每句台词生成配音，并可调整语速与情绪。
- 作为**制作者**，我希望上传真人录音替换某句或整场的配音，并能切回 TTS。

### 1.3 范围

包含：MVP——批量 TTS、逐句重生成、语速与情绪、选定；V2——单句上传、整场上传与切分对齐、切回 TTS。不包含：口型同步（待定）、声音克隆（V2）、BGM（V2）。

## 2. 需求分析

### 2.1 业务流程

```text
配音页：列出本集台词（按场）→ 批量报价（未配音 / 过期的台词）→ 确认 → 逐句 TTS → 候选
→ 试听 → 选定（line_audio_selection）
（V2）上传：单句上传 → 审核 → 成为候选 → 选定
（V2）整场上传：上传整段录音 → 系统按台词文本做强制对齐（ASR + 文本对齐）给出建议切分 → 用户调整分界 → 切分为每句候选 → 选定
```

### 2.2 业务规则

| # | 规则 | 理由 |
| --- | --- | --- |
| R1 | 默认使用角色音色（REQ-16）与其默认参数；可逐句覆盖语速（0.5–2.0）与情绪（模型支持的枚举） | AUD-01 |
| R2 | 台词文本（`content_hash`）变化或角色音色变化 → TTS 音频过期；上传的真人音轨只在文本变化时过期 | LIN-01 |
| R3 | 选定以 `(episode_id, line_key)` 为键，跨结构版本有效 | 稳定键 |
| R4 | （V2）替换后原 TTS 候选保留，可切回 | AUD-02 |
| R5 | （V2）上传格式 mp3 / wav / m4a，统一转码为 48 kHz 单声道 WAV 存储渲染用版本 | 渲染一致 |
| R6 | （V2）整场对齐的 ASR 调用属于付费生成（报价确认）；用户也可以不用 ASR，手动切分 | GEN-11 |
| R7 | 选定音频的时长写入台词（MVP 用于镜头时长参考；V2 供自动粗剪与字幕） | EDT-01、AUD-03 |

### 2.3 状态

台词配音状态：未配音 → 生成中 → 待选 → 已选（TTS / 真人）；叠加“过期”。

### 2.4 异常与边界

- TTS 对特殊字符 / 多音字：支持在台词上设置“发音修正文本”（只影响 TTS 输入，不改台词），作为 TTS 参数。
- 台词为空或仅动作：不生成。

## 3. 验收标准

- Given 第 1 集 48 句台词，When 批量生成配音并选定，Then 每句台词都有选定音频，时长记录在台词上。
- （V2）Given 某句台词已有 TTS，When 上传真人录音并选定，Then 剪辑使用真人录音；切回 TTS 后剪辑随之更新。
- （V2）Given 一段整场录音，When 按建议切分并调整后提交，Then 每句台词生成一个真人音轨候选，时长与切分一致。
- Given 台词文本被修改，When 查看配音，Then 该句 TTS 音频标记过期（V2 起真人音轨同样标记）。
