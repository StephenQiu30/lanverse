## 3. 业务阶段

一部剧的生产分为十个阶段。前三个阶段按**全剧**执行一次（剧本修订时重做受影响部分），后七个阶段按**集**重复执行。**MVP（POC）覆盖阶段 1–8，阶段 9 剪辑与 10 交付在 V2（PRD-01 P25）。**

| # | 阶段 | 粒度 | 输入 | AI 产出（候选） | 人工确认点 | 正式输出 | 完成条件 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| 1 | 导入 | 全剧 | 剧本文件 | 集边界 | 确认分集 | 剧本版本、集列表 | 集列表已确认 |
| 2 | 结构解析 | 集 | 单集原文 | 场、台词、动作、时间地点 | 按集确认 | 集结构版本 | 无“待处理”台词且已确认 |
| 3 | 设定集 | 全剧 | 全部已解析集 | 角色、别名、造型、场景、道具 | 合并 / 拆分后确认 | 设定集条目 | 条目已确认 |
| 4 | 资产定稿 | 集 | 本集用到的设定条目 | 定妆照、三视图、场景图、道具图；音色建议 | 选定参考、选定音色 | 锁定的参考版本、角色音色 | 本集用到的条目全部锁定 |
| 5 | 分镜 | 集 | 集结构、锁定资产 | 镜头表（参数、台词分配、引用、建议模式与参考组合） | 按场确认，逐镜修改 | 镜头版本 | 所有台词已分配、无“缺失”引用 |
| 6 | 关键帧 | 镜头 | 镜头、锁定参考 | 首帧候选 | 选定 | 选定关键帧 | 图生视频镜头均已选定关键帧（全能参考镜头跳过） |
| 7 | 视频 | 镜头 | 关键帧或参考组合、镜头参数 | 视频候选 | 选定 | 选定片段 | 所有镜头已选定片段 |
| 8 | 配音 | 台词 | 台词、角色音色 | 台词音频 | 选定或替换为真人音轨 | 选定台词音频、字幕 | 所有台词有选定音频 |
| 9 | 剪辑（V2） | 集 | 选定片段、音频、字幕 | 自动粗剪 | 时间线编辑、保存 | 剪辑计划版本 | 渲染前校验通过 |
| 10 | 交付（V2） | 集 | 剪辑计划 | 渲染成片 | 审片 | 成片版本、字幕文件 | 成片质检通过 |

阶段之间**不是严格串行**：阶段 7 可在部分镜头完成阶段 6 后开始；阶段 8 可与阶段 6–7 并行；阶段 9 允许存在缺失片段（以占位显示），但阶段 10 要求校验通过。项目概览（REQ-01 PRJ-02）按阶段 2、4–8 统计完成度（V2 起加入 9–10）。

## 4. 主流程

### 4.1 端到端流程

```text
[管理员] 建账号 → 配凭据与模型 → 设价格
[制作者] 建项目（画幅、风格、预算、境外开关）
   → 导入整部剧 → 确认分集
   → 逐集解析（并行，按集确认）
   → 抽取全剧设定集 → 确认
   → 选择一集 ──────────────────────────────────────────────┐
        本集资产定稿（生成参考 → 报价确认 → 选定锁定；选音色）│
        → 生成分镜 → 按场确认 → 逐镜编辑参数、模式、参考组合  │
        → [关键帧：批量报价确认 → 选定]                       │ 每集重复；
        → 视频：批量报价确认 → 选定                           │ 已锁定资产跨集复用
        → 配音：批量报价确认 → 选定 / 替换真人音轨            │
        →（V2）自动粗剪 → 时间线编辑 → 渲染前校验            │
        →（V2）渲染 → 审片 → 导出成片与字幕 ──────────────────┘
```

### 4.2 付费生成子流程（UC-16）

```text
选择对象与模型 → 编辑参数 / 参考 → 请求报价
   ├─ 校验失败（能力、参考、境外、素材未就绪）→ 提示并返回编辑
   ├─ 相同输入已有结果 → 报价 0，复用结果（可选“强制重新生成”）
   └─ 报价成功 → 显示费用与剩余预算
        ├─ 预算不足 → 不可确认
        ├─ 超过 15 min 未确认 → 报价过期，重新报价
        └─ 用户确认 → 预留预算 → 提交供应商
              ├─ 成功 → 下载转存 → 审核 → 候选可见 → 结算
              ├─ 明确失败 → 结算（按供应商实际计费）→ 可重试（重新报价）
              ├─ 结果未知 → 对账 → 按真实状态继续；不支持查询 → 待人工核对
              └─ 用户取消 → 同步取消 → 结算
```

### 4.3 变更影响子流程（UC-18）

```text
上游产生新版本 → 系统计算下游依赖 → 标记“过期”并通知
   → 用户打开影响清单（按集 / 场 / 镜头，含状态与重做预估）
   → 勾选需重做的对象 → 进入批量报价（UC-16）
   → 未勾选对象保持过期标记，可随时处理；过期不阻止渲染，只提示
```

## 5. 关键用例规约

以下用例涉及付费、并发或跨阶段依赖，给出完整规约；其余用例的规则与验收见 REQ-01 对应需求。

### UC-06 解析并确认单集结构

- **前置**：集列表已确认。
- **触发**：用户对一集或多集发起解析。
- **主成功场景**：
  1. 系统为每集启动独立解析任务，界面显示各集进度。
  2. 解析完成后，界面左侧显示原文，右侧显示场、台词、动作列表；每条可定位原文。
  3. 用户修改场边界、说话人、情绪等。
  4. 用户确认本集，系统生成集结构正式版本。
- **扩展**：
  - 1a 某集失败：显示原因与“重试”，其他集不受影响。
  - 2a 存在“待处理”台词：确认按钮不可用，直到用户归属或删除这些台词。
  - 4a 该集已有分镜：确认后引用被修改台词的镜头标记过期（UC-18）。
- **后置**：集结构版本可被分镜引用。

### UC-10 编辑镜头生成模式与参考组合

- **前置**：镜头存在；项目已有锁定的资产版本或就绪的上传素材。
- **主成功场景**：
  1. 用户选择生成模式（图生视频 / 全能参考）与模型。
  2. 界面按模型能力显示各类参考上限与参数表单。
  3. 用户添加参考项并为每项指定用途（主体、场景、道具、动作、运镜、音频）。
  4. 用户保存，系统产生镜头新版本。
- **扩展**：
  - 3a 超出上限：该项标红，保存允许但报价阻止。
  - 3b 引用未就绪素材：该项标记“未就绪”，报价阻止。
  - 4a 版本冲突：提示内容已被修改，刷新后重新编辑。
  - 4b 镜头已有片段：旧片段标记过期（UC-18）。

### UC-12 生成并选定镜头视频

- **前置**：图生视频镜头已选定关键帧，或全能参考镜头参考组合有效。
- **主成功场景**：
  1. 用户对单镜头、整场或整集请求视频报价（包含 UC-16）。
  2. 确认后任务执行，候选陆续出现在镜头卡片与故事板。
  3. 用户逐个或并排播放候选，选定一个。
  4. 系统记录选定（附所用参考版本），镜头视频阶段完成。
- **扩展**：
  - 2a 任务期间用户修改镜头参数：结果仍作为候选出现，但标记“基于旧版本”（GEN-10）。
  - 3a 所有候选不满意：用户调整参数或参考后重新报价。
  - 4a 另一会话已选定其他候选：版本冲突提示。

### UC-17 跟踪、取消与恢复任务

- **主成功场景**：用户在任务中心按项目、集、类型、状态筛选，查看进度、失败原因与费用。
- **扩展**：
  - 服务重启：任务从断点继续，界面自动重连并补齐状态。
  - 结果未知：系统自动对账；对账结果写入任务并通知。
  - 待人工核对：管理员在供应商控制台确认后，在任务上标记“已成功（附结果标识）”或“未执行”，系统据此结算。
  - 取消：见 REQ-01 GEN-07。

### UC-22 与 Agent 对话创作（V2）

- **主成功场景**：
  1. 用户在项目内打开 Agent 面板并输入意图。
  2. Agent 流式回复，读取项目数据，给出修改提案（参数差异、画布变更）或生成草稿（含报价）。
  3. 用户确认提案，系统通过命令层执行；付费草稿进入二次确认（UC-16）。
- **扩展**：
  - 2a 提案所基于的数据已变化：执行时版本冲突，Agent 重新读取后给出新提案。
  - 3a 用户拒绝：提案丢弃，Agent 继续对话。
  - 断线：刷新后从最后一条消息继续。

## 6. 状态模型

状态名称为需求层定义；设计可增加内部状态，但对用户展示须映射到本节状态。

### 6.1 项目

```text
进行中 ──归档──→ 已归档 ──恢复──→ 进行中
进行中 / 已归档 ──删除──→ 回收中 ──30 天──→ 已清除
回收中 ──恢复──→ 原状态
```

约束：有进行中任务时不可删除；已归档项目只读。

### 6.2 解析与确认（适用于分集、集结构、设定集、分镜按场确认）

```text
未开始 → 进行中 → 待确认 ──确认──→ 已确认
            └─→ 失败 ──重试──→ 进行中
已确认 ──重新解析 / 修改──→ 待确认（新版本）
```

### 6.3 资产参考槽位（造型定妆照、三视图、场景图、道具图）

```text
空 → 生成中 → 有候选 ──选定──→ 已锁定(vN)
已锁定(vN) ──改选 / 上传新参考──→ 已锁定(vN+1)（触发 UC-18）
```

### 6.4 镜头

镜头有两个维度的状态：

- **内容状态**：`正常` / `过期`（上游版本变化后）/ `缺失引用`（引用了未锁定资产）。
- **生产进度**：`未生成` → `生成中` → `待选` → `已选定`；任一步骤可进入 `失败`。

故事板同时显示两个维度，例如“已选定 · 过期”。

### 6.5 生成任务（对用户展示）

```text
待确认（已报价）──确认──→ 排队中 → 进行中 → 成功
   │                          │        ├─→ 失败
   └─报价过期                  │        ├─→ 结果未知 → 对账 → 成功 / 失败 / 待人工核对
                              └─取消───┴─→ 已取消
待人工核对 ──管理员处理──→ 成功 / 失败
```

终态：成功、失败、已取消。每个终态都完成结算，且不存在未释放的预留（REQ-02 REL-08）。

### 6.6 剪辑计划与成片（V2）

```text
剪辑计划：草稿(vN) ──保存──→ 草稿(vN+1)；草稿 ──校验通过──→ 可渲染
成片：渲染中 → 质检中 → 可交付；渲染中 / 质检中 ──→ 失败
```

### 6.7 媒体素材

```text
上传中 → 处理中（探测、缩略图、审核）→ 就绪
                           ├─→ 审核未通过（不可引用）
                           └─→ 处理失败（可重试）
就绪 ──删除（未被引用）──→ 回收中 ──30 天──→ 已清除
```

### 6.8 Agent 提案（V2）

```text
已生成 ──确认──→ 执行中 → 已执行 / 部分失败
   ├──拒绝──→ 已拒绝
   └──数据已变化──→ 已失效
```
