# 业务流程与用例模型

## 角色与职责

访客只能进入公开认证流程；需改密用户先完成受限改密；制作者处理授权项目和本人素材/偏好；管理员处理账号、供应商、模型、审计及健康。项目/媒体权限由服务端确认，不以当前页面是否显示按钮判断授权。

## 主流程与异常结果

| 当前流程                      | 真实结果                                | 失败时保留什么                          |
| ----------------------------- | --------------------------------------- | --------------------------------------- |
| 注册/登录 → 首页              | 制作者身份与会话；需改密用户先改密      | 安全错误，不能跳过认证                  |
| 导入/空白创建 → 项目概览      | 项目身份、规格；导入任务与后续分集/设定 | 项目仍存在，解析失败可见                |
| 设定 → 镜头参考               | 明确设定/造型/媒体的锁定版本            | 未声明真人声音不可生成                  |
| 镜头/画布 → 生成候选 → 选定   | 冻结输入、真实任务、候选、人工选择      | unknown先核对；旧选定保留；下游失效可见 |
| 素材 → 加入项目 / 收藏 / 回收 | 对应归属或个人偏好改变                  | 原件引用与历史保留；失败不隐藏成成功    |
| 账号 → 资料/偏好/设备         | 本人持久偏好及真实会话撤销              | 不修改他人或角色；密码不进日志          |
| 管理 → 凭据测试替换/模型发布  | 原子替换或不可变模型版本                | 测试失败保留旧凭据；任务冻结版本不变    |
| 分析/审计/健康 → 查看处理     | 查询真实事实与目标                      | 缺数据、0和故障分开                     |

细节以[需求总览](01-需求总览.md)为准；没有独立的旧工作台步骤。

## 状态与跨模块约束

- 账号启用、锁定和需改密是不同条件；退出/禁用/重置的会话处理见用户需求。
- 草稿可编辑，提交/发布后的冻结版本只读；候选成功、媒体就绪/审核、人工选定或参考锁定是不同事实。
- 排队/运行/成功/失败/结果未知/待人工核对必须可辨；未知不是可直接再次收费的失败，恢复规则须先确认。
- 项目内容与画布布局、素材原件与库归属与收藏、镜头输入与候选与选定分别表达；技术存储形状待Design。
- 提示保存成功须有真实回执；统计、导航、查询、导出采用同一授权上下文。需要持久化的内容刷新能恢复，局部失败不假装全成功。
- 原规格中的状态转换仍需在当次Design明确接口/数据/并发/恢复合同；本文不给未知政策强行补枚举或流程。
