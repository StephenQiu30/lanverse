# 镜头需求

## 目标与范围

制作者能编辑镜头输入，比较并人工采用真实候选。

本模块范围：镜头定位/参数/参考、不可变版本与只读历史、候选比较/选定、存素材、复制参数、只读台词音频、依赖失效。

建议执行顺序为编号顺序；编号不代表排期或已批准实施。本文件按业务模块整体维护，内部功能在同一文档列出，不为每个按钮、接口或技术层建立单独需求文件。

## 功能与数据要求

### 镜头详情

#### 字段与数据量

| 区域       | 必须承载的字段                                          | 设计归属                                             | 一次读取 / 保存的量                              |
| ---------- | ------------------------------------------------------- | ---------------------------------------------------- | ------------------------------------------------ |
| 定位与输入 | 项目/集/场/镜头编号、描述、景别、运镜、时长、模式、模型 | shot + shot_revision                                 | 详情一个，上一/下一镜仅ID与简要标签              |
| 参考       | 用途、排序、对象/媒体ID、冻结版本、锁定提示             | asset_reference；业务参考键写入shot_revision         | 当前参考集合；缩略图按需，不返回原件             |
| 候选       | 候选id、预览、模型/参数、时间、播放进度、当前选定       | generation_output + generation_job；shot持有选定指针 | 首批建议6项，更多按需；播放进度不保存            |
| 台词音频   | 说话者、台词、音色、速度、情绪、时长、音频、选定状态    | shot_revision中有界台词快照/源标识，引用音频output   | 只读播放；当前无逐句编辑表单，不推导独立配音平台 |
| 版本       | 版本号、当前标记、变更说明                              | shot_revision                                        | 首批建议10条摘要，点击才读完整版本               |

#### 功能与失败边界

| 用户动作              | 必须产生的结果                                       | 边界与失败                                                                               |
| --------------------- | ---------------------------------------------------- | ---------------------------------------------------------------------------------------- |
| 参数 / 添加参考       | 保存形成不可变镜头版本并更新current_revision         | 旧revision冲突保留输入；模型不支持选项应解释原因，不回写旧接口默认值                     |
| 生成 / 比较 / 选定    | 生成只追加候选；明确选定后更新镜头结果，旧依赖标失效 | 下游失效是新页面文案明确要求：比较冻结引用与当前选定；不能删需求，也不必预建通用传播平台 |
| 保存到素材 / 复制参数 | 增加素材库条目；参数复制为新草稿                     | 不复制用户会话、签名URL和秘密；旧版本查看不修改当前版本                                  |

## 范围边界

- 镜头、版本、任务输出各存一份；正式选定与候选分开。

## 依赖与待确认

依赖项目、设定/素材与可用模型；生成入口复用14，详情与编辑可先用明确来源的镜头对象验证。

待确认：镜头首次形成的用户链路需与剧本/分镜规则明确；不能凭固定mock认定已形成。

以上缺口只是评审问题，不构成新增产品能力或架构决策。既有功能和约束不因旧接口支持不足而删除或降级。

## 模块验收

1. 本文列出的字段和功能由真实数据及操作结果承载，成功/失败/权限/未接入状态明确，mock不作为业务通过。
2. 需要持久化的写入可刷新恢复；版本冲突保留输入，重复副作用按幂等合同核对；只读/瞬时状态不强加持久化。
3. 当前用户/项目范围服务端验证；管理动作限管理员，秘密不进入响应、普通日志、审计明文或导出。
4. 实现时补与本模块风险匹配的成功、失败、冲突/重复、越权场景，分别记录自动化、真实持久化、浏览器及外部供应商证据，未执行不得报通过。

统一要求见[非功能规格](02-非功能需求规格.md)和[交互需求](05-界面与交互需求.md)；当前均待评审、未完成真实功能验收。本阶段不列Sprint、工时或固定用例数量。
