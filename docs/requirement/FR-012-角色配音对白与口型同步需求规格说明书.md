# FR-012 角色配音、对白与口型同步需求规格说明书

## 1. 目的与范围

为角色建立声音身份，依据确认对白制作可逐句调整的语音候选，并把采用对白与角色画面进行可追溯的口型和音画同步。

## 2. 主业务流程

1. 为角色创建或选择声音身份并校验授权。
2. 解析确认对白，设置发音、重音、情绪、语速和停顿。
3. 按单句或批量生成多个语音候选。
4. 审听候选并与镜头或时间线对齐。
5. 对需要口型的镜头固定视频、角色、对白和语言版本。
6. 生成口型候选、检测同步偏差并局部重做。

## 3. 功能需求

| 编号 | 规范性需求 | 优先级 |
| --- | --- | --- |
| FR-012-001 | 系统应为角色维护稳定声音身份及其来源和授权关系。 | P0 |
| FR-012-002 | 系统应区分声音身份、声音参考、音色版本、演绎候选和当前采用音频。 | P0 |
| FR-012-003 | 系统应在真人声音克隆或仿真前校验单独授权。 | P0 |
| FR-012-004 | 系统应允许用户试听获准声音并记录选角决定。 | P0 |
| FR-012-005 | 系统应把语音任务关联到明确的剧本对白版本和说话角色。 | P0 |
| FR-012-006 | 系统应允许设置读音、重音、情绪、语速、停顿和表演说明。 | P0 |
| FR-012-007 | 系统应支持按单句生成，并使批量任务保持逐句独立结果。 | P0 |
| FR-012-008 | 系统应为每次语音尝试保留独立候选、输入、能力和用量。 | P0 |
| FR-012-009 | 系统应允许只重做变化或未通过的对白。 | P0 |
| FR-012-010 | 系统应把口型任务关联到明确的视频、角色、对白和语言版本。 | P1 |
| FR-012-011 | 系统应为口型同步生成新媒体候选，而不覆盖原视频。 | P1 |
| FR-012-012 | 系统应检测对白起止、口型节奏和音画时间偏移。 | P0 |
| FR-012-013 | 系统应允许只对指定对白区间或角色执行口型返工。 | P1 |
| FR-012-014 | 系统应在剧本、声音授权、视频或时间线变化后标识相关结果及其下游采用关系待复核。 | P0 |
| FR-012-015 | 系统应在对白文本、说话角色、语言或时间范围变化后标识对应语音、口型同步、受影响混音以及各语言配音、字幕和交付输出为待复核或失效。 | P0 |

## 4. 业务规则

- BR-012-001：修改对白文本必须回到剧本形成新版本。
- BR-012-002：批量配音的失败和用量必须追溯到单句。
- BR-012-003：声音授权失效不得删除历史交付证据，但必须阻止新使用。
- BR-012-004：口型同步输出是新媒体版本，自动同步分数不等于审核通过。

## 5. 数据要求

- DR-012-001：保存声音身份、来源、授权、音色/模型版本和适用范围。
- DR-012-002：保存对白版本、发音词典、演绎参数、尝试、候选、时长和采用关系。
- DR-012-003：保存口型输入、说话区间、同步尝试、时间偏差、检测和人工决定。
- DR-012-004：保存对白变化对语音、口型、混音、语言版本和交付输出的影响关系、判定状态与处理记录。

## 6. 异常与恢复

| 场景 | 系统行为 |
| --- | --- |
| 专有名词读音不确定 | 标记人工校正，并允许维护项目发音词典。 |
| 单句批量任务失败 | 仅重试失败句，保留其他成功结果。 |
| 角色口部不可见 | 标记不适用或要求替代镜头，不伪造通过。 |
| 授权失效 | 阻止新任务，并列出受影响镜头和交付。 |

## 7. 验收标准

- AC-012-001：修改一条对白后，对应语音、口型同步、受影响混音以及各语言配音、字幕和交付输出显示待复核或失效；未受该对白影响的结果保持原状态。
- AC-012-002：批量中一条失败可单独重试，其他候选不被覆盖。
- AC-012-003：未经授权的声音克隆任务不能启动。
- AC-012-004：口型处理后仍可访问原视频和原对白版本。
