# 模型需求

## 目标与范围

管理员能维护供创作使用的模型定义和不可变发布版本。

本模块范围：列表/能力/区域/模式、建草稿、参数表单与JSON、版本差异、发布及启停；不建设价格平台。

建议执行顺序为编号顺序；编号不代表排期或已批准实施。本文件按业务模块整体维护，内部功能在同一文档列出，不为每个按钮、接口或技术层建立单独需求文件。

## 功能与数据要求

<a id="req-f-14"></a>

### 模型注册表

#### 字段与数据量

| 区域       | 必须承载的字段                                               | 设计归属                                                              | 一次读取 / 保存的量                |
| ---------- | ------------------------------------------------------------ | --------------------------------------------------------------------- | ---------------------------------- |
| 模型列表   | 名称/key、供应商、能力、区域、支持模式、启停/发布状态        | model + current model_revision + provider                             | 按能力筛选建议20条；样例12不是上限 |
| 编辑与版本 | 默认时长/分辨率/固定镜头、参考上限、支持模式、JSON、版本差异 | model_revision的闭集param_schema/defaults/limits；草稿与published指针 | 一个模型一个编辑版本，历史按需     |
| 新建       | 名称/key/供应商/能力                                         | model首个草稿                                                         | 不从占位模型名猜实际供应商支持     |

#### 功能与失败边界

| 用户动作           | 必须产生的结果                       | 边界与失败                                         |
| ------------------ | ------------------------------------ | -------------------------------------------------- |
| 表单 / JSON / 差异 | 同一版本的三种展示；参数由配置定义   | 不是三个配置副本，修改受revision保护               |
| 发布 / 启停        | 发布不可变版本；启停控制新任务可选性 | 旧任务仍可重现已冻结版本；现有接口形状不限制新参数 |

## 范围边界

- 模型定义与版本分离；当前没有价格管理页，不沿旧文档扩出价格平台。

## 依赖与待确认

依赖供应商归属与管理员权限；生成任务以后引用发布版本。

待确认：参数schema校验细节需要在方案评审中明确，不从演示模型名推断供应商能力。

以上缺口只是评审问题，不构成新增产品能力或架构决策。既有功能和约束不因旧接口支持不足而删除或降级。

## 模块验收

1. 本文列出的字段和功能由真实数据及操作结果承载，成功/失败/权限/未接入状态明确，mock不作为业务通过。
2. 需要持久化的写入可刷新恢复；版本冲突保留输入，重复副作用按幂等合同核对；只读/瞬时状态不强加持久化。
3. 当前用户/项目范围服务端验证；管理动作限管理员，秘密不进入响应、普通日志、审计明文或导出。
4. 实现时补与本模块风险匹配的成功、失败、冲突/重复、越权场景，分别记录自动化、真实持久化、浏览器及外部供应商证据，未执行不得报通过。

统一要求见[非功能规格](02-非功能需求规格.md)和[交互需求](05-界面与交互需求.md)；当前均待评审、未完成真实功能验收。本阶段不列Sprint、工时或固定用例数量。
