# 画布需求

## 目标与范围

制作者能在画布组织内容、保存布局并查看创作结果。

本模块范围：节点/连线/容器/视口、镜头与设定引用、图片视频音频文本、生成草稿/提交、一次构图建议、导出及待处理入口。

建议执行顺序为编号顺序；编号不代表排期或已批准实施。本文件按业务模块整体维护，内部功能在同一文档列出，不为每个按钮、接口或技术层建立单独需求文件。

## 功能与数据要求

<a id="req-f-02"></a>

### 无限画布

#### 字段与数据量

| 区域     | 必须承载的字段                                                  | 设计归属                                                 | 一次读取 / 保存的量                       |
| -------- | --------------------------------------------------------------- | -------------------------------------------------------- | ----------------------------------------- |
| 画布结构 | 文档id/revision、节点id/type/位置/尺寸/容器、连线端点、viewport | canvas、canvas_node、canvas_edge；引用shot/setting/media | 一次当前画布结构；重媒体按可见节点加载    |
| 节点内容 | 镜头表、镜头摘要、角色/场景参考、图片/视频/音频/文本            | 业务节点只存引用；普通文本/生成草稿用有类型config        | 不在画布复制整份镜头历史和媒体字节        |
| 生成输入 | 提示词、图片/视频等能力、模型、画幅、时长、参考                 | 节点草稿 + generation_job冻结输入                        | 一次提交的候选数量由当前表单/模型限制校验 |
| 壳状态   | 缩放、工具、选择、播放、已保存状态、待处理数量                  | 临时状态；保存状态来自服务端回执，数量查询任务           | 缩略图从布局计算；不保存选中/hover        |

#### 功能与失败边界

| 用户动作        | 必须产生的结果                                       | 边界与失败                                                                  |
| --------------- | ---------------------------------------------------- | --------------------------------------------------------------------------- |
| 拖动 / 工具插入 | 提交节点布局或类型明确的新节点；显示保存中/成功/失败 | 适应画布只能改viewport，不能像当前mock那样重置节点位置                      |
| 提交生成        | 冻结当前输入，展示执行中与候选；不覆盖正式选定       | 若真实调用收费，必须在执行前补费用确认；不能继承旧报价平台为默认架构        |
| Agent生成建议   | 读取当前镜头与参考，返回一份可见构图建议             | 当前没有连续对话/历史面板：一次请求和审计足够，不建session/run/proposal平台 |
| 导出 / 任务通知 | 导出当前画布/选定媒体；通知展示本项目待处理项        | 具体导出格式/范围尚无二级控件，列为待定；不自动引入旧时间轴/3D/深度页面     |

## 范围边界

- 业务事实与布局分开；只承载本画板工具与建议弹窗。

## 依赖与待确认

依赖项目与业务对象引用；先保存结构/布局，再接生成和建议；适应视口不得改变节点坐标。

待确认：导出范围/格式/缺媒体策略；建议的模型/费用/结果形状；任务通知范围与跳转。

以上缺口只是评审问题，不构成新增产品能力或架构决策。既有功能和约束不因旧接口支持不足而删除或降级。

## 模块验收

1. 本文列出的字段和功能由真实数据及操作结果承载，成功/失败/权限/未接入状态明确，mock不作为业务通过。
2. 需要持久化的写入可刷新恢复；版本冲突保留输入，重复副作用按幂等合同核对；只读/瞬时状态不强加持久化。
3. 当前用户/项目范围服务端验证；管理动作限管理员，秘密不进入响应、普通日志、审计明文或导出。
4. 实现时补与本模块风险匹配的成功、失败、冲突/重复、越权场景，分别记录自动化、真实持久化、浏览器及外部供应商证据，未执行不得报通过。

统一要求见[非功能规格](02-非功能需求规格.md)和[交互需求](05-界面与交互需求.md)；当前均待评审、未完成真实功能验收。本阶段不列Sprint、工时或固定用例数量。
