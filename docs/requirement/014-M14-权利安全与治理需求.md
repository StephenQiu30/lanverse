# M14 权利、安全与治理需求

> Requirement ID：REQ-GOV
> 状态：reviewed v1（ready_for_design，待产品负责人接受）
> 日期：2026-08-20
> 上游：[目标需求总览](./000-AI视频生产平台目标需求总览.md)
> 对应模块：M14 权利、安全与治理

## 1. 需求结论

来源上传、模型外发、参考绑定、分享和正式交付必须基于可追溯权利声明、组织策略、内容规则、地域、期限和提供商条款进行门禁。拒绝、例外和风险接受必须说明依据并可审计，不能被 Agent、API、重试或管理员角色静默绕过。

## 2. 用户结果与范围

用户在上传、外发、生成、审阅分享和交付前知道哪些内容受限、为什么受限、影响哪些对象、需要补什么声明或批准。管理员可以维护策略和提供商准入，权利负责人可以处理例外和到期风险。

本模块不提供法律意见、不自动证明版权归属、不进行商业分成，也不把内容安全评分直接作为创作主选。

## 4. 权利声明与门禁

每个来源/媒体至少声明创建者或来源、权利依据、允许用途、地域、期限、是否允许模型处理、是否涉及真人/IP/品牌和未知项。声明不等于法律证明，但未知或冲突必须按策略阻止对应动作。

门禁分别发生在上传接纳、参考绑定、计划批准、外部提交、外部审阅分享和正式交付。早期通过不代表后续自动通过；每次评估绑定当时对象版本、策略版本和提供商条款快照。

## 5. 数据外发和提供商治理

1. 用户在批准前看到将外发的数据种类和目的，不要求阅读内部 Payload。
2. 不发送完成任务不需要的完整剧本、人物秘密或其他镜头素材。
3. 提供商连接声明地域、保留、训练使用、删除能力、内容政策和许可边界。
4. 提供商条款或健康变化后停止新路由，已提交任务进入对账和风险提示。
5. 策略例外不能扩展到未列出的对象、期限或提供商。
6. `PolicyException` 只处理权利、安全、地域和数据策略；它不能替代 M10 质量风险接受、M11 资源例外或 M12 审阅批准。

## 6. 失败与恢复

| 场景 | 用户可见结果 | 恢复动作 |
| --- | --- | --- |
| 权利信息缺失 | 阻止受影响外发/分享/交付 | 补充声明和证据 |
| 许可到期 | 新动作阻止，历史交付保留并标注 | 更新许可或停止使用 |
| 提供商条款变化 | 显示受影响计划和数据 | 重评估或切换允许能力 |
| 策略服务不可用 | 高风险动作默认阻止 | 恢复评估或人工应急流程 |
| 内容误报 | 保留规则和证据 | 具名复核或受限例外 |
| 删除与法定保全冲突 | 不物理删除并说明原因 | 到期后重新处理 |

## 7. 非功能需求

| ID | 要求 |

| GOV-NFR-005 | 删除、保留和法定保全在对象存储、数据库、备份和导出一致执行。 |

## 8. 验收条件

| ID | 场景 |
| --- | --- |
| AC-GOV-001 | 未声明权利的真人参考不能提交外部生成。 |
| AC-GOV-002 | 用户批准前能看到提供商、地域和外发数据类别。 |
| AC-GOV-003 | 不允许训练的数据不会路由到条款不兼容提供商。 |
| AC-GOV-004 | 权利到期阻止新交付但不改写历史 Snapshot。 |
| AC-GOV-005 | 例外缺少权限、对象范围、理由或期限时被拒绝。 |
| AC-GOV-006 | Agent、API 和重试无法绕过相同治理门禁。 |
| AC-GOV-007 | 提供商撤销后停止新任务并保留已提交任务对账。 |
| AC-GOV-008 | 法定保全对象不会被普通删除流程物理清除。 |
| AC-GOV-009 | 任一拒绝和例外可追溯策略、输入、主体和结果。 |

## 9. 指标与待确认项

指标包括权利缺失率、外发阻止率、策略误报/复核率、例外数量与到期、许可到期影响范围和删除完成时间。待确认目标地域、真人/IP 审批职责、首批 Provider 数据条款、保留期限和法定保全适用组织。
