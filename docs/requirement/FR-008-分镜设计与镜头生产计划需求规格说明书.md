# FR-008 分镜设计与镜头生产计划需求规格说明书

## 1. 目的与范围

把已确认剧本转换为有顺序、有叙事目的、可审核和可生产的镜头计划，并用结构化 `ShotSpec` 表达镜头语言、动作、声音和资产引用。

## 2. ShotSpec 最小字段

叙事目的、人物、动作、对白、场景、时间、情绪、景别、角度、构图、镜头运动、时长、画幅、视觉风格、角色/场景/服装/道具引用、首尾帧意图、声音意图、负面约束、期望结果和质量约束。

## 3. 主业务流程

1. 从剧本场次创建一个或多个镜头草稿。
2. 补充镜头目的、镜头语言、动作、对白、声音和时长。
3. 关联角色、场景、服装、道具、风格和声音版本。
4. 生成或导入分镜图、首帧、尾帧或关键画面。
5. 系统检查场次覆盖、必填项和总时长。
6. 导演或指定审核者确认唯一当前分镜基线。

## 5. 业务规则

- BR-008-001：分镜是生产意图，不是生成媒体。
- BR-008-002：镜头顺序可变化，镜头稳定标识不得随排序变化。
- BR-008-003：镜头内容完整不等于资产就绪或允许启动生成。
- BR-008-004：自动拆镜未经人工确认不得成为高成本生产基线。
- BR-008-005：删除已进入制作的镜头前必须展示下游影响。

## 6. 数据要求

- DR-008-001：保存 ShotSpec 版本、来源剧本版本、分镜图和资产引用。
- DR-008-002：保存镜头基线、确认人、确认时间和版本差异。
- DR-008-003：保存镜头对任务、候选、时间线和交付的影响关系。

## 7. 验收标准

- AC-008-001：调整镜头顺序后，镜头标识保持不变。
- AC-008-002：缺少叙事目的或时长的镜头不能通过分镜确认。
- AC-008-003：修改已确认镜头对白后，相关生成、配音、字幕和时间线显示待复核。
- AC-008-004：AI 自动拆镜未经人工确认不能启动正式镜头制作。
