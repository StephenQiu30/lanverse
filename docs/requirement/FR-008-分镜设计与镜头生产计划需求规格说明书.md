# FR-008 分镜设计与镜头生产计划需求规格说明书

## 1. 目的与范围

把已确认剧本转换为有顺序、有叙事目的、可审核和可生产的镜头计划，并用结构化 `ShotSpec` 表达镜头语言、动作、声音和资产引用。

## 2. ShotSpec 最小字段

叙事目的、人物、动作、对白、场景、时间、情绪、景别、角度、构图、镜头运动、预期时长毫秒数、画幅、视觉风格、角色/场景/服装/道具引用、首尾帧意图、声音意图、负面约束、期望结果和质量约束。

## 3. 主业务流程

1. 从剧本场次创建一个或多个镜头草稿。
2. 补充镜头目的、镜头语言、动作、对白、声音和时长。
3. 关联角色、场景、服装、道具、风格和声音版本。
4. 生成或导入分镜图、首帧、尾帧或关键画面。
5. 系统按当前已确认立项基线中的单集目标时长与允许偏差，检查场次覆盖、必填项和镜头计划总时长。
6. 导演或指定审核者确认唯一当前分镜基线。

## 4. 功能需求

| 编号 | 规范性需求 | 优先级 |
| --- | --- | --- |
| FR-008-001 | 系统应允许从一个剧本场次创建一个或多个镜头。 | P0 |
| FR-008-002 | 系统应为镜头记录叙事目的、稳定标识、顺序和非负整数毫秒的 `expected_duration_ms`。 | P0 |
| FR-008-003 | 系统应记录景别、机位、角度、构图和镜头运动。 | P0 |
| FR-008-004 | 系统应记录角色动作、表演、视线、画面调度和情绪强度。 | P0 |
| FR-008-005 | 系统应记录场景时间、光线、天气、色调和风格约束。 | P0 |
| FR-008-006 | 系统应记录对白、旁白、环境声、音乐和音效意图。 | P0 |
| FR-008-007 | 系统应允许镜头引用明确的角色、场景、服装、道具、风格和声音资产版本。 | P0 |
| FR-008-008 | 系统应记录首帧、尾帧或关键画面意图。 | P0 |
| FR-008-009 | 系统应允许生成或导入分镜图，并区分提案、当前基准和历史版本。 | P0 |
| FR-008-010 | 系统应以当前已确认立项基线中的单集 `target_duration_ms` 和 `allowed_deviation_ms` 为权威输入，对镜头 `expected_duration_ms` 求和并检查单集计划时长差异；目标为正整数毫秒，偏差与镜头时长为非负整数毫秒，且偏差不得大于目标。 | P0 |
| FR-008-011 | 系统应将自动拆镜和自动导演结果保存为待确认提案。 | P0 |
| FR-008-012 | 系统应允许责任人确认唯一当前分镜基线。 | P0 |
| FR-008-013 | 系统应在分镜变化后标识相关任务、候选、时间线和审核结果待复核。 | P0 |
| FR-008-014 | 系统应允许授权用户编辑镜头的生产规格。 | P0 |
| FR-008-015 | 系统应允许授权用户调整镜头顺序而不改变镜头稳定标识。 | P0 |
| FR-008-016 | 系统应以期望结果和质量约束表达生产目标，不要求 ShotSpec 绑定具体供应商或模型。 | P0 |
| FR-008-017 | 系统应在计划总时长大于 `target_duration_ms + allowed_deviation_ms` 或小于 `target_duration_ms - allowed_deviation_ms` 时给出超出或不足的毫秒数，并以 P0 门禁阻止分镜基线确认。 | P0 |

## 5. 业务规则

- BR-008-001：分镜是生产意图，不是生成媒体。
- BR-008-002：镜头顺序可变化，镜头稳定标识不得随排序变化。
- BR-008-003：镜头内容完整不等于资产就绪或允许启动生成。
- BR-008-004：自动拆镜未经人工确认不得成为高成本生产基线。
- BR-008-005：删除已进入制作的镜头前必须展示下游影响。
- BR-008-006：剧本估算时长、媒体实测时长和前端显示的四舍五入秒数均不得替代已确认立项基线中的单集目标时长；目标或偏差变更必须形成新的立项基线版本。

## 6. 数据要求

- DR-008-001：保存 ShotSpec 版本、来源剧本版本、分镜图和资产引用。
- DR-008-002：保存镜头基线、确认人、确认时间和版本差异。
- DR-008-003：保存镜头对任务、候选、时间线和交付的影响关系。
- DR-008-004：保存时长校验所引用的立项基线版本、目标毫秒数、允许偏差毫秒数、计划总毫秒数、差值和门禁结论。

## 7. 异常与恢复

| 场景 | 系统行为 |
| --- | --- |
| 单集目标时长缺失或允许偏差无效 | 阻止分镜基线确认并要求回到立项基线补充或修正，不使用默认值。 |
| 计划总时长超出或不足允许范围 | 展示差值和受影响镜头，允许编辑草稿但阻止分镜基线确认。 |

## 8. 验收标准

- AC-008-001：调整镜头顺序后，镜头标识保持不变。
- AC-008-002：缺少叙事目的或时长的镜头不能通过分镜确认。
- AC-008-003：修改已确认镜头对白后，相关生成、配音、字幕和时间线显示待复核。
- AC-008-004：AI 自动拆镜未经人工确认不能启动正式镜头制作。
- AC-008-005：目标为 60000 毫秒且允许偏差为 2000 毫秒时，计划总时长 57999 或 62001 毫秒均不能确认，58000 与 62000 毫秒可以通过时长门禁。
