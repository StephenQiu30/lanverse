## 阅读与设计依据

1. 逐页字段/动作 → [新数据设计](../../design/浮光页面数据设计.md) → [新接口设计](../../design/浮光页面接口设计.md) → [验收](../浮光页面非功能与验收.md)。
2. 以当前设计和控件确认“必须有什么”；对源码中明显的mock捷径，如适应画布重置位置、点刷新立刻健康、写死账号可用，不按真实业务实现。
3. 当前设计未说明的细节标为问题，而不是拿旧接口的实现填空。

## 当前设计自身的待定细节

| 问题              | 已确定部分                   | 仍需补充                                   |
| ----------------- | ---------------------------- | ------------------------------------------ |
| 剧本格式          | 文案txt/md/docx必须承载      | input额外pdf是否正式支持                   |
| 画布导出          | 当前有导出入口               | 导出画布图/选定媒体/包的具体格式与范围     |
| 素材容量          | 已用与总量卡片必须有真实来源 | 总量表示磁盘还是分配配额                   |
| 头像              | 更换与保存本人头像是需求     | 文件规格、裁切交互                         |
| 管理建号          | 建号/重置与首次改密保留      | 临时凭据的安全展示/交付方式                |
| 任务通知/全站搜索 | 入口保留                     | 点击后范围、列表与跳转细节                 |
| 真实付费生成      | 不允许mock成功掩盖收费       | 提交按钮前的价格提示、确认与费用不可知处理 |

## 排除的历史范围

旧 `/create`、`/depths`、`/tasks`、`/settings`、旧项目剧本工作台及其时间轴/导演台/深度/素材包等，不因仓库中仍有代码就进入新产品范围。旧接口、字段、状态机、分页、表拆分和中间件拓扑不作为新设计依据。历史仅在独立迁移任务中读取，旧前端实现已由当前设计页面替换；现有数据库与文件数据保持不变。
