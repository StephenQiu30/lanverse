# PG-11 账号设置

依据：[浮光画板 13-2](https://www.figma.com/design/uLqmeRWuQuzfrp9xOYg6FT/?node-id=13-2)；对应新页面 `/account`，源码 `frontend/src/app/account/_components/account-page.tsx`。页面为本地 mock，字段和可见行为用于需求分析；固定样例值和成功提示不证明真实业务已实现。

## 展示字段与数据量

表中的存储名称是本轮新设计的逻辑表，未建表；建议分页量不是既有API合同。

| 区域     | 必须承载的字段                           | 设计归属                                       | 一次读取 / 保存的量                  |
| -------- | ---------------------------------------- | ---------------------------------------------- | ------------------------------------ |
| 资料     | 头像、显示名≤32、只读登录名/角色         | user_account.avatar_asset_id/display_name/role | 当前本人一个摘要                     |
| 会话     | 当前设备、其他设备、最近活动、单设备退出 | user_session安全摘要                           | 当前用户会话列表；不回传token        |
| 偏好     | 深/浅/跟随系统、个人默认提示词后缀       | user_account.theme/default_prompt_suffix       | 点击保存后持久化，主题可本地缓存加速 |
| 来源说明 | 演示模型来源说明                         | 静态说明/模型版本来源字段                      | 不推导独立许可证管理                 |

## 功能与失败边界

| 当前动作                   | 必须产生的结果                                   | 边界与失败                                                 |
| -------------------------- | ------------------------------------------------ | ---------------------------------------------------------- |
| 资料 / 头像保存            | 显示名和受控媒体引用持久化；刷新与重新登录仍存在 | 头像上传控件细节待补，需求本身保留；不受旧user字段宽度约束 |
| 主题 / 提示词保存          | 只影响本人；新草稿采用后缀，已提交任务不变       | 不挪成组织级或operation/mode配置以适配旧接口               |
| 退出设备 / 修改密码 / 退出 | 单设备、其他设备、当前设备三种语义清楚           | 会话撤销服务端立刻生效，不能仅删除设备卡                   |

## 最小设计结论

少量个人偏好直接放账号行；不建泛化偏好中心，也不丢掉跨登录保存需求。 物理字段与关系见[新数据设计](../../design/浮光页面数据设计.md)，请求/响应见[新接口设计](../../design/浮光页面接口设计.md)。

## 验收证据

- 逐项核上述字段与动作，包括空值、失败和权限；业务写入须刷新后保留，冲突不覆盖他人修改。静态/临时状态不套用持久化验收。
- 返回数据只服务当前显示或操作；统计需能复算；mock数值与真实值明确分开。
