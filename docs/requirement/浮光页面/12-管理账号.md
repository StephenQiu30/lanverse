# PG-12 管理账号

依据：[浮光画板 14-2](https://www.figma.com/design/uLqmeRWuQuzfrp9xOYg6FT/?node-id=14-2)；对应新页面 `/users`，源码 `frontend/src/app/users/_components/users-page.tsx`。页面为本地 mock，字段和可见行为用于需求分析；固定样例值和成功提示不证明真实业务已实现。

## 展示字段与数据量

表中的存储名称是本轮新设计的逻辑表，未建表；建议分页量不是既有API合同。

| 区域       | 必须承载的字段                                        | 设计归属                     | 一次读取 / 保存的量                      |
| ---------- | ----------------------------------------------------- | ---------------------------- | ---------------------------------------- |
| 列表       | 登录名、显示名、角色、启用/停用/需改密/锁定、最近登录 | user_account安全投影         | 建议每页20；角色/状态/关键词筛选先于分页 |
| 创建与操作 | 新账号登录名/显示名/角色；重置密码、启停、解锁        | 同一账号与会话记录；审计事件 | 账号不删除；历史操作人ID稳定             |

## 功能与失败边界

| 当前动作                  | 必须产生的结果                             | 边界与失败                                             |
| ------------------------- | ------------------------------------------ | ------------------------------------------------------ |
| 创建账号                  | 管理员创建制作者或管理员；首次使用需改密   | 临时凭据交付方式需补可见结果；不能把秘密放入列表或日志 |
| 禁用 / 启用 / 解锁 / 重置 | 禁用撤销会话；解锁只清登录锁；重置要求改密 | 最后管理员保护；重置不同于解锁；普通用户无权限         |

## 最小设计结论

角色闭集只有当前页面的管理员/制作者；无需动态RBAC或组织平台。 物理字段与关系见[新数据设计](../../design/浮光页面数据设计.md)，请求/响应见[新接口设计](../../design/浮光页面接口设计.md)。

## 验收证据

- 逐项核上述字段与动作，包括空值、失败和权限；业务写入须刷新后保留，冲突不覆盖他人修改。静态/临时状态不套用持久化验收。
- 返回数据只服务当前显示或操作；统计需能复算；mock数值与真实值明确分开。
- 验收遵循[新页面验收](../浮光页面非功能与验收.md)。本轮只形成设计，没有宣称真实功能完成。
