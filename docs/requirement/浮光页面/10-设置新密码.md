# PG-10 设置新密码

依据：[浮光画板 12-2](https://www.figma.com/design/uLqmeRWuQuzfrp9xOYg6FT/?node-id=12-2)；对应新页面 `/reset-password`，源码 `frontend/src/components/auth/auth-view.tsx`。页面为本地 mock，字段和可见行为用于需求分析；固定样例值和成功提示不证明真实业务已实现。

## 展示字段与数据量

表中的存储名称是本轮新设计的逻辑表，未建表；建议分页量不是既有API合同。

| 区域       | 必须承载的字段                              | 设计归属                                             | 一次读取 / 保存的量                      |
| ---------- | ------------------------------------------- | ---------------------------------------------------- | ---------------------------------------- |
| 输入与规则 | 当前密码、新密码、确认；首次/重置后改密说明 | user_account密码hash/force_change_password；sessions | 一次原子提交；新旧密码不同且符合注册规则 |
| 结果       | 成功/失败、重新进入产品、退出登录           | 安全认证结果                                         | 当前设备策略明确；其他设备立即撤销       |

## 功能与失败边界

| 当前动作   | 必须产生的结果                                     | 边界与失败                                      |
| ---------- | -------------------------------------------------- | ----------------------------------------------- |
| 设置新密码 | 验证当前密码后替换hash、清除改密限制、撤销其他会话 | 并发重置/旧凭据拒绝；失败不清空安全之外的上下文 |
| 退出登录   | 撤销当前会话                                       | 不是邮件/短信找回流程，不添加未出现的验证渠道   |

## 最小设计结论

普通主动改密与受限改密用同一密码规则和会话失效语义。 物理字段与关系见[新数据设计](../../design/浮光页面数据设计.md)，请求/响应见[新接口设计](../../design/浮光页面接口设计.md)。
