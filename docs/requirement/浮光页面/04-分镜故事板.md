# PG-04 分镜故事板

依据：[浮光画板 5-2](https://www.figma.com/design/uLqmeRWuQuzfrp9xOYg6FT/?node-id=5-2)；对应新页面 `/storyboard`，源码 `frontend/src/app/storyboard/_components/storyboard-page.tsx`。页面为本地 mock，字段和可见行为用于需求分析；固定样例值和成功提示不证明真实业务已实现。

## 展示字段与数据量

表中的存储名称是本轮新设计的逻辑表，未建表；建议分页量不是既有API合同。

| 区域        | 必须承载的字段                                | 设计归属                                      | 一次读取 / 保存的量                        |
| ----------- | --------------------------------------------- | --------------------------------------------- | ------------------------------------------ |
| 页头与筛选  | 集、场名、镜头数量、状态、模式、视图          | episode/scene；镜头查询聚合                   | 当前集/场范围；建议一页40镜头，初版上限100 |
| 镜头卡 / 行 | 编号、描述、时长、模式、缩略图、画面/视频状态 | shot + current shot_revision + job/output摘要 | 不嵌套所有历史/候选                        |
| 批量状态    | 所选ID、统一时长、生成进度                    | 选择临时；写入shot_revision/任务              | 仅明确选中的镜头，不将全选暗含未加载项     |

## 功能与失败边界

| 当前动作            | 必须产生的结果                             | 边界与失败                         |
| ------------------- | ------------------------------------------ | ---------------------------------- |
| 网格 / 表格 / 筛选  | 共享同一查询及排序；选中范围可见           | 无匹配与加载失败不同               |
| 批量改时长          | 校验全部镜头与模型限制，一次原子提交       | 一项冲突整批不写，返回具体冲突ID   |
| 批量生成 / 打开镜头 | 每镜头生成独立可追踪任务；进入同一shot详情 | 批量失败有逐项状态；不自动选定结果 |

## 最小设计结论

故事板是镜头列表视图，不另建一张故事板状态副本表。 物理字段与关系见[新数据设计](../../design/浮光页面数据设计.md)，请求/响应见[新接口设计](../../design/浮光页面接口设计.md)。

## 验收证据

- 逐项核上述字段与动作，包括空值、失败和权限；业务写入须刷新后保留，冲突不覆盖他人修改。静态/临时状态不套用持久化验收。
- 返回数据只服务当前显示或操作；统计需能复算；mock数值与真实值明确分开。
- 验收遵循[新页面验收](../浮光页面非功能与验收.md)。本轮只形成设计，没有宣称真实功能完成。
