# FR-014 字幕与多语言本地化需求规格说明书

## 1. 目的与范围

从确认对白或音频生成源语言字幕，管理文本、说话人、断句、时间码、样式和标准文件；P1 增加术语、翻译、目标语言配音和独立语言版交付。

## 2. 主业务流程

1. 从确认对白或音频创建字幕草稿。
2. 将音频转写条目关联到确认对白；无法自动关联的条目进入“未匹配转写”并由授权人员处理。
3. 校正文本、说话人、断句和时间码。
4. 检查重叠、阅读速度、安全区和字符支持。
5. 在所有语音转写完成对白关联后确认源语言字幕版本并导出或烧录。
6. P1：创建目标语言版本，使用术语表翻译并人工审核。
7. P1：制作目标语言配音、口型和字幕，形成独立交付版本。

## 3. 功能需求

| 编号 | 规范性需求 | 优先级 |
| --- | --- | --- |
| FR-014-001 | 系统应从确认对白文本或音频创建字幕草稿；仅基于音频且无法匹配确认对白的语音条目必须进入“未匹配转写”状态。 | P0 |
| FR-014-002 | 系统应把已匹配字幕条目关联到剧本对白、说话角色和时间线版本；“未匹配转写”不得伪造对白关联。 | P0 |
| FR-014-003 | 系统应允许编辑字幕文本、起止时间、说话人和断句。 | P0 |
| FR-014-004 | 系统应保留自动转写置信信息并标记低置信内容。 | P0 |
| FR-014-005 | 系统应允许配置字体、字号、位置、颜色、描边和背景样式。 | P0 |
| FR-014-006 | 系统应检测字幕重叠、持续时间、阅读速度、越界和安全区问题。 | P0 |
| FR-014-007 | 系统应在对白或时间线变化后标识相关字幕待复核。 | P0 |
| FR-014-008 | 系统应允许审核者确认明确的源语言字幕版本。 | P0 |
| FR-014-009 | 系统应支持输出 SRT 和 ASS 等带时间码字幕文件。 | P0 |
| FR-014-010 | 系统应禁止字幕校正静默改写剧本对白。 | P0 |
| FR-014-011 | 系统应为目标语言维护角色名、地名和专有名词术语表。 | P1 |
| FR-014-012 | 系统应将自动翻译标识为待人工审核提案。 | P1 |
| FR-014-013 | 系统应分别管理每种语言的文本、配音、口型、字幕、审核和交付状态。 | P1 |
| FR-014-014 | 系统应在源内容变化后标识受影响语言版本。 | P1 |
| FR-014-015 | 系统应为每个音频转写条目保存稳定标识、音频版本、起止时间、匹配状态、候选对白和匹配置信信息。 | P0 |
| FR-014-016 | 系统应允许授权人员把“未匹配转写”人工关联到现有确认对白；不存在对应对白时必须回到剧本形成并确认新对白版本，字幕编辑不得代替该决定。 | P0 |
| FR-014-017 | 系统应在任一语音转写条目尚未关联到确认对白时阻止源语言字幕确认、字幕文件导出和字幕烧录。 | P0 |

## 4. 业务规则

- BR-014-001：自动转写和自动翻译未经人工确认均为提案。
- BR-014-002：各语言版本拥有独立审核和交付状态。
- BR-014-003：修改字幕不得静默修改剧本对白。
- BR-014-004：外挂字幕和烧录字幕必须引用同一明确内容版本。
- BR-014-005：“未匹配转写”是待解决状态，不得被空引用、低置信自动匹配或字幕文本校正隐式转为已关联。

## 5. 数据要求

- DR-014-001：保存字幕版本、条目、文本、时间码、说话人、来源对白和语言。
- DR-014-002：保存样式、转写置信度、校正、检测和审核记录。
- DR-014-003：保存术语表、翻译关系、语言版配音/口型/字幕和交付引用。
- DR-014-004：保存转写条目标识、音频版本、时间范围、匹配状态、候选对白、人工关联人、关联时间和所引用对白版本。

## 6. 异常与恢复

| 场景 | 系统行为 |
| --- | --- |
| 转写置信度不足 | 标记对应条目并要求人工复核。 |
| 音频语音无法匹配确认对白 | 保存为“未匹配转写”，允许继续编辑草稿，但阻止确认、导出和烧录。 |
| 时间线变化 | 仅标记受影响字幕待重新对齐。 |
| 字体缺失或字符不支持 | 阻止烧录并要求选择已批准字体。 |
| 译法存在歧义 | 由本地化责任人选择并记录适用范围。 |

## 7. 验收标准

- AC-014-001：修改时间线后，受影响字幕条目被准确标识。
- AC-014-002：未审核翻译不能进入正式目标语言交付。
- AC-014-003：导出的 SRT/ASS 与确认版本的文本和时间码一致。
- AC-014-004：修正字幕后，原剧本对白保持不变。
- AC-014-005：仅从音频创建的字幕存在一个“未匹配转写”条目时不能确认或导出；人工关联到明确的确认对白版本后才可重新执行门禁。
