## 1. 需求说明

### 1.1 背景与目标

成本上限要在 P0 实测后才能定（P15），因此平台必须精确统计每一分钱花在哪里：按项目、集、镜头、模型；核心指标是“单分钟镜头成本”（PRD-01 §10）。

### 1.2 用户故事

- 作为**制作者**，我希望看到每个镜头、每集、每个项目的费用明细与单分钟成本。
- 作为**管理员**，我希望按时间、模型、项目查看成本报表，并在预算使用达到阈值时收到告警。

### 1.3 范围

包含：账本（预留、结算、释放、调整、预算变更）、按维度汇总、单分钟成本、明细下钻、每日对账；跨项目报表与 CSV 导出、预算告警（阈值 20% 与超支，见 REQ-11、REQ-33）；生产指标（R8）。不包含：发票、支付。

## 2. 需求分析

### 2.1 业务规则

| # | 规则 | 理由 |
| --- | --- | --- |
| R1 | 每次供应商调用的费用记入调用明细；Operation 的供应商实际费用 = 其全部调用费用之和；Operation 结算金额 = 实际费用，按 token 计费且超出预留时为预留金额，超出部分作为“平台承担费用”单独记账（REQ-21 R7）；对账等式：实际费用 = 结算金额 + 平台承担费用 | CST-01 |
| R2 | 账本分录只追加；更正使用 `adjust` 分录 | 可审计 |
| R3 | 分录带归集维度：项目、集、镜头、Operation、模型、区域 | CST-01 |
| R4 | 单分钟成本 = 该集已结算总费用 ÷ 该集选定片段总时长（分钟）；无选定片段时显示“—” | CST-02 |
| R5 | 境外费用保留原币种与汇率 | I18N-02 |
| R6 | 每日对账：预算表的 `reserved`、`settled` 与账本、预留表汇总一致；任务终态无残留预留；差异告警 | REL-08 |
| R7 | 汇总数据由 `billing-report` 消费者增量维护，可从账本全量重建 | 可恢复 |
| R8 | 生产指标（PRD-01 §10），只读、按查询时数据计算；统计范围为**已选定视频的镜头**：**镜头一次通过率** = 选定视频来自该镜头第一次完成的视频生成的镜头数 ÷ 范围内镜头数；**平均每镜视频生成次数** = 范围内镜头已完成的视频生成次数（不含复用，首次生成计 1 次）÷ 范围内镜头数，重拍次数 = 该值 − 1；**剧本到镜头成品耗时** = 从剧本版本导入完成（`imported_at`）到该集全部镜头有选定视频、全部台词有选定配音的日历时间，未完成的集不计算；**操作时间（估算）** = 期间该项目审计动作按 30 分钟无动作切分后的时长之和，仅为基于审计动作的估算、不代表完整在线时长；**预估与实际费用偏差** = (Σ 结算金额 − Σ 报价) ÷ Σ 报价（已进入终态的工作流型操作）。项目级：比率类指标按各集分子、分母分别求和后相除；耗时只汇总已完成的集（数量、中位数）。分母为 0 时返回空值。角色外观一致性抽检通过率见 REQ-02 AIQ-04（人工抽检，TST-03） | PRD-01 §10 |

### 2.2 异常与边界

供应商账单与平台记录不一致：管理员录入 `adjust` 分录并注明依据。

## 3. 验收标准

- Given 镜头 3 生成过 3 次视频，When 查看镜头 3 费用明细，Then 列出 3 条记录及合计。
- Given 第 1 集总费用 360 元、选定片段总时长 2 分钟，When 查看汇总，Then 单分钟成本显示 180 元。
- Given 每日对账运行，When 账本与预算一致，Then 状态为平衡；人为制造差异时产生告警。
- Given 第 1 集 10 个镜头已选定视频，其中 6 个选定的是第一次生成的结果，共完成 18 次视频生成，When 查看生产指标，Then 一次通过率 60%，平均每镜视频生成次数 1.8（重拍 0.8 次）；第 2 集尚未完成时其耗时为空。
