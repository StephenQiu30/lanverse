# 素材需求

## 目标与范围

制作者能上传、查看、收藏和在个人/项目范围复用素材。

本模块范围：原件与元数据、个人/项目归属、文件夹、每页40、预览详情、收藏、加入项目和回收；不是素材包与永久清理。

建议执行顺序为编号顺序；编号不代表排期或已批准实施。本文件按业务模块整体维护，内部功能在同一文档列出，不为每个按钮、接口或技术层建立单独需求文件。

## 功能与数据要求

<a id="req-f-07"></a>

### 素材库

#### 字段与数据量

| 区域       | 必须承载的字段                                                  | 设计归属                                            | 一次读取 / 保存的量                              |
| ---------- | --------------------------------------------------------------- | --------------------------------------------------- | ------------------------------------------------ |
| 范围与导航 | 个人/项目、全部/收藏/最近30天/未分类、文件夹及数量、已用/总容量 | library_item/asset_folder/user_favorite；容量查询   | 当前scope的导航摘要；容量值标实际配额或磁盘口径  |
| 素材卡     | ID、名称、类型、宽高比/时长/字数、引用数、封面                  | library_item + media_asset + asset_reference计数    | **每页40项**来自当前页面；不沿旧接口改成其他分页 |
| 预览详情   | 类型/MIME/尺寸、来源、审核、引用对象、标签、可预览URL           | media_asset事实 + library_item元数据                | 一次一个；URL短时签发                            |
| 上传与交互 | 文件进度、当前页、搜索/类型/排序、收藏状态                      | 上传过程状态；收藏独立按user/item保存；其他交互临时 | 真实字节数上限需实现时与允许格式一起确定         |

#### 功能与失败边界

| 用户动作        | 必须产生的结果                                 | 边界与失败                                                             |
| --------------- | ---------------------------------------------- | ---------------------------------------------------------------------- |
| 上传 / 新文件夹 | 保存真实文件与元数据；创建scope内目录          | 内容探测与格式检查后可用；进度不能用固定64%冒充真实                    |
| 收藏 / 加入项目 | 收藏为当前用户偏好；加入项目创建项目库归属引用 | 不能改变原个人素材身份；被授权共享的字节引用需保留访问范围             |
| 移到回收站      | 当前条目标记回收，主列表移除                   | 当前页没有永久清理/素材包/跨库批处理，不添加旧功能；被引用原件继续保留 |

## 范围边界

- 媒体字节、库中归属与个人收藏分开；新页面没有的包导入/导出和永久删除不列入。

## 依赖与待确认

依赖用户/项目授权；生成结果可在以后接入，先以合法上传验证。

待确认：上传允许格式与字节上限、媒体就绪/审核规则、文件夹命名、容量总量与引用计量口径。

以上缺口只是评审问题，不构成新增产品能力或架构决策。既有功能和约束不因旧接口支持不足而删除或降级。

## 模块验收

1. 本文列出的字段和功能由真实数据及操作结果承载，成功/失败/权限/未接入状态明确，mock不作为业务通过。
2. 需要持久化的写入可刷新恢复；版本冲突保留输入，重复副作用按幂等合同核对；只读/瞬时状态不强加持久化。
3. 当前用户/项目范围服务端验证；管理动作限管理员，秘密不进入响应、普通日志、审计明文或导出。
4. 实现时补与本模块风险匹配的成功、失败、冲突/重复、越权场景，分别记录自动化、真实持久化、浏览器及外部供应商证据，未执行不得报通过。

统一要求见[非功能规格](02-非功能需求规格.md)和[交互需求](05-界面与交互需求.md)；当前均待评审、未完成真实功能验收。本阶段不列Sprint、工时或固定用例数量。
