# 素材需求

## 1. 需求概述

**需求目标：** 制作者能上传、查看、收藏和在个人/项目范围复用素材。

**使用者与价值：** 作为制作者，我希望保存、查找并安全复用个人或项目素材，知道文件来自哪里、被哪些对象引用。

**问题背景：** 当前上传进度和媒体列表含演示状态，不能证明真实字节、归属、收藏和回收生效。

| 属性     | 内容                                                                        |
| -------- | --------------------------------------------------------------------------- |
| 业务角色 | 制作者                                                                      |
| 文档状态 | 原始需求整理稿，待评审；不是已接受的设计或已验收功能                        |
| 范围来源 | 本文件第7、8节保留的原规格、现有页面代码，以及已整理的跨模块流程            |
| 完成依据 | 第3节功能结果、第4节质量条件、第5节验收场景；待确认项解决后才能验收相应能力 |

## 2. 范围与边界

本模块包含：原件与元数据、个人/项目归属、文件夹、每页40、预览详情、收藏、加入项目和回收；不是素材包与永久清理。

包括个人/项目素材、收藏、文件夹与回收，不增加素材包、永久删除或跨库批处理。

业务模块一份文档，内部需求编号仅用于追踪，不对应独立文件、接口、类或开发任务。编号不承诺排期。原资料中的存储名、组件名和分页建议不作为已接受架构。
