# FR-013 音乐音效与基础混音需求规格说明书

## 1. 目的与范围

管理背景音乐、环境声、音效、对白和旁白的来源、时间线使用、音量、淡入淡出、对白避让、混音版本和基础音频质量。

本能力不替代完整数字音频工作站。

## 2. 主业务流程

1. 导入或选择音乐、环境声和音效，并记录权利状态。
2. 把音频关联到镜头或时间线区间。
3. 设置音量、声像、淡入淡出、循环和对白避让。
4. 生成混音版本。
5. 检测削波、异常静音、声道和目标响度。
6. 声音审核者确认后进入整集与交付质检。

## 3. 功能需求

| 编号 | 规范性需求 | 优先级 |
| --- | --- | --- |
| FR-013-001 | 系统应区分背景音乐、环境声、音效、对白和旁白音频类型。 | P0 |
| FR-013-002 | 系统应记录每项音频素材的来源、权利状态和允许用途。 | P0 |
| FR-013-003 | 系统应允许音频素材关联到明确镜头或时间线区间。 | P0 |
| FR-013-004 | 系统应允许设置音量、声像、淡入、淡出、循环和基础均衡参数。 | P0 |
| FR-013-005 | 系统应允许为对白区间设置音乐或环境声避让。 | P0 |
| FR-013-006 | 系统应建立不可静默覆盖的混音版本。 | P0 |
| FR-013-007 | 系统应检测削波、异常静音、声道缺失和目标响度偏差。 | P0 |
| FR-013-008 | 系统应把检测问题定位到音轨和时间区间。 | P0 |
| FR-013-009 | 系统应在音频来源、对白或时间线变化后标识相关混音待复核。 | P0 |
| FR-013-010 | 系统应保留被替换音频及历史使用关系。 | P0 |
| FR-013-011 | 系统应支持按对白、音乐、环境声和音效输出独立音轨或清单。 | P1 |

## 4. 业务规则

- BR-013-001：音频素材、时间线使用关系和最终混音是不同对象。
- BR-013-002：自动响度修正不得覆盖原始音频。
- BR-013-003：音频技术检查通过不等于版权门禁通过。
- BR-013-004：更换采用对白后，旧混音结论不得自动继续有效。

## 5. 数据要求

- DR-013-001：保存音频版本、类型、来源、权利状态和媒体摘要。
- DR-013-002：保存时间区间、轨道、混音参数、版本和采用关系。
- DR-013-003：保存响度、削波、静音、声道检测和审核记录。

## 6. 验收标准

- AC-013-001：更换对白版本后，与其重叠的混音区间显示待复核。
- AC-013-002：检测到削波时，报告包含具体音轨和时间位置。
- AC-013-003：替换背景音乐后，旧混音仍可还原。
- AC-013-004：权利受限音乐不能进入正式交付。
