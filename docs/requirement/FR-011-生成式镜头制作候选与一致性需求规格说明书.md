# FR-011 生成式镜头制作、候选与一致性需求规格说明书

## 1. 目的与范围

依据固定分镜和资产版本制作角色定妆、场景、道具、分镜图和短视频镜头，形成多个可比较候选，并对角色、服装、场景、道具和镜头承接执行一致性检查。

## 2. 主业务流程

1. 用户选择资产或镜头制作目标。
2. 系统根据 ShotSpec、故事圣经和资产引用准备输入。
3. 用户确认能力、成本和候选数量后发起制作。
4. 系统形成一个或多个不可变候选并记录生成谱系。
5. 系统执行基础完整性和视听一致性检查。
6. 用户比较、提交审核或对明确范围局部重做。

## 3. 功能需求

| 编号 | 规范性需求 | 优先级 |
| --- | --- | --- |
| FR-011-001 | 系统应支持角色定妆、多视角、表情、服装、场景、道具和风格参考图的制作目标。 | P0 |
| FR-011-002 | 系统应支持文生图、参考图生图和受控图像编辑。 | P0 |
| FR-011-003 | 系统应支持文生视频、图生视频、参考生视频和首尾帧约束的镜头制作。 | P0 |
| FR-011-004 | 系统应允许镜头指定时长、画幅、分辨率、动作、镜头运动和声音要求。 | P0 |
| FR-011-005 | 系统应允许同一目标生成多个独立候选。 | P0 |
| FR-011-006 | 系统应提供候选并排比较所需的预览、关键参数、成本和来源信息。 | P0 |
| FR-011-007 | 系统应允许用户选择候选提交审核，但不得自动采用。 | P0 |
| FR-011-008 | 系统应支持对镜头、画面区域、时间片段或指定元素进行局部重做。 | P0 |
| FR-011-009 | 系统应在局部重做时允许锁定不应变化的已确认元素。 | P0 |
| FR-011-010 | 系统应依据故事圣经和资产版本检测角色身份、服装、场景、道具和时间状态的显性差异。 | P0 |
| FR-011-011 | 系统应将一致性问题定位到候选、对象和时间范围。 | P0 |
| FR-011-012 | 系统应允许责任人把一致性问题裁决为确认、误报、剧情例外或待定。 | P0 |
| FR-011-013 | 系统应在候选或基线变化后把旧检测结论标记为过期。 | P0 |
| FR-011-014 | 系统应禁止新候选覆盖旧候选或已采用版本。 | P0 |

## 4. 业务规则

- BR-011-001：一集不得作为单次不可拆分视频生成目标，应按短镜头生产。
- BR-011-002：生成成功不等于质量通过、审核通过或正式采用。
- BR-011-003：自动一致性分数不等于正式审核结论。
- BR-011-004：角色一致性必须引用稳定资产和故事圣经，不只依赖提示词。
- BR-011-005：未经授权不得静默切换模型或供应能力。

## 5. 数据要求

- DR-011-001：保存制作目标、ShotSpec、输入资产、能力版本、提示摘要、参数、种子和成本引用。
- DR-011-002：保存候选、输出哈希、比较结果、锁定元素和局部重做范围。
- DR-011-003：保存一致性检测基线、问题、严重度、位置、人工裁决和返工关系。

## 6. 异常与恢复

| 场景 | 系统行为 |
| --- | --- |
| 能力不支持指定输入或时长 | 阻止启动，并返回支持边界。 |
| 结果质量不满足创作要求 | 保留为候选质量问题，不计为平台执行失败。 |
| 检测服务不可用 | 标记“未检测”，不得显示为通过。 |
| 局部重做改变锁定元素 | 标记违反约束，阻止自动替换采用版本。 |

## 7. 验收标准

- AC-011-001：同一镜头可保留多个候选，重试不覆盖历史结果。
- AC-011-002：角色服装与分镜引用不符时，报告定位具体候选和时间区间。
- AC-011-003：检测失败显示“未完成检测”，而不是“通过”。
- AC-011-004：局部重做只影响指定范围，其余已锁定元素保持引用和审核状态。
