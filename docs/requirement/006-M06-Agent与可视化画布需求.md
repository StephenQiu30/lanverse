# M06 Agent 与可视化画布需求

> Requirement ID：REQ-AIC
> 状态：proposed v1
> 日期：2026-08-20
> 上游：[目标需求总览](./000-AI视频生产平台目标需求总览.md)
> 对应模块：M06 Agent 与可视化画布

## 1. 需求结论

Agent、表格、工作台、画布和 API 是同一领域事实的不同入口。Agent 负责生成可解释提案和操作计划，用户接受后仍由权威业务规则执行；画布负责空间化查看和局部接管，布局、装饰连线和聊天记忆都不能成为第二事实源。

受限 Agent 与最小可视化接管视图进入切片 B；完整空间画布、多人布局和组织模板进入切片 F。这样既能早期验证“Agent 首稿、用户局部接管”，又不把完整画布作为核心数据前置条件。

## 2. 用户结果与范围

用户可以让 Agent 分析来源、提出人物/场景/道具、拆镜、解释阻塞、准备低消耗预演或局部修复方案；每个建议都能看到目标、证据、影响、资源和权限，并逐项接受、编辑、拒绝或暂缓。

用户可以在最小关系视图中查看实体、镜头、参考、候选和问题依赖，选择节点后执行与列表相同的命令。完整画布提供空间布局、团队视图和批量操作，但不开放任意代码节点或数据库写入。

## 4. Agent 交互契约

每个 AgentProposalItem 至少包含：动作类型、目标对象与版本、字段级变更、依据/证据、置信和不确定项、预计影响、预计资源、权限要求、是否产生外部副作用以及过期条件。

说明性回答不得伪装成已执行；计划完成不得宣告生成、采用、审阅或交付完成。聊天上下文可以帮助理解当前请求，但正式事实只能来自用户授权查询到的版本化对象。

Agent Tool 使用最小范围：只读查询和提交类型化提案；不得获得数据库、对象存储、密钥、任意文件或跨项目通配访问。Tool 失败逐项报告，不把整包显示为成功。

## 5. 画布语义

1. 节点键对应真实领域对象及可选修订，节点位置不是执行顺序。
2. 删除节点默认只移出当前视图；归档或删除领域对象使用独立命令和影响确认。
3. 业务依赖边来自可重建投影；用户装饰连线不得进入影响计算。
4. 画布上的实体、镜头、候选和问题编辑打开权威结构化表单。
5. 无画布时，所有 P0 操作仍可通过列表、表格和表单完成。

## 6. 状态、并发与恢复

AgentRun 可表达 `queued | running | waiting_user | partial | failed | cancelled | completed | superseded`；ProposalItem 为 `pending → accepted | accepted_with_changes | rejected | deferred | expired`。

页面刷新和 Worker 重启后运行与提案可恢复。模型输出重复、非法、越权或引用旧版本时，业务副作用必须为零。同一 ProposalItem 重复接受回读原结果；不同用户并发接受互斥变更时返回领域版本冲突。

## 7. 失败与恢复路径

| 场景 | 用户可见结果 | 恢复动作 |
| --- | --- | --- |
| 模型不可用 | 手工工作台继续可用 | 稍后重跑或手工完成 |
| 部分 Tool 失败 | 显示成功项、失败项和未执行项 | 只重跑失败项 |
| 提案基线过期 | 显示变更对象和风险 | 重新计算或人工迁移 |
| Agent 结果非法 | 保留诊断，不产生正式事实 | 修正输入、模型或契约 |
| 画布实时连接中断 | 显示离线并回源查询 | 重连后按版本刷新 |
| 批量命令部分失败 | 逐项结果和补偿建议 | 重试安全项或人工处理 |

## 8. 非功能需求

| ID | 要求 |
| --- | --- |
| AIC-NFR-001 | Agent 不可用时核心手工业务闭环完整。 |
| AIC-NFR-002 | 提案输出使用版本化结构契约，非法字段拒绝进入业务命令。 |
| AIC-NFR-003 | 会话、Tool 输入、日志和事件按最小数据原则处理敏感来源。 |
| AIC-NFR-004 | 画布大项目性能、内存和可访问性必须通过真实规模原型验证。 |
| AIC-NFR-005 | 所有 P0 操作不依赖拖拽、颜色或空间记忆。 |
| AIC-NFR-006 | Agent 质量指标分别统计提案正确性和人工修改，不用回复满意度替代业务结果。 |

## 9. 验收条件

| ID | 场景 |
| --- | --- |
| AC-AIC-001 | Agent 提出 10 个镜头时用户可逐项接受、修改和拒绝。 |
| AC-AIC-002 | 接受提案与手工提交相同命令产生相同领域结果。 |
| AC-AIC-003 | 非法、重复、越权和过期输出不改变业务事实。 |
| AC-AIC-004 | 高消耗生成只能形成待批准计划，不能由 Agent 回复直接提交。 |
| AC-AIC-005 | 关闭 Agent 后已建立的结构、实体、镜头和后续流程仍可使用。 |
| AC-AIC-006 | 最小关系视图可以定位受人物状态变化影响的镜头并进入结构化修订。 |
| AC-AIC-007 | 删除画布节点只影响布局，不删除实体、镜头或候选。 |
| AC-AIC-008 | 画布、列表和 API 对同一版本冲突返回一致结果。 |
| AC-AIC-009 | Worker 重启后 AgentRun 从已提交检查点恢复且不重复提案。 |

## 10. 指标与待确认项

指标包括提案接受/修改/拒绝率、过期率、非法输出拒绝数、从首稿到可审阅版本时间、手工接管次数、Tool 失败率和关闭 Agent 后任务完成率。待确认完整画布的首发必要性、多人实时协作方式、允许自动应用的低风险草稿类型和每类 Agent 能力的数据外发范围。
