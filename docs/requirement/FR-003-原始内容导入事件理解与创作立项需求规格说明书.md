# FR-003 原始内容导入、事件理解与创作立项需求规格说明书

## 1. 目的与范围

接收创意、梗概、小说片段、故事或已有剧本，保全原始内容和来源；对长篇内容形成带证据的事件与关系提案，并在高成本制作前形成可确认的创作任务书。

## 2. 主业务流程

1. 用户提交原始内容、来源和使用权声明。
2. 系统固定原始内容版本，识别内容类型、完整程度和导入失败范围。
3. 适用时，系统按章节或内容片段提取事件、参与者、状态变化和关系提案，并保留原文证据。
4. 用户修正、接受或拒绝提案，形成可供改编策划引用的事件版本。
5. 用户定义题材、受众、单集规模、语言、画幅、风格、节奏、预算、交付目标和禁用项。
6. 系统检查目标缺失和显性冲突；AI 可提出改编建议，但均保持待确认。
7. 有权责任人确认唯一当前立项基线。

## 4. 业务规则

- BR-003-001：原始内容是不可变来源事实，整理和改编结果是派生版本。
- BR-003-002：无法判断的原著事实不得由系统虚构为确定事实。
- BR-003-003：立项确认只表示生产目标明确，不表示剧本、资产或制作条件已就绪。
- BR-003-004：禁用项的优先级高于普通创作偏好。
- BR-003-005：来源或权利未知不得默认视为可商用；本能力只记录来源事实和权利声明引用，不裁定权利或合规结论。
- BR-003-006：事件提取是来源理解提案，不自动成为故事圣经事实或改编决定。
- BR-003-007：当前已确认立项基线是单集目标时长及允许偏差的权威来源；下游估算、分镜或成片时长不得反写该基线。

## 5. 数据与权限要求

- DR-003-001：保存原始文件或文本、哈希、来源片段、顺序和导入报告。
- DR-003-002：保存派生内容到来源片段的映射、增删改类型和人工决定。
- DR-003-003：保存创作任务书、每集目标时长与允许偏差、版本、确认人、确认时间和影响关系。
- DR-003-004：保存事件版本、事件关系、证据片段、提取运行、置信信息和人工决定。
- DR-003-005：权利声明引用至少保存 `declaration_id`、`declaration_version` 及 `subject_ref`；`subject_ref` 必须包含对象类型 `object_type`、跨版本稳定的 `object_id` 和不可变的 `object_version`，权利状态与证据由合规事实所有者维护，本能力不得复制为权威事实。
- 只有内容创作者可编辑草稿；立项确认权限必须单独授予。

## 6. 异常与恢复

| 场景 | 系统行为 |
| --- | --- |
| 文件损坏、加密或不支持 | 导入失败，不创建伪成功记录。 |
| 仅部分解析成功 | 保留已完成范围，并允许补充或重试失败范围。 |
| 权利声明缺失 | 允许保存受限草稿并标记“待合规核验”；商业制作和正式交付由版本化合规证据门禁阻断。 |
| 立项目标冲突 | 阻止确认并列出冲突；不得擅自修改目标。 |
| 事件关系无法判断或来源冲突 | 保持待定或冲突并展示证据，不虚构确定关系。 |

## 7. 验收标准

- AC-003-001：修改改编稿后，原始内容和哈希保持不变。
- AC-003-002：任一改编段落均可反查原文依据或显示“新增内容”。
- AC-003-003：任一单集缺少 `target_duration_ms`、`allowed_deviation_ms` 或交付范围，目标不是正整数毫秒，或偏差不是小于等于目标的非负整数毫秒时，立项不能被确认。
- AC-003-004：已确认立项被编辑时，系统创建新草稿且旧基线不变。
- AC-003-005：任一事件提案可定位到来源版本和证据片段，重新提取不覆盖既有人工决定。
- AC-003-006：无法确认因果关系时，系统保留待定状态且不把它作为确定改编依据。

## 8. 非目标、契约与依赖方向

不定义文本解析模型、文件解析库、创作页面或合规裁决。上游仅依赖 [SRS-001](SRS-001-AI短剧制作平台总体需求规格说明书.md)；权利声明和合规证据通过共享的版本化契约协作，不构成本规格对合规模块的文档前置依赖。

- 来源内容、导入报告、事件和立项基线的事实所有者是 `story-development`。
- `RightsDeclaration.v1` 的事实所有者是 `compliance-governance`；本能力提交的 `subject_ref` 固定为 `{object_type, object_id, object_version}`，其中 `object_id` 跨版本稳定、`object_version` 指向不可变来源版本，并保存返回的 `declaration_id + declaration_version`。
- 契约升级必须创建新版本；不得覆盖已被制作或交付证据固定引用的声明版本。
