# 分析需求

## 目标与范围

制作者能从真实事实了解当前项目进度和待处理内容。

本模块范围：统计卡、时间/分集口径、任务趋势、按模型结果、分集阶段、待处理与跳转。

建议执行顺序为编号顺序；编号不代表排期或已批准实施。本文件按业务模块整体维护，内部功能在同一文档列出，不为每个按钮、接口或技术层建立单独需求文件。

## 功能与数据要求

<a id="req-f-05"></a>

### 数据分析

#### 字段与数据量

| 区域   | 必须承载的字段                                               | 设计归属                                          | 一次读取 / 保存的量                  |
| ------ | ------------------------------------------------------------ | ------------------------------------------------- | ------------------------------------ |
| 统计卡 | 完成镜头/总数、任务量/环比、成功率/失败/待核对、平均/P95耗时 | shot、generation_job查询计算                      | 固定卡片，均含as_of、窗口和样本数    |
| 图表   | 每日任务、按模型结果、分集阶段进度                           | 任务按时间桶/模型版本聚合；阶段由实际内容事实计算 | 7/14天或全时段有界桶，最多建议366点  |
| 待处理 | 原因、对象摘要、目标ID、数量                                 | 失败/未知任务和失效镜头查询                       | 首批建议10项，分页；无通知表前置依赖 |

#### 功能与失败边界

| 用户动作          | 必须产生的结果                   | 边界与失败                                       |
| ----------------- | -------------------------------- | ------------------------------------------------ |
| 时间 / 分集切换   | 图表与卡片采用同一筛选口径       | 0分母、未知、依赖失败不显示为正常0               |
| 查看趋势 / 待处理 | 有界趋势下载或展开；跳转有权目标 | 图中样例不是数据事实；无明确定义的阶段显示未接入 |

## 范围边界

- 分析需要读模型与计算口径，不默认增加汇总库、计数表或新消息中间件。

## 依赖与待确认

依赖镜头/任务/版本事实；没有真实数据的指标明确未接入。

待确认：阶段完成判据与分母；趋势展开/下载格式范围；待处理与通知入口关系。

以上缺口只是评审问题，不构成新增产品能力或架构决策。既有功能和约束不因旧接口支持不足而删除或降级。

## 模块验收

1. 本文列出的字段和功能由真实数据及操作结果承载，成功/失败/权限/未接入状态明确，mock不作为业务通过。
2. 需要持久化的写入可刷新恢复；版本冲突保留输入，重复副作用按幂等合同核对；只读/瞬时状态不强加持久化。
3. 当前用户/项目范围服务端验证；管理动作限管理员，秘密不进入响应、普通日志、审计明文或导出。
4. 实现时补与本模块风险匹配的成功、失败、冲突/重复、越权场景，分别记录自动化、真实持久化、浏览器及外部供应商证据，未执行不得报通过。

统一要求见[非功能规格](02-非功能需求规格.md)和[交互需求](05-界面与交互需求.md)；当前均待评审、未完成真实功能验收。本阶段不列Sprint、工时或固定用例数量。
