# 项目需求

## 目标与范围

制作者能建立、查找、复制并打开同一创作项目。

本模块范围：空白/剧本创建的项目规格、项目列表/搜索/排序/视图、复制与打开；剧本处理细节见11。

建议执行顺序为编号顺序；编号不代表排期或已批准实施。本文件按业务模块整体维护，内部功能在同一文档列出，不为每个按钮、接口或技术层建立单独需求文件。

## 功能与数据要求

<a id="req-f-01"></a>

### 首页与项目库

#### 字段与数据量

| 区域     | 必须承载的字段                                          | 设计归属                                       | 一次读取 / 保存的量                                  |
| -------- | ------------------------------------------------------- | ---------------------------------------------- | ---------------------------------------------------- |
| 新建表单 | 名称≤50字、剧本文件、9:16/16:9/1:1、写实/动漫/国风/胶片 | project；script_document保存上传原件与解析结果 | 一次新建一个项目；文件流上传，不能在首页响应携带全文 |
| 项目卡片 | id、名称、封面、画幅、风格；最近更新排序键              | project + media_asset预览；updated_at用于排序  | 建议每页20条摘要；总数另计，样例项目数量不作容量     |
| 列表操作 | 名称搜索、最近更新/名称排序、网格/列表                  | 筛选/视图留URL或页面状态                       | 同一筛选下数据一致，打开项目才读详情                 |

#### 功能与失败边界

| 用户动作        | 必须产生的结果                                              | 边界与失败                                                                        |
| --------------- | ----------------------------------------------------------- | --------------------------------------------------------------------------------- |
| 空白 / 剧本创建 | 支持全部当前画幅与风格；建项目后按上传剧本自动分集/抽取设定 | 文件文案支持txt/md/docx；input额外pdf是否保留是新页面自身歧义，不能沿旧接口裁掉md |
| 复制项目        | 生成新项目身份、独立可编辑内容及复制状态                    | 共享只读原件可引用，删除不能损坏副本；无需先建设通用复制平台                      |
| 打开项目 / 画布 | 进入同一project上下文的概览或画布                           | 没有数据、无匹配、失败分开；不追加旧工作台目录/归档功能                           |

## 范围边界

- 主页字段足以定义项目与导入；没有目录树、回收管理或独立剧本工作台的当前消费者。

## 依赖与待确认

依赖用户身份和项目归属；复制只读原件时复用素材引用。

待确认：复制包含的内容与历史范围；PDF支持由剧本需求明确。

以上缺口只是评审问题，不构成新增产品能力或架构决策。既有功能和约束不因旧接口支持不足而删除或降级。

## 模块验收

1. 本文列出的字段和功能由真实数据及操作结果承载，成功/失败/权限/未接入状态明确，mock不作为业务通过。
2. 需要持久化的写入可刷新恢复；版本冲突保留输入，重复副作用按幂等合同核对；只读/瞬时状态不强加持久化。
3. 当前用户/项目范围服务端验证；管理动作限管理员，秘密不进入响应、普通日志、审计明文或导出。
4. 实现时补与本模块风险匹配的成功、失败、冲突/重复、越权场景，分别记录自动化、真实持久化、浏览器及外部供应商证据，未执行不得报通过。

统一要求见[非功能规格](02-非功能需求规格.md)和[交互需求](05-界面与交互需求.md)；当前均待评审、未完成真实功能验收。本阶段不列Sprint、工时或固定用例数量。
