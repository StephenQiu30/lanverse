# FR-018 内容权利、安全与 AI 标识合规需求规格说明书

## 1. 目的与范围

对原始内容、参考素材、人物肖像、声音、生成媒体和交付版本建立权利声明、内容安全检查、人工复核和 AI 生成标识机制，阻止权利不明、违反强制安全规则或缺少法定标识的内容进入正式交付。

本规格定义平台应支持的合规能力，不构成对任何项目或地区的法律意见。具体规则、适用地区和证据期限须由业务与法务确认并配置。

## 2. 主业务流程

1. 用户提交内容或资产时声明来源、权利主体、允许用途和证据。
2. 系统根据项目地区、渠道和用途判断所需权利与检查项。
3. 系统对输入、生成结果和成片版本执行适用的安全检查。
4. 命中项进入自动阻断、人工复核或提醒流程。
5. 审核人员记录结论、理由、适用范围和有效期限。
6. 系统在输出及相关元数据中写入适用的 AI 生成标识。
7. 权利或规则变化时，相关下游结果进入待复核状态。

## 3. 功能需求

| 编号 | 规范性需求 | 优先级 |
| --- | --- | --- |
| FR-018-001 | 系统应为原始内容、外部参考、肖像、声音和生成媒体记录独立的来源与权利声明。 | P0 |
| FR-018-002 | 系统应记录权利主体、授权或单独同意证据、允许用途、期限、地区、渠道、撤回状态和限制条件。 | P0 |
| FR-018-003 | 系统应将未知、待核验、允许、受限、过期和禁止作为可区分的权利状态。 | P0 |
| FR-018-004 | 系统应根据项目地区、渠道、用途和内容类型确定适用的合规规则版本。 | P0 |
| FR-018-005 | 系统应对进入生产的输入内容执行适用的内容安全检查。 | P0 |
| FR-018-006 | 系统应对生成候选和成片版本执行适用的内容安全检查。 | P0 |
| FR-018-007 | 系统应把检查结果区分为强制阻断、需人工复核和仅提醒。 | P0 |
| FR-018-008 | 系统应允许有权审核人员记录复核结论、理由、范围和证据。 | P0 |
| FR-018-009 | 系统应支持对可申诉检查结果发起复核申请并保留原结论。 | P0 |
| FR-018-010 | 系统应在适用的可见位置添加 AI 生成或合成内容显式标识。 | P0 |
| FR-018-011 | 系统应在适用的文件或元数据中写入机器可识别的 AI 内容标识。 | P0 |
| FR-018-012 | 系统应在权利、规则或上游内容变化后标识受影响的任务、候选和交付版本。 | P0 |
| FR-018-013 | 系统应生成与固定交付版本对应的权利、检查、复核和 AI 标识清单。 | P0 |
| FR-018-014 | 系统应根据发行地区、内容类别、制作主体和渠道确定适用的审核层级、备案或许可材料要求。 | P0 |
| FR-018-015 | 系统应记录制作主体、内容分类、审核结论、备案号或许可证号、证明文件、适用渠道和有效状态。 | P0 |
| FR-018-016 | 系统应在适用备案或许可材料缺失、未知、失效或待复核时阻止正式交付。 | P0 |

## 4. 业务规则

- BR-018-001：权利状态未知不得默认解释为允许商业使用。
- BR-018-002：肖像授权、声音授权和适用的个人信息处理单独同意应分别确认，不能相互替代。
- BR-018-003：强制阻断不得通过普通业务审批绕过。
- BR-018-004：人工复核结论仅对记录的对象版本、用途和适用范围生效。
- BR-018-005：AI 标识要求应同时考虑用户可见标识和机器可识别标识。
- BR-018-006：规则变化不改写历史结论，但应触发尚未交付或再次交付内容的重新判断。
- BR-018-007：备案或许可字段仅在适用地区、类别和渠道下成为强制门禁，不得把地区规则错误套用到所有项目。

## 5. 数据要求

- DR-018-001：保存权利声明、证据引用、主体、用途、地区、渠道、期限和状态历史。
- DR-018-002：保存规则来源、版本、生效时间、适用范围和门禁级别。
- DR-018-003：保存检查输入、结果、命中项、复核、申诉、处置和标识写入证据。
- DR-018-004：交付清单必须引用固定的内容版本和规则版本。
- DR-018-005：保存内容分类、制作主体、审核层级、备案或许可材料、适用渠道和有效性历史。

## 6. 异常与恢复

| 场景 | 系统行为 |
| --- | --- |
| 权利证据缺失或过期 | 将对象标记为受限并阻止其进入新的商业交付。 |
| 安全检查服务暂不可用 | 将检查置为未完成，不得将其解释为通过。 |
| 人工复核发生分歧 | 保持阻断或待复核状态，交由指定责任人裁决。 |
| 标识写入或验证失败 | 阻止正式交付并保留失败证据。 |
| 适用备案或许可材料无法核验 | 保持未知或待复核，不得解释为已满足。 |

## 7. 验收标准

- AC-018-001：没有有效声音授权或缺少适用单独同意证据的克隆声音不能进入商业交付版本。
- AC-018-002：安全检查服务故障时，系统不会显示检查已通过。
- AC-018-003：命中强制阻断规则的内容不能通过普通审核决定进入交付。
- AC-018-004：权利到期后，历史交付记录仍可查询，新交付被阻断。
- AC-018-005：任一交付版本均可导出其权利依据、规则版本、检查结论和 AI 标识证据。
- AC-018-006：要求备案号或许可证号的发行目标缺少有效材料时，正式交付被阻断并显示责任人和补充项。
