# F05 项目管理

| 项 | 内容 |
| --- | --- |
| 需求 | PRJ-01 创建项目；PRJ-02 项目列表与概览；PRJ-06 归档与删除；PRJ-07 生成策略设置 |
| 优先级 | MVP |
| 用例 | UC-04 |
| 页面 | 项目列表、项目概览、项目设置 |
| 依赖功能 | F01、F03、F06 |
| 状态 | 草案（2026-09-25） |

## 1. 需求说明

### 1.1 背景与目标

项目是一部作品的生产容器，统一画幅、风格、预算与生成策略；所有生成与导出都遵循项目规格。概览让制作者一眼看到每集做到哪一步。

### 1.2 用户故事

- 作为**制作者**，我希望创建项目并设置画幅与风格，以便后续所有生成与导出遵循统一规格。
- 作为**制作者**，我希望看到所有项目，以及每个项目各集各阶段的进度与累计成本。
- 作为**制作者**，我希望归档已完成的项目，删除不需要的项目，并能在 30 天内恢复。
- 作为**制作者**，我希望设置默认模型，并决定本项目是否允许使用境外模型。

### 1.3 范围

- 包含：创建、修改（可修改字段）、列表、概览、归档 / 恢复、删除 / 恢复 / 到期清理、生成策略、AIGC 标识样式。
- 不包含：成员与角色（V2）、项目模板与快照（V2）、项目导出（0202 DAT-07，V1）。

## 2. 需求分析

### 2.1 业务流程

```text
创建（名称、画幅、风格类型、子风格、风格预设、描述）→ 自动创建预算（默认 0，需设置后才能生成，见 F06）
→ 生产 → 概览跟踪 → 归档（只读）⇄ 恢复
删除 → 回收中（30 天）→ 恢复 | 到期彻底清理（数据库记录 + 对象存储）
```

### 2.2 业务规则

| # | 规则 | 理由 |
| --- | --- | --- |
| R1 | 名称 1–50 字，组织内可重名（以 ID 区分） | 内部使用，避免无谓限制 |
| R2 | 画幅（9:16 / 16:9）与风格类型（写实 / 风格化）创建后不可修改；风格化必须选子风格 | 已生成的素材与画幅、风格强绑定（P3、P12） |
| R3 | 输出分辨率固定 1080p | P12 |
| R4 | 可修改：名称、描述、风格预设、默认模型、是否允许境外模型、AIGC 标识样式 | — |
| R5 | 允许境外模型默认关闭；关闭时境外模型在该项目中不可选，报价返回 `overseas_not_allowed` | CMP-06 |
| R6 | 关闭境外开关不影响已确认的境外任务 | 不中断已付费任务 |
| R7 | 归档项目只读：所有写接口返回 `state_conflict`；可浏览、下载 | PRJ-06 |
| R8 | 有进行中任务（`confirmed` 至 `ingesting`、`unknown`、`reconciling`、`manual`）的项目不能删除或归档 | 避免任务结果无处落地 |
| R9 | 删除后 30 天内可恢复；到期由清理任务彻底删除项目数据与媒体对象，审计记录保留 | DAT-05、PRV-05 |
| R10 | 概览按集显示 8 个阶段的完成数 / 总数：场次确认、资产定稿、分镜、关键帧、视频、配音、剪辑、成片 | PRJ-02、0203 §3 |

### 2.3 状态

`project.status`：`active` ⇄ `archived`；`active | archived` → `deleted`（`is_delete = true`，`delete_time`、`purge_after`）→ 恢复为原状态 | 清理。恢复原状态需记录删除前状态（`status` 保留原值，仅 `is_delete` 置位）。

### 2.4 异常与边界

- 概览在大项目（100 集）上计算较重：使用 Redis 物化，事件增量更新；缓存缺失时回源计算（≤ 2 秒）。
- 恢复时若同名项目存在不冲突（R1）。

### 2.5 前置与依赖

风格预设（组织级内置 5 套：写实 + 4 种风格化，P0 后由管理员维护）。

## 3. 实现所需

### 3.1 数据

| 表 / 存储 | 关键字段 | 为什么需要 |
| --- | --- | --- |
| `workspace.project` | `aspect_ratio`、`style_type`、`style_subtype`、`style_preset_id`、`allow_overseas_models`、`default_models`、`aigc_mark_style`、`status`、`is_delete`、`delete_time`、`purge_after` | 项目规格与生命周期；触发器保证 R2 |
| `workspace.style_preset` | `prompt_fragment`、`negative_prompt`、`reference_asset_ids` | 生成时自动带入风格 |
| `billing.budget` | 创建项目时同事务创建 | F06 |
| Redis `overview:{project_id}` | 集 × 阶段计数 | 概览性能 |

概览各阶段的数据来源：

| 阶段 | 完成条件（按集） | 来源 |
| --- | --- | --- |
| 场次确认 | `episode.parse_status = confirmed` | script |
| 资产定稿 | 本集用到的参考槽位全部锁定 | bible.episode_asset_usage + reference_slot |
| 分镜 | 所有场 `scene_board.status = confirmed` | storyboard |
| 关键帧 | 图生视频镜头已选关键帧数 / 图生视频镜头数 | storyboard.shot |
| 视频 | 已选片段镜头数 / 镜头数 | storyboard.shot |
| 配音 | 已选音频台词数 / 台词数 | audio.line_audio_selection |
| 剪辑 | 存在校验通过的剪辑计划版本 | edit |
| 成片 | 存在 `ready` 的成片 | delivery |

### 3.3 异步与工作流

- `ProjectPurgeSchedule`（每日）：对 `purge_after < now()` 的项目执行分批清理工作流（删除对象存储前缀、删除各 schema 数据），可断点续跑。
- 概览物化：`realtime` 之外新增 `overview` 消费者，按事件增量更新 Redis。

### 3.4 事件与实时

`workspace.project_changed.v1`（创建、修改、归档、删除、恢复）→ audit、realtime。

### 3.5 界面

项目列表（卡片 / 表格切换、状态筛选、回收站视图）；新建项目对话框（风格类型切换后显示子风格与预设缩略图）；项目概览矩阵（单元格点击跳转）；设置页（画幅与风格只读并说明原因）。

### 3.6 权限与审计

MVP 所有制作者可访问组织内全部项目。审计：`project.created`、`project.updated`、`project.archived`、`project.unarchived`、`project.deleted`、`project.restored`、`project.purged`。

### 3.7 非功能要求

PERF-01（概览首屏 ≤ 2 秒）；PERF-03（进度更新 ≤ 2 秒）；PRV-05（彻底删除含媒体）。

## 4. 验收标准

- Given 制作者创建 16:9、风格化 / 国风的项目，When 进入该项目的任意生成面板，Then 画幅默认且固定为 16:9，风格预设已带入。
- Given 已创建的项目，When 打开项目设置，Then 画幅与风格类型为只读；直接调用接口修改返回 `validation_failed`。
- Given 第 1 集 30 个镜头中 12 个已选定视频，When 打开项目概览，Then 第 1 集“视频”阶段显示 12/30，刷新后不变。
- Given 有进行中任务的项目，When 用户删除项目，Then 操作被拒绝并列出进行中的任务。
- Given 项目被删除 10 天，When 用户在回收列表中恢复，Then 项目及其媒体完整恢复。
- Given 项目未允许境外模型，When 制作者尝试通过接口对 OpenRouter 模型报价，Then 被拒绝并提示“本项目未允许使用境外模型”。

## 5. 测试要点

- 集成：清理工作流中断后续跑；触发器拒绝修改画幅。
