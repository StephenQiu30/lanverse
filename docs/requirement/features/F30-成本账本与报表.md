# F30 成本账本与报表

| 项 | 内容 |
| --- | --- |
| 需求 | CST-01 调用记账；CST-02 成本汇总；CST-06 成本报表与预算告警（V1） |
| 优先级 | MVP（CST-06 为 V1） |
| 用例 | UC-19 |
| 页面 | 成本 |
| 依赖功能 | F06、F16、F19 |
| 状态 | 草案（2026-09-25） |

## 1. 需求说明

### 1.1 背景与目标

成本上限要在 P0 实测后才能定（P15），因此平台必须精确统计每一分钱花在哪里：按项目、集、镜头、模型；核心指标是“单分钟成片成本”（0101 §10）。

### 1.2 用户故事

- 作为**制作者**，我希望看到每个镜头、每集、每个项目的费用明细与单分钟成本。
- （V1）作为**管理员**，我希望按时间、模型、项目查看成本报表，并在预算使用达到阈值时收到告警。

### 1.3 范围

包含：账本（预留、结算、释放、调整、预算变更）、按维度汇总、单分钟成本、明细下钻、每日对账；V1：跨项目报表、导出、阈值告警配置。不包含：发票、支付。

## 2. 需求分析

### 2.1 业务规则

| # | 规则 | 理由 |
| --- | --- | --- |
| R1 | 每次供应商调用的费用记入 `provider_call.cost_micros`；Operation 结算金额 = 其全部调用费用之和 | CST-01 |
| R2 | 账本分录只追加；更正使用 `adjust` 分录 | 可审计 |
| R3 | 分录带归集维度：项目、集、镜头、Operation、模型、区域 | CST-01 |
| R4 | 单分钟成本 = 该集已结算总费用 ÷ 最新成片分钟数；未出成片时显示“—” | CST-02 |
| R5 | 境外费用保留原币种与汇率 | I18N-02 |
| R6 | 每日对账：预算表的 `reserved`、`settled` 与账本、预留表汇总一致；任务终态无残留预留；差异告警 | REL-08 |
| R7 | 汇总数据由 `billing-report` 消费者增量维护，可从账本全量重建 | 可恢复 |

### 2.2 异常与边界

供应商账单与平台记录不一致：管理员录入 `adjust` 分录并注明依据。

## 3. 实现所需

### 3.1 数据

| 表 | 关键字段 | 为什么需要 |
| --- | --- | --- |
| `billing.ledger_entry` | `entry_type`、`amount_micros`、`operation_id`、`episode_id`、`shot_id`、`model_key`、`region`、`orig_*` | 明细 |
| `billing.reconciliation_run` | `run_date`、`status`、`diff` | 对账 |
| 新增 `billing.cost_summary` | `project_id`、`episode_id`（可空）、`model_key`（可空）、`capability`、`settled_micros`、`operation_count` | 汇总读模型（0302 同步） |

### 3.2 接口

```http
GET /api/v1/projects/{pid}/costs?group_by=episode
200 { "total_settled_micros": 1820000000, "total_reserved_micros": 12000000,
      "items": [ { "episode_id": "…", "seq_no": 1, "settled_micros": 360000000, "delivery_minutes": 2.0, "cost_per_minute_micros": 180000000,
                   "by_capability": { "video.generate": 300000000, "image.generate": 30000000, "audio.tts": 10000000, "text.structured": 20000000 } } ] }
GET /api/v1/projects/{pid}/costs?group_by=shot&episode_id=…
GET /api/v1/projects/{pid}/ledger?operation_id=&episode_id=&limit=
POST /api/v1/admin/ledger:adjust  { "project_id": "…", "amount_micros": -500000, "operation_id": "…", "note": "供应商退款" }   （管理员）
GET /api/v1/admin/costs?from=&to=&group_by=project|model|day   （V1）
```

### 3.3 异步与工作流

`billing-report` 消费者；`LedgerReconcileSchedule`（每日 02:00）。

### 3.4 事件与实时

消费 `operation.completed/failed.v1`；发布 `billing.reconciliation_diff.v1`（告警）。

### 3.5 界面

成本页：项目总览卡（已结算、预留、预算）、按集表格（费用、成片分钟、单分钟成本、按能力拆分）、镜头明细下钻、账本明细。

### 3.6 权限与审计

制作者可查看；调整仅管理员，审计 `ledger.adjusted`。

### 3.7 非功能要求

COST-01（100% 可归集）；COST-02（报价偏差）；REL-08。

## 4. 验收标准

- Given 镜头 3 生成过 3 次视频，When 查看镜头 3 费用明细，Then 列出 3 条记录及合计。
- Given 第 1 集总费用 360 元、成片 2 分钟，When 查看汇总，Then 单分钟成本显示 180 元。
- Given 每日对账运行，When 账本与预算一致，Then 状态为平衡；人为制造差异时产生告警。

## 5. 测试要点

汇总与全量重建一致性；对账差异检测。
