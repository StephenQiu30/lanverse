# F22 图生视频

| 项 | 内容 |
| --- | --- |
| 需求 | VID-01 图生视频；VID-02 视频时长 |
| 优先级 | MVP |
| 用例 | UC-12 |
| 页面 | 镜头详情 · 视频、故事板 |
| 依赖功能 | F16、F17、F21 |
| 状态 | 草案（2026-09-25） |

## 1. 需求说明

### 1.1 背景与目标

以选定关键帧为首帧、结合镜头语言与运动描述生成视频，是构图可控的生成方式。时长需与镜头设定一致，否则影响剪辑节奏。

### 1.2 用户故事

- 作为**制作者**，我希望用选定的关键帧生成视频，时长符合镜头设定。

### 1.3 范围

包含：前置校验、提示词组装、时长处理、生成与选定。不包含：首尾帧（V1）。

## 2. 需求分析

### 2.1 业务规则

| # | 规则 | 理由 |
| --- | --- | --- |
| R1 | 前置：镜头模式为图生视频且已选定关键帧，否则 `precondition_missing` | VID-01 |
| R2 | 输入：`first_frame`（选定关键帧）+ `prompt`（`compose_prompt` 由镜头描述、景别、机位、运镜、运动描述、风格组装；用户改写优先） | 0301 §6.4 |
| R3 | 生成时长 = 镜头时长与模型允许时长的交集；模型只支持离散时长（如 5 / 10 秒）时取不小于镜头时长的最小值，并在剪辑时裁剪 | VID-02 |
| R4 | 镜头时长超出模型上限：报价提示“超出模型范围”，建议拆分镜头或更换模型 | VID-02 |
| R5 | 结果记录实测时长（ffprobe）；与生成时长差 > 0.5 秒时提示 | VID-02 |
| R6 | 输出画幅、分辨率按项目；供应商返回分辨率不符时转码到 1080p 并记录 | P12 |

### 2.2 异常与边界

供应商内容审核拒绝：失败，不可重试（同输入），提示调整描述。

## 3. 实现所需

### 3.1 数据

`operation.operation`（`target_type = shot_take`、`mode = image2video`）；`operation_input`（`first_frame` → 关键帧 `operation_output` 与 `media_asset`，`prompt`）；`media_asset.duration_ms`；`lineage.dependency`（片段 → 关键帧选定、镜头版本）。

### 3.2 接口

```http
POST /api/v1/projects/{pid}/quotes
{ "items": [ { "target_type": "shot_take", "target_id": "<shot_id>", "capability": "video.generate", "mode": "image2video", "output_count": 2 } ] }
→ 422 precondition_missing { "message": "请先选定关键帧" } | input_limit_exceeded { "errors": [{ "field": "duration_ms", "message": "超出模型范围 4–10 秒" }] }
GET /api/v1/shots/{id}/prompt-preview?capability=video.generate   → 组装后的提示词（不计费规则拼接；AI 改写需报价）
```

### 3.3 异步与工作流

OperationWorkflow（异步视频）：提交 → 轮询（退避 5 s → 30 s）→ 接管（下载、ffprobe、转码、缩略图、代理）→ 审核 → 完成。`compose_prompt` 为规则模板拼接（免费）；可选“AI 优化提示词”走 `llm.run_skill(compose_prompt)`（付费确认）。

### 3.4 事件与实时

同 F16、F17。

### 3.5 界面

镜头详情“视频”标签页：前置状态提示、提示词预览与改写、时长提示、生成、候选对比。

### 3.6 权限与审计

同 F16、F17。

### 3.7 非功能要求

PERF-09（供应商完成到候选可见 ≤ 30 秒）。

## 4. 验收标准

- Given 镜头未选定关键帧，When 选择图生视频并请求报价，Then 被阻止并提示先选定关键帧。
- Given 镜头时长 12 秒而模型最长 10 秒，When 请求报价，Then 提示超出模型范围并建议拆分镜头或更换模型。
- Given 镜头时长 4 秒、模型只支持 5 秒，When 生成完成，Then 片段 5 秒，自动粗剪按 4 秒裁剪。

## 5. 测试要点

时长交集计算；提示词组装快照测试；接管流程（转码、代理）。
