# F37 BGM、音效与转场

| 项 | 内容 |
| --- | --- |
| 需求 | AUD-04 BGM 与音效轨；EDT-04 转场 |
| 优先级 | V1 |
| 用例 | UC-13、UC-14 |
| 页面 | 剪辑 |
| 依赖功能 | F26、F27、F28 |
| 状态 | 草案（2026-09-25） |

## 1. 需求说明

### 1.1 背景与目标

MVP 成片只有画面、对白与字幕；V1 补齐背景音乐、音效与常用转场，达到可直接发布的完成度。

### 1.2 用户故事

- 作为**制作者**，我希望添加背景音乐与音效轨并调整音量，在对白时自动压低音乐。
- 作为**剪辑**，我希望在片段之间添加常用转场。

### 1.3 范围

包含：BGM 轨、音效轨（上传或 AI 生成 `audio.music` / `audio.sfx`）、音量与淡入淡出、对白闪避（ducking）、转场（叠化、黑场、白闪、推拉）。不包含：多轨混音台、自定义转场。

## 2. 需求分析

| # | 规则 |
| --- | --- |
| R1 | 时间线增加 `bgm`、`sfx` 轨（0302 `timeline_item.track` 已预留） |
| R2 | 音乐与音效可上传（F28）或 AI 生成（F16 报价确认），生成结果进入媒体库 |
| R3 | 对白闪避：对白出现时 BGM 自动降低 −12 dB，淡入淡出 300 ms，可关闭 |
| R4 | 转场作为视频条目属性 `transition`：类型 + 时长（200–1,000 ms）；转场占用相邻两片段的重叠时间，校验片段余量 |
| R5 | 使用的音乐须有授权记录（上传时声明来源，或为平台 AI 生成） |
| R6 | 渲染时混音响度仍归一到 −16 LUFS |

## 3. 实现所需

- 数据：`edit.timeline_item`（`track = bgm | sfx`、`gain_db`、`transition`）；`timeline_item` 增加 `fade_in_ms`、`fade_out_ms`、`ducking boolean`（0302 同步）；媒体增加 `license_note`（音乐来源声明，0302 同步）。
- 接口：剪辑计划版本保存接口扩展轨道；报价 `capability = audio.music | audio.sfx`（`target_type = free`，结果入媒体库）。
- 工作流：RenderWorkflow 增加 `MixMusic`、`ApplyTransitions` 步骤。
- 界面：时间线新增两条音轨、音量包络、转场下拉。
- 权限与审计：同 F26、F27。

## 4. 验收标准

- Given 添加一段 BGM 并开启闪避，When 渲染，Then 对白处音乐明显降低，整体响度 −16 LUFS ± 1。
- Given 在两个片段间添加 500 ms 叠化，When 渲染，Then 成片总时长减少 500 ms 且过渡平滑。

## 5. 测试要点

FFmpeg 滤镜图黄金样例；转场余量校验。

## 6. 待确认

无。
