# F14 生成模式与参考组合

| 项 | 内容 |
| --- | --- |
| 需求 | SB-04 生成模式与参考组合 |
| 优先级 | MVP |
| 用例 | UC-10 |
| 页面 | 镜头详情 · 参考组合编辑 |
| 依赖功能 | F03、F10、F13、F24、F28、F12 |
| 状态 | 草案（2026-09-25） |

## 1. 需求说明

### 1.1 背景与目标

全能参考是必须能力（P10）：一个镜头可同时输入多个角色造型图、场景图、道具图、动作 / 运镜参考视频、参考音频。参考组合是镜头内容的一部分，决定视频生成的输入，因此需要结构化、可校验、可版本化。

### 1.2 用户故事

- 作为**制作者**，我希望为每个镜头选择“图生视频”或“全能参考”，并在全能参考模式下编辑参考组合，每一项注明用途。

### 1.3 范围

- 包含：生成模式切换、视频模型选择、参考项增删排序、用途选择、按模型上限校验、就绪校验、版本化。
- 不包含：参考项的生成（F10、F28）、首尾帧（V1，F36）。

## 2. 需求分析

### 2.1 业务流程

```text
镜头详情 → 选择模式与视频模型（默认取项目默认模型）→ 参考组合面板显示模型上限
→ 添加参考：从设定集选锁定版本（subject / scene / prop / style）、从媒体库选就绪视频（motion / camera）或音频（audio）、选本镜台词音频（audio）
→ 实时校验：数量上限、类型、时长、就绪、授权 → 保存 → 镜头新版本
→ 报价时再次校验（以服务端为准）并展开为 Operation 输入
```

### 2.2 业务规则

| # | 规则 | 理由 |
| --- | --- | --- |
| R1 | 用途枚举：主体 `subject`、场景 `scene`、道具 `prop`、风格 `style`、动作 `motion`、运镜 `camera`、音频 `audio`（V1 增加首帧 / 尾帧） | 0301 §4.2 |
| R2 | 可引用：锁定的参考版本、`ready` 且审核通过的媒体、已选定的台词音频、（V1）已选定的片段 | SB-04 |
| R3 | 用途与类型匹配：subject / scene / prop / style 只能是图片；motion / camera 只能是视频；audio 只能是音频 | 防止错误输入 |
| R4 | 数量与时长上限来自所选模型版本的 `limits`；超限项标红，可保存，报价被阻止 | 允许先编辑后换模型 |
| R5 | 引用未就绪或未授权素材：标记并阻止报价 | SB-04、BIB-07 |
| R6 | 参考组合属于镜头版本：任何修改产生新版本，已生成的片段标记过期 | VID-04 |
| R7 | 分镜生成的默认参考组合：本镜出现的角色造型（subject）、场景（scene）、关键道具（prop）；有台词且模型支持音频参考时加入台词音频（若已选定） | 减少手工操作 |
| R8 | 切换为图生视频时参考组合保留但不参与生成（界面折叠提示） | 允许来回切换 |
| R9 | 台词音频作为参考时引用其 `dialogue_audio_id`；台词音频改选后镜头过期 | 表演与声音一致 |

### 2.3 状态

无独立状态；校验结果为派生值。

### 2.4 异常与边界

- 模型切换导致原组合超限：保留组合，标红超出项，给出“按优先级自动裁剪”建议（不自动执行）。
- 引用的参考版本被新版本取代：组合仍指向旧版本并显示“有新版本”，一键更新到最新版本（产生镜头新版本）。

### 2.5 前置与依赖

F03 注册表的 `limits`；F10 锁定版本；F28 就绪素材。

## 3. 实现所需

### 3.1 数据

| 表 | 关键字段 | 为什么需要 |
| --- | --- | --- |
| `storyboard.shot_version` | `generation_mode`、`video_model_key`、`video_params` | 模式与模型 |
| `storyboard.reference_item` | `seq_no`、`role`、`ref_type`、`ref_id`、`owner_hint` | 参考组合（属于版本，不可变） |
| `operation.operation_input` | 报价时展开：`role`、`ref_type`、`ref_id`、`ref_version`、`media_asset_id` | 冻结输入 |
| `lineage.dependency` | 镜头版本 → 每个参考项的上游 | 过期 |

### 3.2 接口

```http
POST /api/v1/shots/{id}/versions
{ "expected_revision": 5, "patch": { "generation_mode": "omni_reference", "video_model_key": "ark.seedance-2-pro",
  "references": [ { "role": "subject", "ref_type": "reference_version", "ref_id": "…" },
                  { "role": "subject", "ref_type": "reference_version", "ref_id": "…" },
                  { "role": "scene",   "ref_type": "reference_version", "ref_id": "…" },
                  { "role": "camera",  "ref_type": "media_asset",       "ref_id": "…" },
                  { "role": "audio",   "ref_type": "dialogue_audio",    "ref_id": "…" } ] } }
201 { "version_no": 6, "revision": 6, "validation": { "ok": true, "usage": { "image": [3, 9], "video": [1, 3], "audio": [1, 3] } } }

POST /api/v1/shots/{id}:validate-references   { "video_model_key": "…" }    → 不保存，仅校验
200 { "ok": false, "errors": [ { "seq_no": 4, "code": "input_limit_exceeded", "message": "音频参考最多 3 段" },
                               { "seq_no": 2, "code": "input_not_ready", "message": "素材尚未就绪" } ] }
```

参考选择器数据源：`GET /projects/{pid}/characters?episode_id=`（锁定版本）、`GET /projects/{pid}/media?kind=video&status=ready`、`GET /episodes/{eid}/dialogue?shot_id=`。

### 3.3 异步与工作流

无；报价时由命令层展开（0304 §报价）。

### 3.4 事件与实时

随镜头版本事件发布。

### 3.5 界面

参考组合面板（0205 §4.4）：顶部上限条；卡片列表（缩略图 / 波形、名称与版本、用途下拉、“有新版本”提示、移除）；添加菜单（设定集 / 媒体库 / 台词音频 / 上传）；拖拽排序。

### 3.6 权限与审计

制作者；随镜头版本留痕。

### 3.7 非功能要求

校验 P95 ≤ 200 ms（纯内存计算 + 一次批量查询）。

## 4. 验收标准

- Given 全能参考镜头，When 添加两个角色造型、一个场景、一段运镜参考视频、一段台词音频，Then 参考组合显示 5 项及其用途。
- Given 所选模型音频参考上限为 3，When 添加第 4 段音频，Then 该项标红并提示上限，报价被阻止。
- Given 参考组合引用了一段仍在处理中的上传视频，When 请求报价，Then 被阻止并提示“素材尚未就绪”。
- Given 参考组合中的造型有新锁定版本，When 打开镜头，Then 显示“有新版本”，点击更新后产生镜头新版本。

## 5. 测试要点

校验器的所有规则组合（表驱动单元测试）；前后端校验结果一致性（共用测试向量）。
