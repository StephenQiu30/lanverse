# F27 渲染与成片交付

| 项 | 内容 |
| --- | --- |
| 需求 | EDT-03 渲染前校验；DLV-01 渲染成片；DLV-02 AIGC 标识；DLV-03 成片版本 |
| 优先级 | MVP |
| 用例 | UC-15 |
| 页面 | 剪辑（校验）、交付 |
| 依赖功能 | F25、F26、F31 |
| 状态 | 草案（2026-09-25） |

## 1. 需求说明

### 1.1 背景与目标

最终产物是可发布的 1080p 成片（P12），必须带 AIGC 显式与隐式标识（CMP-01），可复现、可追溯（成片清单记录全部引用版本）。

### 1.2 用户故事

- 作为**制作者**，我希望渲染前知道哪些问题会阻止渲染；渲染出带 AIGC 标识的 1080p 成片；每次渲染保留为一个版本，可随时下载旧版本。

### 1.3 范围

包含：渲染前校验、渲染、AIGC 标识、质检、成片版本与清单、下载。不包含：剪映 / Premiere 工程导出（V2）、多码率导出、平台直发。

## 2. 需求分析

### 2.1 业务流程

```text
选择剪辑计划版本 → 校验：
  阻止：片段未选定（占位）、素材未就绪 / 不可用、音频或字幕时码越界、引用对象已逻辑删除、审核未通过
  提示：过期素材、对白溢出、估算时长的字幕
→ 渲染（RenderWorkflow）：
  1. 逐片段裁剪并统一为 1080p、项目画幅、25 fps、H.264（CRF 18）
  2. 拼接视频轨；混音对白轨（响度归一到 −16 LUFS，峰值 −1 dBTP）
  3. 烧录字幕（项目样式）+ 叠加 AIGC 显式标识（项目样式）
  4. 写入隐式标识（MP4 元数据：AIGC 标记、平台、生成时间、内容 ID）
  5. 质检：完整解码、时长 = 计划时长 ± 0.1 秒、分辨率、音频电平
  6. 生成 SRT、成片清单 → delivery = ready → 通知
```

### 2.2 业务规则

| # | 规则 | 理由 |
| --- | --- | --- |
| R1 | 校验不通过不能渲染；过期只提示 | EDT-03 |
| R2 | 输出：MP4（H.264 High + AAC-LC 48 kHz 立体声），1080×1920（9:16）或 1920×1080（16:9） | DLV-01 |
| R3 | 每集的每次渲染产生新成片版本，旧版本保留可下载 | DLV-03 |
| R4 | 成片清单包含：剪辑计划版本、每个片段的 `media_asset_id` 与 sha256、每个片段的生成操作 ID 与模型、音频来源、字幕、渲染参数、标识方式 | 可追溯、CMP-01 |
| R5 | AIGC 显式标识：默认右下角半透明“AI 生成”字样，项目可选预设位置；不可关闭 | CMP-01 |
| R6 | 隐式标识写入文件元数据，并记录到 `media_asset.aigc_marked = true` | CMP-01 |
| R7 | 同一剪辑计划版本同一时刻只能有一个渲染（Redis 锁 + Workflow ID `render/{edit_plan_version_id}`）；重复请求返回已有渲染 | 幂等 |
| R8 | 渲染使用平台算力，不计入模型费用；渲染耗时计入平台开销统计 | 11 成本 |

### 2.3 状态

`delivery.status`：`rendering` → `checking` → `ready`；任一步骤 → `failed`（可重试）。

### 2.4 异常与边界

- FFmpeg 失败：保留日志摘要，重试 2 次；仍失败标记失败并显示原因类别。
- 渲染中剪辑计划有新版本：不影响本次渲染（引用的是固定版本）。

## 3. 实现所需

### 3.1 数据

| 表 | 关键字段 | 为什么需要 |
| --- | --- | --- |
| `edit.edit_plan_version.validation` | 最近一次校验结果 | 展示 |
| `delivery.delivery` | `version_no`、`edit_plan_version_id`、`status`、`video_asset_id`、`srt_asset_id`、`manifest`、`qc_result`、`workflow_id` | 成片版本 |
| `media.media_asset` | `origin = rendered`、`aigc_marked` | 成片文件 |

### 3.2 接口

```http
POST /api/v1/edit-plan-versions/{id}:validate
200 { "renderable": false, "blocking": [ { "code": "take_not_selected", "shot_no": "1-7" } ], "warnings": [ { "code": "stale", "shot_no": "1-3" } ] }

POST /api/v1/edit-plan-versions/{id}:render
202 { "delivery_id": "…", "version_no": 2, "status": "rendering" }
422 render_blocked { "meta": { "issues": [ … ] } }

GET /api/v1/episodes/{eid}/deliveries
GET /api/v1/deliveries/{id}          → 状态、清单、质检结果、标识信息
GET /api/v1/deliveries/{id}/download?file=video|srt   → 预签名 URL（1 小时），写审计
```

### 3.3 异步与工作流

`RenderWorkflow`（`render/{edit_plan_version_id}`，`media` 队列）：`PrepareClips`（并行，每片段一个 Activity）→ `ConcatAndMix` → `BurnSubtitlesAndMark` → `WriteMetadata` → `QualityCheck` → `BuildSrt` → `flow.RegisterDelivery`。长 Activity 心跳 10 秒；中间文件存对象存储临时前缀，生命周期 7 天。

### 3.4 事件与实时

`delivery.status_changed.v1` → realtime、notify、audit。

### 3.5 界面

剪辑页“校验”面板（阻止项与提示分组，可点击定位）；交付页成片版本列表（版本、时长、时间、状态、下载）、清单查看、质检结果、AIGC 标识预览。

### 3.6 权限与审计

制作者；审计 `delivery.rendered`、`delivery.downloaded`。

### 3.7 非功能要求

PERF-08（2 分钟成片 ≤ 5 分钟）；CMP-01；CPT-03。

## 4. 验收标准

- Given 1 个镜头未选定片段、1 个镜头素材过期，When 请求渲染，Then 渲染被阻止并列出未选定镜头；过期镜头只显示提示。
- Given 剪辑计划时长 92 秒，When 渲染完成，Then 成片分辨率为 1080×1920（9:16）或 1920×1080（16:9），时长 92 秒 ± 0.1 秒，主流播放器可完整播放。
- Given 成片，When 播放与读取元数据，Then 画面可见标识，元数据包含标识字段。
- Given 已有成片 v1，When 替换一个镜头后重新渲染，Then 产生 v2，v1 仍可下载。

## 5. 测试要点

FFmpeg 管线黄金样例（像素与响度校验）；质检失败路径；重复渲染请求幂等。
