# F15 故事板视图

| 项 | 内容 |
| --- | --- |
| 需求 | SB-05 故事板视图 |
| 优先级 | MVP |
| 用例 | UC-09、UC-12 |
| 页面 | 分镜 · 故事板 |
| 依赖功能 | F13、F17、F18、F29 |
| 状态 | 草案（2026-09-25） |

## 1. 需求说明

### 1.1 背景与目标

镜头表适合编辑参数，故事板适合“看”：以缩略图网格浏览整场或整集，快速发现未生成、失败、过期的镜头，并作为批量生成与选片的入口。

### 1.2 用户故事

- 作为**制作者**，我希望以缩略图网格浏览整场或整集的镜头，一眼看到每个镜头的状态，并多选批量生成。

### 1.3 范围

包含：网格展示、双维度状态、筛选（按状态、场、模式）、多选、跳转镜头详情、悬停播放片段。不包含：画布（V1）。

## 2. 需求分析

### 2.1 业务规则

| # | 规则 | 理由 |
| --- | --- | --- |
| R1 | 每格显示：镜号、模式图标、封面（已选片段封面 > 已选关键帧 > 最新候选 > 占位）、生产进度、内容状态（过期 / 缺失引用） | SB-05、0203 §6.4 |
| R2 | 生产进度由 Operation 事件驱动更新 `shot.progress`：有进行中任务 → `generating`；有候选未选 → `awaiting_selection`；已选 → `selected`；最近一次失败且无候选 → `failed` | 状态一致 |
| R3 | 悬停自动静音播放已选片段（同时最多 1 个），视口外不加载视频 | 性能 |
| R4 | 筛选条件写入 URL，刷新保持 | 0205 §2 |

### 2.2 异常与边界

150 个镜头一次加载；封面使用 `thumb_640` 渲染版本；视频只在悬停时请求 `proxy_720p`。

## 3. 实现所需

### 3.1 数据

复用 `storyboard.shot`（`progress`）、`shot_version`、`operation_output` 与 `media.rendition`（封面）、`lineage.stale_mark`。`shot.progress` 由 `storyboard-progress` 消费者根据 `operation.status_changed.v1` 更新（只写进度字段，符合 GEN-10）。

### 3.2 接口

复用 `GET /api/v1/episodes/{eid}/shots`，增加 `?view=board` 返回精简字段（封面 URL、进度、状态），单次响应 ≤ 150 条、≤ 200 KB：

```json
{ "items": [ { "id": "…", "shot_no": "3-12", "mode": "omni_reference", "cover_url": "…", "take_preview_url": "…",
               "progress": "awaiting_selection", "candidates": 3, "stale": true, "missing_refs": 0, "revision": 5 } ] }
```

### 3.3 异步与工作流

无。

### 3.4 事件与实时

SSE `shot.updated`、`operation.updated`、`stale.changed` → 局部刷新对应格子。

### 3.5 界面

网格（TanStack Virtual 行虚拟化）；按场分组标题；筛选栏；多选（Shift 连选）后底部操作栏：批量生成关键帧 / 视频、批量改参数（跳镜头表）。

### 3.6 权限与审计

制作者；只读视图无审计。

### 3.7 非功能要求

PERF-04（150 格首次渲染 ≤ 1 秒、滚动 ≥ 50 fps）；PERF-03（状态更新 ≤ 2 秒）。

## 4. 验收标准

- Given 一集 150 个镜头，When 打开故事板，Then 所有镜头按顺序显示状态，滚动无明显卡顿。
- Given 某镜头视频生成完成，When 停留在故事板，Then 2 秒内该格显示“待选 N”。
- Given 某造型改锁，When 查看故事板，Then 受影响的镜头显示“过期”。

## 5. 测试要点

进度状态机单元测试；前端性能录制（150 格）。

## 6. 待确认

无。
