# F24 台词配音与真人音轨

| 项 | 内容 |
| --- | --- |
| 需求 | AUD-01 台词配音；AUD-02 上传真人音轨替换 |
| 优先级 | MVP |
| 用例 | UC-13 |
| 页面 | 配音与字幕 |
| 依赖功能 | F08、F11、F16、F17、F28 |
| 状态 | 草案（2026-09-25） |

## 1. 需求说明

### 1.1 背景与目标

声音以 AI 配音为主，可替换为上传的真人音轨（P8）。每句台词独立生成、试听、选定；真人录音可以按句或按整场上传后切分对齐。

### 1.2 用户故事

- 作为**制作者**，我希望按角色音色为每句台词生成配音，并可调整语速与情绪。
- 作为**制作者**，我希望上传真人录音替换某句或整场的配音，并能切回 TTS。

### 1.3 范围

包含：批量 TTS、逐句重生成、语速与情绪、选定、单句上传、整场上传与切分对齐、切回。不包含：口型同步（待定）、声音克隆（V2）、BGM（V1）。

## 2. 需求分析

### 2.1 业务流程

```text
配音页：列出本集台词（按场）→ 批量报价（未配音 / 过期的台词）→ 确认 → 逐句 TTS → 候选
→ 试听 → 选定（line_audio_selection）
上传：单句上传 → 审核 → 成为候选 → 选定
整场上传：上传整段录音 → 系统按台词文本做强制对齐（ASR + 文本对齐）给出建议切分 → 用户调整分界 → 切分为每句候选 → 选定
```

### 2.2 业务规则

| # | 规则 | 理由 |
| --- | --- | --- |
| R1 | 默认使用角色音色（F11）与其默认参数；可逐句覆盖语速（0.5–2.0）与情绪（模型支持的枚举） | AUD-01 |
| R2 | 台词文本（`content_hash`）变化或角色音色变化 → TTS 音频过期；上传的真人音轨只在文本变化时过期 | LIN-01 |
| R3 | 选定以 `(episode_id, line_key)` 为键，跨结构版本有效 | 稳定键 |
| R4 | 替换后原 TTS 候选保留，可切回 | AUD-02 |
| R5 | 上传格式 mp3 / wav / m4a，统一转码为 48 kHz 单声道 WAV 存储渲染用版本 | 渲染一致 |
| R6 | 整场对齐的 ASR 调用属于付费生成（报价确认）；用户也可以不用 ASR，手动切分 | GEN-11 |
| R7 | 选定音频的时长写入台词（供自动粗剪与字幕） | EDT-01、AUD-03 |

### 2.3 状态

台词配音状态：未配音 → 生成中 → 待选 → 已选（TTS / 真人）；叠加“过期”。

### 2.4 异常与边界

- TTS 对特殊字符 / 多音字：支持在台词上设置“发音修正文本”（只影响 TTS 输入，不改台词），作为 TTS 参数。
- 台词为空或仅动作：不生成。

## 3. 实现所需

### 3.1 数据

| 表 | 关键字段 | 为什么需要 |
| --- | --- | --- |
| `audio.dialogue_audio` | `episode_id`、`line_key`、`line_content_hash`、`source`、`media_asset_id`、`operation_output_id`、`voice_profile_revision`、`speed`、`emotion`、`duration_ms` | 候选与过期判断 |
| `audio.line_audio_selection` | `(episode_id, line_key)` 唯一、`dialogue_audio_id`、`subtitle_text`、`revision` | 当前选定 |
| `operation.operation` | `target_type = dialogue_audio`、`capability = audio.tts` / `audio.asr` | 生成与对齐 |

新增 `audio.line_tts_override`（`episode_id`、`line_key`、`pronunciation_text`、`speed`、`emotion`）保存逐句覆盖参数（0302 同步）。

### 3.2 接口

```http
GET /api/v1/episodes/{eid}/dialogue?scene_key=
200 { "items": [ { "line_key": "…", "speaker": { "character_id": "…", "name": "李明" }, "content": "你怎么来了？",
                   "voice": { "voice_id": "…", "name": "青年男声·沉稳" }, "override": { "speed": 1.1, "emotion": "surprised" },
                   "selected": { "dialogue_audio_id": "…", "source": "tts", "duration_ms": 1830, "url": "…" },
                   "candidates": 2, "state": { "stale": false }, "revision": 3 } ] }

PUT  /api/v1/episodes/{eid}/dialogue/{line_key}/override   { "speed": 1.1, "emotion": "surprised", "pronunciation_text": null }

POST /api/v1/episodes/{eid}/dialogue/{line_key}:select-audio   { "dialogue_audio_id": "…", "expected_revision": 3 }
POST /api/v1/episodes/{eid}/dialogue/{line_key}/uploads        { "media_asset_id": "…" }

POST /api/v1/episodes/{eid}/dialogue:align-upload

```

`target_id` 使用组合键字符串 `<episode_id>:<line_key>`；0302 的 `operation.target_id` 为 uuid，因此增加 `target_key text` 列存放组合键（0302 同步）。

### 3.3 异步与工作流

TTS：OperationWorkflow（同步型）。整场切分：`AudioSplitWorkflow`（`media` 队列 FFmpeg 切分 → 每段登记 `media_asset` 与 `dialogue_audio`）。

### 3.4 事件与实时

`audio.selection_changed.v1` → lineage（剪辑过期）、realtime。

### 3.5 界面

按场分组的台词表：说话人、文本、音色、语速 / 情绪、候选播放、选定、上传；批量工具栏；整场对齐编辑器（波形 + 台词分界拖拽）。

### 3.6 权限与审计

制作者；审计 `dialogue_audio.selected`。

### 3.7 非功能要求

PERF-04（台词表 ≥ 150 行流畅）；CAP-01（全剧约 1.5 万句）。

## 4. 验收标准

- Given 第 1 集 48 句台词，When 批量生成配音并选定，Then 每句台词都有选定音频，时长记录在台词上。
- Given 某句台词已有 TTS，When 上传真人录音并选定，Then 剪辑使用真人录音；切回 TTS 后剪辑随之更新。
- Given 一段整场录音，When 按建议切分并调整后提交，Then 每句台词生成一个真人音轨候选，时长与切分一致。
- Given 台词文本被修改，When 查看配音，Then 该句 TTS 与真人音轨都标记过期。

## 5. 测试要点

过期规则（文本、音色）；整场切分精度（边界 ± 50 ms）；转码格式。
