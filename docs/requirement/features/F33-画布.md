## 1. 需求说明

### 1.1 背景与目标

LibTV 式无限画布是探索与精修的界面：把镜头、角色、素材、生成节点摆在一起，连线即参考、运行即生成（P9：与流水线并重、共享数据）。画布只拥有布局，业务数据与流水线是同一份。

### 1.2 用户故事

- 作为**制作者**，我希望在无限画布上以节点展示镜头表、镜头、角色、素材与生成节点，并连线与分组。
- 作为**制作者**，我希望在画布上运行生成节点，连线即参考，结果可以“提升”为镜头的正式片段。
- 作为**制作者**，我希望布局自动保存，支持撤销重做、复制粘贴与快捷键，大画布依然流畅。

### 1.3 范围

包含：节点类型 × 动作（0301 §9.1）、四种连线、布局命令、业务命令转调、生成节点运行、素材预设节点、撤销重做、快照、性能优化。不包含：多人实时协作（后续）、画布模板（V2 PRJ-05）。

## 2. 需求分析

### 2.1 业务规则

| # | 规则 | 理由 |
| --- | --- | --- |
| R1 | 业务对象节点只存 `ref_type + ref_id` 与布局；显示内容实时读业务数据 | 单一事实源（0301 P1） |
| R2 | `reference` 连线 = 镜头参考组合中的一项：创建连线即调用镜头改版本命令（F14），删除连线同理；与流水线同一份数据 | CNV-03 |
| R3 | `input` 连线 = 自由生成节点的输入（不影响业务对象） | CNV-02 |
| R4 | `promote` 连线 = 选定命令：把自由生成结果提升为镜头的片段 / 关键帧或槽位参考 | 0301 §9.2 |
| R5 | 生成节点运行走 F16 报价确认；结果写入节点的 `last_operation_id`（任务只写结果字段） | GEN-11、GEN-10 |
| R6 | 画布命令批量提交带 `expected_revision`；冲突时基于最新文档重放本地未确认命令 | 0301 §9.3 |
| R7 | 撤销只撤销布局命令与非付费的业务编辑（通过反向命令）；付费生成、选定、确认不撤销 | CNV-05 |
| R8 | 素材预设节点（风格、镜头语言）连到生成节点即套用参数 | CNV-08 |
| R9 | 性能：视口裁剪、缩放阈值切换缩略图、同时播放视频 ≤ 3、500 节点 ≥ 50 fps | CNV-06、PERF-06 |

### 2.2 异常与边界

- 业务对象被删除：节点显示“对象已删除”，可移除。
- 超大画布（> 2,000 节点）：提示拆分为多个画布（按集）。

## 3. 实现所需

### 3.1 数据

`canvas.document`（`revision`、`scope`、`viewport`）、`canvas.node`（`node_type`、`node_action`、`ref_type`、`ref_id`、`config`、坐标尺寸、`parent_id`、`last_operation_id`）、`canvas.edge`（`edge_type`、`role`、`binding`）、`canvas.document_snapshot`；见 0302 §5.13。新增 `canvas.command_log`（`document_id`、`revision`、`commands jsonb`、`create_by`）用于冲突重放与审计（0302 同步）。

### 3.2 接口

```http
GET  /api/v1/projects/{pid}/canvases                  → 画布列表
POST /api/v1/projects/{pid}/canvases                  { "name": "第 1 集探索", "scope": { "episode_id": "…" } }
GET  /api/v1/canvases/{id}                            → 文档、节点、连线、revision，以及业务节点的摘要数据
GET  /api/v1/canvases/{id}/changes?since_revision=12  → 增量
POST /api/v1/canvases/{id}/commands
{ "expected_revision": 12, "commands": [
    { "type": "AddNodes", "nodes": [ { "id": "…", "node_type": "video", "node_action": "generate", "config": { "capability": "video.generate", "mode": "omni_reference", "model_key": "…" }, "x": 100, "y": 200 } ] },
    { "type": "Connect", "edge": { "id": "…", "edge_type": "reference", "source_node_id": "…", "target_node_id": "…", "role": "camera" } },
    { "type": "MoveNodes", "moves": [ { "id": "…", "x": 320, "y": 80 } ] } ] }
200 { "revision": 13, "results": [ { "ok": true }, { "ok": true, "business": { "shot_id": "…", "shot_version_no": 7 } }, { "ok": true } ] }

POST /api/v1/canvases/{id}/nodes/{nid}:run            → 报价（F16）
POST /api/v1/canvases/{id}/snapshots
```

### 3.3 异步与工作流

生成节点运行复用 OperationWorkflow；无新工作流。

### 3.4 事件与实时

`canvas.document_changed.v1`；SSE `canvas.updated`（其他标签页或 Agent 修改后拉取增量）；业务对象事件驱动节点内容刷新。

### 3.5 界面

React Flow 引擎 + 移植 infinite-canvas 卡片与交互（0308 §7）；左侧节点库、右侧属性面板、顶部工具栏、小地图；快捷键见 0205 §7。

### 3.6 权限与审计

制作者；布局命令不审计，业务命令按对应功能审计（`origin = canvas`）。

### 3.7 非功能要求

PERF-06（500 节点 ≥ 50 fps、打开 ≤ 3 秒）；0205 §4.8（两侧修改 2 秒内可见）。

## 4. 验收标准

- Given 在画布上修改镜头 3 的时长，When 切换到流水线视图，Then 镜头 3 时长已更新。
- Given 画布生成节点，When 点击运行，Then 弹出报价确认；确认后任务中心出现该任务。
- Given 在画布上把一段音频连到镜头 7，When 打开流水线中镜头 7 的参考组合，Then 出现这段音频，用途为“音频”。
- Given 调整节点位置后刷新或换设备登录，When 打开画布，Then 布局一致。
- Given 500 节点的画布，When 平移缩放，Then 帧率 ≥ 50 fps。

## 5. 测试要点

命令冲突重放；reference 连线与参考组合双向一致；Playwright 性能录制。
