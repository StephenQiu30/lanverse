# F25 字幕

| 项 | 内容 |
| --- | --- |
| 需求 | AUD-03 字幕与时码；DLV-04 导出字幕 |
| 优先级 | MVP |
| 用例 | UC-13、UC-15 |
| 页面 | 配音与字幕、剪辑、交付 |
| 依赖功能 | F24、F26、F27 |
| 状态 | 草案（2026-09-25） |

## 1. 需求说明

### 1.1 背景与目标

短剧几乎都带字幕。字幕文本来自台词，时码由选定音频在时间线上的位置决定；成片要能烧录字幕，也要能导出 SRT 供平台上传。

### 1.2 用户故事

- 作为**制作者**，我希望字幕自动根据台词与配音生成，可修改文本与时码，并能导出与成片一致的 SRT。

### 1.3 范围

包含：字幕生成、文本修改、时码微调、长句自动断行、烧录样式（项目级）、SRT 导出。不包含：多语言字幕、花字特效。

## 2. 需求分析

### 2.1 业务规则

| # | 规则 | 理由 |
| --- | --- | --- |
| R1 | 字幕文本默认 = 台词内容；人工修改保存在 `line_audio_selection.subtitle_text`，不改台词本身 | 字幕可口语化调整 |
| R2 | 时码 = 对白轨上该台词音频的起止；自动粗剪与时间线保存时重算 | AUD-03 |
| R3 | 字幕时段不得越出所在视频片段的时间范围（跨片段时拆为两条） | EDT-03 |
| R4 | 单行超过画幅相应字数（9:16 每行 ≤ 14 字，16:9 ≤ 22 字）自动断行，最多 2 行；超出则按标点拆为多条字幕并按字数比例分配时长 | 可读性 |
| R5 | 字幕可在时间线上逐条微调时码（±），保存为剪辑计划新版本 | EDT-02 |
| R6 | SRT 导出基于成片版本的剪辑计划，保证与成片时码一致 | DLV-04 |
| R7 | 字幕烧录样式（字体、字号、描边、位置）为项目设置；字体须有商用授权（内置思源黑体） | 版权 |

### 2.2 异常与边界

台词没有选定音频：按字数 × 0.25 秒估算时长并标记“估算”，渲染前校验提示。

## 3. 实现所需

### 3.1 数据

`audio.line_audio_selection.subtitle_text`；`edit.timeline_item`（`track = subtitle`、`text`、`start_ms`、`duration_ms`、`line_key`）；`delivery.srt_asset_id`；`workspace.project` 增加 `subtitle_style jsonb`（0302 同步）。

### 3.2 接口

```http
PATCH /api/v1/episodes/{eid}/dialogue/{line_key}/subtitle   { "text": "你怎么来啦？", "expected_revision": 4 }
GET   /api/v1/episodes/{eid}/edit-plan                       → 包含 subtitle 轨
GET   /api/v1/deliveries/{id}/download?file=srt              → 预签名 URL
```

### 3.3 异步与工作流

SRT 生成在 RenderWorkflow 中（`media` 队列 `BuildSrt`），与成片同版本。

### 3.4 事件与实时

随剪辑、成片事件。

### 3.5 界面

配音页字幕列（行内编辑）；时间线字幕轨（拖拽边界微调）；项目设置字幕样式与预览。

### 3.6 权限与审计

制作者。

### 3.7 非功能要求

无特殊。

## 4. 验收标准

- Given 剪辑完成，When 生成字幕，Then 每句字幕显示时段与对应音频重叠，不越出片段范围。
- Given 成片 v2，When 导出字幕，Then 得到与 v2 时码一致的 SRT 文件。
- Given 一句 30 字的台词（9:16），When 生成字幕，Then 拆分为多条且每条不超过 2 行。

## 5. 测试要点

断行与拆分算法；SRT 格式（时间格式、编号、UTF-8）。

## 6. 待确认

无。
