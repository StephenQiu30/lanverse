## 1. 需求说明

### 1.1 背景与目标

1–2 人团队维护全部组件（P14）。管理员需要在产品内一眼看到生成链路是否健康，不必每次打开 Grafana。

### 1.2 用户故事

- 作为**管理员**，我希望看到各队列积压、失败率、结果未知与待人工核对数量、各供应商可用性，异常时高亮。

### 1.3 范围

包含：只读汇总视图、跳转 Grafana / Temporal UI。不包含：告警配置（在 OPS-03）。

## 2. 需求分析

| # | 规则 |
| --- | --- |
| R1 | 数据来自 Prometheus 查询与业务库统计，30 秒刷新 |
| R2 | 阈值（与 OPS-03 告警一致）：队列积压 > 100、失败率 15 分钟 > 20%、`unknown` > 10、`manual` > 0 超过 24 小时、Outbox 积压 > 1,000 |
| R3 | 只读；不提供重启、清队列等操作 |

## 3. 验收标准

- Given 模拟供应商失败率 50%，When 打开系统健康，Then 该供应商高亮为异常。
- Given 存在超过 24 小时的待人工核对任务，When 打开页面，Then 显示数量并可跳转到任务列表。
