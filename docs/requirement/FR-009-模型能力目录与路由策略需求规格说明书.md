# FR-009 模型能力目录与路由策略需求规格说明书

## 1. 目的与范围

统一登记图像、视频、语音、音乐、字幕、口型、审核和渲染能力的版本、限制、价格、可用性、地区、隐私和商业许可，并为生产任务提供可解释的匹配和路由。

## 2. 主业务流程

1. 运营人员登记供应或内部能力及版本。
2. 录入输入输出限制、价格、可用性、地区、隐私和许可证信息。
3. 完成质量与风险评估后启用能力。
4. 工作空间配置白名单、成本、地区和数据使用策略。
5. 制作前根据目标和 ShotSpec 筛选可用能力。
6. 版本、价格或条款变化时执行影响评估和受控停用。

## 3. 功能需求

| 编号 | 规范性需求 | 优先级 |
| --- | --- | --- |
| FR-009-001 | 系统应为每项制作能力记录类型、供应来源、稳定标识和版本。 | P0 |
| FR-009-002 | 系统应记录能力支持的输入类型、参考数量、时长、画幅、分辨率、语言和输出类型。 | P0 |
| FR-009-003 | 系统应记录能力价格、计量单位、预计等待时间和并发限制。 | P0 |
| FR-009-004 | 系统应记录能力适用地区、数据留存、训练再利用、商用许可和内容限制。 | P0 |
| FR-009-005 | 系统应维护可用、降级、维护、停用和禁止使用状态。 | P0 |
| FR-009-006 | 系统应允许工作空间配置能力白名单、黑名单、最大成本和地区策略。 | P1 |
| FR-009-007 | 系统应根据镜头结果、输入条件、质量、时效、成本、地区和许可筛选能力。 | P0 |
| FR-009-008 | 系统应说明能力被选择或排除的原因。 | P0 |
| FR-009-009 | 系统应禁止被停用、许可不兼容或地区不可用的能力启动新任务。 | P0 |
| FR-009-010 | 系统应禁止未经用户策略授权的静默供应切换。 | P0 |
| FR-009-011 | 系统应在能力版本或条款变化时标识受影响项目、模板和可复现性。 | P0 |
| FR-009-012 | 系统应保存能力的质量、时延、失败率和有效成片成本评估。 | P1 |
| FR-009-013 | 系统应将企业自带密钥仅保存到经批准、受 KMS 保护的密钥存储中，逻辑路径为 `secret://byok/{workspace_id}/{provider_id}/{credential_id}`；业务数据库只保存不可反解的 `credential_ref` 和状态元数据。 | P1 |
| FR-009-014 | 系统应以结构化枚举记录文本、单图、多参考、首帧、首尾帧、音频参考和视频参考等输入模式及组合限制。 | P0 |
| FR-009-015 | 系统应记录可兼容的时长与分辨率组合、原生音频、异步查询、回调和取消能力。 | P0 |
| FR-009-016 | 系统应依据能力描述选择生产路径并说明原因，不得仅通过模型名称字符串决定输入或工作流。 | P0 |
| FR-009-017 | 系统应将企业密钥绑定严格限定为 `workspace_id + provider_id`，禁止跨工作空间或跨供应商解析、复用或回退。 | P1 |
| FR-009-018 | 系统应允许工作空间管理员撤销企业密钥；撤销后未开始和新建任务必须立即停止解析该密钥，且不得回退到平台密钥或其他工作空间密钥。 | P1 |
| FR-009-019 | 系统应在任务载荷、请求/响应日志、错误、追踪、回调证据和管理界面中只显示 `credential_ref` 与脱敏尾标，禁止记录或返回明文密钥和完整认证头。 | P1 |
| FR-009-020 | 系统应在密钥存储不可用、引用不存在、作用域不匹配、密钥过期或已撤销时以稳定错误 `BYOK_CREDENTIAL_UNAVAILABLE` 失败关闭，不得向供应商发起请求。 | P1 |

## 4. 业务规则

- BR-009-001：代码许可证不等于模型、权重、训练数据、LoRA、插件或编解码器许可证。
- BR-009-002：供应失败不得默认切换到风格或商用条款不同的能力。
- BR-009-003：已锁定项目应固定能力版本，或由用户明确接受升级。
- BR-009-004：生产环境只允许经过安全和许可审核的能力与工作流。
- BR-009-005：供应适配器可以转换厂商协议，但不得改变用户已确认的业务输入和限制。
- BR-009-006：企业密钥仅在供应适配器发起获准请求时按引用解析到内存，任务编排、队列、事件和证据均不得携带明文。
- BR-009-007：撤销不能召回已发送给供应商的请求；系统必须标记撤销时仍在执行的尝试并按供应商取消与对账能力处理。

## 5. 数据要求

- DR-009-001：保存能力、版本、输入输出限制、模式组合、时长/分辨率矩阵、价格、可用性和地区。
- DR-009-002：保存隐私、留存、商用条款、许可证快照、审核人和生效期。
- DR-009-003：保存工作空间策略、评估指标、停用原因和受影响对象。
- DR-009-004：保存 `credential_ref`、工作空间、供应商、创建人、状态、创建/轮换/撤销时间和脱敏尾标；不得保存密钥明文、可逆密文或完整认证头。

## 6. 异常与恢复

| 场景 | 系统行为 |
| --- | --- |
| 价格或条款无法确定 | 标记不可估价或受限，阻止需要确定预算/商用的任务。 |
| 能力临时故障 | 显示不可用，不静默切换。 |
| 许可证发现不兼容 | 阻止新任务，并评估历史输出和交付影响。 |
| 供应升级未提供兼容保证 | 保留旧版本或要求项目明确升级。 |
| 企业密钥不可解析或已撤销 | 返回 `BYOK_CREDENTIAL_UNAVAILABLE`，保持任务未执行并指明需由工作空间管理员修复凭据。 |

## 7. 验收标准

- AC-009-001：不支持参考图的能力不会出现在需要角色参考的镜头可用列表中。
- AC-009-002：停用能力不能启动新任务，历史任务仍显示原能力版本。
- AC-009-003：供应故障时，系统不会未经授权自动切换其他模型。
- AC-009-004：每次生成前可显示预计成本、等待时间、商用条件和选择理由。
- AC-009-005：在多参考、首帧和首尾帧能力之间切换时，系统选择匹配路径并逐项说明不兼容原因。
- AC-009-006：工作空间 A 为供应商 X 配置的企业密钥不能被工作空间 B 或供应商 Y 的任务解析。
- AC-009-007：撤销企业密钥后重复提交任务返回 `BYOK_CREDENTIAL_UNAVAILABLE`，且业务数据库、任务载荷、日志和证据中均不存在明文密钥或完整认证头。
