# 用户需求

## 目标与范围

访客、制作者与管理员能按角色登录、维护自己账号并执行必要的账号管理。

本模块范围：账号认证与会话；注册/登录/改密/退出、资料与个人偏好、设备会话、管理员建号/启停/解锁/重置。

建议执行顺序为编号顺序；编号不代表排期或已批准实施。本文件按业务模块整体维护，内部功能在同一文档列出，不为每个按钮、接口或技术层建立单独需求文件。

## 功能与数据要求

<a id="req-f-08"></a>

### 登录

#### 字段与数据量

| 区域       | 必须承载的字段                                       | 设计归属                           | 一次读取 / 保存的量                     |
| ---------- | ---------------------------------------------------- | ---------------------------------- | --------------------------------------- |
| 认证输入   | 登录名、密码、保持登录                               | user_account密码hash；user_session | 提交一次，不把密码作为普通日志/幂等body |
| 反馈与导航 | 登录失败、5次错误锁15分钟、改密限制、注册/联系管理员 | 账号状态与会话认证结果             | 错误原因可安全归类，不暴露账号是否存在  |

#### 功能与失败边界

| 用户动作        | 必须产生的结果                         | 边界与失败                                                      |
| --------------- | -------------------------------------- | --------------------------------------------------------------- |
| 登录            | 普通用户进首页；需改密用户只能进入改密 | 服务端验证，UI错误应按结果出现，不能永久写死                    |
| 保持登录 / 退出 | 决定会话Cookie持久性和有效期           | 账号页明确空闲12小时、绝对7天；未勾选用会话Cookie仍有服务端到期 |
| 注册 / 忘记密码 | 注册进入新页面；忘记密码提示联系管理员 | 不因为旧工作台本机身份而移除真实认证需求                        |

<a id="req-f-09"></a>

### 注册

#### 字段与数据量

| 区域     | 必须承载的字段                              | 设计归属                        | 一次读取 / 保存的量                            |
| -------- | ------------------------------------------- | ------------------------------- | ---------------------------------------------- |
| 建号输入 | 显示名≤32、登录名、密码、确认密码、可用提示 | user_account；确认密码只验证    | 一账号；可用提示需真实检查且提交时仍靠唯一约束 |
| 密码规则 | 至少10位、同时含字母与数字、两次一致        | 密码hash；不存明文/confirmation | 客户端提示和服务端验证同规则                   |

#### 功能与失败边界

| 用户动作 | 必须产生的结果                       | 边界与失败                                               |
| -------- | ------------------------------------ | -------------------------------------------------------- |
| 创建账号 | 自助注册制作者，成功建立会话进入首页 | 管理员角色只能管理员创建；登录名不可改，重复返回字段错误 |
| 返回登录 | 直接切换认证入口                     | 不预设邀请码、邮件验证或组织创建；这些未出现在当前设计   |

<a id="req-f-10"></a>

### 设置新密码

#### 字段与数据量

| 区域       | 必须承载的字段                              | 设计归属                                             | 一次读取 / 保存的量                      |
| ---------- | ------------------------------------------- | ---------------------------------------------------- | ---------------------------------------- |
| 输入与规则 | 当前密码、新密码、确认；首次/重置后改密说明 | user_account密码hash/force_change_password；sessions | 一次原子提交；新旧密码不同且符合注册规则 |
| 结果       | 成功/失败、重新进入产品、退出登录           | 安全认证结果                                         | 当前设备策略明确；其他设备立即撤销       |

#### 功能与失败边界

| 用户动作   | 必须产生的结果                                     | 边界与失败                                      |
| ---------- | -------------------------------------------------- | ----------------------------------------------- |
| 设置新密码 | 验证当前密码后替换hash、清除改密限制、撤销其他会话 | 并发重置/旧凭据拒绝；失败不清空安全之外的上下文 |
| 退出登录   | 撤销当前会话                                       | 不是邮件/短信找回流程，不添加未出现的验证渠道   |

### 账号设置

#### 字段与数据量

| 区域     | 必须承载的字段                           | 设计归属                                       | 一次读取 / 保存的量                  |
| -------- | ---------------------------------------- | ---------------------------------------------- | ------------------------------------ |
| 资料     | 头像、显示名≤32、只读登录名/角色         | user_account.avatar_asset_id/display_name/role | 当前本人一个摘要                     |
| 会话     | 当前设备、其他设备、最近活动、单设备退出 | user_session安全摘要                           | 当前用户会话列表；不回传token        |
| 偏好     | 深/浅/跟随系统、个人默认提示词后缀       | user_account.theme/default_prompt_suffix       | 点击保存后持久化，主题可本地缓存加速 |
| 来源说明 | 演示模型来源说明                         | 静态说明/模型版本来源字段                      | 不推导独立许可证管理                 |

#### 功能与失败边界

| 用户动作                   | 必须产生的结果                                   | 边界与失败                                                 |
| -------------------------- | ------------------------------------------------ | ---------------------------------------------------------- |
| 资料 / 头像保存            | 显示名和受控媒体引用持久化；刷新与重新登录仍存在 | 头像上传控件细节待补，需求本身保留；不受旧user字段宽度约束 |
| 主题 / 提示词保存          | 只影响本人；新草稿采用后缀，已提交任务不变       | 不挪成组织级或operation/mode配置以适配旧接口               |
| 退出设备 / 修改密码 / 退出 | 单设备、其他设备、当前设备三种语义清楚           | 会话撤销服务端立刻生效，不能仅删除设备卡                   |

### 管理账号

#### 字段与数据量

| 区域       | 必须承载的字段                                        | 设计归属                     | 一次读取 / 保存的量                      |
| ---------- | ----------------------------------------------------- | ---------------------------- | ---------------------------------------- |
| 列表       | 登录名、显示名、角色、启用/停用/需改密/锁定、最近登录 | user_account安全投影         | 建议每页20；角色/状态/关键词筛选先于分页 |
| 创建与操作 | 新账号登录名/显示名/角色；重置密码、启停、解锁        | 同一账号与会话记录；审计事件 | 账号不删除；历史操作人ID稳定             |

#### 功能与失败边界

| 用户动作                  | 必须产生的结果                             | 边界与失败                                             |
| ------------------------- | ------------------------------------------ | ------------------------------------------------------ |
| 创建账号                  | 管理员创建制作者或管理员；首次使用需改密   | 临时凭据交付方式需补可见结果；不能把秘密放入列表或日志 |
| 禁用 / 启用 / 解锁 / 重置 | 禁用撤销会话；解锁只清登录锁；重置要求改密 | 最后管理员保护；重置不同于解锁；普通用户无权限         |

## 范围边界

- 账号与会话是新设计明确需要的业务能力。
- 注册保留为当前需求，不能再以旧接口没有公开注册为理由降级或取消。
- 普通主动改密与受限改密用同一密码规则和会话失效语义。
- 少量个人偏好直接放账号行；不建泛化偏好中心，也不丢掉跨登录保存需求。
- 角色闭集只有当前页面的管理员/制作者；无需动态RBAC或组织平台。

## 依赖与待确认

本模块是其他业务权限的基础；不要求先实现项目或生成。

待确认：改密后当前设备的认证处理；头像规格与裁切；临时凭据生成/展示/交付；管理员联系方式。

以上缺口只是评审问题，不构成新增产品能力或架构决策。既有功能和约束不因旧接口支持不足而删除或降级。

## 模块验收

1. 本文列出的字段和功能由真实数据及操作结果承载，成功/失败/权限/未接入状态明确，mock不作为业务通过。
2. 需要持久化的写入可刷新恢复；版本冲突保留输入，重复副作用按幂等合同核对；只读/瞬时状态不强加持久化。
3. 当前用户/项目范围服务端验证；管理动作限管理员，秘密不进入响应、普通日志、审计明文或导出。
4. 实现时补与本模块风险匹配的成功、失败、冲突/重复、越权场景，分别记录自动化、真实持久化、浏览器及外部供应商证据，未执行不得报通过。

统一要求见[非功能规格](02-非功能需求规格.md)和[交互需求](05-界面与交互需求.md)；当前均待评审、未完成真实功能验收。本阶段不列Sprint、工时或固定用例数量。
