## 1. 需求说明

### 1.1 背景与目标

全能参考是必须能力（P10）：一个镜头可同时输入多个角色造型图、场景图、道具图、动作 / 运镜参考视频、参考音频。参考组合是镜头内容的一部分，决定视频生成的输入，因此需要结构化、可校验、可版本化。

### 1.2 用户故事

- 作为**制作者**，我希望为每个镜头选择“图生视频”或“全能参考”，并在全能参考模式下编辑参考组合，每一项注明用途。

### 1.3 范围

- 包含：生成模式切换、视频模型选择、参考项增删排序、用途选择、按模型上限校验、就绪校验、版本化。
- 不包含：参考项的生成（REQ-15、REQ-30）、首尾帧（REQ-39）。

## 2. 需求分析

### 2.1 业务流程

```text
镜头详情 → 选择模式与视频模型（默认取项目默认模型）→ 参考组合面板显示模型上限
→ 添加参考：从设定集选锁定版本（subject / scene / prop / style）、从媒体库选就绪视频（motion / camera）或音频（audio）、选本镜台词音频（audio）
→ 实时校验：数量上限、类型、时长、就绪、授权 → 保存 → 镜头新版本
→ 报价时再次校验（以服务端为准）并展开为 Operation 输入
```

### 2.2 业务规则

| # | 规则 | 理由 |
| --- | --- | --- |
| R1 | 用途枚举：主体 `subject`、场景 `scene`、道具 `prop`、风格 `style`、动作 `motion`、运镜 `camera`、音频 `audio`（V2 增加首帧 / 尾帧） | DES-01 §4.2 |
| R2 | 可引用：锁定的参考版本、`ready` 且审核通过的媒体、已选定的台词音频、（V2）已选定的片段 | SB-04 |
| R3 | 用途与类型匹配：subject / scene / prop / style 只能是图片；motion / camera 只能是视频；audio 只能是音频 | 防止错误输入 |
| R4 | 数量与时长上限来自所选模型版本的 `limits`；超限项标红，可保存，报价被阻止 | 允许先编辑后换模型 |
| R5 | 引用未就绪或未授权素材：标记并阻止报价 | SB-04、BIB-07 |
| R6 | 参考组合属于镜头版本：任何修改产生新版本，已生成的片段标记过期 | VID-04 |
| R7 | 分镜生成的默认参考组合：本镜出现的角色造型（subject）、场景（scene）、关键道具（prop）；有台词且模型支持音频参考时加入台词音频（若已选定） | 减少手工操作 |
| R8 | 切换为图生视频时参考组合保留但不参与生成（界面折叠提示） | 允许来回切换 |
| R9 | 台词音频作为参考时引用其 `dialogue_audio_id`；台词音频改选后镜头过期 | 表演与声音一致 |

### 2.3 状态

无独立状态；校验结果为派生值。

### 2.4 异常与边界

- 模型切换导致原组合超限：保留组合，标红超出项，给出“按优先级自动裁剪”建议（不自动执行）。
- 引用的参考版本被新版本取代：组合仍指向旧版本并显示“有新版本”，一键更新到最新版本（产生镜头新版本）。

### 2.5 前置与依赖

REQ-08 注册表的 `limits`；REQ-15 锁定版本；REQ-30 就绪素材。

## 3. 验收标准

- Given 全能参考镜头，When 添加两个角色造型、一个场景、一段运镜参考视频、一段台词音频，Then 参考组合显示 5 项及其用途。
- Given 所选模型音频参考上限为 3，When 添加第 4 段音频，Then 该项标红并提示上限，报价被阻止。
- Given 参考组合引用了一段仍在处理中的上传视频，When 请求报价，Then 被阻止并提示“素材尚未就绪”。
- Given 参考组合中的造型有新锁定版本，When 打开镜头，Then 显示“有新版本”，点击更新后产生镜头新版本。
