# 设定需求

## 目标与范围

制作者能管理角色、场景和道具，并明确可用于生成的参考。

本模块范围：条目与别名、造型版本、四参考槽位、上传/生成、明确锁定、音色试听及真人来源声明。

建议执行顺序为编号顺序；编号不代表排期或已批准实施。本文件按业务模块整体维护，内部功能在同一文档列出，不为每个按钮、接口或技术层建立单独需求文件。

## 功能与数据要求

<a id="req-f-06"></a>

### 设定集

#### 字段与数据量

| 区域       | 必须承载的字段                                                | 设计归属                                                | 一次读取 / 保存的量                     |
| ---------- | ------------------------------------------------------------- | ------------------------------------------------------- | --------------------------------------- |
| 设定列表   | 角色/场景/道具、名称/别名、出场集数、造型数、锁定/待定/未生成 | setting_entry + setting_revision；出场由场/镜头引用计算 | 当前类型列表建议20条；详情独立          |
| 造型与参考 | 造型名称/版本、正面半身/侧面/全身/表情组、锁定与缩略图        | setting_revision的有界looks + asset_reference           | 一次选中造型的4个槽位，不拉所有版本媒体 |
| 声音与授权 | 音色名称/试听音频、真人来源、声明状态/说明                    | setting_revision.voice及声明快照、media_asset           | 声明关联具体声音来源和提交人/时间       |

#### 功能与失败边界

| 用户动作               | 必须产生的结果                                 | 边界与失败                                                           |
| ---------------------- | ---------------------------------------------- | -------------------------------------------------------------------- |
| 新增 / 名称别名 / 造型 | 生成对应设定新版本，锁定指针保持明确           | 同名不同对象不合并；合并别名不等同实体合并                           |
| 上传 / 生成参考        | 按槽位保存媒体或生成候选，明确锁定版本         | 不能把生成完成直接视为所有参考自动锁定                               |
| 声音试听 / 授权声明    | 播放真实音频；声明文本、主体、来源、时间持久化 | 页面要求未声明真人声音不得生成：该规则保留，不能因旧表没有支持而删除 |

## 范围边界

- 角色/场景/道具共享有限的设定结构；不先搭建通用授权审批平台。

## 依赖与待确认

依赖项目与素材；先实现编辑/上传/锁定，参考生成再依赖模型和生成合同。

待确认：真人声音声明的正文与主体/来源规格；抽取内容的确认与同名/别名判定。

以上缺口只是评审问题，不构成新增产品能力或架构决策。既有功能和约束不因旧接口支持不足而删除或降级。

## 模块验收

1. 本文列出的字段和功能由真实数据及操作结果承载，成功/失败/权限/未接入状态明确，mock不作为业务通过。
2. 需要持久化的写入可刷新恢复；版本冲突保留输入，重复副作用按幂等合同核对；只读/瞬时状态不强加持久化。
3. 当前用户/项目范围服务端验证；管理动作限管理员，秘密不进入响应、普通日志、审计明文或导出。
4. 实现时补与本模块风险匹配的成功、失败、冲突/重复、越权场景，分别记录自动化、真实持久化、浏览器及外部供应商证据，未执行不得报通过。

统一要求见[非功能规格](02-非功能需求规格.md)和[交互需求](05-界面与交互需求.md)；当前均待评审、未完成真实功能验收。本阶段不列Sprint、工时或固定用例数量。
