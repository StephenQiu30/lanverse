# M01 组织、身份与访问需求

> Requirement ID：REQ-IAM
> 状态：reviewed v1（ready_for_design，待产品负责人接受）
> 日期：2026-08-20
> 上游：[目标需求总览](./000-AI视频生产平台目标需求总览.md)
> 对应模块：M01 组织、身份与访问

## 1. 需求结论

系统必须以 Workspace 作为租户隔离边界，以成员身份、项目职责和高风险能力授权共同决定一次操作是否允许。登录成功不等于拥有项目权限；界面、API、后台任务、媒体访问和 Agent Tool 必须得到相同授权结果。

## 2. 用户结果与范围

用户需要能够：创建和管理工作区、管理或停用现有成员、分配组织角色与项目职责、了解自己为何可以或不能执行某项操作、撤销会话和服务身份，并追溯高风险授权变化。

本模块包含成员、组织角色、项目职责、会话、服务身份、临时能力授权、访问决策和安全审计。不包含成员自助加入、定价套餐、客户账单、公开社交账号体系，也不负责各业务模块自己的批准规则。

## 3. 角色与职责

| 角色 | 主要结果 | 默认限制 |
| --- | --- | --- |
| Workspace Owner | 管理租户、管理员和关键策略 | 不能绕过内容权利与不可变历史 |
| 管理员 | 管理现有成员、配置角色和服务身份 | 高风险策略按组织规则需要双人批准 |
| 制片人/主创 | 获得项目职责并执行创作或批准 | 权限只在被分配项目内生效 |
| 操作员 | 执行受分配的生成与媒体任务 | 不能自行扩大资源、权利或交付权限 |
| 审片人/访客 | 查看指定审阅包或项目范围 | 默认无源文件、生成和发布权限 |
| 服务身份 | 执行明确机器任务 | 无交互登录，不得获得通配权限 |

## 5. 关键业务规则

1. Workspace 成员关系是访问任何业务对象的必要条件，但不是充分条件。
2. 项目职责只授予项目范围能力，不能继承另一个 Workspace 或项目的权限。
3. 外部模型调用、权利例外、突破硬资源上限和正式交付必须使用独立能力检查，不能被通用 `editor` 角色隐式包含。
4. Owner 不能删除最后一个可用 Owner；所有权转移必须由当前 Owner 明确确认。
5. 成员停用不删除其历史决定、评论、审计和产物署名。
6. 服务身份不得拥有交互式登录、无限期通配令牌或跨 Workspace 数据访问。
7. 缓存的授权结果必须绑定策略版本并有短有效期；高风险操作提交时重新校验。

## 6. 状态、并发与恢复

成员关系状态为 `active → suspended | removed`。服务身份为 `active → rotating | suspended → revoked`。

- 项目职责更新使用预期版本，冲突时展示当前分配，不静默覆盖。
- 成员在批准等待期间被停用时，待执行动作必须重新授权。
- 身份提供商不可用时，已有短期会话按组织策略运行；不得自动降级为匿名或管理员。

## 7. 失败与恢复

| 场景 | 用户可见结果 | 恢复动作 |
| --- | --- | --- |
| 身份存在但无 Workspace 成员关系 | 显示无租户访问权 | 申请加入或切换 Workspace |
| 权限在提交前被撤销 | 操作不执行并说明已变化能力 | 刷新权限或联系管理员 |
| SSO/目录同步部分失败 | 保留已确认成员状态并列出差异 | 重跑差异或人工处理 |
| 服务令牌泄露或异常 | 停止新调用并标记受影响范围 | 撤销、轮换和审计 |

## 8. 非功能需求

| ID | 要求 |
| --- | --- |
| IAM-NFR-001 | 所有业务查询、写入、队列任务、媒体和审计都强制 Workspace 隔离。 |
| IAM-NFR-002 | 访问拒绝不能泄露目标对象是否存在或属于哪个租户。 |
| IAM-NFR-003 | 会话和能力撤销必须在签认时间窗内对新请求生效，具体目标由容量基线确认。 |
| IAM-NFR-004 | 权限负向测试覆盖 UI、API、Worker、媒体链接和 Agent Tool。 |
| IAM-NFR-005 | 审计不保存凭据、完整令牌或无关敏感正文。 |

## 9. 验收条件

| ID | 场景 |
| --- | --- |
| AC-IAM-001 | 已知另一 Workspace 对象 UUID 的成员无法查询、修改或通过异步任务引用该对象。 |
| AC-IAM-002 | 成员被停用后，旧页面刷新、旧会话、新任务和签名媒体访问均不能继续扩大访问。 |
| AC-IAM-003 | 编辑者没有生成批准权时可以编辑草稿，但不能提交高消耗计划。 |
| AC-IAM-004 | 审片人只能访问指定冻结审阅范围，不能读取未授权来源或项目草稿。 |
| AC-IAM-006 | 服务身份只能调用声明用途和项目范围内的命令。 |
| AC-IAM-007 | 权限变化后待执行高风险动作重新校验并被正确阻止。 |
| AC-IAM-008 | 所有角色和策略变化可以追溯操作者、基线、时间、理由和结果。 |

## 10. 指标与待确认项

指标包括跨租户拒绝数、权限拒绝原因分布、撤销传播时间、异常服务身份调用和人工权限恢复时间。实施前仍需签认企业 SSO/SCIM 优先级、双人批准适用动作和紧急只读访问流程。
