# M13 装配与交付需求

> Requirement ID：REQ-DLV
> 状态：reviewed v1（ready_for_design，待产品负责人接受）
> 日期：2026-08-20
> 上游：[目标需求总览](./000-AI视频生产平台目标需求总览.md)、[M09](./009-M09-媒体候选与选择需求.md)、[M12](./012-M12-审阅协作与批准需求.md)
> 对应模块：M13 装配与交付

## 1. 需求结论

本模块提供完成平台闭环所需的基础装配和可复现交付，不替代专业 NLE。用户可以按镜头顺序完成基础画面裁剪、简单转场、对白/旁白/环境声/音乐放置、音量、字幕和交付规格；高级调色、复杂特效、多机位、任意插件和完整工程交换不在首期范围。

DeliveryBuild 是可失败、取消和重跑的执行过程；DeliverySnapshot 只在全部必需输出和校验成功后创建，创建后不可补写或覆盖。

## 2. 用户结果与范围

用户可以从当前选择建立装配版本、完成基础音视频/字幕同步、执行交付预检、渲染主文件和附属文件，并得到带校验信息、输入谱系和权利/审批依据的不可变交付快照。

## 4. 基础装配边界

基础画面能力限于稳定镜头顺序、入出点、简单转场、画幅适配和必要黑场/占位；基础音频限于轨道放置、裁剪、淡入淡出、音量和静音；字幕限于时间、文本、基础样式和导入导出。

调色节点、复杂合成、动态跟踪、任意 VFX、专业混音、第三方插件、多人 NLE 工程合并不进入本模块。出现这些需求时导出标准素材和 Manifest 到专业工具，而不是扩张内部时间线。

## 5. 时间与版本规则

1. 项目在装配创建时固定帧率、分辨率和音频时间基。
2. 时间码、裁剪、字幕和评论不使用浮点秒作为权威值。
3. AssemblyRevision 引用明确 ShotOrder、Selection 和 MediaArtifact 版本。
4. 主选或顺序变化不修改旧 AssemblyRevision；用户显式创建新版本并查看差异。
5. DeliveryBuild 输入冻结后，项目当前状态变化只提示有新版本，不改变运行中的 Build。

## 6. 预检、构建与快照

预检至少验证：所有必需镜头有可用主选、媒体完整、时间范围合法、音视频规格可处理、字幕无非法时间、质量阻塞关闭或存在有效 QualityRiskAcceptance、权利有效或存在允许交付的 PolicyException、审阅批准满足、输出位置和保留策略可用。两类例外必须分别校验，不能相互替代。

Build 可以 `queued | rendering | validating | partial | failed | cancelled | succeeded`。Snapshot 没有 `preparing` 状态；它只能在 Build 成功、所有必需输出存在且哈希/规格验证通过后一次创建。

同一冻结 Manifest 重复 finalize 必须回读同一 DeliverySnapshot；需要发布新的交付时必须产生新的 Assembly/Build/Manifest 身份，不能用重跑制造内容相同但无法区分的重复快照。

Manifest 至少包含项目/内容单元、Brief/Narrative/ShotOrder/Assembly/Review 版本、镜头与 Selection、媒体文件、输出规格、哈希、权利摘要、批准记录、构建版本和创建者。

## 7. 失败与恢复

| 场景 | 用户可见结果 | 恢复动作 |
| --- | --- | --- |
| 缺主选或媒体 | 预检阻塞到具体镜头 | 返回选择/媒体修复 |
| 权利或批准缺失 | 不启动正式 Build | 完成授权或审阅 |
| 渲染中断 | 保留运行和确定性中间产物 | 安全续跑或新 RenderRun |
| 主文件成功、字幕失败 | Build partial，不创建 Snapshot | 只重做缺失附属输出 |
| 校验失败 | 隔离输出并显示差异 | 修复后重新构建 |
| 下载链接撤销 | Snapshot 不变，访问立即失效 | 重新授权新链接 |

## 8. 非功能需求

| ID | 要求 |
| --- | --- |
| DLV-NFR-001 | 相同冻结输入和渲染版本产生可解释、可校验输出。 |

| DLV-NFR-003 | 渲染过程可恢复，失败不覆盖历史成功交付。 |
| DLV-NFR-004 | 分数帧率、长时音频和字幕时间使用精确整数时间基。 |
| DLV-NFR-005 | 交付下载、保留和删除受 M14 权利与安全策略控制。 |

## 9. 验收条件

| ID | 场景 |
| --- | --- |
| AC-DLV-001 | 用户可把至少 10 个主选镜头装配成可播放基础版本。 |

| AC-DLV-004 | 渲染失败或附属输出缺失不会创建 Snapshot。 |
| AC-DLV-005 | 成功 Snapshot 可还原全部输入、选择、批准、权利和输出哈希。 |
| AC-DLV-006 | 项目后续修改不改变旧 Snapshot 或下载内容。 |
| AC-DLV-007 | 相同 Build 重跑形成独立运行记录且不重复发布快照。 |
| AC-DLV-008 | 有序独立镜头素材包的 Manifest 与文件集合一致。 |
| AC-DLV-009 | 高级 NLE 操作不出现在首期功能或验收中。 |

## 10. 指标与待确认项

指标包括预检一次通过率、Build 成功/部分失败率、平均恢复时间、交付可复现率、每交付分钟资源消耗和 Snapshot 完整性错误。待确认首批输出预设、字幕格式、基础转场集合、音频响度规则和是否需要标准 NLE 交换格式。
