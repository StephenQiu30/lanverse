## 1. 问题、范围与非目标

Projects 模块为创作者提供稳定的 Project/Episode 上下文、顺序、概览、阻塞和下一动作。它不能保存下游模块的正文、任务终态、候选或包文件，也不能让用户手工修改“生产阶段”冒充真实进度。

范围：Project/Episode 创建、元数据、默认制作设置、原子重排、归档恢复、受控删除、ProductionSnapshot 和 NextAction。

非目标：剧本正文、资产、Shot、媒体、Provider Task、编辑时间线、成片、支付运营、项目 ACL 和自定义工作流阶段。

## 2. 事实所有者与依赖

Projects 拥有：Workspace 下 Project、Project 下 Episode、二者生命周期和 revision、EpisodeOrderRevision、只读 ProductionSnapshot/BlockingReason/NextAction 投影。

依赖：

- Identity 提供 ActorContext/Workspace 权限；
- Scripts/Assets/Storyboards/Keyframes/Videos/Exports/Platform 提供版本化摘要事件或 Query；
- Projects 只存来源模块、统计口径、来源 revision/事件时间和派生结果，不复制下游对象。

## 3. 模型、版本与关系

| 实体 | 关键内容 | 变更方式 |
| --- | --- | --- |
| Project | 稳定 ID、Workspace、名称、简介、默认画幅/视觉方向、状态、revision | 乐观并发；默认值变化不改历史输入 |
| Episode | 稳定 ID、Project、标题/显示编号、状态、revision | 重命名/重排不变 ID |
| EpisodeOrderRevision | 完整 active Episode ID 顺序、revision、actor/time | 原子新修订 |
| ProductionSnapshot | 目标 Project/Episode、各模块摘要、来源和更新时间 | 事件投影；可重建 |
| BlockingReason | 来源模块、对象、错误码、严重度、next action | 派生，不由用户编辑 |
| NextAction | action code、目标路由、所需权限、理由 | 派生建议，不代表已执行 |

不变式：

1. Project/Episode ID 不因重命名、重排、归档而变化。
2. 同 Project active Episode 顺序唯一且完整。
3. Project 默认设置只影响未来未固定输入；已有 Script/Asset/Shot/Task/Candidate/Snapshot 不改。
4. 下游 unavailable 不等于 0/ready。
5. 归档后历史可读、禁止新业务事实；只有完全空白且无引用对象可硬删除。
6. ProductionSnapshot 是可重建投影，绝不成为下游 current 的第二事实源。

## 4. 同步命令与查询

| 能力 | 事务输入 | 输出/冲突 |
| --- | --- | --- |
| CreateProject | Workspace、元数据、幂等键 | Project + 首个下一动作；同意图回读 |
| UpdateProject | 允许字段、expected revision | 新 revision + 影响摘要 |
| CreateEpisode | Project、显示信息、位置、幂等键 | Episode + 新 OrderRevision |
| UpdateEpisode | Episode、允许字段、expected revision | 新 revision |
| ReorderEpisodes | 完整 active Episode ID 列表、expected order revision | 新 OrderRevision 或零写入冲突 |
| Archive/Restore | 目标、expected state、确认 | 新状态或任务/引用阻塞清单 |
| DeleteBlank | 目标、expected state | 删除或完整引用阻塞 |
| GetWorkbench | Project/Episode、筛选 | 模块摘要、partial failure、blocker、next action |

所有命令重新检查 Workspace 和 owner/editor；viewer 只读。创建和重排使用数据库唯一约束与单事务，不能靠前端排序避免重复。

## 5. 异步投影与事件

Projects 发布：`ProjectCreated`、`ProjectDefaultsChanged`、`EpisodeCreated`、`EpisodeOrderChanged`、`ProjectArchivedOrRestored`、`EpisodeArchivedOrRestored`。

Projects 消费各模块的 `...VersionChanged`、`...ReadinessChanged`、`WorkTaskStatusChanged`、`ExportPackageChanged` 摘要事件。消费流程：Inbox 去重 → 按来源 revision/时间拒绝旧事件覆盖新投影 → 更新对应分区 → 重新计算 blocker/next action → 发布 `ProductionSnapshotChanged`。

手动刷新直接并行 Query 各来源模块，并返回分区级超时；不能等待所有来源后整页失败。

## 6. 状态与失败恢复

```text
Project/Episode: active ↔ archived
Delete: active → deleted（仅空白且无引用）
Snapshot partition: available | stale_projection | unavailable
```

| 失败 | 产品行为 | 恢复 |
| --- | --- | --- |
| 重复创建 | 不产生重复项目/剧集 | 用原幂等键回读 |
| 重排并发 | 顺序零写入 | 展示最新顺序后重做 |
| 某下游摘要失败 | 其他分区可读，该分区 unavailable | 重试单分区/手动刷新 |
| 归档时任务 running/unknown | 列出具体 Task 并阻断或提供安全动作 | 由 DES-012 对账/取消，不自动终止 |
| 删除存在引用 | 返回主要引用类型和导航 | 先解除允许解除的引用；不级联历史 |
| 权限中途变化 | 当前写失败，工作台切只读 | 保留本地草稿并重新加载 |

## 7. 权限与安全

- Project/Episode 的 Workspace 从父对象解析，不信任客户端重复字段；
- owner/editor 创建、修改、重排、归档；viewer 查询；owner 管理成员不属于本模块；
- 搜索、统计和直接 ID 均使用相同 Workspace 过滤；
- 归档/删除/默认设置变化写 Audit；
- ProductionSnapshot 事件不得含剧本正文、Prompt、媒体 URL 或 Provider 原错误。

## 8. 可观测性

- Metric：项目/剧集命令延迟与冲突率、Snapshot 分区延迟、unavailable 比例、Outbox age；
- Trace：Project/Episode 命令、来源 Query、投影事件和 next action 计算；
- 日志：稳定 ID、revision、action、错误码，不记录项目私密正文；
- 每个摘要值返回来源模块、统计口径、来源更新时间和投影更新时间。

## 9. 验证

- AC-CUR-PRJ-001～007：创建、修改、剧集维护和原子重排；
- AC-CUR-PRJ-008～010：摘要、partial failure、阻塞定位和下一动作；
- AC-CUR-PRJ-011～012：归档、恢复、受控删除和引用保护；
- 跨 Workspace 列表、搜索、直接 ID 和写入成功数为 0；
- 10 集、每集 120 Shot proposed 样本满足 CUR-PRJ-NFR-004/005；
- 一来源停机时其他摘要仍可用；键盘可完成 P0 流程。
