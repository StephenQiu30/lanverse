# Design 03：素材

执行编号：03；原始需求模块：08。依据[原始需求](../requirement/08-素材需求.md)、[PRD](../prd/03-素材.md)与[Plan](../plan/03-素材.md)。本文件把原始需要转换成项目方案，**全部新增设计选择仍待评审**；数据对象和接口为拟议合同，不表示已有表或已实现API。共同约束见[整体设计](00-项目需求设计.md)。原始FR、质量条件与AC仍须同时满足。

## 原件、媒体与素材条目分开

媒体负责真实字节、校验、元数据、就绪及预览授权；素材条目负责个人/项目范围、文件夹、收藏与回收。生成候选引用MediaObject，加入素材库再建LibraryEntry，不把每张候选自动变成用户收藏或复制文件。

| 对象              | 设计字段与责任                                                                         |
| ----------------- | -------------------------------------------------------------------------------------- |
| MediaObject       | id/version、类型、MIME、字节数、摘要、尺寸/时长/字数、存储键、来源任务；字节版本不可变 |
| MediaAccess       | 个人所有权及项目使用授权；使用时再次校验，存储地址不是授权                             |
| MediaAvailability | receiving→validating→ready或failed；审核状态独立unknown/approved/rejected等待确认状态  |
| LibraryEntry      | scope、media_id/version、folder_id、source_entry_id、recycled_at、revision             |
| Folder/Favorite   | 文件夹归属于一个scope；收藏唯一(user_id, entry_id)，不改变别人的偏好                   |

上传只接受实际探测允许的字节；扩展名不证明格式，docx解压等需防超限。通过完整写入、探测与授权登记才ready。生成输出也经过此路径，供应商success不自动ready。就绪和审核均未确认前不进有效参考/可用预览。

## 接口、计量与失败恢复

拟议POST /media/uploads取得受控上传操作；完成后查询/media/{id}状态；GET /media/{id}/preview经授权提供短期预览或代理。POST /library/entries建立条目、GET /library/entries查询、PUT /entries/{id}/favorite设置状态、POST /entries/{id}/project-memberships加入项目、POST /entries/{id}/recycle回收。新授权不能只依赖浏览器持有旧URL；签名地址失效后按media_id重新取，不写进画布/历史。

建议服务端预留上传操作，再写字节，最后条件登记ready；中断只有未完成记录。失败重传/清理孤立字节按明确策略，不能删除被引用原件。项目成员关系建议唯一(project_id, media_id, version)，重复加入返回原关系；事务内建立授权与条目，不增加原件物理计量。逻辑容量与物理字节分开，容量未知返回不可用，不填0。

列表先按scope授权、收藏/最近30天/未分类/文件夹/搜索类型筛选再排序分页，每页40。列表数量和容量给as_of及同一范围口径。详情按需读引用摘要；所有预览、参考和导出再校验访问。回收只是移除当前范围条目，已有合法引用仍保留原件；本需求没有永久删除。

## 原始需求到设计追踪

| 原始FR      | 项目设计与验收观察                                            |
| ----------- | ------------------------------------------------------------- |
| FR-ASSET-01 | 上传操作＋字节探测/完整写入；真实进度、超限失败、不就绪不可用 |
| FR-ASSET-02 | scope查询＋计量口径；40项分页、真实空/故障/未知区分           |
| FR-ASSET-03 | Folder范围事务；刷新读回、不进入他人范围                      |
| FR-ASSET-04 | MediaAvailability＋按需详情预览；同一文件版本及审核事实       |
| FR-ASSET-05 | Favorite设置命令；重复幂等且仅本人变化                        |
| FR-ASSET-06 | 授权项目关系＋source_entry_id；不复制原件，重复规则有明确回执 |
| FR-ASSET-07 | LibraryEntry回收标记；原引用仍有效，未扩永久删除              |

验证真实图片/视频解码、故意错误MIME、写入/探测故障、输出重复入库、越权原件地址、重复加入和引用回收；恢复核同media_id/version与权限。浏览器只加载可见缩略图，播放再请求相应资源；耗时阈值与文件/容量上限未确定不报通过。

## 待评审选择与实施入口

格式/大小/时长限制、审核来源和无审核时准入、文件夹重名、逻辑配额、重复加入、30天时区/时钟、预览撤权时效及原件保留待确认。首轮候选媒体可用条件必须D0接受；素材库完整管理不阻塞[Demo](06-画布生图生视频Demo.md)媒体子链。

### 物理存储、转存和一致性

私有对象键由media_id/version生成，不含原文件名或凭据。上传操作ID使用media_ingest_jobs.id；PUT只接该操作完整字节，不把任意URL当上传。对象写入→内容探测→登记metadata/ready、项目Grant及候选关联，网络和对象操作在SQL事务外；只有最后成功提交才可用。对象已经写但SQL失败时重做同对象/摘要登记，不生成新的原件身份。派生缩略图按原件ID/版本定位，不改变原件。

源输出的临时定位信息仅服务端加密保管，输出来源受控；media_ingest_jobs.state失败不修改Task的供应商成功事实。运行时SecretStore读取、允许网络来源、内容限额、过期输出核对及保留参数在D0接受。ready不等于moderation=approved；首轮审核规则未接受时不可偷偷放行unknown。

### 未探测信息与容量读模型

UploadStart的声明类型/大小/文件名只是用户输入，分别保存在declared_mime/expected_kind/安全文件名；真实kind/mime/byte_size在探测前为null，不能在媒体DTO冒充已识别。ready才要求实际格式和完整原件元数据；生成候选也遵循同条件。
容量建议个人范围按本人持有的ready原件去重计量，项目范围按有效MediaGrant的ready原件去重计量；library收藏/多个引用不重复，回收条目不自动释放仍保留的原件。总量来自接受的范围配额配置，未配置为null，若实际已用可计算则分别显示，不将未知总量当0或无限。该计量/回收取舍仍需原业务政策接受。

### 对象不可变与失败后的同身份写入

存储适配器按Media ID/version使用只创建/条件写入原件键；已存在时比较实际摘要，相同才恢复登记，不同内容返回冲突，不覆盖已就绪字节。首次接收先完整暂存并探测，再建立原件；中断临时对象不作为ready或Candidate可用。对象版本/写入条件是否由目标存储支持在D0核验；实现不能只锁SQL行却允许任意覆盖私有原件键。

### 图片/视频原件读取与Range合同

首轮建议PreviewView.url返回同源授权content路径（不包含token），签名直链作为后续受控替代。Browser图片/视频直接请求字节接口；不让生成client把完整视频当JSON/普通base64返回。每个新请求重新核会话/project/Media版本/ready准入，Cache-Control采用private，注销/项目切换停止播放。

| 方法与路径                                                                                                                                                                 | 权限          | 请求                                      | 响应/HTTP状态                                                                          | 边界                                                                   |
| -------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------- | ----------------------------------------- | -------------------------------------------------------------------------------------- | ---------------------------------------------------------------------- |
| GET /api/media/{media_id}/content                                                                                                                                          | 本人/授权项目 | version:Rev、project_id?:Id；Range?请求头 | 200完整或206字节区间；Content-Type/Length、Accept-Ranges、Content-Range/ETag按实际原件 | 404失权、422未ready、416无效范围；按存储流式读，不加载整视频到前端状态 |
