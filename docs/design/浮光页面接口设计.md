# 浮光页面驱动的接口设计

下面是从[新页面](../requirement/浮光页面/index.md)推导的目标合同，**不是旧接口目录或旧端点适配清单**。路径以 `/api/v1` 表示新合同边界；所有接口均处于设计阶段，未宣称已挂载。前端不能为旧接口缺字段而删掉当前设计控件。

## 1. 请求与响应规则

- JSON字段使用snake_case；UUID标识对象，UTC ISO时间。成功返回`data`，列表附`page/page_size/total`或`next_cursor`，不把数字样例当真实值。
- 错误 `{error:{code,message,field_errors?,current_revision?,request_id}}`。401需登录、403无权限、404对象不可见/不存在、409版本/唯一冲突、422字段不合法、429限流、503依赖不可用。枚举和分页为新合同自行定义，不继承旧系统的差异错误。
- 普通编辑带expected_revision；生成/复制/导入带request_key，重复同键同输入返回原任务，异输入409。普通保存网络不确定时先重读，不引入全局命令框架作为前置。
- 服务端始终验证项目/用户范围。生成模型、引用、目标与当前权限一起校验；客户端禁用态不是授权。
- 列表只摘要，详情按选中对象取；媒体URL短时授权。字段仅为当前展示或动作服务，不回传数据库内部密钥和对象路径。

## 3. 关键请求示例

以下是字段示例，不是生产ID或可直接调用的已实现接口。

```json
{
  "name": "新项目",
  "aspect_ratio": "1:1",
  "style": "film"
}
```

```json
{
  "expected_revision": 3,
  "description": "人物在雨中回望",
  "shot_size": "medium",
  "camera_move": "push",
  "duration_ms": 4000,
  "mode": "image_to_video",
  "model_revision_id": "<模型版本UUID>",
  "params": {},
  "references": [{ "type": "setting", "id": "<设定UUID>", "version": 2 }]
}
```

```json
{
  "data": {
    "items": [
      {
        "id": "<素材条目UUID>",
        "title": "雨夜参考",
        "kind": "image",
        "width": 2048,
        "height": 1152,
        "is_favorite": true,
        "reference_count": 2
      }
    ],
    "page": 1,
    "page_size": 40,
    "total": 128
  }
}
```

最后一个示例的128是演示值，生产必须真实计算；URL、引用对象和审核细节按需单独读取。

## 4. 页面冲突与异步状态

- 输入保存：CAS返回新revision，收到成功才显示“已保存”；409保留草稿供刷新/比较。版本历史只读，切标签不回滚当前内容。
- 引用/选定：服务端验证同项目、用途、模型支持与媒体就绪；输出属于冻结的镜头输入。采用旧版本候选需要显式确认并返回stale原因；下游引用比较显示失效，不自动重做。
- 生成：queued → running → succeeded/failed；无法判断供应商是否已执行为unknown，需人工信息为manual。unknown使用同一provider_request_id核查；禁止自动重新收费。成功候选不自动采用。
- 候选凭据：测试中 → 成功替换 / 失败保留旧值；若测试期间revision变化返回409，不覆盖并发保存。密钥不得写入请求审计快照。
- 批量：参数保存全组原子；生成是逐项任务集合，部分失败必须可见且重试只针对未确认执行项。
- 文件：上传成功但未探测/审核时还不能当ready；原文解析/复制任务与项目建立分开，失败项目仍可进入并看到说明。

## 5. 统计口径

| 显示         | 新合同口径                                                | 空值 / 说明                                                  |
| ------------ | --------------------------------------------------------- | ------------------------------------------------------------ |
| 完成镜头x/y  | 当前有效视频选定数 / 当前镜头总数                         | 当前快照，不按时间窗排除旧镜头；总数0显示未开始              |
| 任务量/环比  | 窗口内已提交generation_job；比较前一等长窗口              | 上期0则环比null；重复同键不多计                              |
| 成功率       | succeeded / (succeeded+failed)                            | unknown/manual单列；分母0=null，返回分母便于解释             |
| 平均/P95耗时 | 窗口内已结束视频生成的started_at到finished_at             | 统计样本/计时边界明确；不是视频时长                          |
| 模型结果     | 按冻结model_revision归属聚合                              | 模型改名不改变归属；展示当前安全名称和版本                   |
| 分集进度     | 剧本/设定/分镜/画面/视频/声音等各阶段真实有效对象数量比例 | 每阶段分母定义后才显示；无法推导的阶段返回null，不新建假状态 |
| 素材容量     | 当前用户/项目可访问实际字节用量；总量注明配额或磁盘       | 不把原型2.3GB/10GB当产品套餐                                 |
| 健康         | 指定窗口任务/供应商/队列实时数据及as_of                   | 未部署/无法采集组件为unavailable，不是健康0                  |

## 6. 页面自身尚未定稿的细节

pdf导入（input与文案冲突）、画布导出格式、素材容量的分母、头像上传规格、临时密码交付、全站搜索范围、通知点击后的呈现、真实付费执行确认，需补充具体交互。这些是新页面本身的信息缺口，**不是等待旧接口同意**。先记录最小问题，不用旧平台替代设计，也不凭一个按钮预建整套系统。
