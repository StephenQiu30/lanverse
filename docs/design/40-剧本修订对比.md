## 2. 数据

`script.script_version`（多版本）；`script.episode` 增加 `previous_episode_id`（对齐关系）与 `inherit_status`（DES-02 同步）；台词匹配结果记录在新结构版本的 `origin = ai_diff`。

## 3. 接口

`POST /api/projects/{pid}/script-imports`（`mode = revision`）；`GET /api/projects/{pid}/script-versions/{a}/diff/{b}` → 集级变化（不变 / 修改 / 新增 / 删除）与文本差异；`POST /api/projects/{pid}/script-versions/{id}:adopt` → 报价重解析变化集。

## 4. 异步与工作流

`ScriptRevisionWorkflow`（对齐 → 重解析变化集 → 台词匹配 → 待确认）。

## 5. 界面

版本对比页（集列表带变化标记、并排文本差异、受影响镜头数）。

## 6. 权限与审计

制作者；审计 `script.revision_adopted`。

## 7. 测试设计

台词匹配准确率（评测集）；集对齐边界（插入新集导致集号偏移时按内容相似度对齐）。

## 8. 待确认

无。
