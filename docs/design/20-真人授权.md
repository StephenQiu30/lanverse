## 2. 数据

| 表 | 关键字段 | 为什么需要 |
| --- | --- | --- |
| `media.consent_record` | `subject_name`、`scope`、`declaration`、`document_asset_ids`、`status`（`active` / `revoked`）、`revoked_at/by`、`revoke_reason` | 声明、材料与作废 |

## 3. 接口

```http
POST /api/media/consents
{ "project_id": "…", "subject_name": "张三", "scope": "portrait", "declaration_accepted": true, "document_asset_ids": ["…"] }
201 { "id": "…", "declaration": "本人确认已取得……", "create_time": "…" }

POST /api/uploads/{media_asset_id}:complete   { "contains_real_person": true, "consent_record_id": "…" }
GET  /api/media/consents/{id}                 （受限；写审计）
POST /api/media/consents/{id}:revoke          { "reason": "授权到期" }   （管理员）
200 { "status": "revoked", "affected_assets": 3, "stale_objects": 12 }
```

作废流程：同一事务内 `consent_record.status = revoked`、写 Outbox `media.consent_revoked.v1`；lineage 消费者把引用关联素材的锁定参考、参考组合、选定关键帧 / 片段标记过期（原因 `consent_revoked`），notify 通知这些对象的最近操作人；此后报价、锁定、参考组合校验对关联素材返回 `consent_required`；已报价未确认的任务在确认时逐项作废（原因 `consent_revoked`，DES-04 §6）；已确认排队的任务在工作流开始时，以及进入 submitting 的事务内（与作废事务互斥）复核授权，作废则以 `failed(consent_revoked)` 结束，未提交故不计费、释放预留，并通知确认人（DES-04 §8.1）；已提交供应商的任务按正常流程完成，其产出随关联对象被标记过期。

引用校验失败：`422 input_not_ready { "errors": [{ "code": "consent_required" }] }`。

## 4. 异步与工作流

无。

## 5. 事件与实时

`media.consent_recorded.v1` → lineage、notify；`media.consent_revoked.v1` → lineage（过期传播）、notify；审计经 `audit.recorded.v1`。

## 6. 界面

上传对话框中的“包含真实人物”开关与声明表单；媒体详情显示授权状态；参考选择器中未授权素材置灰并说明原因。

## 7. 权限与审计

制作者创建；管理员可作废。审计：`consent.recorded`、`consent.viewed`、`consent.revoked`。

## 8. 非功能要求

PRV-04；CMP-02。

## 9. 测试设计

引用校验在锁定、参考组合、报价三处均生效。
