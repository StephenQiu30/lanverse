### 3.1 正式资源与命令合同

画布使用 DOM/SVG/rAF InfiniteCanvas 与正式 Go 节点、命令和媒体端口，详细职责见[工作台设计](工作台设计.md)。整体工作台、生成、参考、正式选定与流水线分别验收，基础交互或 Demo 不替代完整业务。

复用已有画布列表/创建/读取/命令、单工作区身份和项目读取合同；当前身份由 Workspace 注入，不使用登录与首登改密，写请求使用精确 Origin 与 UUID 幂等键。正式 UUID 节点类型闭集 text/image/video/audio/group，node_action=resource；增加 title、parent_id、z_index 与类型安全 config。媒体以 ref_type=media_asset/ref_id 引用当前项目 ready/passed 已接管资产，URL/缩略图由服务端授权投影；不接收任意外部 URL、blob URL、本机路径、storageKey、凭据、任务或选定事实。精确 DTO/配置白名单与请求边界以服务端类型/在线 Swagger 为准，业务节点计划按既有引用合同接入。

| 命令集合                                           | 当前语义                                                                                  |
| -------------------------------------------------- | ----------------------------------------------------------------------------------------- |
| AddNodes、MoveNodes、UpdateNodeConfig、DeleteNodes | 正式资源节点的新增/批量移动/类型配置/删除；删除节点不删除业务对象                         |
| ResizeNodes、RenameNodes、SetNodeZIndex            | 尺寸、正式标题和层级，不借任意 config 字段写入                                            |
| SetNodeParents                                     | 同文档 group 父节点，禁止自引用/环；world 绝对坐标不因 parent 变化重算                    |
| Connect(annotation)、Disconnect                    | 当前注释边；两端同文档，禁止非法角色/绑定；reference/promote 计划按对应业务合同接入后开放 |
| SetViewport                                        | source k 与 API zoom 显式映射，zoom 0.05～4；有限坐标/数值                                |

**当前配置/命令形状（由后端类型核对）：**text config 为 {text:string}，group 为 {collapsed:boolean}，image/video/audio 为 {}；未知字段拒绝。RenameNodes 使用 names:[{id,title}]，ResizeNodes 使用 sizes:[{id,width,height}]，SetNodeParents 使用 parents:[{id,parent_id|null}]，SetNodeZIndex 使用 z_indices:[{id,z_index}]，Connect 仅 edges:[annotationEdge]，Disconnect 仅 ids:[edgeUUID]；不继续使用旧历史单 edge/id 形状。

节点标题非空且最多128字符，文本最多10,000字符；坐标有限且绝对值≤1,000,000，z_index 为±1,000,000范围整数。普通节点宽高40～2,000，group为40～100,000；每批1～100命令，请求最多1MiB，文档最多2,000节点/4,000边。每个命令后的父关系均须合法，不允许只在整批末尾消除临时环。非法数据422 invalid_request、未知能力422 unsupported_command，命令错误 meta.command_index 为0起始；同键异体422 idempotency_key_reused，修订冲突409 revision_conflict/meta.current_revision。

| 当前额外端点                                     | 成功合同与边界                                                                                                                               |
| ------------------------------------------------ | -------------------------------------------------------------------------------------------------------------------------------------------- |
| PATCH /api/canvases/{id}                         | {expected_revision,name} → 完整文档；Origin/UUID幂等，正式名称更新                                                                           |
| DELETE /api/canvases/{id}                        | {expected_revision} → {id,revision,deleted:true}；软删除，不删媒体或SQL历史，同键可重放                                                      |
| GET /api/projects/{pid}/media                    | kind/limit/cursor；默认50、limit1～200、UUID keyset → {items,next_cursor}；当前授权可用媒体库                                                |
| GET /api/projects/{pid}/media/{asset_id}/preview | {asset:{id,project_id,kind,file_name,mime_type,byte_size,width?,height?,duration_ms?,revision},url,expires_at}；10分钟签名且private,no-store |

媒体 URL 通过独立授权 preview 查询取得，在前端映射源节点展示；Document.Node 只含资产身份，不放 URL。本机上传以工作台设计 §3.2 的本地 multipart 接管与显式人工确认合同为准，不能凭固定 fixture 证明真实上传完成。

移动 group 的客户端批次包含 children 并应用同一 delta，服务端只提交本批明确移动记录，不能再重复移动 children。删除 group 解组，保留 children 和 world 坐标；批次按命令顺序校验，父关系在每个命令后必须无环且有效。复制新 UUID、重映射内部 parent/annotation，并清除不可继承的任务/选定身份。服务端成功返回完整确认文档和 results。

权限、归档只读、持久幂等、revision、日志/Outbox 与回执原子性继续沿用正式合同；任一命令失败全批回滚。网络失败以原幂等键查明/重放，409 获取最新正式文档并提示，不能静默覆盖别人配置或自动重放付费操作。只读/切换项目取消在途手势；保存确认后入撤销历史，反向操作产生新 revision。

现有业务数据和不可变修订保留，title/parent/z_index 等实际结构由 Schema 维护，既有库按 DES-02 §10 精确增量升级。历史纯备注记录保持可读编辑，快照恢复产生新修订；不得清库或用本地 workspace 覆盖事实。

## 4. 异步与工作流

生成节点运行复用 OperationWorkflow；无新工作流。

## 5. 事件与实时

`canvas.document_changed.v1`；SSE `canvas.updated`（其他标签页或 Agent 修改后拉取增量）；业务对象事件驱动节点内容刷新。

## 6. 界面

DOM/SVG/rAF 核心、节点壳、连线、视口、选择、分组和小地图消费现有 shadcn/Geist 组件及 Go 正式端口，界面依赖与业务事实保持分离。

## 7. 权限与审计

制作者；布局命令不审计，业务命令按对应功能审计（`origin = canvas`）。

## 8. 非功能要求

PERF-06（500 节点 ≥ 50 fps、打开 ≤ 3 秒）；REQ-05 §4.8（两侧修改 2 秒内可见）。

## 9. 测试设计

完整功能：命令冲突重放；reference 连线与参考组合双向一致；Playwright 性能录制。

保存端验证创建/读取、原子 revision、同键重放、整批回滚、跨组织隔离、归档只读和非法业务节点/边拒绝；浏览器以真实 Workspace 与项目验证节点编辑、关联边删除、移动、注释连线、视口保存、撤销重做与刷新恢复。资源布局验证不替代生成、业务引用和 promote 的完整业务验收。

性能采用60秒浏览器运动窗口，视口/节点连续150ms不动停止计交互帧率，隐藏中断，运动不足30秒或缺可信输入明确标记。浏览器主动选择媒体最多40个、单件100MiB、合计300MiB，blob URL 及时释放；这是浏览器资源预算，不是上传 API 合同。500/600、500/800、2000节点分别记录冷启动、实际运动、帧率、内存来源、视口和播放数；真实媒体、M1/8GB、Windows 中端目标与跨设备恢复分别验收。

专项验证包括核心视口/框选/拖动/分组/连线/复制/历史、真实库媒体授权/parent无环/删组解组/revision/幂等/Outbox原子性，以及正式浏览器只读、保存、冲突、失败和刷新恢复。合成、真实媒体、目标机器与跨设备分别提供当前证据，旧记录不代替。

## 10. 待确认

`canvas.command_log` 保留最近1000条或7天、生成快照后截断更早记录的策略仍待实际恢复合同和验收，不因存在候选值而自动清理历史。需求层面的未决项见 [REQ-36](../requirement/36-画布.md)。固定来源、版权与许可归 [NOTICE](../../THIRD_PARTY_NOTICES.md)。

性能按 PERF-06 验证500节点/800连线平移缩放≥50fps、打开≤3秒、2000节点≥30fps，同时保留500节点（300图、40视频）、600连线及内存观测场景。记录浏览器、机器、视口、实际播放数、重复测量和录制；600连线或单机样本不能替代800连线及目标机器验收。
