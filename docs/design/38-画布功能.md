### 3.1 历史检查点：E-36-07 备注布局（已被替代，未验收）

以下是 07dfd2d 保存的旧切片合同，只留历史追溯；当前迁移以 §3.2 为准，不保留旧前端或兼容入口，不据本节限制为纯备注。

当时切片将现有前端样例接入当前登录会话和组织内项目，复用公共认证、项目读取、命令幂等、统一错误和在线 Swagger 生成链。画布内容由 Go 用例和 PostgreSQL 持久化，浏览器刷新后以服务端文档恢复。切片只交付 CNV-01 / CNV-04 / CNV-05 中的备注布局；生成、业务引用、参考组合、选定及 Agent 提案分别按后续任务验收。

**范围与数据：**复用 DES-02 §5.12 的 `canvas.document/node/edge/command_log`，新建画布 `revision = 1`，项目 scope 固定 `{}`。节点仅允许 `node_type = text`、`node_action = resource`，`config` 仅有 `text`；`ref_type/ref_id/parent_id/last_operation_id` 均为空。连线仅允许纯注释 `annotation`，不带 `role/binding`。不创建平行的浏览器持久化或第二套画布表；快照及增量清理归原 E-36-01/02/03。

| 接口 | 本轮合同 |
| --- | --- |
| `GET /api/projects/{pid}/canvases` | 当前用户组织内、未删除项目的画布摘要 `{items:[...],next_cursor:null}`；本轮返回项目全部有效画布，分页待后续 |
| `POST /api/projects/{pid}/canvases` | `{ "name": "备注画布", "scope": {} }`；返回新建文档。带 `Idempotency-Key` 和 CSRF |
| `GET /api/canvases/{id}` | 返回 `id/project_id/name/scope/revision/viewport/nodes/edges`；节点和连线 ID 均为 UUID，数组不含已删除记录 |
| `POST /api/canvases/{id}/commands` | `{ "expected_revision": 1, "commands": [...] }`；成功返回完整文档（含新 `revision`）与逐命令 `results`，便于校准前端状态；带 `Idempotency-Key` 和 CSRF |

成功 DTO 由后端 Gin 注解与类型生成，前端从本次运行的 `/swagger/doc.json` 生成客户端。登录、首次改密、GET /api/auth/me 与项目列表复用 identity/workspace 公共合同；本轮不新增项目详情，不得以固定样例项目替代当前登录用户的项目授权。

| 命令 | JSON 形状与约束 |
| --- | --- |
| `AddNodes` | `{ "type": "AddNodes", "nodes": [{ "id": "UUID", "node_type": "text", "node_action": "resource", "config": { "text": "备注" }, "x": 0, "y": 0 }] }`；可选 `width/height` |
| `MoveNodes` | `{ "type": "MoveNodes", "moves": [{ "id": "UUID", "x": 100, "y": 80 }] }` |
| `UpdateNodeConfig` | `{ "type": "UpdateNodeConfig", "id": "UUID", "config": { "text": "修改后的备注" } }`；替换该节点备注配置 |
| `DeleteNodes` | `{ "type": "DeleteNodes", "ids": ["UUID"] }`；删除节点及相连注释边，不能删除项目或业务对象 |
| `Connect` | `{ "type": "Connect", "edge": { "id": "UUID", "edge_type": "annotation", "source_node_id": "UUID", "target_node_id": "UUID" } }`；两端必须是当前文档中不同的有效节点 |
| `Disconnect` | `{ "type": "Disconnect", "id": "边 UUID" }` |
| `SetViewport` | `{ "type": "SetViewport", "viewport": { "x": 0, "y": 0, "zoom": 1 } }` |

名称 1～128 个字符；备注最多 10,000 个字符；坐标为有限数且绝对值不超过 1,000,000；可选节点宽高为 40～2,000；zoom 为 0.1～4。每批 1～100 个命令、请求最多 1 MiB，文档最多 2,000 个节点。未知命令返回 `422 unsupported_command`；未知配置字段、其他节点类型 / 动作、业务绑定及 `input/reference/promote` 边均返回参数错误，不能静默忽略或转成备注。`run` 路由和业务命令本轮不注册。

**事务、权限与失败：**读取和写入复核当前用户及项目组织；归档项目可读且禁止写入，删除或跨组织项目/文档不可见。命令在一个事务中锁定文档、核对 `expected_revision`、按顺序应用全批、写命令日志及 Outbox，成功只递增 revision 一次；任一命令失败则全批、日志、事件和幂等回执一起回滚。同键同体重放返回首次结果，不再次变更；同键异体返回公共幂等冲突。过期修订返回 `409 revision_conflict` 及 `meta.current_revision`，前端取最新文档并提示重新操作，不自动重放可能覆盖他人修改的配置。非法数据按 RFC 9457 映射，错误应指出命令序号；无权限不泄露其他组织文档内容。

**前端与撤销：**操作期间保持页面内临时状态，拖拽/视口变更结束后提交；服务端确认后才显示“已保存”。撤销栈仅记录本页已成功的布局操作，反向命令以新幂等键和当前 revision 提交；删除节点的反向命令恢复原备注节点及注释边。重做同理，revision 继续递增。刷新、重新登录或发生修订冲突后清空局部撤销栈。保存失败保留可重试草稿并显示失败，不用“本页预览”冒充持久化成功。付费生成及正式选定没有撤销入口。

本轮项目 SSE 可沿当前公共实时合同接入，但不以完整 `canvas.updated` 消费者或全部业务节点实时同步作为 E-36-07 放行条件；跨标签页以最新读取和 revision 冲突证明安全，完整实时传播仍归 E-36-03。E-36-07 的接口不得触发付费供应商调用。

### 3.2 当前合同：BeefTV 核心与正式资源接入（2026-09-30）

用户确认直接复用 BeefTV 固定 0d9e9f48 InfiniteCanvas 及核心设计，替换全部旧前端画布；具体模块、端口、删除范围和许可见 [迁移设计](BeefTV能力引入设计.md)。这是无限画布迁移，不是全 BeefTV 应用搬运，也不是纯备注或外观替换。整项目验证/Demo 优先，完整 CNV/业务要求保持。

复用已有画布列表/创建/读取/命令、单工作区身份和项目读取合同；当前移除登录及首登改密，写请求使用精确 Origin 与 UUID 幂等键。正式 UUID 节点类型闭集 text/image/video/audio/group，node_action=resource；增加 title、parent_id、z_index 与类型安全 config。媒体以 ref_type=media_asset/ref_id 引用当前项目 ready/passed 已接管资产，URL/缩略图由服务端授权投影；不接收任意外部 URL、blob URL、本机路径、storageKey、凭据、任务或选定事实。精确 DTO/配置白名单与请求边界以服务端类型/在线 Swagger 为准，业务节点后续按既有引用合同扩展。

| 命令集合 | 当前语义 |
| --- | --- |
| AddNodes、MoveNodes、UpdateNodeConfig、DeleteNodes | 正式资源节点的新增/批量移动/类型配置/删除；删除节点不删除业务对象 |
| ResizeNodes、RenameNodes、SetNodeZIndex | 尺寸、正式标题和层级，不借任意 config 字段写入 |
| SetNodeParents | 同文档 group 父节点，禁止自引用/环；world 绝对坐标不因 parent 变化重算 |
| Connect(annotation)、Disconnect | 当前注释边；两端同文档，禁止非法角色/绑定；reference/promote 按对应业务合同后续开放 |
| SetViewport | source k 与 API zoom 显式映射，zoom 0.05～4；有限坐标/数值 |

**当前配置/命令形状（由后端类型核对）：**text config 为 {text:string}，group 为 {collapsed:boolean}，image/video/audio 为 {}；未知字段拒绝。RenameNodes 使用 names:[{id,title}]，ResizeNodes 使用 sizes:[{id,width,height}]，SetNodeParents 使用 parents:[{id,parent_id|null}]，SetNodeZIndex 使用 z_indices:[{id,z_index}]，Connect 仅 edges:[annotationEdge]，Disconnect 仅 ids:[edgeUUID]；不继续使用旧历史单 edge/id 形状。

节点标题非空且最多128字符，文本最多10,000字符；坐标有限且绝对值≤1,000,000，z_index 为±1,000,000范围整数。普通节点宽高40～2,000，group为40～100,000；每批1～100命令，请求最多1MiB，文档最多2,000节点/4,000边。每个命令后的父关系均须合法，不允许只在整批末尾消除临时环。非法数据422 invalid_request、未知能力422 unsupported_command，命令错误 meta.command_index 为0起始；同键异体422 idempotency_key_reused，修订冲突409 revision_conflict/meta.current_revision。

| 当前额外端点 | 成功合同与边界 |
| --- | --- |
| PATCH /api/canvases/{id}                         | {expected_revision,name} → 完整文档；Origin/UUID幂等，正式名称更新                                                                           |
| DELETE /api/canvases/{id} | {expected_revision} → {id,revision,deleted:true}；软删除，不删媒体或SQL历史，同键可重放 |

| GET /api/projects/{pid}/media/{asset_id}/preview | {asset:{id,project_id,kind,file_name,mime_type,byte_size,width?,height?,duration_ms?,revision},url,expires_at}；10分钟签名且private,no-store |

媒体 URL 通过独立授权 preview 查询取得，在前端映射源节点展示；Document.Node 只含资产身份，不放 URL。本轮上传以迁移设计 §3.2 的本地 multipart 接管与显式人工确认合同为准，不能凭固定 fixture 证明真实上传完成。

移动 group 的客户端批次包含 children 并应用同一 delta，服务端只提交本批明确移动记录，不能再重复移动 children。删除 group 解组，保留 children 和 world 坐标；批次按命令顺序校验，父关系在每个命令后必须无环且有效。复制新 UUID、重映射内部 parent/annotation，并清除不可继承的任务/选定身份。服务端成功返回完整确认文档和 results。

权限、归档只读、持久幂等、revision、日志/Outbox 与回执原子性继续沿用正式合同；任一命令失败全批回滚。网络失败以原幂等键查明/重放，409 获取最新正式文档并提示，不能静默覆盖别人配置或自动重放付费操作。只读/切换项目取消在途手势；保存确认后入撤销历史，反向操作产生新 revision。

现有 DDL 和用户历史保留，新增 title/parent/z_index 等所需约束追加 forward 迁移；旧备注记录在新引擎可读/编辑。不得删除已发布 SQL、清库或用源 local workspace 覆盖数据。快照端点不在本轮自行扩展；未来恢复产生新修订。旧前端 poc/live/creation 引擎和独立产品页删除，测试/e2e/acceptance 正常命名，新引擎性能和整项目 Demo 重新留证。
