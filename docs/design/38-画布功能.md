## 2. 数据

`canvas.document`（`revision`、`scope`、`viewport`）、`canvas.node`（`node_type`、`node_action`、`ref_type`、`ref_id`、`config`、坐标尺寸、`parent_id`、`last_operation_id`）、`canvas.edge`（`edge_type`、`role`、`binding`）、`canvas.document_snapshot`；见 DES-02 §5.12。新增 `canvas.command_log`（`document_id`、`revision`、`commands jsonb`、`create_by`）用于冲突重放与审计（DES-02 同步）。

## 3. 接口

```http
GET  /api/projects/{pid}/canvases                  → 画布列表
POST /api/projects/{pid}/canvases                  { "name": "第 1 集探索", "scope": { "episode_id": "…" } }
GET  /api/canvases/{id}                            → 文档、节点、连线、revision，以及业务节点的摘要数据
GET  /api/canvases/{id}/changes?since_revision=12  → 增量
POST /api/canvases/{id}/commands
{ "expected_revision": 12, "commands": [
    { "type": "AddNodes", "nodes": [ { "id": "…", "node_type": "video", "node_action": "generate", "config": { "capability": "video.generate", "mode": "omni_reference", "model_key": "…" }, "x": 100, "y": 200 } ] },
    { "type": "Connect", "edge": { "id": "…", "edge_type": "reference", "source_node_id": "…", "target_node_id": "…", "role": "camera" } },
    { "type": "MoveNodes", "moves": [ { "id": "…", "x": 320, "y": 80 } ] } ] }
200 { "revision": 13, "results": [ { "ok": true }, { "ok": true, "business": { "shot_id": "…", "shot_version_no": 7 } }, { "ok": true } ] }
409 revision_conflict { "meta": { "current_revision": 14 } }
POST /api/canvases/{id}/nodes/{nid}:run            → 报价（REQ-21）
POST /api/canvases/{id}/snapshots
```

## 4. 异步与工作流

生成节点运行复用 OperationWorkflow；无新工作流。

## 5. 事件与实时

`canvas.document_changed.v1`；SSE `canvas.updated`（其他标签页或 Agent 修改后拉取增量）；业务对象事件驱动节点内容刷新。

## 6. 界面

React Flow 引擎 + 移植 infinite-canvas 卡片与交互（DES-08 §7）；左侧节点库、右侧属性面板、顶部工具栏、小地图；快捷键见 REQ-05 §7。

## 7. 权限与审计

制作者；布局命令不审计，业务命令按对应功能审计（`origin = canvas`）。

## 8. 非功能要求

PERF-06（500 节点 ≥ 50 fps、打开 ≤ 3 秒）；REQ-05 §4.8（两侧修改 2 秒内可见）。

## 9. 测试设计

命令冲突重放；reference 连线与参考组合双向一致；Playwright 性能录制。

**DES-38-Q1 PoC 核对范围**：REQ-02 PERF-06 要求 500 节点、800 连线时平移缩放 ≥ 50 fps、打开 ≤ 3 秒，2,000 节点时 ≥ 30 fps；DES-08 §7 的技术 PoC 样本写的是 500 节点（300 图、40 视频）、600 连线、内存 < 1.5 GB。PoC 应保留 DES-08 的内容组成与内存观测，同时增加 800 连线的需求验收场景和 2,000 节点场景；分别记录浏览器、机器、视口、媒体播放数、重复测量结果与性能录制。600 连线的结果不能替代 PERF-06 的 800 连线验收。

**DES-38-Q1 本机 PoC 结果（2026-09-27）**：三组固定样本均达到上述帧率目标，500/800 冷会话就绪时间低于 3 秒；2,000 节点场景浏览器进程组 RSS 代理指标低于 1.5 GB。交互时暂停视频是达到帧率目标的必要措施。样本使用重复的本地媒体素材，具体数据、测法与内存指标局限见 [P0-05 记录](../acceptance/P0-画布PoC记录.md)。技术 PoC 建议继续采用 React Flow 与该固定版本界面适配；正式选型仍待产品负责人确认，真实媒体与完整业务画布的验收留在 E-36。
