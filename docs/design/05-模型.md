# Design 05：模型

执行编号：05；原始需求模块：10。依据[原始需求](../requirement/10-模型需求.md)、[PRD](../prd/05-模型.md)与[Plan](../plan/05-模型.md)。本文件把原始需要转换成项目方案，**全部新增设计选择仍待评审**；数据对象和接口为拟议合同，不表示已有表或已实现API。共同约束见[整体设计](00-项目需求设计.md)。原始FR、质量条件与AC仍须同时满足。

## 草稿、发布与任务引用

模型模块负责配置内容和能力契约，不保存秘密、不执行供应商调用。生成消费不可变PublishedModelVersion及是否允许新任务；供应商模块提供运行配置和受测能力事实。

Model定义稳定id、key、provider_id、名称、能力、启停；ModelDraft含revision及参数模式；PublishedModelVersion含不可变版本ID、发布内容/摘要、发布时间/操作者与能力证据引用。参数模式描述input_role、允许模式/数量/画幅/分辨率/时长及限制，区分首帧与普通参考，不默认所有模型都支持。

## 编辑、发布与新任务准入

拟议GET /models?capability=…返回授权可选发布摘要；管理员POST /models建草稿、PATCH /models/{id}/draft条件编辑、POST /models/{id}/publications发布、PUT /models/{id}/enabled设置可选状态；版本详情按需查。

表单和JSON在边界解析为同一规范数据，差异视图比较同一版本；未知字段/矛盾能力拒绝，不悄悄舍弃。发布校验供应商绑定、参数范围与能力证据，事务内生成不可变版本和审计；后续编辑创建新草稿，不能改历史发布内容。建议同一草稿revision的发布意图唯一，重复请求返回既有发布版本，避免丢回执后多次发布。

建议key在模型目录内唯一，规范字符/大小写仍待确认。新任务事务校验模型仍启用且发布版本可选，防止“预检后停用”竞态。已接收任务冻结原发布版本；建议普通停用只禁止新准入，在途继续用原版，安全紧急停用另有明确策略，不静默迁移到别的模型。

## 原始需求到设计追踪

| 原始FR      | 项目设计与验收观察                                        |
| ----------- | --------------------------------------------------------- |
| FR-MODEL-01 | 发布可选目录；草稿/停用模型不进入创作选择，新提交也校验   |
| FR-MODEL-02 | Model＋版本草稿；唯一key和供应商绑定校验，错误保留输入    |
| FR-MODEL-03 | 单一规范草稿＋expected_revision；三视图一致、非法JSON拒绝 |
| FR-MODEL-04 | 不可变PublishedModelVersion；发布后编辑不改旧任务         |
| FR-MODEL-05 | 准入检查与停用事务协调；历史保留，在途政策单列            |

验证双编辑冲突、重复发布意图、无证据能力、首帧/参考模式不匹配、预检后停用和历史版本读回。预检可用不代表供应商成功，候选列表也不能用固定名称报真实支持。

## 待评审选择与实施入口

key规范、参数schema可表达范围、区域/模式、证据有效期、在途停用及发布/停用与提交的锁定次序待评审。首轮先覆盖实际接受的一个生图和一个单图首帧视频能力；复杂目录和多供应商覆盖后续按[Plan](../plan/05-模型.md)补齐。

## 工程合同：模型目录数据库与发布接口

### 库表与字段

采用[整体数据库约定](00-项目需求设计.md#工程合同数据库全局约定)。除显式NULL字段外均NOT NULL；B/C/P含义见全局约定。这里给出待接受的表/字段设计，不修改或执行运行中的schema.sql。

| 表               | 字段、类型、空值与默认                                                                                                                                                                                                                               | 主外键、唯一及检查约束                                                                                                                  | 查询索引                   | 生命周期                            |
| ---------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------- | -------------------------- | ----------------------------------- |
| `models`         | C；key text、provider_id uuid FK providers、name text、capability text；enabled boolean DEFAULT false、current_published_version_id uuid NULL                                                                                                        | UNIQUE(key)；capability image/video/audio/text；发布指针复合FK(models.id,version.id)；enabled要求发布指针非空                           | (capability,enabled,id)    | 启停只影响新准入；版本不覆写        |

### HTTP接口与DTO

路径统一以`/api`开头；字段后`?`表示可空/可省，其他为必需，`Id/Rev/Time/Money/Page`及通用错误见[全局HTTP合同](00-项目需求设计.md#工程合同http全局约定)。响应只包含所列字段，不直接序列化ORM。

| DTO                | 字段与类型/语义                                                                                                                       |
| ------------------ | ------------------------------------------------------------------------------------------------------------------------------------- |
| `ModelCreate`      | request_key:Id、key:string、name:string、provider_id:Id、capability:image/video/audio/text                                            |
| `ModelDraftChange` | request_key:Id、expected_revision:Rev、content:Json（名称/区域/模式/参数schema/输入roles及证据引用）                                  |
| `ModelPublish`     | request_key:Id、expected_draft_revision:Rev                                                                                           |
| `ModelEnable`      | request_key:Id、expected_revision:Rev、enabled:boolean                                                                                |
| `ModelView`        | id:Id、key/name:string、provider_id:Id、capability:string、enabled:boolean、revision:Rev、published_version_id:Id?                    |
| `ModelVersionView` | id:Id、model_id:Id、version_no:Rev、content:Json、parameter_schema:Json、input_roles:string[]、evidence_ref:string、published_at:Time |
| `ModelDraftView`   | model_id:Id、revision:Rev、content:Json、published_diff:Json?                                                                         |

| 方法与路径                                         | 权限              | 请求                           | 响应/HTTP状态                       | 错误与写入边界                                  |
| -------------------------------------------------- | ----------------- | ------------------------------ | ----------------------------------- | ----------------------------------------------- |
| `GET /api/models`                                  | 正常制作者        | capability/mode/input_role筛选 | 200 ModelView[]                     | 只返回启用且发布可选；创建Task再次校验          |
| `GET /api/models/{model_id}/versions/{version_id}` | 有权创作者/管理员 | 无                             | 200 ModelVersionView                | 可用目录/有权历史Task关联才可读旧版本           |
| `GET /api/admin/models`                            | 管理员            | capability/status/page筛选     | 200 Page<ModelView>                 | 含草稿/停用摘要                                 |
| `POST /api/admin/models`                           | 管理员            | ModelCreate                    | 201 ModelView＋draft:ModelDraftView | 422 key/供应商非法；目录和首草稿同事务          |
| `GET /api/admin/models/{model_id}/draft`           | 管理员            | 无                             | 200 ModelDraftView                  | 历史正文按需                                    |

| `POST /api/admin/models/{model_id}/publications`   | 管理员            | ModelPublish                   | 201 ModelVersionView                | 唯一source_draft_revision；冻结版本/audit同事务 |
| `PUT /api/admin/models/{model_id}/enabled`         | 管理员            | ModelEnable                    | 200 ModelView                       | 409目录版本；发布必需；不开新供应商调用         |

### 参数schema与发布准入

content/parameter_schema必须能表达capability、mode、input_roles（first_frame与reference_image区分）、candidate_count、ratio、resolution和duration_ms的允许集合/范围。表单/JSON/差异均读写同content，不用各自常量。evidence_ref是安全资料/核验记录定位，不内嵌供应商秘密或伪造测试成功。

发布锁models及model_drafts，校验expected_draft_revision，生成version_no并插model_versions、更新发布指针/audit。普通启停锁models；生成准入在冻结事务内FOR SHARE同模型，停用不能在提交校验后悄悄穿过。是否继续已接收在途仍按前文建议评审，不把禁用改成删旧版本。
