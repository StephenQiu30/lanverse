## 验收标准

- 根目录可追溯到指定参考；基础组件统一使用主题 token，而非各页面重复硬编码。
- 首页注册/登录入口仍可操作；认证表单字段、禁用和错误状态不回退。
- 内容卡片无闭合框线、无轮廓阴影，分组仍可辨认；次级按钮与输入框保持轻边界，焦点清晰可见。
- 1440px 桌面、390px 移动及 320px 窄屏无非预期横向溢出；明暗主题可读。
- agent-browser 检查的是运行中的 Docker 页面，不是静态 HTML 或 Mock 页面。
- 单元测试与实际浏览器验收分别记录，不用公共页面检查替代登录后全业务验收。
