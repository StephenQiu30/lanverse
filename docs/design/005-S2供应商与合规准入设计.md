## 3. D-003 AI 服务接入边界

### 3.1 已接受决策

| 项目 | 决策 |
| --- | --- |
| 供应商与模型 | DeepSeek 官方 API；`deepseek-v4-pro`；`thinking=disabled`；不使用已退役别名 |
| LangChain 边界 | 只安装 `langchain-deepseek==1.1.0` 及其锁定传递依赖，使用 `ChatDeepSeek.with_structured_output`；不安装 LangGraph，不建立通用 agent/chain/graph 注册中心 |

| 业务边界 | 剧本导入、版本、候选决议和人工修改保持供应商无关；Worker 读取固定 ScriptVersion，DeepSeek 结果只能形成待人工决议的候选 |

| 失败与恢复 | 未配置密钥返回 `ai_service_unavailable`；明确拒绝/结构错误进入 failed；限流、服务异常和网络结果不明不得盲目重发，进入可解释失败或 unknown，由新 Batch 显式重试 |
| 测试 | 单元和状态机可使用确定性替身；必须增加脱敏 HTTP 契约，并以真实 DeepSeek 调用完成 S2 验收，替身不能作为真实服务证据 |

禁止创建多供应商注册中心、降级链、模型市场或 LangGraph 状态机。LangChain 只负责 DeepSeek 消息和结构化输出转换；PostgreSQL Task/Batch、RabbitMQ 和现有 Pydantic DTO 仍是业务状态与边界。S4 的 Seedream/Seedance 必须通过 production 的类型化 Port 与唯一火山方舟适配器接入，不能把火山参数泄漏到 ShotSpec 或前端。

图片 API 是同步外部副作用，且当前 SDK 的生图/生视频创建参数不含客户端幂等键。因此内部 `provider_request_key` 只能防止我方 Worker 重复执行，不能伪装成供应商幂等契约：

1. Seedream 使用 `b64_json` 直接将返回字节写入当前唯一 MinIO 的隔离对象，不持久化供应商临时 URL。请求结果丢失或进程在隔离对象落地前崩溃时，Attempt 进入 `unknown/manual_attention`，禁止自动重发。
2. Seedance 在获得 provider task ID 后可通过 get/list 对账；回调可重复且终态发送失败只会有限重试，因此 Scheduler 轮询是最终收敛路径。创建响应在 task ID 落库前丢失时不能仅凭时间/模型推测任务，必须 `unknown/manual_attention`。
3. SDK 公开契约证明 DELETE 方法存在，但不能单独证明各模型在哪些状态可取消、取消后的可查询时长或最终计费语义。D-004 关闭前统一按最大努力取消设计；running/终态仍以真实查询和账单结果登记媒体及费用，内部取消决议长期保存在 PostgreSQL。
4. 视频结果 URL 每次通过 task ID 查询获取，只用于下载到 MinIO，不作为 Candidate/MediaLocation 保存。下载失败只重试查询和下载，不重新生成。

## 4. D-005 工程合规基线

### 4.1 候选适用范围

本基线按“面向中国大陆公众提供人工智能短剧制作与下载服务”接受。若首发范围变更，必须重新完成当地适用性评审，不能直接复用本结论。

主要公开规则包括：[生成式人工智能服务管理暂行办法](https://www.cac.gov.cn/2023-07/13/c_1690898327029107.htm)、[互联网信息服务深度合成管理规定](https://www.cac.gov.cn/2022-12/11/c_1672221949354811.htm)、[人工智能生成合成内容标识办法](https://www.cac.gov.cn/2025-03/14/c_1743654684782215.htm)及[个人信息保护法](https://www.miit.gov.cn/jgsj/zfs/fl/art/2022/art_515a4b20c12f430eab54bb4f56d89f56.html)。是否需要算法备案或其他上线手续必须由指定合规责任人根据真实服务方式确认。

### 4.2 最小权利与授权模型

每份 ConsentRevision 至少记录：授权主体、权利类型（著作权/肖像/声音/其他）、被授权用途、生成与发布渠道、地域、有效期、撤回规则、授权证明的 MediaVersion、提交人和审查人。涉及人脸、声纹或可识别自然人的材料，必须单独确认处理的必要性、目的、方式、范围和同意；未成年人材料在 MVP 默认阻断，直到监护人授权流程另行接受。

声音人格权益依据还包括：[民法典关于声音保护的规则](https://gdca.miit.gov.cn/zwgk/zcwj/flfg/art/2020/art_573d6ef5018b46b6a4e1f31ca085a710.html)和[最高人民法院人工智能生成声音人格权案例](https://www.court.gov.cn/zixun/xiangqing/467631.html)。系统只验证证据是否完整、有效且覆盖目标用途，不自动判断授权文件的法律效力；有争议时必须转人工审查。

### 4.3 审核、标识与留存

| 能力 | MVP 基线 |
| --- | --- |
| 责任分工 | 内容提交人声明来源和授权；平台运营审查证据；产品负责人承担最终产品/运营合规责任角色；系统只执行已接受规则 |
| 生成门禁 | 权利状态为未知、过期、撤回或覆盖不足时可以保存草稿，但禁止 ready、提交生成和交付 |
| 内容检查 | 保存 Provider 内容安全结果和人工决议；检查服务不可用时对生成与交付 fail-closed |
| 显式标识 | 预览和下载成片必须展示人工智能生成/合成标识；MVP 不提供“无标识导出” |
| 隐式标识 | 交付媒体元数据记录生成属性、服务提供者标识和可追踪内容编号；DeliveryManifest 同步记录 |
| 留存 | 不设一个适用所有事实的统一年限；用途终止且引用、计费/对账、申诉、争议、安全事件与法定保全全部解除后，按 4.5 逐类删除、匿名化或仅保留不可还原最小摘要 |
| 撤回 | 撤回只阻止后续使用和生成，不篡改已发生的审计事实；历史交付的处置由人工决议记录 |

标识办法自 2025-09-01 起施行，并规定特定未显式标识场景的用户义务和日志留存要求。Lanverse MVP 直接禁止无标识导出，因此不把该例外设计成产品能力；未来若增加，必须先修订 Requirement、Design、PRD 和留存策略。

### 4.4 脱敏授权验收样例

授权验收 fixture 只使用虚构主体和仓库生成的占位资产，不得包含真实姓名、证件、声音、肖像、签名或供应商原始响应。每个样例固定包含 `fixture_id`、主体类型、权利人角色、权利类型、资产及版本、授权用途、发布渠道、地域、有效期、撤回状态、证明文件版本、提交人、审查人、期望决议和原因码。

| fixture_id | 场景与输入 | 期望决议 | 原因码 |
| --- | --- | --- | --- |
| `consent-valid-adult-001` | 虚构成年主体；图像与声音权利；覆盖 AI 短剧生成及中国大陆公开发布；授权在有效期内；证明文件版本可访问 | 可进入生成与交付门禁 | `consent_valid` |
| `consent-revoked-001` | 字段完整，但权利人在生成前已撤回 | 允许保留草稿；阻断后续生成与交付 | `consent_revoked` |
| `consent-insufficient-001` | 授权只覆盖内部演示，本次请求公开发布 | 阻断生成与交付，并提示补充用途范围 | `purpose_not_covered` |
| `consent-expired-001` | 授权有效期早于本次生成时间 | 阻断生成与交付 | `consent_expired` |
| `consent-minor-001` | 主体为未成年人，MVP 没有已接受的监护人授权流程 | 默认阻断，不进入自动复核 | `minor_not_supported` |

同一 `ConsentRevision` 的判定必须是可复现的纯规则：输入事实版本和规则版本相同，输出决议及原因码相同。修改授权不覆盖历史版本；撤回生成新版本并只影响撤回后的新动作。人工审查只能产生带审查人、时间和理由的新决议，不得直接改写旧审计事实。

### 4.5 留存与删除策略矩阵

下表是产品负责人已签认的 MVP 工程策略，不把尚无依据的统一年限写入代码。个人信息遵循目的限定和最短必要期限；删除项目或账号时，业务资产按已接受策略删除或匿名化，受到投诉、争议、法定义务或安全事件保全的事实进入访问受限的 legal hold，不随软删除消失。

| 事实类型 | 留存目的与起算点 | MVP 已接受处理 | 已接受删除触发/期限 |
| --- | --- | --- | --- |
| 授权证明及 `ConsentRevision` | 证明目标资产在生成/发布时具有相应授权；从最后一次使用或撤回起算 | 对业务用户不可见后转受限存储；争议时保全；触发删除后移除证明文件并仅保留不可还原最小审计摘要 | 最后使用/撤回目的结束，且相关交付、计费、申诉、争议与 legal hold 全部关闭 |
