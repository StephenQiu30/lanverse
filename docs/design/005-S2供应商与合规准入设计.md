## 1. 结论

D-003 已关闭：项目不固定 Text Provider、模型、接口地址、密钥名、价格或本地模型，也不把未被业务使用的 AI 服务写入环境配置。2026-07-29，产品负责人再次确认不引入未要求的 AI 服务、替代服务或本地模型。实际 AI 服务只在对应业务能力进入实现时，依据用户提供的真实配置接入和验收。

D-005 仍未关闭：工程合规候选基线已经形成，但首发地区、合规责任人和留存规则尚未获得产品负责人确认。该决定阻止授权/权利门禁被标记为 accepted，也阻止真实生成、公开交付和上线；它不阻止使用合成数据实现 S2 的 Task/Outbox、剧本版本和私有媒体基础能力。未关闭前所有真实生成与交付必须 fail-closed，不得用默认值伪造签认。本文件是工程决策输入，不构成法律意见。

## 2. 事实、推断与待确认事项

| 类型 | 内容 | 处理方式 |
| --- | --- | --- |
| 用户决策 | 不引入未要求的 AI 服务、替代服务、本地运行时或模型 | 删除专属配置、探针和候选模型；未提供真实服务配置前不猜测替代方案 |
| 公开事实 | 中国大陆已对生成式人工智能服务、深度合成、人工智能生成内容标识和个人信息处理设定义务 | 在公开发布前完成适用性评审；显式标识、隐式元数据、授权证据和审计记录必须进入交付链 |
| 待确认 | 首发地区、合规责任人、正式留存期限、未成年人策略 | D-005 保持 `open`；阻止治理验收、真实生成、公开交付和上线，但不阻止无外部副作用的内部工程 |

## 3. D-003 AI 服务接入边界

### 3.1 已接受决策

| 项目 | 决策 |
| --- | --- |
| 供应商与模型 | 不固定、不预装、不提供默认值 |
| 配置 | 只有用户明确提供实际 AI 服务时才增加该服务真实需要的环境变量；不保留空供应商配置 |
| 业务边界 | 剧本导入、版本、候选决议和人工修改不依赖特定 AI SDK；自动提取能力未配置时返回明确不可用状态 |
| 技术边界 | 实际接入时优先复用已接受的 LangChain；只有出现多步骤恢复或人工节点时才使用 LangGraph |
| 测试 | 单元和状态机测试允许使用确定性替身；启用真实 AI 能力前必须补充该配置对应的脱敏契约，替身不能作为真实服务验收 |

禁止提前创建多供应商注册中心、路由器、降级链、模型目录、价格同步器或供应商专属环境变量。供应商错误、限流、重试和费用规则只在选定真实服务后根据其实际契约实现，不凭通用猜测写入生产代码。

### 3.2 D-003 关闭证据

2026-07-29，产品负责人明确不引入未要求的 AI 服务或替代实现。因此 D-003 以“不固定 Text Provider，按实际业务配置接入”为结论关闭。此前为未确认服务准备的探针、专属环境变量、候选模型、费用快照和未被业务调用的错误适配均删除；D-003 不再阻塞 S2 开工，也不代表任何真实 AI 服务已经验收。

## 4. D-005 工程合规基线

### 4.1 候选适用范围

本基线按“面向中国大陆公众提供人工智能短剧制作与下载服务”准备，但只有产品负责人明确首发地区后才能接受。若首发范围不同，必须重新完成当地适用性评审，不能直接复用本结论。

主要公开规则包括：[生成式人工智能服务管理暂行办法](https://www.cac.gov.cn/2023-07/13/c_1690898327029107.htm)、[互联网信息服务深度合成管理规定](https://www.cac.gov.cn/2022-12/11/c_1672221949570926.htm)、[人工智能生成合成内容标识办法](https://www.cac.gov.cn/2025-03/14/c_1743654684782215.htm)及[个人信息保护法](https://www.miit.gov.cn/jgsj/zfs/fl/art/2022/art_515a4b20c12f430eab54bb4f56d89f56.html)。是否需要算法备案或其他上线手续必须由指定合规责任人根据真实服务方式确认。

### 4.2 最小权利与授权模型

每份 ConsentRevision 至少记录：授权主体、权利类型（著作权/肖像/声音/其他）、被授权用途、生成与发布渠道、地域、有效期、撤回规则、授权证明的 MediaVersion、提交人和审查人。涉及人脸、声纹或可识别自然人的材料，必须单独确认处理的必要性、目的、方式、范围和同意；未成年人材料在 MVP 默认阻断，直到监护人授权流程另行接受。

声音人格权益依据还包括：[民法典关于声音保护的规则](https://gdca.miit.gov.cn/zwgk/zcwj/flfg/art/2020/art_573d6ef5018b46b6a4e1f31ca085a710.html)和[最高人民法院人工智能生成声音人格权案例](https://www.court.gov.cn/zixun/xiangqing/467631.html)。系统只验证证据是否完整、有效且覆盖目标用途，不自动判断授权文件的法律效力；有争议时必须转人工审查。

### 4.3 审核、标识与留存

| 能力 | MVP 基线 |
| --- | --- |
| 责任分工 | 内容提交人声明来源和授权；平台运营审查证据；产品负责人指定最终合规责任人；系统只执行已接受规则 |
| 生成门禁 | 权利状态为未知、过期、撤回或覆盖不足时可以保存草稿，但禁止 ready、提交生成和交付 |
| 内容检查 | 保存 Provider 内容安全结果和人工决议；检查服务不可用时对生成与交付 fail-closed |
| 显式标识 | 预览和下载成片必须展示人工智能生成/合成标识；MVP 不提供“无标识导出” |
| 隐式标识 | 交付媒体元数据记录生成属性、服务提供者标识和可追踪内容编号；DeliveryManifest 同步记录 |
| 留存 | 不臆造统一年限；Consent、审核、生成和交付审计不可随业务软删除立即消失，具体期限在公开测试前由合规责任人形成表格并接受 |
| 撤回 | 撤回只阻止后续使用和生成，不篡改已发生的审计事实；历史交付的处置由人工决议记录 |

标识办法自 2025-09-01 起施行，并规定特定未显式标识场景的用户义务和日志留存要求。Lanverse MVP 直接禁止无标识导出，因此不把该例外设计成产品能力；未来若增加，必须先修订 Requirement、Design、PRD 和留存策略。

### 4.4 脱敏授权验收样例

授权验收 fixture 只使用虚构主体和仓库生成的占位资产，不得包含真实姓名、证件、声音、肖像、签名或供应商原始响应。每个样例固定包含 `fixture_id`、主体类型、权利人角色、权利类型、资产及版本、授权用途、发布渠道、地域、有效期、撤回状态、证明文件版本、提交人、审查人、期望决议和原因码。

| fixture_id | 场景与输入 | 期望决议 | 原因码 |
| --- | --- | --- | --- |
| `consent-valid-adult-001` | 虚构成年主体；图像与声音权利；覆盖 AI 短剧生成及中国大陆公开发布；授权在有效期内；证明文件版本可访问 | 可进入生成与交付门禁 | `consent_valid` |
| `consent-revoked-001` | 字段完整，但权利人在生成前已撤回 | 允许保留草稿；阻断后续生成与交付 | `consent_revoked` |
| `consent-insufficient-001` | 授权只覆盖内部演示，本次请求公开发布 | 阻断生成与交付，并提示补充用途范围 | `purpose_not_covered` |
| `consent-expired-001` | 授权有效期早于本次生成时间 | 阻断生成与交付 | `consent_expired` |
| `consent-minor-001` | 主体为未成年人，MVP 没有已接受的监护人授权流程 | 默认阻断，不进入自动复核 | `minor_not_supported` |

同一 `ConsentRevision` 的判定必须是可复现的纯规则：输入事实版本和规则版本相同，输出决议及原因码相同。修改授权不覆盖历史版本；撤回生成新版本并只影响撤回后的新动作。人工审查只能产生带审查人、时间和理由的新决议，不得直接改写旧审计事实。

可执行输入位于 [授权门禁 fixture](../../backend/tests/fixtures/governance/consent_gate_cases.json)，契约校验位于 [fixture 契约测试](../../backend/tests/contract/test_consent_fixture_contract.py)。fixture 只使用 `synthetic-*` 引用，不引用外部 URL，也不携带姓名、证件、电话、邮箱、地址或签名字段；它们是后续 GOV-001/002 Red 测试的固定输入，不代表产品负责人已经接受规则。

### 4.5 留存与删除候选矩阵

下表是提交合规责任人签认的工程候选，不把尚无依据的统一年限写入代码。个人信息遵循目的限定和最短必要期限；删除项目或账号时，业务资产按已接受策略删除或匿名化，受到投诉、争议、法定义务或安全事件保全的事实进入访问受限的 legal hold，不随软删除消失。

| 事实类型 | 留存目的与起算点 | MVP 候选处理 | 负责人待确认项 |
| --- | --- | --- | --- |
| 授权证明及 `ConsentRevision` | 证明目标资产在生成/发布时具有相应授权；从最后一次使用或撤回起算 | 对业务用户不可见后转受限存储；争议时保全；到期删除证明文件并保留不可还原的最小审计摘要 | 合同、争议处理和适用法律对应的最终期限 |
| 审核决议与内容安全结果 | 支撑发布门禁、申诉和监管审计；从决议完成起算 | 原始敏感正文不进入普通日志；保留决议、规则版本、原因码和证据引用；到期删除或匿名化 | 申诉窗口及最终期限 |
| 生成任务与 Provider 请求标识 | 重试、幂等、故障对账和成本核算；从任务终态或账单结清起算 | 保存任务状态、模型、地域、请求标识和 token 用量；不把提示词或供应商原文复制进审计表 | 供应商合同、账单周期对应的最终期限 |
| 交付物、隐式标识与 `DeliveryManifest` | 用户下载、内容追踪和交付证明；从最后交付或项目删除起算 | 用户可按产品策略删除业务副本；发生争议时冻结相应版本；到期删除对象并保留最小不可还原摘要 | 项目/账号删除后的宽限期及最终期限 |
| 操作 `AuditEvent` | 安全调查和责任追踪；从事件发生起算 | 只记录主体、动作、对象标识、结果和关联标识；禁止记录凭据、完整输入、预签名 URL | 安全事件响应和适用监管对应的最终期限 |
| 无标识导出的接收者日志 | 仅在未来允许用户要求无显式标识导出时适用 | MVP 禁止该能力，因此不采集；未来若启用，按标识办法记录用户信息和日志且保存不少于六个月 | 当前为“不适用”；启用前重新评审 |
| 临时上传/下载地址 | 完成受控传输 | 只在请求时短期签发，不作为业务事实或日志字段保存；过期即失效 | 预签名 URL 的短期有效时长 |

最终期限必须配置在统一的留存策略中，由清理任务按事实类型执行；领域代码不得散落硬编码天数。软删除只控制业务可见性，不等同于完成个人信息删除，也不能成为无限期保留的理由。

### 4.6 产品负责人签认清单

关闭 D-005 只需要对以下四项给出明确结论，不能用“默认同意”代替：

1. 首发是否面向中国大陆公众；如果不是，提供首发地区并重新评审适用规则。
2. 指定一名可被追责的产品/运营合规责任人（姓名或组织角色均可，但必须能够实际处理审核、申诉和上线材料）。
3. 接受“无标识导出不进入 MVP”“未成年人材料默认阻断”以及本节五个脱敏授权样例的期望决议。
4. 在 4.5 的每一行填写最终期限或明确的删除触发条件；在签认前实现只允许使用更严格的临时策略，不能声称长期策略已验收。

### 4.7 D-005 关闭条件

1. 产品负责人明确首发服务地区；若为中国大陆，书面接受本节作为工程基线。
2. 指定可被追责的产品/运营合规责任人，并由其确认算法备案、生成式人工智能服务适用性及上线材料清单。
3. 接受 ConsentRevision 字段、未成年人默认阻断、人工审查责任和“无标识导出不进入 MVP”。
4. 签认 4.5 的留存/删除矩阵并补齐最终期限或删除触发条件。
5. 接受 4.4 的脱敏授权模板、撤回样例、权利不足样例和未成年人阻断样例；标识验收样片在 S4 合成交付实现前补齐，作为 GOV-005/006 测试输入。

当前未决证据：截至 2026-07-29，脱敏授权验收 fixture、对应契约测试与按事实类型划分的留存/删除候选矩阵已经形成；仓库仍没有首发地区确认记录、明确的合规责任人、对模板与策略的签认，以及各事实类型的最终期限或删除触发条件，因此 D-005 不能关闭，相关产品任务不能 accepted。

## 5. S2 执行边界

1. D-003 已关闭，`DEV-S2-01` 可先实现最小 Task/Outbox/Inbox/RabbitMQ，随后实现不依赖真实 AI 服务的剧本版本与私有媒体能力。
2. D-005 未关闭时，授权规则只能使用脱敏 fixture 做 fail-closed 工程验证；`PT-GOV-001/002`、ready 资产和整个 S2 均不得标记为 accepted。
3. 真实 AI 服务未配置时，自动提取返回明确的能力不可用；确定性替身只用于内部状态测试，不能形成真实调用验收证据。
4. 关闭 D-005 后再完成授权签认、ready 资产和 S2 产品验收；真实生成与公开交付还必须分别满足 D-004 和 S5 门禁。
