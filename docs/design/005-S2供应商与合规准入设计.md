## 1. 结论

S2 暂不具备实施准入条件。D-003 已形成可评审的 Text Provider 候选基线，但当前开发环境没有可用的生产调用凭据，不能验证账号实际额度、地域可用性和真实响应契约；D-005 已形成面向中国大陆首发的工程合规基线，但首发地区、合规责任人和留存规则尚未获得产品负责人确认。

在两项门禁关闭前，只允许维护脱敏 fixture、Provider 端口契约和合规测试清单，不创建 S2 业务表、Worker、空模块或模拟“真实供应商已验收”的实现。本文件是工程决策输入，不构成法律意见。

## 3. D-003 Text Provider 候选基线

### 3.1 固定候选

| 项目 | 候选决策 |
| --- | --- |
| Provider | 阿里云百炼 Model Studio，中国大陆北京地域 |
| 接口 | `https://dashscope.aliyuncs.com/compatible-mode/v1/chat/completions` |
| 模型 | 固定快照 `qwen3.7-plus-2026-05-26`，不使用会自动升级的浮动别名 |
| 调用方式 | 非流式、`enable_thinking=false`、`response_format={"type":"json_object"}`，提示词明确要求 JSON |
| 建议参数 | `temperature=0.1`、`top_p=0.8`、输出上限 16K tokens；真实样例通过后再调整 |
| 输出验证 | Provider JSON 必须再经 Pydantic 领域模型校验；缺字段、未知枚举或引用不存在均不得写入确认事实 |
| 凭据 | 只读取本地 secret 中的 `DASHSCOPE_API_KEY`；不写入文档、日志、消息或 Git |
| 禁止项 | 不使用仅面向个人编程场景的 Coding/Token Plan key 承担平台生产自动化 |

公开能力依据：[模型列表与上下文规格](https://help.aliyun.com/en/model-studio/text-generation-model/)、[结构化输出](https://help.aliyun.com/en/model-studio/qwen-structured-output)、[北京地域调用方式](https://help.aliyun.com/zh/model-studio/model-calling-in-sub-workspace)。

### 3.2 能力与费用快照

以下数值只用于 2026-07-29 的准入预算，不是长期价格契约：固定快照在不超过 256K 输入时，公开价为输入 2 元/百万 tokens、输出 8 元/百万 tokens；超过 256K 至 1M 时为输入 6 元/百万 tokens、输出 24 元/百万 tokens。官方公开限流为 600 RPM、1,000,000 TPM。账号实际免费额度、并发和账单必须通过目标账号验证，不能依据公开页面推定。

来源：[模型价格](https://help.aliyun.com/zh/model-studio/model-pricing)、[限流说明](https://help.aliyun.com/en/model-studio/rate-limit)、[模型下线策略](https://help.aliyun.com/zh/model-studio/model-depreciation)。每次调用保存 `provider`、`region`、实际 `model`、请求标识、输入/输出 token 和计价快照版本；价格查询失败不得阻止保存提取结果，但不得将未确认费用展示为最终费用。

官方隐私说明称请求数据不用于模型训练，但调用数据仍会按适用法律和服务条款处理；精确保存期限必须以目标账号签署的服务协议为准。依据：[百炼隐私政策](https://help.aliyun.com/zh/model-studio/privacy-notice)、[数据安全常见问题](https://help.aliyun.com/en/model-studio/faq-about-alibaba-cloud-model-studio)。在该边界获得负责人接受前，真实契约样例必须脱敏，不向 Provider 发送可识别自然人的正文、声音、肖像或授权证明。

### 3.3 失败分类

| 类别 | 典型结果 | 系统动作 |
| --- | --- | --- |
| 输入不可接受 | HTTP 400、结构校验失败 | 不重试；任务失败并显示可修改输入的下一动作 |
| 配置或权限错误 | HTTP 401/403/404 | 不自动重试；标记服务不可用并告警，禁止泄露凭据或原始正文 |
| 限流 | HTTP 429 | 有界指数退避并加入抖动；保留同一业务幂等键 |
| 供应商暂时故障 | HTTP 500/503、连接超时 | 有界重试；无法判断副作用时进入 `unknown`，使用原请求标识对账 |
| 输出不符合契约 | 非 JSON、字段非法、引用不存在 | 保存脱敏诊断，不写入业务事实；允许人工重新提取 |

依据：[官方错误码](https://help.aliyun.com/zh/model-studio/error-code/)、[限流处理建议](https://help.aliyun.com/zh/model-studio/rate-limiting-best-practices)。正文、提示词、授权证明和供应商原始响应不得进入 RabbitMQ 消息或普通日志；消息只携带任务标识和事实版本标识。

### 3.4 D-003 关闭条件

1. 产品/AI 负责人接受上述 Provider、地域、固定模型和参数，确认可调整参数只进入能力快照。
2. 在本地 secret 配置目标账号的 `DASHSCOPE_API_KEY`，确认不是个人 Coding/Token Plan key。
3. 使用仓库内脱敏固定剧本发起一次真实调用，记录日期、地域、实际模型、请求标识、token 用量、HTTP 结果和 Pydantic 校验结果；不保存密钥和原始供应商正文。
4. 验证目标账号的实际额度、限流和账单查询路径，并给出 S2 测试预算上限。
5. 对 400、401/403、429、超时、5xx 和非法 JSON 建立可执行契约测试后，才把 D-003 改为 `closed`。

当前阻塞证据：截至 2026-07-29，本地环境未配置 `DASHSCOPE_API_KEY`，因此没有真实请求、目标账号额度或账单样例。安装了 Ollama 但没有本地模型，它不能替代目标 Provider 的生产契约验收。

## 4. D-005 工程合规基线

### 4.1 候选适用范围

本基线按“面向中国大陆公众提供人工智能短剧制作与下载服务”准备，但只有产品负责人明确首发地区后才能接受。若首发范围不同，必须重新完成当地适用性评审，不能直接复用本结论。

主要公开规则包括：[生成式人工智能服务管理暂行办法](https://www.cac.gov.cn/2023-07/13/c_1690898327029107.htm)、[互联网信息服务深度合成管理规定](https://www.cac.gov.cn/2022-12/11/c_1672221949570926.htm)、[人工智能生成合成内容标识办法](https://www.cac.gov.cn/2025-03/14/c_1743654684782215.htm)及[个人信息保护法](https://www.miit.gov.cn/jgsj/zfs/fl/art/2022/art_515a4b20c12f430eab54bb4f56d89f56.html)。是否需要算法备案或其他上线手续必须由指定合规责任人根据真实服务方式确认。

### 4.2 最小权利与授权模型

每份 ConsentRevision 至少记录：授权主体、权利类型（著作权/肖像/声音/其他）、被授权用途、生成与发布渠道、地域、有效期、撤回规则、授权证明的 MediaVersion、提交人和审查人。涉及人脸、声纹或可识别自然人的材料，必须单独确认处理的必要性、目的、方式、范围和同意；未成年人材料在 MVP 默认阻断，直到监护人授权流程另行接受。

声音人格权益依据还包括：[民法典关于声音保护的规则](https://gdca.miit.gov.cn/zwgk/zcwj/flfg/art/2020/art_573d6ef5018b46b6a4e1f31ca085a710.html)和[最高人民法院人工智能生成声音人格权案例](https://www.court.gov.cn/zixun/xiangqing/467631.html)。系统只验证证据是否完整、有效且覆盖目标用途，不自动判断授权文件的法律效力；有争议时必须转人工审查。

### 4.3 审核、标识与留存

| 能力 | MVP 基线 |
| --- | --- |
| 责任分工 | 内容提交人声明来源和授权；平台运营审查证据；产品负责人指定最终合规责任人；系统只执行已接受规则 |
| 生成门禁 | 权利状态为未知、过期、撤回或覆盖不足时可以保存草稿，但禁止 ready、提交生成和交付 |
| 内容检查 | 保存 Provider 内容安全结果和人工决议；检查服务不可用时对生成与交付 fail-closed |
| 显式标识 | 预览和下载成片必须展示人工智能生成/合成标识；MVP 不提供“无标识导出” |
| 隐式标识 | 交付媒体元数据记录生成属性、服务提供者标识和可追踪内容编号；DeliveryManifest 同步记录 |
| 留存 | 不臆造统一年限；Consent、审核、生成和交付审计不可随业务软删除立即消失，具体期限在公开测试前由合规责任人形成表格并接受 |
| 撤回 | 撤回只阻止后续使用和生成，不篡改已发生的审计事实；历史交付的处置由人工决议记录 |

标识办法自 2025-09-01 起施行，并规定特定未显式标识场景的用户义务和日志留存要求。Lanverse MVP 直接禁止无标识导出，因此不把该例外设计成产品能力；未来若增加，必须先修订 Requirement、Design、PRD 和留存策略。

### 4.4 D-005 关闭条件

1. 产品负责人明确首发服务地区；若为中国大陆，书面接受本节作为工程基线。
2. 指定可被追责的产品/运营合规责任人，并由其确认算法备案、生成式人工智能服务适用性及上线材料清单。
3. 接受 ConsentRevision 字段、未成年人默认阻断、人工审查责任和“无标识导出不进入 MVP”。
4. 形成按事实类型划分的留存/删除表，至少覆盖授权证明、审核决议、生成任务、Provider 请求标识、内容安全结果、交付物和操作审计。
5. 提供不含真实个人信息的授权模板、撤回样例、权利不足样例和标识验收样片，作为 GOV-001/002 与后续 GOV-005/006 测试输入。

当前阻塞证据：截至 2026-07-29，仓库没有首发地区确认记录、明确的合规责任人、已接受的授权模板或留存表，因此 D-005 不能关闭。
