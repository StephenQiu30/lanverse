# Design 13：分析

执行编号：13；原始需求模块：17。依据[原始需求](../requirement/17-分析需求.md)、[PRD](../prd/13-分析.md)与[Plan](../plan/13-分析.md)。本文件把原始需要转换成项目方案，**全部新增设计选择仍待评审**；数据对象和接口为拟议合同，不表示已有表或已实现API。共同约束见[整体设计](00-项目需求设计.md)。原始FR、质量条件与AC仍须同时满足。

## 指标读模型与事实范围

分析只读取授权项目的镜头/输入/采用、真实任务/执行/费用及失效事实，不生成任务或建立通知平台。拟议QueryScope包含project_id、集过滤、起止窗口/时区与as_of；每个MetricResult包含value、numerator/denominator或sample_count、window、availability和口径版本。趋势与下载共用Scope，不用前端累加分页数据假造总量。

建议无样本为no_sample，未接入为not_connected，依赖失败为unavailable，真实0仅在完整事实下返回0。unknown/manual单列，不计为普通failed或success。任何空/null都不借用fixture正常值。

## 聚合接口和口径提案

拟议GET /projects/{id}/analytics汇总与趋势、GET /projects/{id}/pending-items待处理、GET /projects/{id}/analytics/exports按确认格式导出。数据库读同as_of快照或明确统计水位，局部错误标availability并保留最后成功信息，不把不同时间范围混为一张完整统计。

| 指标               | 建议口径（待评审）                                                                                |
| ------------------ | ------------------------------------------------------------------------------------------------- |
| 任务数与环比       | 按created_at落窗口的真实Task；前一个等长窗口，分母0则无可计算环比                                 |
| 成功率/失败/待核对 | 同创建窗口Task的截至as_of状态；成功率=success/(success＋failed)，分母同时返回，unknown/manual另计 |
| 耗时平均/P95       | 有真实起止时间的终态执行样本；P95算法统一选定，未完成/不明样本不伪造耗时                          |
| 镜头完成/总数      | 同授权集范围镜头，完成定义需接受采用/可用条件；未定时not_connected                                |
| 模型分组           | published_model_version归属，不把修改过的当前模型名当旧模型事实                                   |
| 分集阶段           | 从真实内容/采用条件计算；阶段判定未定时明确未接入                                                 |

7/14天使用一致时区日桶和窗口边界；有界全时段、最多366点仍是需求中的建议，不自动升级已接受上限。跨窗任务状态会变化，返回as_of以解释复查差异。待处理从授权unknown/manual/failed及stale对象聚合，原因/目标ID可追溯；已处理后按最新事实读取，不维持假固定通知数。

## 原始需求到设计追踪

| 原始FR          | 项目设计与验收观察                                           |
| --------------- | ------------------------------------------------------------ |
| FR-ANALYTICS-01 | Scope/MetricResult＋公式版本；窗口/分母一致，0/未知/失败分开 |
| FR-ANALYTICS-02 | 日桶/模型版本/分集投影；固定事实可复算，有界查询             |
| FR-ANALYTICS-03 | PendingItem真实原因/目标；授权跳转及已处理后更新             |
| FR-ANALYTICS-04 | 展开/下载使用同Scope/as_of；格式/范围未定前不提供假输出      |

验收先构造已知创建/完成时刻、success/failed/unknown/manual、跨窗口和0分母事实集，手工复算；再核真实数据权限和局部故障。量测成本/性能以接受规模为准，禁止将固定值或旧查询名称当数据来源。

## 待评审选择与实施入口

完成定义、窗口锚点/时区、成功率分母、P95算法、环比、全部时间范围和下载格式/上限均须确认。上述是候选口径，不宣称唯一行业标准。Demo只需任务状态与来源，不等待完整分析；按[Plan](../plan/13-分析.md)在事实稳定后落地。

## 工程合同：分析查询模型与API

### 数据源与SQL查询设计

本模块不新增指标写表或固定统计值表。查询使用projects/episodes/shots/shot_selections、generation_tasks/attempts/task_events/cost_facts、媒体就绪与版本引用。现有源表索引在所属Design定义；需要事实规模证据后才增索引/物化读模型，本轮无提前聚合平台。

| 查询              | 数据和连接条件                                                              | 窗口/公式/可空边界                                                                                     | 索引落点                                                         |
| ----------------- | --------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------ | ---------------------------------------------------------------- |
| task_totals       | 授权project内Task；集筛选经shot输入/shot.episode_id；自由画布Task不冒充某集 | [from,to)按Task.created_at，截止本请求as_of状态；success/failed/unknown/manual分别计                   | tasks(project_id,created_at,id)，shots(project_id,episode_id,id) |
| success_rate      | 同一cohort中明确终态Task                                                    | success/(success+failed)，分母0返回null＋no_sample，未知不混失败                                       | tasks(project_id,state,updated_at,id)                            |
| duration          | 同cohort且有真实started_at/finished_at的终态Task                            | 平均/P95按服务端观察到的执行耗时，P95建议percentile_cont(0.95)，样本数必返；不是供应商内部耗时         | tasks(project_id,created_at,id)                                  |
| daily/model_trend | Task.created_at按已确认时区日桶；按model_version_id分组                     | 7/14天或有界全时段；0样本/依赖错误和未接入分开                                                         | tasks(project_id,created_at,id)                                  |
| shot_completion   | 同项目/集镜头＋明确采用媒体当前可用事实                                     | 建议有可用选定视频才completed；定义待接受，未定时not_connected                                         | shots(project_id,episode_id,id)，selections(shot_id,revision)    |
| pending           | Task失败/unknown/manual＋当前选择/锁定与下游冻结版本不一致                  | 不创建通知表；按object_type/object_id/reason去重；当前真实状态变化会改数量                             | tasks(project_id,state,updated_at,id)，版本引用索引              |
| export            | 同QueryScope/口径版本和授权范围一次有界读取                                 | as_of是取样水位；不能宣称不同请求必然同一MVCC快照；如需精确同快照下载，保存本次授权结果/水位方案后接受 | 同上述查询                                                       |

metric公式均是本轮建议；原“完成”“环比”“全部窗口/P95”等接受条件仍适用。迟到事件用recorded_at解释后来事实，不能把供应商事件时间回填成之前已知道的状态。单请求汇总/趋势在只读Repeatable Read中完成，避免同时读出不一致分母。

### HTTP接口与DTO

路径统一以/api开头；字段后?表示可空/可省，其他为必需；Id/Rev/Time/Money/Page及通用错误见[全局HTTP合同](00-项目需求设计.md#工程合同http全局约定)。响应只包含所列字段，不直接序列化ORM。

| DTO                    | 字段与类型/语义                                                                                                                                                                                                                                                                                                                                                                                      |
| ---------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `AnalyticsQuery`       | from:Time、to:Time、timezone:string、episode_id:Id?、bucket:day；7/14/all由已确认范围映射，最大窗口配置                                                                                                                                                                                                                                                                                              |
| `MetricView`           | value:number?、numerator/denominator/sample_count:integer?、availability:available/no_sample/not_connected/unavailable、reason_code:string?                                                                                                                                                                                                                                                          |
| `AnalyticsView`        | scope:{project_id:Id,episode_id:Id?,from/to:Time,timezone:string}、as_of:Time、definition_version:string、metrics:{task_count:MetricView,success_rate:MetricView,failed:MetricView,unknown:MetricView,manual:MetricView,duration_mean_ms:MetricView,duration_p95_ms:MetricView,shot_completion:MetricView}、daily:[{date:string,task_count:MetricView}]、models:[{model_version_id:Id,metrics:Json}] |
| `PendingView`          | object_type:string、object_id:Id、reason_code:string、updated_at:Time、target:{project_id:Id,canvas_id/shot_id/task_id:Id?}                                                                                                                                                                                                                                                                          |
| `AnalyticsExportQuery` | AnalyticsQuery＋format:csv/json（格式作为待接受提案）、definition_version:string                                                                                                                                                                                                                                                                                                                     |

| 方法与路径                                         | 权限       | 请求                 | 响应/HTTP状态                              | 错误与写入边界                                       |
| -------------------------------------------------- | ---------- | -------------------- | ------------------------------------------ | ---------------------------------------------------- |
| `GET /api/projects/{project_id}/analytics`         | 项目所有者 | AnalyticsQuery       | 200 AnalyticsView                          | 422无效/超窗口；局部数据源不可用返回分组availability |
| `GET /api/projects/{project_id}/pending-items`     | 项目所有者 | type/reason/cursor?  | 200 CursorPage<PendingView>＋total:integer | 同项目真实待处理，有权跳转；与Canvas入口复用         |
| `GET /api/projects/{project_id}/analytics/exports` | 项目所有者 | AnalyticsExportQuery | 200确认格式的文件                          | 422格式未接受/超限；读取同筛选同公式，不导样例       |
