本文把 [REQ-28](../requirement/28-全能参考生视频.md) 拆解为实现设计。需求目标、业务规则（文中 R1、R2… 指 REQ-28 §2 的规则）与验收标准以 REQ-28 为准；表结构以 [DES-02](02-领域与数据模型.md)、接口签名以 [DES-03](03-接口设计.md)、工作流与生成操作以 [DES-04](04-工作流与生成操作.md) 为准，本文说明该功能用到哪些部分、如何组合。设计发现需求问题时先改需求（[文档规则](../README.md#文档规则) 2）。

## 1. 设计清单

| 类别 | 内容 |
| --- | --- |
| 数据表 | `lineage.dependency`、`operation.operation`、`operation.operation_input`、`storyboard.reference_item` |
| 接口 | `POST /api/projects/{pid}/quotes` |
| 工作流与任务 | 无 |
| 领域事件 | 无 |
| 测试用例 | TC-28-xx（[TST-02](../test/02-需求追踪矩阵.md)） |

## 2. 数据

| 表 | 关键字段 | 为什么需要 |
| --- | --- | --- |
| `storyboard.reference_item` | 参考组合 | 输入模板 |
| `operation.operation_input` | `seq_no`、`role`、`ref_type`、`ref_id`、`ref_version`、`media_asset_id`、`text_value` | 冻结输入、证据 |
| `operation.operation` | `mode = omni_reference`、`input_hash` | 执行与复用 |
| `lineage.dependency` | 片段 → 每个参考项上游 | 过期 |

`reference_item` 增加可选列 `trim_start_ms integer`（音频 / 视频参考起点，R5；DES-02 同步）。

## 3. 接口

```http
POST /api/projects/{pid}/quotes
{ "items": [ { "target_type": "shot_take", "target_id": "<shot_id>", "capability": "video.generate", "mode": "omni_reference", "output_count": 2 } ] }
200 { "items": [ { "operation_id": "…", "quote_micros": 30000000, "inputs_preview": [
        { "seq": 1, "role": "subject", "label": "图1 李明 / 日常装 v1" }, { "seq": 2, "role": "subject", "label": "图2 王芳 / 默认 v2" },
        { "seq": 3, "role": "scene", "label": "图3 医院走廊 v1" }, { "seq": 4, "role": "camera", "label": "视频1 推镜参考" },
        { "seq": 5, "role": "audio", "label": "音频1 台词 3-12-1" } ],
      "prompt_preview": "图1 中的男子与图2 中的女子在图3 的走廊相遇，参考视频1 的推镜运动，按音频1 的节奏说话……" } ] }
```

Activity `provider.submit` 的 `inputs[]`（DES-03 §7.1）按 `seq_no` 传递 `role`、`media_url`、`media_type`、`duration_ms`、`label`。

## 4. 异步与工作流

同 REQ-27（异步视频）；适配器层负责用途映射，供应商不支持某用途时在报价阶段已被 `limits` 拒绝。

## 5. 事件与实时

同 REQ-21、REQ-22。

## 6. 界面

镜头详情：参考组合（REQ-19）+ 提示词预览（带指代编号高亮）+ 生成；候选卡片可展开“所用参考”列表。

## 7. 权限与审计

同 REQ-21、REQ-22。

## 8. 非功能要求

AIQ-04、AIQ-05；PERF-09。

## 9. 测试设计

- 适配器映射单元测试（每个供应商的参数形态）；提示词指代与输入顺序一致性。
- 人工评测：TST-03 全能参考评测集（写实 + 4 种风格化 × 单角色 / 双角色 / 动作 / 运镜 / 音频）。
