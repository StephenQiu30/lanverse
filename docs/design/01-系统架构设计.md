# 浮光最小系统设计

## 问题与范围

承载[当前页面](../requirement/浮光页面/index.md)的账号、项目内容、素材、画布、模型执行及管理查询。仅按必要的数据和流程划分模块；旧微服务、队列与工作台拓扑不作为设计前提。

## 模块边界

| 职责       | 拥有的数据                           | 依赖                                   |
| ---------- | ------------------------------------ | -------------------------------------- |
| 账号与会话 | 账号、个人偏好、会话                 | 受控头像读取                           |
| 项目内容   | 项目、导入、集/场、镜头/设定版本     | 账号授权、媒体引用、生成结果           |
| 画布       | 布局、节点、连线、局部草稿           | 只读业务摘要，通过明确用例改变业务对象 |
| 素材       | 原件元数据、库归属、目录、收藏、引用 | 项目与用户权限                         |
| 模型与执行 | 供应商密钥、模型版本、任务、候选     | 冻结输入、媒体产物、审计               |
| 管理查询   | 审计、统计、健康聚合                 | 上述事实与实际运行指标                 |

采用模块化服务边界，HTTP层 → 应用用例 → 领域规则；数据库/对象存储/供应商为外部适配器。异步导入、复制和生成需要可持久任务，但当前不预定Kafka、Temporal、微服务或通用任务引擎。实现前依据必要消费者选择最小运行方式。

## 数据与失败

[新表模型](浮光页面数据设计.md)与[新接口](浮光页面接口设计.md)是本轮合同。文件处理、供应商调用在事务外执行，结果发布在受控事务内；unknown先核对，不能自动重复收费。私有媒体、凭据和密码不进入前端包/普通日志。

## 非目标

旧深度/导演台/时间轴/素材包产品；组织邀请、动态权限平台、订阅计费、完整Agent会话平台；为了延续旧结构而增加兼容层。本轮不实现这些模块，也不删除旧运行数据。
