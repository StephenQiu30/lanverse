# M07 生成规划、提示编译与路由详细设计

> Design ID：DES-M07
> Requirement：[REQ-PLN](../../requirement/007-M07-生成规划提示编译与路由需求.md)
> 状态：proposed

## 1. 设计结论

GenerationPlan 是所有真实媒体外调的冻结批准边界。计划、编译、路由和预检属于 M07；运行状态属于 M08；资源事实属于 M11；治理结论属于 M14。低消耗预演可被策略预授权，但仍创建同样的 Plan/Job 证据链。

## 2. 对象与快照

| 对象 | 设计 |
| --- | --- |
| CapabilityRevision | provider/model/version、media kind、limits、region、rights、usage unit、health |
| GenerationPlan/Item | purpose、target revision、execution disposition、usage cap、approval |
| InputSnapshot/Ref | ShotPlan、entity states、references、rules、rights hash |
| PromptCompilation | compiler/profile version、included/omitted fields、positive/negative、params |
| RouteDecision | eligible/rejected capability、reason codes、primary、approved fallbacks |
| PreflightReport | plan hash、policy versions、checks、blockers、warnings、expiry |

## 3. 编译与路由流程

加载批准镜头/知识 → 解析 capability hard constraints → 编译 provider-neutral intent → 为候选能力适配 Prompt/参数 → M14 外发/条款检查 → M11 估计 → 展示路由与淘汰原因 → 冻结计划 → 批准 `start_now|hold`。

Prompt 产物保留可读预览和敏感字段说明；用户覆盖保存 patch 与理由，但不能绕过硬门禁。相同输入、编译器和 capability profile 必须获得相同内容 hash。

## 4. 应用接口与事务

- Commands：`CreateGenerationPlan`、`CompilePlanItem`、`RunPreflight`、`OverrideRoute`、`Approve/Reject/SupersedePlan`、`SubmitHeldPlan`；
- Queries：计划差异、Prompt 预览、外发数据、资源区间、能力淘汰原因；
- Events：`GenerationPlanApproved`、`GenerationPlanSuperseded`、`CapabilityRevisionChanged`；
- 批准事务同时验证 expected hash、能力/治理、创建 M11 Reservation、写 approval 和 Outbox；`start_now` 通过 M08 端口创建 Operation/Jobs。

## 5. 状态与不变量

`draft → preflight_ready | blocked → awaiting_approval → approved | rejected | superseded | cancelled`。approved 永不变成 running/succeeded。每个 PlanItem 最多一个逻辑 Job；fallback 只能来自批准集合且不得改变冻结输入/资源/权利边界。

预授权规则必须固定 workspace、purpose、capability set、单项/批次硬上限和有效期；命中时仍记录批准策略版本和主体，未命中回到人工审批。

## 6. 失败与恢复

缺字段/参考回到具体 M04/M05 对象；能力下线保留原计划并创建替代计划；Prompt 超限显示被裁字段，禁止静默截断关键事实；估计不可用按策略阻止或明确保守上限；hold 启动前重新校验动态健康/权利但不改冻结输入。

## 7. 验证

Golden 编译样本、能力约束属性测试、预检逐项测试、并发批准和资源预留集成测试。切片 C 用一个图像+视频能力验证接入；只有两个同类视频能力完成故障切换 Gate 后才验收 PLN-FR-012。其余映射 PLN-FR-001—013、PLN-NFR-001—005、AC-PLN-001—008。
