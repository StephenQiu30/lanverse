# M13 装配与交付详细设计

> Design ID：DES-M13
> Requirement：[REQ-DLV](../../requirement/013-M13-装配与交付需求.md)
> 状态：proposed

## 1. 设计结论

M13 只实现平台闭环所需基础时间线。AssemblyRevision 是可编辑/批准事实，DeliveryBuild/RenderRun 是耐久过程，DeliverySnapshot/Manifest 是完成后原子发布的不可变结果；三者不能合并。

## 2. 数据与时间模型

| 对象 | 关键规则 |
| --- | --- |
| AssemblyRevision/TrackItem | ShotOrder、SelectionDecision、artifact、source PTS、timeline ticks |
| CaptionRevision | language、integer cues、style preset、status |
| AudioMixRevision | tracks、gain/fade/mute、loudness target、status |
| ExportPresetRevision | container/codec/raster/frame rate/audio/subtitle；发布后冻结 |
| DeliveryBuild/Input | assembly、preset、review/quality/rights refs、input manifest/hash |
| RenderRun | run number、render plan hash、stage、diagnostics |
| DeliverySnapshot/Manifest | build unique、input/output hash、required artifact items |

时间使用项目 rational timebase 和 integer ticks；禁止浮点秒作为裁剪、字幕或交付清单权威值。

## 3. 装配边界

支持顺序、入出点、简单转场、画幅适配、必要黑场；音频轨放置/裁剪/淡入淡出/音量；字幕校对和基础样式。高级调色、VFX、跟踪、专业混音、插件和多人 NLE 工程留给外部工具，通过有序素材包/Manifest 交换。

## 4. 预检与构建

冻结 Assembly → 检查每个必需 purpose 的 Selection/媒体 → 校验时间/规格 → 校验 M10 QualityRiskAcceptance、M14 PolicyException 和 M12 ReviewDecision 各自有效 → 冻结 Build Manifest → M08 风格 Operation 调度 Media Worker → 验证所有 required output → 单事务创建 Snapshot/Manifest。

同 build/manifest 的重复 finalize 回读同一 Snapshot。RenderRun 可重跑并复用内容寻址中间产物；新交付必须新建 Assembly/Build/Manifest 链。

## 5. 应用接口

- Commands：`Create/Update/ApproveAssemblyRevision`、`CreateCaption/AudioMixRevision`、`RunDeliveryPreflight`、`Start/Cancel/RetryDeliveryBuild`、`FinalizeDeliverySnapshot`、`Grant/RevokeDeliveryAccess`；
- Queries：时间线、装配差异、预检 blockers、Build stages、Manifest/下载；
- Events：`AssemblyApproved`、`DeliveryBuildStateChanged`、`DeliverySnapshotCreated`。

## 6. 失败与恢复

缺主选/权利/审批在 Build 前阻止；渲染中断从确定阶段恢复或新 RenderRun；主文件成功但字幕失败为 partial 且无 Snapshot；校验失败隔离输出；链接撤销不删除 Snapshot；外部 NLE 返回包必须以新来源/装配版本摄取。

## 7. 安全、观测与验证

Media Worker 使用限权临时磁盘/对象前缀，无 Provider 凭据；Manifest 规范化引用防止源媒体提前删除。指标：预检一次通过率、partial、恢复时间、快照完整性和可复现率。

映射 DLV-FR-001—013、DLV-NFR-001—005、AC-DLV-001—009。A 仅做顺序预演；E 完成审阅、基础装配和不可变交付。
