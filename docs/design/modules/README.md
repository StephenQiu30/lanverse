模块 Design 与 Requirement 一一对应，负责实现边界、事实所有权、命令/查询、状态、失败恢复、权限、观测和验证。模块 Design 不表示独立微服务；首期仍按 A—F 纵向切片实现。

每份详细 Design 只描述目标系统，至少给出业务目标与非目标、事实所有权、功能分解、跨模块契约、状态/并发与幂等、失败恢复、页面可观察状态、Requirement ID 验收映射和切片依赖。实施进度与真实执行证据分别记录在 `docs/plan` 和 `docs/acceptance`；Design 不引用旧代码路径、不建立复用或替换方案，也不以同名表、接口或 Mock 证明能力成立。
