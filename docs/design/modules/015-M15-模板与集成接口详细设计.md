# M15 模板与集成接口详细设计

> Design ID：DES-M15
> Requirement：[REQ-INT](../../requirement/015-M15-模板与集成接口需求.md)
> 状态：proposed

## 1. 设计结论

模板是已批准结构的不可变发布版本，集成是受限身份调用相同应用端口。API、Webhook、私有能力和扩展不获得数据库写权限，也不实现另一套资源/治理/执行规则。

## 2. 模板模型

TemplateRevision 保存类型、schema version、包含项、默认值、依赖、capability requirements、rights summary 和 source refs；TemplateRelease 决定组织可见性。实例化先生成 preview manifest，验证依赖后创建新项目身份并记录 source release/local overrides。

升级只计算新增、删除、冲突、能力缺口和影响，输出迁移 Proposal；用户逐项接受后调用各模块正式命令，绝不直接 patch 项目表。

## 3. API 与客户端

ApiClient/ServiceIdentity 由 M01 管理身份，M15 保存 contract/scope/rate policy。所有写请求要求 idempotency key、expected revision 和 workspace/project scope；高风险动作仍要求对应批准事实。

首批 API 只暴露纵向闭环需要的项目、来源、镜头、计划、任务、候选、审阅和交付查询/命令，不暴露内部表或通用 CRUD。

## 4. Webhook

WebhookSubscription 声明事件类型、过滤、endpoint、secret ref、contract version 和 status。Delivery 保存 event ID、attempt、signature version、response summary、next retry/dead letter。事件只含必要 ID/version/status/trace；重放不产生新业务事实。

## 5. 私有能力与扩展

PrivateCapabilityRegistration 声明模型/LoRA version、media kind、input/output、reference limits、region/data policy、usage unit、health and rollback。注册后生成 M07 CapabilityRevision，通过 M08 Provider Adapter 执行。

ExtensionManifest 只申请白名单 Query/Command；运行在隔离进程/外部连接中，无数据库、对象桶或密钥通配访问。首期不支持任意脚本节点和公共市场。

## 6. 应用接口与失败恢复

- Commands：`Create/Publish/RetireTemplateRevision`、`Preview/Instantiate/MigrateTemplate`、`Register/RevokeApiClient`、`Create/Pause/ReplayWebhook`、`Register/RevokePrivateCapability`；
- Queries：模板差异/兼容、API scope、Webhook 投递、能力健康；
- Events：`TemplateReleased`、`WebhookDeliveryFailed`、`PrivateCapabilityChanged`。

依赖缺失在实例化前阻止；API 重复回读同结果；Webhook 失败进入重试/死信，不回滚业务；凭据撤销立即阻止新调用；能力不健康停止新路由并保留历史计划/对账。

## 7. 安全与验证

契约版本有弃用窗口；Webhook 签名/时间窗/重放自动验证；凭据仅存密钥引用。契约测试保证 UI/API 同权限、冲突、幂等和治理结果。
