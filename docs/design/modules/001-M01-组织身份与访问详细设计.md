# M01 组织、身份与访问详细设计

> Design ID：DES-M01
> Requirement：[REQ-IAM](../../requirement/001-M01-组织身份与访问需求.md)
> 状态：proposed

## 1. 设计结论

M01 在 Python 模块化单体中提供统一 `AuthorizationPort`。账户认证、Workspace 成员、项目职责和临时能力授权分层计算；UI、API、Worker、媒体签名和 Agent Tool 只调用该端口，不各自解释角色。

## 2. 边界与依赖

- 拥有：Workspace、Membership、Invitation、ProjectAssignment、ServiceIdentity、Session、CapabilityGrant、PolicyRevision、AccessAudit；
- 读取：M02 Project 身份和 M14 高风险策略结论；
- 不拥有：各模块内容批准、资源例外、质量风险或交付决定；
- 存储：PostgreSQL 权威事实；短期鉴权缓存必须绑定 policy version。

## 3. 不变量与数据约束

1. 所有业务对象都带 `workspace_id`，授权请求必须同时提供 actor、workspace、action 和 subject；
2. `(workspace_id, account_id)` 最多一个活动 Membership；邀请 token 只存哈希且单次消费；
3. 最后一个 active Owner 不可被移除；历史主体不因成员停用删除；
4. CapabilityGrant 必须有 scope、purpose、expires_at 和 grantor；高风险提交时重新校验；
5. ServiceIdentity 无交互登录和通配项目权限，凭据只保存密钥引用。

## 4. 应用接口

| 类型 | 接口 | 关键输入/输出 |
| --- | --- | --- |
| Command | `CreateWorkspace` | owner account、name、idempotency key |
| Command | `InviteMember` / `AcceptInvitation` | role、expiry、expected invitation state |
| Command | `AssignProjectRole` | project、capabilities、expected revision |
| Command | `SuspendMembership` | reason、revocation mode、effective time |
| Command | `Issue/RevokeCapabilityGrant` | action scope、limit、expiry |
| Query | `Authorize` | allow/deny、reason_code、policy_version、next_action |
| Query | `ListEffectiveCapabilities` | organization + project + temporary grants |

成功写命令与 `AuditEvent`、必要 Outbox 事件在同一事务提交。拒绝不泄露对象是否存在。

## 5. 状态与流程

Invitation：`pending → accepted | expired | revoked`；Membership：`invited → active → suspended | removed`。停用流程先提交成员状态和撤销事件，再由 Reconciler 撤销会话、媒体授权和未启动任务资格；已收单外部任务进入 M08 对账而非丢弃。

## 6. 失败与恢复

- IdP 不可用：只按组织策略允许未过期短会话，禁止管理员降级；
- 撤销传播延迟：高风险命令实时回源，后台持续对账旧会话；
- 并发邀请接受：唯一约束回读同一 Membership；
- 职责冲突：返回 expected/current revision 和字段差异；
- 审计/Outbox 写失败：业务事务整体回滚。

## 7. 安全、观测与验证

RLS 使用非 owner 业务角色并覆盖负向集成测试；对象签名包含 workspace、subject、action 和 expiry。指标至少包括拒绝原因、撤销传播时间、跨租户尝试和异常服务身份调用。

验证覆盖 IAM-FR-001—012、IAM-NFR-001—005、AC-IAM-001—008；切片 A 先实现单 Workspace/项目职责和隔离，SSO/SCIM、委派、双人批准留到 F。
