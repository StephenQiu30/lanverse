# M14 权利、安全与治理详细设计

> Design ID：DES-M14
> Requirement：[REQ-GOV](../../requirement/014-M14-权利安全与治理需求.md)
> 状态：proposed

## 1. 设计结论

M14 是横切门禁模块，但不是全局 `utils`。它拥有权利声明、提供商条款、策略评估、PolicyException、保留/法定保全和治理审计；业务模块在上传、绑定、Agent、计划、提交、分享和交付各自调用显式端口。

## 2. 领域对象

| 对象 | 规则 |
| --- | --- |
| RightsDeclaration | subject、source/creator、uses、regions、expiry、external processing、evidence |
| ConsentRecord | person/voice、purpose、regions、validity、revocation |
| ProviderPolicyRevision | region、retention、training use、deletion、terms snapshot |
| ContentPolicyRevision | scope、rules、severity、effective time |
| PolicyEvaluation | action、subject/input hash、provider、rules、result/reasons |
| PolicyException | evaluation、exact scope/action/provider、reason、approvers、expiry |
| RetentionPolicy/LegalHold | data class、duration、hold behavior |

## 3. 门禁矩阵

| 动作 | 最少检查 |
| --- | --- |
| 上传接纳 | 来源声明、文件安全、禁止内容、保留分类 |
| 参考绑定 | subject 权利、用途、真人/IP/品牌限制 |
| AgentRun | 实际外发字段、目的、模型/地域、保留/训练条款 |
| GenerationPlan/Job | Prompt/参考/媒体、Provider、用途、策略版本 |
| 外部审阅 | reviewer、可见字段、下载权、地域和期限 |
| 交付 | 所有采用输入、地域/用途/期限、Review 和例外有效性 |

早期通过不自动继承；每次评估绑定动作时版本。策略服务不可用时高风险 fail closed。

## 4. 应用接口

- Commands：`Declare/ReviseRights`、`Record/RevokeConsent`、`EvaluatePolicy`、`Approve/RevokePolicyException`、`ApplyRetentionAction`、`Place/ReleaseLegalHold`；
- Queries：对象权利摘要、外发披露、阻塞原因、例外/到期、删除影响；
- Events：`RightsChanged`、`PolicyExceptionExpired`、`ProviderPolicyChanged`、`LegalHoldPlaced`。

PolicyException 只覆盖权利、安全、地域、数据和内容政策，不能代替 QualityRiskAcceptance、UsageException 或 ReviewDecision。

## 5. 数据生命周期与失败恢复

删除请求先生成数据库/对象/派生/备份/导出清单并检查引用/LegalHold；执行结果逐项记录。Provider 条款变化停止新路由，已提交任务由 M08 对账。许可到期阻止未来动作，历史 Snapshot 保留当时依据。

误报通过复核/有限例外处理；评估规则未知进入 blocked；异常删除不物理清除保全对象。审计只保存哈希、引用和脱敏摘要。

## 6. 验证

矩阵测试覆盖 UI/API/Agent/Worker/重试不可绕过、真人参考、禁止训练 Provider、到期许可、例外范围、法定保全和删除一致性。映射 GOV-FR-001—013、GOV-NFR-001—005、AC-GOV-001—009；A 建来源声明，C 建外发门禁，F 建企业治理。
