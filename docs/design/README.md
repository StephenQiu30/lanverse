# Design 文档

本目录存放设计方案类文档。

正式设计必须以 [`requirement/`](../requirement/README.md) 中已接受的 SRS、FR、NFR 和 TCR 为输入，并满足 [`ADG-001 前后端集成契约与设计完整性评审门禁`](../requirement/ADG-001-前后端集成契约与设计完整性评审门禁.md)。未通过门禁的内容不得直接进入实现。

## 适合放入

1. 技术方案。
2. 架构决策。
3. 接口、数据结构和模块设计。
4. 关键实现权衡。

## 不适合放入

1. 纯产品需求。
2. 执行排期。
3. 测试结果或发布流程。
4. 未形成长期设计决策的临时探索记录。

## 命名建议

总体设计使用 `ARCH-xxx-主题设计.md`，长期技术决策使用 `ADR-xxx-主题.md`。建议至少覆盖总体架构、领域与数据、异步任务、媒体、安全以及部署/可观测性/灾备；允许合并文档，但不得遗漏 `ADG-001` 的强制交付内容。
