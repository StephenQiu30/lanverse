# Design 08：设定

执行编号：08；原始需求模块：12。依据[原始需求](../requirement/12-设定需求.md)、[PRD](../prd/08-设定.md)与[Plan](../plan/08-设定.md)。本文件把原始需要转换成项目方案，**全部新增设计选择仍待评审**；数据对象和接口为拟议合同，不表示已有表或已实现API。共同约束见[整体设计](00-项目需求设计.md)。原始FR、质量条件与AC仍须同时满足。

## 实体、造型与锁定版本

设定模块拥有项目内角色/场景/道具实体、别名、造型版本、参考槽位和声音声明；原件归媒体，生成候选归生成。名字用于显示与搜索，不能作为实体唯一性或跨剧本自动合并依据。

SettingEntity含稳定id/project_id/category、名称/别名与来源；AppearanceVersion含不可变版本、描述、来源和四参考槽位；ActiveDraft含revision；LockedReference记录用户明确锁定的版本/媒体、操作者和时间。声音单独VoiceSourceVersion/VoiceDeclaration，避免把角色图像锁定等同声音已获授权。

## 编辑、生成与采用接口

拟议GET /projects/{id}/settings按类别/关键词/待确认过滤；POST建实体、PATCH /settings/{id}/draft条件编辑、POST /settings/{id}/locks明确锁定；GET /settings/{id}/appearances/{version_id}按需详情；POST /settings/{id}/voice-declarations保存声明。

四参考槽位为正面半身、侧面、全身、表情组。上传结果经媒体准入后可绑定草稿；生成经[共享生成](10-生成.md)追加候选，不自动绑定或锁定。采用事务核项目、媒体版本/就绪/审核、expected_revision，生成新AppearanceVersion与明确锁定关系；若输入变化，不能把旧锁定冒充当前新输入已确认。

锁定建议以造型版本及其四槽位内容为单位，实体基本信息/声音是否一起锁定另待确认。已有镜头引用旧锁定版本仍有效；新编辑产生新版本，使用者明确更新才改变引用。来源版本、引用用途与旧媒体不能被原地改写。出场集数来自确认的内容引用，不是抽取候选中出现次数。

声音预览必须从授权media或明确供应商音色取得真实音频。真人来源相关生成需当前VoiceSourceVersion对应声明，保存声明正文/主体/来源/提交人/时间；更换来源产生新版本，旧声明不可自动沿用。服务端生成预检再次校验，不能只靠勾选框。

## 原始需求到设计追踪

验证并发锁定、四槽位越权/未就绪、候选晚到、同名实体、改输入后的锁定状态、旧镜头引用及声音声明与来源错配；审计只记录安全版本/动作，不回传秘密或未经授权音频。

## 待评审选择与实施入口

实体/别名合并确认、造型与锁定范围、旧引用失效标记、真人主体/声明正文与音色来源待明确；首轮画布直接选图片，不依赖设定四槽位。完整设定按[Plan](../plan/08-设定.md)接入，不扩为声音克隆或对话平台。

### 造型锁定与生成边界

名称/别名、每个造型、声音分别版本化，解决一个角色多造型与同名多实体。造型生成预检冻结metadata_version与setting_version，并在提交事务检查二者当前指针；改名不原地改历史Task。新造型版本复制已合法槽位，再替换明确更新的槽；锁定明确版本，媒体准入检查与指针/audit同事务。
声音声明引用具体voice_source_versions.id，而不是“某个角色已声明”的布尔；生成引用非媒体音色时同样冻结source/声明版本，见生成Ref形状补充。source_kind未知或真人声明缺失在调用前拒绝。首轮锁范围以单造型版本为建议，整实体锁范围仍待原政策接受。
