# Design 09：镜头

执行编号：09；原始需求模块：13。依据[原始需求](../requirement/13-镜头需求.md)、[PRD](../prd/09-镜头.md)与[Plan](../plan/09-镜头.md)。本文件把原始需要转换成项目方案，**全部新增设计选择仍待评审**；数据对象和接口为拟议合同，不表示已有表或已实现API。共同约束见[整体设计](00-项目需求设计.md)。原始FR、质量条件与AC仍须同时满足。

## 镜头身份与输入版本

镜头模块拥有同项目集/场内的镜头身份、创作输入、明确采用和历史；生成拥有执行与候选。Shot含project/episode/scene/id/ordinal及当前版本引用；ShotInputVersion为不可变描述、景别/运镜、时长、模式、模型发布版本和按用途/顺序的media/setting refs；ShotSelection记录明确候选/media版本及操作者/时间。导航由同一授权顺序计算，不用页面fixture编号。

首镜头如何由确认剧本/分集/场形成仍待设计接受；无真实镜头时展示空/未接入，不能默认创建样例。画布自由节点可以独立于镜头，后续通过明确引用绑定。

## 编辑、提交、采用与失效

拟议GET /projects/{id}/shots/{shot_id}读当前详情、GET /shots/{id}/versions按需历史；POST /shots/{id}/input-versions提交expected_revision；PUT /shots/{id}/selection采用；POST /shots/{id}/candidate-library-entries存到素材。生成提交仍走/generation/tasks，镜头接口不能另起供应商调用。

参数编辑边界按发布模型能力统一校验，事务内创建不可变输入版本、推进current指针及审计；冲突返回当前revision并保留草稿。参考带用途/顺序和具体版本，复制参数只建新草稿，不复制临时URL或凭据。历史详情只读，播放/比较当前交互不修改版本。

采用时核候选属于此镜头、媒体可用与权限及expected_selection_revision，只改Selection。晚到候选只追加，不能替代人工采用。依赖项存冻结上游版本与用途，当前版本不同时提供stale原因；建议采用源变化后标下游失效而不自动修改或重生成。失效检测可由版本比对产生，具体范围和保留规则在切片接受，不预建全产品依赖图引擎。

复用候选到素材调用[素材用例](03-素材.md)，保留task/input/media来源；重复存库按明确唯一关系处理。只读台词音频来自真实音频版本及说话者/台词/音色/速度/情绪/时长事实，缺字段为空；不在本模块新增逐句配音编辑。

### 版本事务与失效查询

接口参考数组拆成shot_input_references，保留类型/角色/顺序/不可变ID，不用URL；Task冻结后拆进generation_task_refs进行实际媒体/版本FK校验。镜头输入校验端口按项目/模型能力核完整引用，历史字节保留由媒体与对应输入版本关系保证。
采用只追加shot_selections并改变current_selection_id，stale读投影比较下游冻结ref版本与当前明确采用/锁定，不覆盖旧输入。当前只读台词音频随有来源的输入/结果事实返回；不从文字生成假波形。镜头新建和输入变更与关键audit同事务，真实生成继续走共享接口。
