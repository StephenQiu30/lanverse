## 2. 体验结构与主路径

主路径为“进入工作区 → 创建项目或继续制作 → 导入与确认剧本 → 准备本集设定 → 审阅分镜 → 生成并选定视频 → 生成并选定配音”。每个阶段允许进入画布精修，再返回原对象，不要求用户重新建立制作流程。

全局导航保留四个稳定入口：**创作、项目、媒体、任务**。底部放工作区设置与系统状态；通知作为入口徽标与列表，不占首页主体。跨项目媒体必须先选项目，不合并成无归属素材池。
进入项目后，顶栏显示项目 / 集 / 当前对象、任务状态与 Agent；左栏改为概览、剧本、设定集、本集制作、画布、媒体、影响清单、成本、设置。项目内路径优先于全局入口，返回位置明确。
“本集制作”内用阶段导航串联资产定稿、分镜、视频、配音；镜头表与故事板是同一分镜的两种排列，不增加第三套对象状态。完整阶段进度来自业务事实，不按访问页面次数计完成。

首页采用宽留白、大标题和中央创作区，桌面内容最大宽度约 1280 px。工作台压缩留白、增加信息密度；画布独立全屏。不同页面继承同一字体、颜色和控件语义，不把营销页的巨大空白套到生产表格上。

## 4. 表单与无限画布的一份数据

表单适合批量确认、结构化输入和逐集生产；画布适合围绕角色 / 镜头组合参考、探索候选和局部精修。模式切换是视图切换，不是“导出到画布”或复制项目。
生成表单也支持项目内自由创作；切换到画布时定位同一自由生成配置及其操作与候选，不能重新提交一次生成。图片表单以提示词、参考与输出尺寸为主；视频表单先明确图生视频 / 首尾帧 / 全能参考，再显示适用输入；配音表单围绕台词、音色与试听，不做一个囊括全部模型参数的大表单。
自由配置仍归所选画布文档中的节点；表单读取和编辑该节点配置，只建立一次引用与生成记录，不新增另一套自由创作数据模型。正式镜头与槽位继续由各自业务模块拥有。
项目、集、场、镜头、造型、台词、素材、候选与生成操作拥有稳定业务身份。画布仅拥有节点位置、尺寸、层级、分组、注释和自由生成配置；业务节点通过引用读取同一正式对象。
业务字段只走所属业务命令；布局只走画布命令。任务与正式选定由服务端事实决定，不能保存到节点私有 JSON 再反向覆盖业务对象。多候选同时保留，画布上的“采用”与表单选定使用同一版本门禁。

建议 URL / 定位状态携带项目、集、镜头与视图；画布携带文档及选中节点。刷新恢复已保存的位置与视口；筛选状态由 URL 或已接受的页面状态合同管理，不另造持久化事实。
表单点“在画布中定位”：已有绑定节点则聚焦与高亮；多个文档则选文档；无节点则提示在现有 / 新画布添加引用。画布点“在表单中打开”定位对应条目，保留返回画布的文档、视口与选区。
切换前有未保存编辑则提交允许的编辑命令：成功后按同一对象切换；网络失败保留草稿与原幂等键，显示“尚未保存”并允许查明 / 重试；409 拉取最新版本，保留差异并要求重新确认，不能把草稿当成另一视图的正式事实。生成任务在后台继续，不因切换视图取消。跨视图更新目标保持原合同 2 秒内可见，断线后先补齐服务端事实。

画布沿用 BeefTV 的平移缩放、框选、群拖、对齐、分组、连接、小地图、布局、快捷键、空间索引与 LOD；不换为新的画布引擎或第二份本地数据库。
默认轻点阵；背景、小地图可关闭。内容节点以表面色、媒体与文字辨识；必要的选中轮廓、连接端口、焦点和分组边界保留，它们表达编辑状态，不给全部页面内容加框。
缩放 0.05～4，100%、全画布、选区定位始终可用。折叠组显示数量与状态摘要；连线端点映射到组，缺失引用留有明确标记。删除节点只移除画布引用；删除 group 解组并保留子节点与绝对位置；删除业务对象必须是独立明确命令。
连接先校验类型、用途、模型上限与正式输入语义。自由生成输入、镜头参考与提升选定按 DES-06 区分；目标不支持时解释原因，不让装饰连线看起来已修改业务参考。
Agent 的布局与字段提案在独立预览层显示，应用后才生成正式命令；撤销限已允许的编辑命令，不撤销付费、正式选定或账本事实。

## 5. 生成、候选与可信失败状态

统一生成流程为“准备输入 → 校验引用与模型能力 → 取得报价 → 审阅并明确确认 → 跟踪任务 → 审核 / 接管 → 对比候选 → 选定”。表单、画布、Agent 和批量共用同一报价确认体验。
模型参数依据冻结的模型 schema 呈现，能力、参考用途、数量上限与不支持项在操作现场解释。图生视频与全能参考分开展示输入，首尾帧、改图、续接只对已支持模型开放。
报价对话框显示对象范围、模型版本、数量、费用上限 / 计费方式、剩余预算、预留、有效期与服务区域；批量可展开逐项。过期、预算不足、输入 / 目标 / 模型价格版本变化或费用不能核定时使 quote 失效，重新报价前不能确认。
批量输入变化仅使对应项报价失效；确认界面重新汇总有效项与需重新报价项，不把其他已完成项重发。已绑定镜头的生成读取正式参考组合；自由节点的 input 与镜头 reference 在界面中明确区分。
确认按钮写成“确认生成 N 项 · 最高 ¥X”或对应可信费用语义；不由 Enter、普通快捷键、拖线或 Agent 回复自动触发。若模型实际费用不可核定，禁止显示免费；复用 ¥0 仅在服务端明确返回复用事实时显示。

候选区默认 2–4 列，展示版本、模型、生成时间、审核与来源；没有字段就不补造。图像支持放大与前后对照；视频支持同步起播、静音、逐帧；音频支持逐句试听与波形。
“聚焦候选”“预览”“选定”是三个不同动作。选定用明确按钮与“已选定”文字；其他候选继续保留。改选会影响下游时先展示数量与对象，未审核 / 未接管结果不能选定。
自由结果的“加入画布”只创建资源引用，“设为镜头片段”走正式选定与版本门禁，两者分开展示。用户已改选、删除节点或切换项目后，迟到结果仍归原操作候选，不覆盖新选定、不恢复已删除节点。导出 / 下载保留正式来源与既有标识合同；不把候选直接称为成片。

| 媒体接管 / 审核失败  | 显示失败阶段；恢复同一操作的对应阶段，不用“重新生成”掩盖已有付费事实       |
| 取消请求             | “取消请求已发送 / 正在核对”；上游确认前不报已取消，也不承诺退款或零费      |
| 输入或引用过期       | 保留原结果，说明哪个上游版本变化；选择重做范围并重新报价                   |
| revision 冲突        | 保留本地草稿，拉取最新事实并提示需重新确认的字段；禁止静默覆盖             |
| 批量部分失败         | 成功、失败、未知分别计数；只对明确可重新执行项准备新报价                   |

任务、选定和新鲜度分成不同状态维度，例如“已选定 · 上游已变更”；状态用文字、图标和语义表达，颜色辅助。加载、空、错误、只读和服务不可用有完整状态，错误可复制追踪 ID，不展示堆栈或凭据。

## 6. Agent 与媒体

Agent 作为项目上下文中的右侧面板，顶部明确项目、集和选区；上下文引用可查看 / 移除。首页入口先确定项目，再建立对话；不创建无归属的正式制作对象。
回复分为解释、提案、报价草稿和执行结果。提案逐项显示对象与旧值 → 新值，可应用 / 拒绝；输入版本变化后重新校验，不把聊天文字作为已完成的写入证据。
付费提案先生成报价草稿，用户应用提案也不等于已授权付费；每个入口均走统一确认。工具结果显示实际对象、任务与失败原因，暂停 / 中断不隐藏已发生的请求与费用。

媒体始终属于项目，浏览器仅使用服务端授权的素材 ID 与临时预览地址。缩略图、海报和波形稳定占位；不在列表自动播放有声视频。详情可查上传 / 生成来源、审核依据、使用位置和关联任务。
列表超过 100 行使用既有虚拟化方案；画布仅渲染视口内节点，按缩放选择缩略图，同时播放视频不超过 3 个。沿用性能目标：500 节点 ≥50 fps，2,000 节点 ≥30 fps；测量须包含真实交互与媒体负载。
文件选择、拖入与粘贴图片进入同一上传确认；按当前合同要求用户确认已检查内容、拥有使用权且无需要另行授权的真人素材。需真人授权的素材等待正式流程，不伪造授权或云审核通过。
当前上传合同：图片 JPG/PNG/WebP ≤20 MiB；视频 MP4/MOV ≤500 MiB 且 ≤60 秒；音频 MP3/WAV/M4A ≤100 MiB。界面提前提示，服务端内容探测与接管结果决定是否可用。
上传成功但画布保存失败时明确“素材已上传，节点尚未保存”，重试原命令而非重传。预览授权过期可重新获取；跨项目切换清理选区、预览和上传状态，释放离屏播放与临时 URL。

## 8. 响应式、键盘与可访问性

桌面 ≥1280 px 为完整生产环境；1280–1440 折叠侧栏、按需展开属性 / Agent，保持主要候选与参数可达。镜头表可有受控横向滚动，页面本身不横向溢出。
768–1279 px 建议支持任务、媒体、候选审阅与轻量表单；三栏改为两栏 / 分段视图。移动 <768 px 建议支持项目、任务、通知和媒体审阅，完整画布 / 批量表格提示进入桌面；不把旧草案手机限制默认为已更改合同。
上述非桌面范围是待评审提案：最终支持深度需同步 REQ-02/05。移动不出现不可解释的空白，不用缩小全部桌面 UI 假装生产可用。
所有图标动作有可访问名称，输入关联标签与错误；状态更新适度播报，异步完成不抢焦点。正文对比 ≥4.5:1；控件与焦点可辨，触控目标约 44 px。
对话框打开后聚焦标题 / 安全起点，关闭恢复触发处；报价不默认焦点到付费确认。抽屉、菜单与候选播放器复用官方语义，键盘可退出，避免焦点陷阱叠加。
`Cmd/Ctrl+K` 跳转，`Cmd/Ctrl+J` Agent，`?` 帮助；编辑态不触发页面快捷键。画布保留选择、平移、撤销 / 重做与复制粘贴；方向键在工具控件上只移动焦点，不同时移动节点。
鼠标拖拽操作提供菜单 / 按钮替代，如创建引用、排序、连接、定位和分组。媒体播放有文字按钮、静音与暂停；全局快捷键不能触发付费，候选选定快捷键仍受业务确认门禁。

## 9. 当前公共能力与完整目标边界

2026-10-01 依据实际 Go HTTP Handler 注解核对当前公开业务契约，共 12 个操作；此处记录源码合同，不声称服务在运行或端到端通过。

| 当前公开操作                                                                        | 可直接支持的重建范围                                                                      |
| ----------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------- |
| `GET/POST /api/projects`、`GET /api/style-presets`                                  | 项目列表、搜索 / 分页与新建所支持字段；名称、画幅、风格按真实 DTO 呈现                    |
| `GET/POST /api/projects/{pid}/canvases`                                             | 同项目画布列表与创建                                                                      |
| `GET/PATCH/DELETE /api/canvases/{id}`                                               | 读取正式文档、画布更名 / 软删除，遵守 revision 与只读合同                                 |
| `POST /api/canvases/{id}/commands`                                                  | 现有 text/image/video/audio/group 资源节点及布局 / 注释命令；不据此声称业务生成节点可运行 |

剧本、设定集、镜头、报价、批量、正式选定、成本、任务、通知、影响清单与 Agent 的完整 UI 是目标设计；内部 Go 类型 / 测试存在不等于已有公开可用入口。真实 Codex 图片、Seedream / Seedance 与 OpenRouter 生成和费用仍待专项验证。
原型可用明确标记的合成数据展示目标状态；生产入口只在端口、权限、价格、审核与恢复合同就绪时启用，否则说明“当前能力尚未接通”和实际可执行下一步，不显示虚假任务或费用。

## 10. 评审与验收场景

以下是设计验收场景，用于选择视觉并检查完整体验；不是实施任务拆分，也不是已完成的测试结果。

1. 首次进入不登录，从首页选择表单或画布，新建项目后始终看到明确项目归属；无内容状态能引导导入而非停在空仪表盘。
2. 导入多集剧本，校对分集与解析、定位原文，复用已锁定设定，为一集准备镜头与台词，确认 MVP 终点不包含成片时间线。
3. 在镜头表定位某镜到画布，调整同一参考组合，再返回表单；刷新保留对象 / 视图，另一侧更新，无第二份业务状态。
4. 同一镜用图生视频与全能参考分别准备输入，超限 / 缺失引用准确阻断；四入口报价一致，过期与预算不足不能误确认。
5. 并排审阅多图、多视频和多句音频，明确选择一个正式版本；改选显示真实影响，迟到候选不覆盖人工决定。
6. Agent 提议修改一场镜头与批量生成；先查看并应用差异，再审阅费用并明确确认；拒绝提案不改变业务事实。
7. 供应商超时、浏览器断线、Worker 重启、媒体失败与取消依次呈现正确状态；unknown 不自动重发，账本无虚构零费用。
8. 上传视频成功但节点保存失败，恢复节点保存且不重传；授权过期、跨项目引用、需真人授权与只读项目都有可执行说明。
9. 上游造型改版后只重做勾选镜头，旧结果和费用可查；成功 / 失败 / 未知批次分别处理，支持第 2 集复用。
10. 1440/1280 桌面、平板 / 手机审阅与明暗主题覆盖核心状态；键盘完成导航、表单、候选、画布菜单与焦点恢复，无误触付费。
11. 固定 BeefTV 核心承载 500 / 2,000 节点与真实媒体，记录机器、浏览器、视口、真实运动 FPS / 内存 / 播放数；历史或空闲录制不替代新验收。
