# Design 12：画布

执行编号：12；原始需求模块：16。依据[原始需求](../requirement/16-画布需求.md)、[PRD](../prd/12-画布.md)与[Plan](../plan/12-画布.md)。本文件把原始需要转换成项目方案，**全部新增设计选择仍待评审**；数据对象和接口为拟议合同，不表示已有表或已实现API。共同约束见[整体设计](00-项目需求设计.md)。原始FR、质量条件与AC仍须同时满足。

## 结构编辑与业务内容边界

画布模块拥有文档结构、节点位置/尺寸/容器、类型化引用、文本/生成草稿和用户明确选择。生成模块拥有任务/冻结输入/候选；素材拥有原件/权限；镜头和设定仍是业务内容事实来源，画布不复制整份业务历史。

| 对象              | 设计内容与不变量                                                                                      |
| ----------------- | ----------------------------------------------------------------------------------------------------- |
| CanvasDocument    | id/project_id、document_revision、节点/边结构版本；任何业务对象均属同授权项目                         |
| CanvasNode        | 稳定id/type、position/size/container_id；结构版本不作为生成结果标识                                   |
| NodeDraft         | node_id、input_revision、规范草稿内容、发布模型引用；修改只产生新输入版本；被任务引用的旧输入保持可查 |
| NodeSelection     | node_id、selection_revision、candidate_id/media_id/version、明确采用者/时间                           |
| InputEdge         | edge_id、源/目标节点与端口、输入用途、candidate/media版本、source_selection_revision、edge_revision   |
| BusinessReference | 类型、目标ID/明确版本/用途；不内嵌镜头全部历史或媒体字节                                              |

Task/Candidate摘要是只读查询投影，客户端保存不得改task.state、media.ready或注入候选。引用都要经过所属模块解析和授权，不接受任意URL充当media_id。首轮image-generation/video-generation节点及first_frame边的精确约束见[Demo设计](06-画布生图生视频Demo.md)。

## 保存与版本冲突

拟议GET /projects/{id}/canvases/{canvas_id}读结构/草稿；PUT同资源提交expected_document_revision和可编辑字段；PUT /canvases/{id}/nodes/{node_id}/selection明确采用候选；POST /canvases/{id}/input-edges保存绑定、PATCH指定边更新输入。

首轮建议文档整体CAS保存，验证结构、节点ID唯一、端点/容器存在、不非法嵌套、数字/坐标有限及授权引用后一次提交。请求具save_key，本轮建议作用域用户＋画布；同键同内容返回原保存回执，异内容冲突，保存操作记录保留策略与文档历史一起确认。已接收的save_key先查原回执，解决成功但响应丢失后的重复保存。更新NodeDraft时才推进input_revision，单纯移动不改变生成输入。

前端串行提交本画布保存队列，保留本地edit_sequence；旧回执不能把后来的编辑标成已保存。冲突保留本地草稿并展示当前服务端版本，用户选择重载或比较后重新提交，首轮不自动合并。取消浏览器请求不等于服务端未保存，恢复先查save_key/服务端版本。

选择候选和绑定边使用独立命令、明确expected_selection/edge_revision；与文档保存采用共同条件事务/锁次序防互相覆盖。完整文档PUT不能覆盖Selection或已有边的服务端绑定事实；结构编辑若改变绑定须走命令。边创建/更换输入需同时生成目标节点的新input_revision并保存对应edge_revision，提交校验两者；源Selection改变只标来源变化，不改旧边。任务与候选追加不会推进布局revision，避免背景回执让拖动保存无故冲突。

## 视口、生命周期和后续能力

建议首轮viewport只在当前会话保存；刷新按节点范围fit。zoom/fit/pan不改position或输入版本。选中、hover、播放不持久化。可见媒体按需查询，进入播放再载重媒体；切项目/卸载取消订阅/请求、停止播放，按当前user/project/canvas防晚到更新。

首轮建议不提供节点删除、撤销/重做；完整需求须明确结构移除、仍运行任务的归属、历史引用保留、撤销跨度和是否取消外部执行，不能删节点顺便清原件或退款。拖动建议增加键盘移动及位置输入作为等价操作；焦点/读屏/保存提示分别验证。

后续业务节点只保存BusinessReference，编辑回所属业务入口；@引用在输入草稿中保留实体/用途/版本，提交冻结。一次Agent构图建议可返回有来源的布局/构图差异候选，用户显式采用后条件保存，不自动执行其他收费任务；输出形状、模型/费用尚未定，暂不实施。导出需先确定结构/图片/媒体范围、格式、缺媒体处理、授权和规模，再冻结导出范围，不提供假按钮。待处理直接读取授权项目的任务/失效投影，与[分析](13-分析.md)共享口径，不造通知表。

### 保存、选择与边版本的真实关系

节点head复合FK引用同节点input_revision/selection_revision；input.first_frame引用同目标的edge版本，edge版本引用同画布的源节点及其不可变Selection。候选/media从Selection不可变行读，关系链不会因源节点current_selection改变而变化。Task/Refs再冻结对应Media/边/Selection及摘要，数据库与供应商安全输入摘要可相互核对。

布局PUT只接nodes布局/文本/生成draft，不接受Selection、候选、Task状态、媒体就绪或输入边。存在节点未在请求中出现时，首轮返回422 deletion_not_supported，不用全量PUT隐式删节点。新增节点ID可客户端生成UUID，服务端只接受未占用ID并校验授权画布；所有节点ID在画布内唯一，不能借已有ID改他人节点。

一次保存先收集涉及模型/媒体ID，按全局锁次序锁Actor/Project、发布Model、Canvas及节点，随后锁媒体授权：查command_receipts(save_key)→核expected_document_revision→校验可编辑字段→写布局→内容变化才插新input_revision并更新node head→推进Canvas.revision/回执/audit。回执保留result_revision及安全结果，旧请求成功回放不能再次推进revision。

选图命令同时核expected_document_revision及expected_selection_revision（未选为HTTP "0"）、candidate归属/ready/审核并追加Selection、改node head、推进Canvas.revision/audit；**不改旧EdgeVersion，也不调用生成**。新增/换边命令必须同时校验expected_document_revision、expected_target_input_revision、expected_source_selection_revision及expected_edge_revision（新边为"0"）。同事务插EdgeVersion、复制新目标InputVersion/edge引用、更新heads和Canvas.revision/回执/audit。旧版本保持，选择/边命令与布局CAS不能互相覆盖。

### 字段级边界与后续功能

SQL CHECK坐标可使用x/y介于负Infinity与正Infinity的有限范围条件，应用同时拒绝NaN/Infinity；尺寸>0，具体坐标/节点上限是待接受容量参数，不随意写死。params按所选发布版本schema验证，未选模型的草稿可存，生成预检仍拒绝不完整输入。

文本/业务引用节点后续采用同node/input版本框架，业务引用增加明确类型/ID/版本关系列；Agent建议/导出缺政策时不注册成功接口。对应FR保留，具体后续合同见前文及待决定项，不能先创建空扩展表。候选与Task摘要在读时关联，不允许浏览器保存它们的只读字段。
