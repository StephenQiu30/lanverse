# 需求实现追踪

## 1. 状态与规则

本矩阵仅证明 MVP Requirement 已有设计落点和可执行验证入口，不证明实现完成。当前 Requirement 为 `review`，Design、PRD 与 Plan 为顺序待审草案；它们逐级转为 `accepted` 并通过 `implementation_start` 前，不得开始实现。

统一追踪链为：

```text
Requirement 条款
  → ADR/ARCH 章节 + Design AC
  → PRODUCT-01 User Story / AC-PRD
  → PLAN-01 Task / Test ID / Evidence ID
  → implementation path / commit
  → ACCEPTANCE-01 result / evidence / residual risk
```

本矩阵的追踪全集仅由 frontmatter `inputs` 所列活动 Requirement 与 Design 构成；新增或变更范围必须先更新 Requirement，再按 Design→PRD→Plan 顺序重新接受。
