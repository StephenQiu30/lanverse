本文把 [REQ-22](../requirement/22-多候选与选定.md) 拆解为实现设计。需求目标、业务规则（文中 R1、R2… 指 REQ-22 §2 的规则）与验收标准以 REQ-22 为准；表结构以 [DES-02](02-领域与数据模型.md)、接口签名以 [DES-03](03-接口设计.md)、工作流与生成操作以 [DES-04](04-工作流与生成操作.md) 为准，本文说明该功能用到哪些部分、如何组合。设计发现需求问题时先改需求（[文档规则](../README.md#文档规则) 2）。

## 1. 设计清单

| 类别 | 内容 |
| --- | --- |
| 数据表 | `media.rendition`、`operation.operation_output`、`storyboard.shot`、`storyboard.shot_selection_log` |
| 接口 | `GET /api/shots/{id}/candidates`<br>`POST /api/shots/{id}:select-take` |
| 工作流与任务 | 无 |
| 领域事件 | `storyboard.selection_changed.v1` |
| 测试用例 | TC-22-xx（[TST-02](../test/02-需求追踪矩阵.md)） |

## 2. 数据

| 表 | 关键字段 | 为什么需要 |
| --- | --- | --- |
| `operation.operation_output` | `media_asset_id`、`moderation_status`、`seq_no` | 候选 |
| `storyboard.shot` | `selected_frame_output_id`、`selected_take_output_id`、`revision` | 当前选定 |
| `storyboard.shot_selection_log` | `slot`、`output_id`、`shot_version_no`、`create_by` | 选定历史 |
| `media.rendition` | `poster`、`proxy_720p` | 对比播放 |

## 3. 接口

```http
GET /api/shots/{id}/candidates?slot=take
200 { "items": [ { "output_id": "…", "operation_id": "…", "based_on_version_no": 3, "current_version_no": 5,
                   "poster_url": "…", "proxy_url": "…", "duration_ms": 5040, "moderation_status": "passed",
                   "model_key": "…", "create_time": "…", "selected": false } ] }

POST /api/shots/{id}:select-take   { "output_id": "…", "expected_revision": 6 }
200 { "revision": 7, "stale": { "shots": 1 } }          // 引用本片段作为参考的后续镜头（DES-41）
409 revision_conflict     422 input_not_ready（审核未通过）
```

槽位与台词音频的选定接口分别见 [DES-18](18-参考定稿与跨集复用.md)、[DES-32](32-台词配音.md)。

## 4. 异步与工作流

无；选定为同步命令。

## 5. 事件与实时

`storyboard.selection_changed.v1` → lineage、realtime、audit。

## 6. 界面

`CandidateCompare` 组件：2–4 列网格；视频同步播放、逐帧（`← →`）、静音切换；数字键 1–9 聚焦，`S` 选定（REQ-05 §7）；“已选定”角标；改选确认框（影响数量）。

## 7. 权限与审计

制作者；审计 `shot.frame_selected`、`shot.take_selected`（前后 output）。

## 8. 非功能要求

对比播放：4 个 720p 代理同时播放不卡顿（代理码率 ≤ 2 Mbps）。

## 9. 测试设计

选定命令并发；改选下游过期；前端同步播放。
