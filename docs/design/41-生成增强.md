## 2. 数据

`storyboard.reference_item` 已预留 `operation_output` 与 `first_frame` / `last_frame`（DES-02 §5.6）；`storyboard.shot_version.generation_mode` 增加 `frames2video`（CHECK 迁移）；新增 `operation_input` 的 `mask_asset_id`（改图蒙版，DES-02 同步）。

## 3. 接口

`POST /api/shots/{id}/frames:extract-from-take`（`{ "take_output_id": "…", "position": "last" }` → 图片候选，免费）；报价项支持 `mode = frames2video`、`capability = image.edit`（`params.mask_asset_id`、`params.instruction`）；`GET /api/shots/{id}/candidates?model_key=`。

## 4. 异步与工作流

抽帧 `media.ExtractFrame`；其余复用 OperationWorkflow。

## 5. 界面

参考选择器新增“前一镜片段”；首尾帧槽位；关键帧编辑器（画笔蒙版 + 描述）；候选对比按模型筛选。

## 6. 权限与审计

同 REQ-21、REQ-22。

## 7. 测试设计

抽帧精度；新模式在注册表与适配器中的映射；过期传播扩展。
