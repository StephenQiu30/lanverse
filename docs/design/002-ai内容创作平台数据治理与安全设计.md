# AI 内容创作平台数据治理与安全设计

## 1. 适用范围

平台同时处理两类数据，必须分别治理：

1. 从第三方来源采集的提示词模板、参数和示例文件。
2. 用户主动输入的提示词、生成任务和生成作品。

第三方模板只有获得自动访问、保存和公开展示依据后才能发布。用户创作默认私有，不自动公开、不进入模板库、不用于训练。

## 2. 来源准入

每个内容来源维护以下记录：

| 字段 | 说明 |
| --- | --- |
| `access_method` | 官方 API、公开数据集、允许的网页抓取或书面授权 |
| `terms_url` / `robots_url` | 评审依据 |
| `allowed_actions` | 访问、保存、公开展示、复制和商业使用的独立结论 |
| `rate_limit` | 请求频率、并发和重试要求 |
| `reviewed_at` / `expires_at` | 评审与复审时间 |
| `status` | `pending | active | paused | denied` |

管理员明确激活后 Scheduler 才能创建网络任务。页面公开可访问不代表允许自动采集；条款变化、401/403、连续失败或投诉可立即暂停来源。

每条模板保留来源、原始链接、来源对象 ID、采集版本、时间、许可和内容哈希。需要署名时展示作者；没有保存依据时不采集作者账号信息。

## 3. 生成供应商边界

MVP 选择火山方舟北京区域的 Seedream 5.0 Lite。启用真实调用前必须确认：

- API 是否允许本平台的用户生成与商业用途。
- 输入、输出和日志的保存期限及训练用途。
- 内容政策、地域限制、并发、价格和删除能力。
- 供应商故障、超时、重复请求和退款/额度补偿方式。

只向供应商发送生成所需的 prompt、参数和输入图片，不发送用户邮箱、会话、内部模板权利记录或 MinIO 凭证。供应商响应和 webhook 均视为不可信输入。

## 4. 数据生命周期

第三方模板：

```text
fetched → normalized → rights/safety checked → published
                      ↘ quarantined | rejected
published → suppressed → deleted
```

用户生成：

```text
draft → input moderated → queued → provider running
→ output validated/moderated → private work | rejected/failed
private work → user deleted → deleted
```

生成任务失败不删除必要的计费和故障审计，但 prompt 与文件按用户删除和保存期规则清除。供应商返回成功但平台超时时进入 reconcile，确认结果前不重复调用生成接口。

## 5. MinIO 数据分区

| Bucket | 用途 | 访问边界 |
| --- | --- | --- |
| `source-ingest` | 第三方临时采集文件，TTL 24 小时 | 采集/媒体 Worker |
| `source-original` | 获准保存的来源原文件 | 受控后台与媒体 Worker |
| `source-display` | 去元数据后的公开示例文件 | API 短时只读签名 |
| `generated-original` | 用户生成原始结果 | 本人、生成/媒体 Worker |
| `generated-display` | 用户作品展示衍生文件 | 本人短时签名；公开分享另行授权 |

第三方示例与用户作品不跨 bucket 去重。数据库只保存 bucket、key、hash 和状态，不保存 S3 URL；Web 不持有 MinIO 密钥。

## 6. 用户数据与权限

- 公开目录不要求登录；生成和作品页必须登录。
- 用户只能读取自己的 draft、job、prompt 和作品。
- 管理员默认不能查看用户原始 prompt 或作品；安全审核使用最小化、带审计的专用权限。
- 密码使用 Argon2id；会话使用 HttpOnly、Secure、SameSite cookie，写请求校验 CSRF。
- 用户删除作品时立即隐藏，在线对象、衍生文件和可删除供应商副本在 24 小时内清除。

## 7. 输入与输出安全

- 输入 prompt 作为纯文本处理，不执行 HTML、Markdown、URL 或其中的指令。
- 生成前执行成人、违法、未成年人和明显滥用检查；失败或低置信时不投递供应商。
- 供应商结果下载只允许预期域名、HTTPS 和受限重定向，并执行 SSRF 检查。
- 输出图片必须通过格式、尺寸、解码和内容审核后才能进入用户作品。
- MVP 只接受 JPEG、PNG 和静态 WebP；单文件 ≤20 MiB，总像素 ≤40 MP。
- 展示衍生图移除 EXIF、XMP 和 GPS 后重新编码；SVG、PDF、动画和无法解码文件拒绝。

## 8. 采集安全

- SourceConnector 只访问配置中的 HTTPS 域名，不接受用户提供的任意 URL。
- 每次重定向重新校验目标，禁止内网、loopback、link-local 和云 metadata 地址。
- 请求设置连接、总时长和响应大小上限，遵守来源限速与 `Retry-After`。
- RabbitMQ 消息只携带业务 ID、事件版本和 `trace_id`，不携带 prompt、媒体或凭证。

## 9. 发布、分享与下架

模板公开必须满足：

```text
source active + public display allowed + moderation passed + not suppressed
```

用户作品默认 `private`。MVP 不提供公开分享；后续开放分享时必须增加用户明确授权、举报、撤回和公开内容审核，不复用第三方模板的展示授权。

第三方投诉或许可撤销先下架模板，使公共页面 5 分钟内不可见，再在 24 小时内删除在线文件和索引。用户删除采用相同在线 SLA。删除失败持续重试并保存 receipt；备份恢复先应用 suppression/deletion ledger。

## 10. 模块边界与审计

`governance` 只产出准入、审核和下架决定，不直接修改 catalog、asset、search 或 generation 表。各模块通过 `DESIGN-004` 定义的 Port 和版本化事件执行具体动作。

来源管理、审核、任务补偿和删除必须记录操作者、对象、原因、时间和 `trace_id`。密钥通过 secret 注入，不写入仓库、日志、数据库业务字段或 RabbitMQ。

## 11. 接受门禁

1. 模板来源具备可复核的访问、保存和公开展示依据。
2. 生成供应商的数据用途、保存、价格、区域和删除能力已评审。
3. 未发布模板、其他用户作品、失败审核内容和已下架内容均不可越权查询。
4. 重复采集或重复消息不产生重复文件；重复生成不造成重复扣费。
5. SSRF、恶意文件、输入/输出审核和删除 SLA 有可执行测试。
6. 运营法域、内容安全负责人和投诉处理责任人已确认。

Design 已接受中国大陆运营、成人内容完全拒绝和用户作品默认私有。第 1、2、5、6 项仍是外部来源或真实供应商的运行激活门禁，不阻塞 PRD/Plan，但未满足时系统只能使用 fixture/fake provider。
