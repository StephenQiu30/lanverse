# Design 02：项目

执行编号：02；原始需求模块：07。依据[原始需求](../requirement/07-项目需求.md)、[PRD](../prd/02-项目.md)与[Plan](../plan/02-项目.md)。本文件把原始需要转换成项目方案，**全部新增设计选择仍待评审**；数据对象和接口为拟议合同，不表示已有表或已实现API。共同约束见[整体设计](00-项目需求设计.md)。原始FR、质量条件与AC仍须同时满足。

## 项目是权限与创作上下文

项目模块拥有Project身份、归属、基本参数及复制操作；所有创作对象引用project_id。首轮空白项目直接创建画布，不要求剧本、镜头或设定。带剧本创建先提交Project，再请求剧本导入，解析失败不回滚已创建项目。

建议Project包含id、owner_id、name、ratio、style_key、revision、created_at、updated_at；name≤50，画幅只接受9:16、16:9、1:1。风格枚举的“四种/五种”冲突尚未确认，不从页面常量推定。CopyOperation保存源项目/源版本、复制范围、request_key、结果项目与实际状态。

拟议HTTP：POST /projects、GET /projects、GET /projects/{id}、POST /projects/{id}/copies、GET /project-copies/{id}。操作者来自会话，创建不能替别人写owner。列表统一筛选和排序后给网格/列表摘要；正文、脚本、镜头与全媒体不随列表返回。

## 创建、打开和复制的事务

空白创建建议同事务保存Project及初始Canvas身份，返回真实project_id/canvas_id。创建request_key建议按用户＋操作范围唯一，保留到操作记录删除；同输入返回原项目，异输入冲突，丢回执可查回。初始Canvas布局归画布模块负责，不由项目模块复制草稿规则。

打开前后每个入口都校验同一项目授权；切换项目取消旧请求，晚到响应不能写新页面。未知或越权ID返回安全失败，不回落到样例项目。查询顺序建议updated_at降序＋id稳定排序；“最近打开”需要独立访问事实，当前不能冒充updated_at。

复制建议首轮后以明确范围快照执行：新项目及独立可编辑内容使用新ID，跨对象引用必须重映射；媒体原件可授权引用，计量与回收按素材设计。历史任务/费用事实建议不复制成新执行事实。操作持久记检查点，同键恢复不能多建副本；先构建不可见副本，全部引用校验成功后一次发布，失败保留可诊断操作，不展示半成品为完成。

### 复制和创建的提交顺序

Project与初始Canvas在共享事务内创建，真实身份在commit后返回。选择剧本的原件在提交前校验，导入操作失败仍保留项目，ProjectView返回安全import_operation状态。

复制事务先固定scope/源revision并分配building副本ID；Worker按checkpoint重映射episodes/settings/shots/canvas的ID，媒体仅建已授权引用。最后校验完整关系，将目标改active并标Copy成功/audit同事务。旧执行Task/CostFact不作为副本新运行记录，history选项未确认不能使用。故障恢复从旧copy_id/checkpoint继续，不能再建另一个target_project_id。

### 当前复制范围与约束兼容

本轮建议先只复制已接受的可编辑内容/参数布局，selected_results=false、history=false；尚未接受更广范围时接口明确422，不宣称完整复制已通过。复制生成节点重新建立input身份，清Task/Selection及依赖未复制候选的first_frame绑定，并明确待重新选图；不能将源项目Candidate/Selection塞进新项目绕过同项目复合FK。
设定/镜头内容按新ID映射，媒体引用先建立目标Grant；复制参考保留原件与安全来源，不伪造新生成/新锁定/新声音声明。造型锁定和声音来源声明需要依复制政策重新明确；选定结果/历史如何独立复用必须先接受扩展来源合同，不能制造新Task、费用或跨项目孤立外键。
