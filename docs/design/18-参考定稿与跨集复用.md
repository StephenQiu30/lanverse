## 2. 数据

| 表 | 关键字段 | 为什么需要 |
| --- | --- | --- |
| `bible.reference_slot` | `owner_type`、`owner_id`、`kind`、`current_version_id`、`revision` | 槽位与当前锁定 |
| `bible.reference_version` | `version_no`、`media_asset_id`、`source_output_id`、`create_by` | 锁定历史、依赖上游版本 |
| `bible.episode_asset_usage` | 本集用到的条目 | 定稿清单 |
| `operation.operation` | `target_type = reference_slot` | 候选生成 |
| `lineage.dependency` | 镜头版本 → `reference_version`（`upstream_key = reference_slot_id`） | 过期传播 |

## 3. 接口

```http
GET /api/episodes/{eid}/asset-readiness
200 { "ready": false, "items": [ { "owner_type": "look", "owner_id": "…", "name": "李明 / 日常装",
        "slots": [ { "slot_id": "…", "kind": "portrait", "required": true, "locked_version_no": 1, "candidates": 0, "inflight": 0 },
                   { "slot_id": "…", "kind": "turnaround", "required": false, "locked_version_no": null, "candidates": 4, "inflight": 0 } ] } ] }

GET /api/reference-slots/{sid}
200 { "slot_id": "…", "kind": "portrait", "revision": 3,
      "current": { "version_no": 1, "media_asset_id": "…", "thumb_url": "…", "locked_by": "…", "create_time": "…" },
      "versions": [ … ], "candidates": [ { "output_id": "…", "operation_id": "…", "thumb_url": "…", "moderation_status": "passed" } ] }

GET /api/reference-slots/{sid}/impact
200 { "shots": 20, "episodes": [1,2], "shot_ids": [ … ] }

POST /api/reference-slots/{sid}:lock
{ "output_id": "…", "expected_revision": 3 }          // 或 { "media_asset_id": "…" }
200 { "version_no": 2, "revision": 4, "stale_shots": 20 }
422 input_not_ready（未审核通过 / 缺授权声明）
```

生成候选：`POST /api/projects/{pid}/quotes`，`target_type = reference_slot`、`capability = image.generate`。

## 4. 异步与工作流

候选生成使用通用 OperationWorkflow（DES-04）。锁定为同步命令；事务内写 `reference_version`、更新槽位、写 Outbox `bible.reference_locked.v1`。

## 5. 事件与实时

`bible.reference_locked.v1` → lineage（过期传播）、realtime、audit；SSE `reference_slot.locked`、`stale.changed`。

## 6. 界面

资产定稿页：按角色 / 场景 / 道具分组的卡片，每卡显示槽位锁定状态；批量“为未锁定槽位生成”；槽位详情：候选网格（REQ-22 组件）、锁定按钮、版本历史、改锁影响确认框。

## 7. 权限与审计

制作者。审计：`reference.locked`（含前后版本）。

## 8. 非功能要求

AIQ-04（一致性抽检）；PERF-09（候选可见 ≤ 30 秒）。

## 9. 测试设计

锁定并发冲突；改锁过期传播覆盖（参考组合、关键帧、视频）；本集清单计算。
