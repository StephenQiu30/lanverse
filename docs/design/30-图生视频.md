## 2. 数据

`operation.operation`（`target_type = shot_take`、`mode = image2video`）；`operation_input`（`first_frame` → 关键帧 `operation_output` 与 `media_asset`，`prompt`）；`media_asset.duration_ms`；`lineage.dependency`（片段 → 关键帧选定、镜头版本）。

## 3. 接口

```http
POST /api/projects/{pid}/quotes
{ "items": [ { "target_type": "shot_take", "target_id": "<shot_id>", "capability": "video.generate", "mode": "image2video", "output_count": 2 } ] }
→ 422 precondition_missing { "message": "请先选定关键帧" } | input_limit_exceeded { "errors": [{ "field": "duration_ms", "message": "超出模型范围 4–10 秒" }] }
GET /api/shots/{id}/prompt-preview?capability=video.generate   → 组装后的提示词（不计费规则拼接；AI 改写需报价）
```

## 4. 异步与工作流

OperationWorkflow（异步视频）：提交 → 轮询（退避 5 s → 30 s）→ 接管（下载、ffprobe、转码、缩略图、代理）→ 审核 → 完成。`compose_prompt` 为规则模板拼接（免费）；可选“AI 优化提示词”走 `llm.run_skill(compose_prompt)`（付费确认）。

## 5. 事件与实时

同 REQ-21、REQ-22。

## 6. 界面

镜头详情“视频”标签页：前置状态提示、提示词预览与改写、时长提示、生成、候选对比。

## 7. 权限与审计
