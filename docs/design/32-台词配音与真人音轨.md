## 2. 数据

| 表 | 关键字段 | 为什么需要 |
| --- | --- | --- |
| `audio.dialogue_audio` | `episode_id`、`line_key`、`line_content_hash`、`source`、`media_asset_id`、`operation_output_id`、`voice_profile_revision`、`speed`、`emotion`、`duration_ms` | 候选与过期判断 |
| `audio.line_audio_selection` | `(episode_id, line_key)` 唯一、`dialogue_audio_id`、`subtitle_text`、`revision` | 当前选定 |
| `operation.operation` | `target_type = dialogue_audio`、`capability = audio.tts` | 生成 |

新增 `audio.line_tts_override`（`episode_id`、`line_key`、`pronunciation_text`、`speed`、`emotion`）保存逐句覆盖参数（DES-02 同步）。

## 3. 接口

```http
GET /api/episodes/{eid}/dialogue?scene_key=
200 { "items": [ { "line_key": "…", "speaker": { "character_id": "…", "name": "李明" }, "content": "你怎么来了？",
                   "voice": { "voice_id": "…", "name": "青年男声·沉稳" }, "override": { "speed": 1.1, "emotion": "surprised" },
                   "selected": { "dialogue_audio_id": "…", "source": "tts", "duration_ms": 1830, "url": "…" },
                   "candidates": 2, "state": { "stale": false }, "revision": 3 } ] }

PUT  /api/episodes/{eid}/dialogue/{line_key}/override   { "speed": 1.1, "emotion": "surprised", "pronunciation_text": null }
POST /api/projects/{pid}/quotes  { "items": [ { "target_type": "dialogue_audio", "target_id": "<episode_id>:<line_key>", "capability": "audio.tts" } ] }
POST /api/episodes/{eid}/dialogue/{line_key}:select-audio   { "dialogue_audio_id": "…", "expected_revision": 3 }
```

`target_id` 使用组合键字符串 `<episode_id>:<line_key>`；DES-02 的 `operation.target_id` 为 uuid，因此增加 `target_key text` 列存放组合键（DES-02 同步）。

## 4. 异步与工作流

TTS：`OperationWorkflow`（同步型）。

## 5. 事件与实时

`audio.selection_changed.v1` → realtime（SSE 刷新台词表）；V2 剪辑上线后由 lineage 消费以标记时间线过期。

## 6. 界面

按场分组的台词表：说话人、文本、音色、语速 / 情绪、候选播放、选定；批量工具栏（批量报价 TTS、批量选定最新候选）。

## 7. 权限与审计

制作者；审计 `dialogue_audio.selected`。

## 8. 非功能要求

PERF-04（台词表 ≥ 150 行流畅）；CAP-01（全剧约 1.5 万句）。

## 9. 测试设计

过期规则（文本、音色）；逐句覆盖参数进入 `input_hash`；组合键 `target_key` 解析。

## 10. 待确认

无。
