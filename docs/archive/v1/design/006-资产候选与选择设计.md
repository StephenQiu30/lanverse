# DES-006 资产候选与选择设计

- 状态：proposed
- 版本：v1.0
- 日期：2026-08-14
- 关联需求：CUR-AST-FR-001～011、CUR-AST-NFR-001～011
- 关联验收：AC-CUR-AST-001～016
- 上游：[CUR-AST](../requirement/005-角色场景与道具资产需求.md)、[DES-005](./005-剧本与叙事版本设计.md)

## 1. 问题、范围与非目标

Assets 模块必须稳定管理角色、场景和道具身份及其剧情状态，支持从剧本候选建立或关联资产、形成不可变规格/参考图候选，并显式选择当前参考版本。名称相同、图片最新或 AI 相似度都不能自动合并身份或成为 current。

范围：Asset/AssetState、类型化 AssetVersion、Occurrence、剧本候选决议、图片上传/生成 Candidate、星标/拒绝/current、分用途 readiness、影响预览、归档恢复。

非目标：服装独立模块、跨 Project 资产库、图片精修、Shot 顺序、视频生成/主选、AI 自动淘汰、商业图库。

## 2. 事实所有者与模型

| 实体 | 含义 | 版本策略 |
| --- | --- | --- |
| Asset | Project 内 Character/Location/Prop 稳定身份、别名、状态 | revision；名称可变 |
| AssetState | 剧情阶段状态、出现证据、enabled/disabled | 稳定 ID + revision |
| AssetVersion | 类型化规格、固定参考输入、来源 | 不可变；current 指针分离 |
| AssetOccurrence | AssetState 与 Episode/NarrativeUnitVersion 的出现证据 | 固定版本边 |
| AssetImageCandidate | 上传/生成的不可变图片候选 | 固定 MediaVersion/InputSnapshot |
| AssetCandidateDecision | 对剧本 ExtractionCandidate 的创建/关联/合并/忽略 | 追加式 |
| AssetSelectionDecision | starred/rejected/select/replace/clear | 追加式 |
| AssetReadiness | 固定版本+用途的 ready/blocked/unavailable | 可重建投影 |
| AssetImpact | 高影响命令前固定输入和引用摘要 | 有效期/摘要变化即失效 |

图片媒体、WorkTask/Attempt 和 Cost 由 Platform 拥有；Rights/Content/Audit 决定由 Governance 拥有；Assets 保存类型化业务引用和选择语义。

## 3. 类型化规格与不变式

- Character：外观、年龄印象、气质/性格；至少 portrait 用途；基础状态可自动创建。
- Location：空间描述、时间/天气、视觉元素、光照；environment 用途。
- Prop：外观、材质、使用语境；object 用途。

不变式：

1. Asset、AssetState、AssetVersion 使用稳定 ID，显示名称不作外键。
2. 已发布 AssetVersion 不原地修改；编辑产生新版本。
3. 同一 AssetState + reference purpose 同时最多一个 current，可有多个 starred。
4. starred 不等于 current，rejected 不等于删除。
5. current 切换不修改既有 ShotSpecVersion、KeyframeCandidate 或历史包。
6. 下游正式引用固定 Asset、State、Version 三元组。
7. readiness 由用途和固定依赖计算，用户不能手工标 ready。
8. AI 相似度只作提示，不能自动合并身份、选择 current 或拒绝 Candidate。

## 4. 同步命令与查询

| 能力 | 输入 | 原子结果 |
| --- | --- | --- |
| Create/RenameAsset | Project、类型、身份字段、expected revision | Asset/冲突/可能重复提示 |
| DecideExtractionCandidate | Script Candidate、决定、目标 Asset/规格、幂等键 | Decision + 稳定引用；不重复身份 |
| Create/UpdateAssetState | Asset、剧情语义、Occurrence、expected revision | State revision + 影响 |
| PublishAssetVersion | 类型化规格、来源、固定媒体/输入 | 新不可变 Version |
| SwitchCurrentVersion | State、目标 Version、expected current、影响确认 | current 切换 + event 或冲突 |
| Mark/SelectImageCandidate | Candidate、purpose、expected selection | 追加 Decision + 唯一 current |
| GetReadiness | Version、purpose、目标 Shot 上下文 | ready/blocked/unavailable + 原因/next action |
| PreviewImpact | 目标变更、引用 revision | 固定 Impact 摘要/有效期 |
| UpgradeShotReferences | Impact ID、明确 Shot 集合、expected versions | 委托 Storyboards 原子命令或零执行 |
| Archive/Restore/Delete | 目标、expected state、影响确认 | 新状态或完整阻塞 |

高影响操作执行时重新验证 Impact 的引用摘要；任一引用变化则零写入，不能沿用旧确认。

## 5. 异步工作流与事件

图片生成：Capability preflight → 固定 AssetVersion/用途/InputSnapshot → WorkTask → Provider → Media stored/probed/ready → 登记 Candidate。生成成功不自动主选。

上传：隔离上传 → 实际类型/安全解码/hash/像素探测 → Media ready → Candidate；重复字节可提示既有 Candidate，但不能跨 Workspace 去重泄露。

事件：`AssetCreatedOrRenamed`、`AssetStateCreatedOrChanged`、`AssetVersionPublished`、`CurrentAssetVersionChanged`、`AssetImageCandidateAvailable`、`AssetSelectionChanged`、`AssetArchivedOrRestored`。

事件只含稳定 ID、版本、purpose、decision 类型和输入摘要；不含图片 URL、完整 Prompt 或权利证明正文。

## 6. 状态与失败恢复

```text
Asset: active ↔ archived；active → deleted（仅空白草稿）
AssetState: enabled ↔ disabled
Candidate media: validating → valid | blocked | unavailable
Selection: missing → selected → needs_reconfirmation → selected
Readiness: incomplete | ready | stale | blocked | unavailable
```

| 失败 | 行为 | 恢复 |
| --- | --- | --- |
| 重复剧本候选接受 | 不创建第二 Asset | 回读首次 Decision/目标 |
| 上传中断/解码失败 | 无 valid Candidate | 续传/重传，不影响历史 |
| 图片任务 unknown | 不显示成功/失败 | DES-012 对账，禁止盲重试 |
| current 并发冲突 | 旧 current 保持 | 返回最新选择后比较 |
| Impact 过期 | 高影响命令零写入 | 刷新预览 |
| readiness 依赖失败 | unavailable | 阻止新生成，保留语义编辑 |
| 批量升级部分冲突 | 整个选定升级命令不执行 | 调整范围/版本重试 |
| 媒体后续不可用 | 历史可审计，当前用途 blocked | 替换或恢复媒体，不删旧 Candidate |

## 7. 权限、安全与权利

- owner/editor 创建、生成、上传、标记、选择和归档；viewer 只读。
- 上传必须填写来源/权利说明；生成、选择用于下游和导出时按 DES-013 重新检查治理决定，并由 DES-012 执行 Capability/媒体预检。
- 接受 PNG/JPEG/静态 WebP 的 proposed 边界必须以实际内容识别；SVG、动画、压缩包和可执行内容拒绝。
- 原图 private；预览和下载使用短期授权；完整 Prompt、URL 和证明文件不进入事件/普通日志。
- 反向使用查询从下游事实读取，Assets 不维护可编辑的第二份“被哪些镜头使用”。

## 8. 可观测性

- Asset/State/Version 数、Candidate valid/blocked、current 冲突、Impact 过期和 readiness 原因；
- Provider Task、MediaArtifact、Candidate、Selection 和下游固定引用可串联；
- 候选画廊首屏、影响查询和筛选 P95；
- Selection/Decision/readiness/WorkTask 事实提交到列表与 Canvas 可见的延迟，目标 P95 ≤5 秒；未确认新鲜度时显示刷新/最后确认时间，不伪造最新；
- 日志只记录 ID、类型、purpose、错误码和诊断 ID，不记录媒体地址。

## 9. 验证

- AC-CUR-AST-001～006：身份、状态、版本和来源；
- AC-CUR-AST-007～010：生成/上传、候选比较、唯一 current、高影响切换；
- AC-CUR-AST-011～016：readiness、影响、引用升级、问题浏览和归档；
- 数据库唯一约束证明每用途最多一个 current；
- current 切换后旧 ShotSpecVersion 和历史 Candidate 不变；
- 重复/并发决议不产生重复 Asset/Decision；
- 300 Asset、每 Asset 10 State、每 State 20 Candidate proposed 样本满足 CUR-AST-NFR；
- 对同一稳定 ID/版本抽样比对 Assets 列表与 Canvas 的 Selection/readiness/Task，差异为 0；SSE 缺口后回源恢复且不重放命令；
- 跨 Workspace 图片、来源、直接 ID 泄露为 0；键盘可完成 P0 选择流程。
