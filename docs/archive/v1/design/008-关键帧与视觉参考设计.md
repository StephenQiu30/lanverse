# DES-008 关键帧与视觉参考设计

- 状态：proposed
- 版本：v1.0
- 日期：2026-08-14
- 关联需求：CUR-KFR-FR-001～009、CUR-KFR-NFR-001～010、CUR-PLT-FR-004
- 关联验收：AC-CUR-KFR-001-A～AC-CUR-KFR-009-B
- 上游：[CUR-KFR](../requirement/007-镜头关键帧与视觉参考需求.md)、[DES-007](./007-分镜基线与叙事覆盖设计.md)

## 1. 问题、范围与非目标

Keyframes 模块把固定 StoryboardBaseline/ShotSpec 和资产版本转换为视频生成可消费的显式视觉输入。它区分 start_frame、end_frame 和有序 visual_reference，保留多候选，并禁止把最新、星标或最高分候选自动当主选。

范围：视觉上下文、BriefVersion、图片生成/上传、不可变 Candidate、比较、星标/拒绝、Slot 唯一 Selection、VisualReferenceRevision、readiness、stale/reconfirmation。

非目标：ShotSpec 编辑、资产治理、图片精修/画布、视频生成/主选、裁切/转码、时间线和成片。

## 2. 事实所有者与模型

| 实体 | 含义 | 版本/所有权 |
| --- | --- | --- |
| KeyframeSlot | Shot 下明确用途与基数 | 稳定；类型由产品/Capability 约束 |
| KeyframeBriefVersion | 槽位创作说明、固定 Shot/Asset 输入、Prompt 意图 | 不可变 |
| KeyframeGenerationRun | 固定说明/输入的一次业务请求 | 引用 DES-012 Task，不复制 Attempt |
| KeyframeCandidate | 生成/上传图片业务候选 | 不可变 MediaVersion/InputSnapshot |
| CandidateDecision | starred/rejected/undo/质量说明 | 追加式 |
| KeyframeSelection | select/replace/clear/reconfirm | 追加式 + current projection |
| VisualReferenceRevision | 有序 Candidate/Asset Media 引用、用途和显示别名 | 不可变修订 |
| KeyframeReadiness | 固定视频模式下槽位/参考是否可交接 | 派生投影 |

WorkTask、Attempt、Media、Cost 由 Platform 拥有，Rights/Content/Audit 决定由 Governance 拥有；本模块不建第二套通用状态或治理结论。

## 3. 槽位与不变式

| 槽位 | 基数 | 当前规则 |
| --- | --- | --- |
| start_frame | 0..1 current | I2V 模式必需；必须显式选择 |
| end_frame | 0..1 current | 仅 Capability/用户启用时必需 |
| visual_reference | 0..N 有序项 | 可多项，顺序和用途固定；不是 Slot current |

不变式：

1. Candidate 登记后原始媒体、来源和 InputSnapshot 不可替换。
2. starred ≠ selected，rejected ≠ deleted。
3. 每 Slot 同时最多一个 current Selection；必需 Slot 交接时恰好一个。
4. start/end/reference 的用途和选择规则互相独立。
5. 最新成功、最高分、首项或 starred 不得自动补主选。
6. 上游变化保留 Candidate，使 Selection `needs_reconfirmation`，不改媒体事实。
7. 历史 VideoRequest 始终能解释当时固定的 Slot 与 VisualReferenceRevision。

## 4. 固定输入与生成预检

KeyframeInputSnapshot 至少固定：Workspace/Project/Episode、StoryboardBaseline、Shot、ShotSpecVersion、视觉说明、Asset/State/Version、资产参考 MediaVersion、BriefVersion、CapabilityConfigVersion 和业务参数。

预检检查：

- Baseline/Shot/Spec 仍匹配；
- Asset 引用 ready 或给出 blocker；
- Capability 支持输入数量、画幅、尺寸和参数；
- 权限、权利、容量和预计消耗；
- 输入 hash 和有效期。

预检无 Task、无预占、无 Provider 副作用。正式提交必须按同一 input hash 和 Capability version 重检。

## 5. 同步命令与查询

| 能力 | 输入 | 结果 |
| --- | --- | --- |
| GetVisualContext | Shot、目标 Baseline | 固定 Spec/Asset、Slot、Candidate、Selection、readiness、partial failure |
| CreateBriefVersion | Slot、说明、expected upstream/spec | 新 BriefVersion 或差异冲突 |
| PreflightGeneration | Brief/Input、数量、Capability | ready/warning/blocked、预计和 input hash |
| RegisterUploadIntent | Slot、来源/权利、文件元数据 | 受控上传 session，不创建 valid Candidate |
| MarkCandidate | Candidate、star/reject/undo、expected decision | 追加 Decision；Selection 不变 |
| SelectCandidate | Slot、Candidate、expected current/input | 唯一 current 或冲突 |
| ClearSelection | Slot、expected current | current 清空，历史保留 |
| ReconfirmSelection | Selection、当前 input hash、差异理由 | 追加 reconfirmation 或输入冲突 |
| ReviseVisualReferences | 完整有序引用、用途、expected revision | 新 Revision 或零写入冲突 |
| GetReadiness | Shot、目标视频模式 | 必需 Slot、引用、stale/blocker 和固定交接摘要 |

## 6. 异步工作流与事件

生成流程：Preflight → WorkTask → Provider → 受控保存 → Media probe/hash/ready → KeyframeCandidate。Provider 成功但下载失败只恢复媒体步骤。

上传流程：tus/multipart session → quarantine object → hash/实际类型/完整解码/像素探测 → Media ready → Candidate。上传完成本身不等于 Candidate valid。

事件：`KeyframeBriefVersionCreated`、`KeyframeCandidateAvailable`、`KeyframeCandidateBlocked`、`KeyframeCandidateDecisionChanged`、`KeyframeSelectionChanged`、`VisualReferenceRevisionPublished`、`KeyframeReadinessChanged`。

Videos 只消费显式交接 Snapshot，不重新推断主选。

## 7. 状态与失败恢复

```text
Candidate: validating → valid | blocked | unavailable
Mark: unmarked ↔ starred；active ↔ rejected
Selection: missing → selected → needs_reconfirmation → selected
Readiness: incomplete | ready | stale | blocked | unavailable
```

| 失败 | 行为 | 恢复 |
| --- | --- | --- |
| 图片 Capability unavailable | 显示原因，上传仍可用 | 切换已验证能力/上传 |
| Provider unknown | 无伪 Candidate | 对账；禁止盲目新 Attempt |
| 上传中断 | 未完整对象不 valid | 同 upload session 续传/重试 |
| hash/解码/探测失败 | Candidate blocked 或不建立 | 保留隔离证据，替换文件 |
| 主选并发冲突 | 旧 current 保持 | 返回最新 current 后比较 |
| ShotSpec/Asset 变化 | Candidate 历史不变，Selection 待确认 | 重选、重生成或有理由 reconfirm |
| 原图后续不可读 | 历史可见，Selection/readiness blocked | 恢复字节或替换，不静默选其他项 |

## 8. 权限、安全与权利

- owner/editor 编辑 Brief、生成、上传、标记、选择和重新确认；viewer 只读。
- 上传进入 private quarantine；PNG/JPEG/WebP、25 MiB、512～8192 均是 proposed 样片假设，不在开放问题关闭前冒充硬限制。
- 实际 MIME、静态/动画、完整解码、尺寸、hash 由 Platform 通用媒体层判断。
- 上传来源/权利说明必填；视频生成和导出时再次门禁。
- 短期媒体 URL、Prompt、权利证据和 Provider 原响应不进入事件、普通日志或指标。

## 9. 可观测性

- 每 Slot Candidate 数、validating/blocked、star/reject、Selection/reconfirmation 和 readiness；
- 提交到 Task 可见、Provider 到媒体 ready、媒体到 Candidate 的阶段延迟；
- 20 Candidate 首屏和 4 项比较交互性能；
- InputSnapshot、Task/Attempt、Media、Candidate、Selection 可由诊断 ID 串联；
- 指标不使用 Candidate/Media ID 作为标签。
