# Acceptance 文档

本目录存放验收与验证类文档。

Acceptance 只在对应实现完成后创建，用于记录事实而非预写期望。验收标准在 Design/PRD 中定义，验证任务与证据编号在 Plan 中定义；本目录只回填实际版本、命令、结果、证据、残余风险和结论。

## 适合放入

1. 逐项验收结论。
2. 测试记录。
3. 验证报告。
4. 回归证据和残余风险说明。

## 不适合放入

1. 产品需求或执行计划。
2. 架构设计草案。
3. 发布流程说明。
4. 没有验收结论或长期复用价值的临时测试过程记录。

## 命名建议

使用 `ACC-xxx-主题验收报告.md`，例如 `ACC-001-可信项目入口验收报告.md`。

## 推荐结构

1. `验收范围`：实现版本、提交、环境、Requirement/Design/PRD/Plan 精确版本。
2. `变更清单`：实际文件、迁移、契约、运行制品和范围偏差。
3. `逐项结果`：每个 Design/PRD AC 与 Plan Test/Evidence ID 的 `passed/failed/insufficient/not_applicable` 结论。
4. `命令与证据`：完整命令、退出码、时间、环境、样本/分母、日志/截图/报告路径。
5. `非功能与演练`：适用的安全、性能、可访问性、兼容、恢复和回滚结果。
6. `残余风险`：影响、责任人、截止点和风险接受者；P0 失败不得以风险描述改判通过。
7. `最终结论`：只允许通过、风险接受或不通过，并说明是否满足 `implementation_release`。

报告不得只写“已测试”或引用 CI 首页；证据必须能复现并追溯到本次实现版本。未执行、证据缺失或样本不足必须明确记录，不能判定为通过。
