### 实现与自审

- 6 份 Kafka/ELK 环境配置迁至 `.github/ci/observability`，Compose、两处 CI 初始化、README 和架构合同同步；旧 backend 路径仍删除。Dockerfile 构建时生成入口，保留 tmpfs、0400、降权边界。

- 根据 447 条 ST1005 诊断修正错误文本首字母及精确文本断言；保留代码、状态与错误链，未禁用规则。
- Media Complete 在对象读取后重新鉴权、读取当前时间，取消保留 context 错误链。
- Media Initialize 采用 GORM OnConflict DoNothing 与既有唯一约束，再读取实际会话；同键同声明返回同一会话，不同声明返回 idempotency_conflict。曾采用 raw SQL advisory lock，架构测试失败后已移除；未放宽数据库边界。持久化测试位于 tests/media/adapter/gormdb。
- 新死信模板预定义严格字段及 ILM。两个 CI 新建环境索引使用数字后缀，满足 rollover 合同；不迁移已有用户索引。
