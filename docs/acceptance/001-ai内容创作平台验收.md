## 4. 产品场景

### 场景 P-A：发现与做同款

访客发现模板，查看详情并做同款；登录后回到预填工作台，不兼容字段可见。覆盖 AC-P01 至 AC-P03。

### 场景 P-B：生成与私有作品

创作者提交空白或模板创作，观察真实状态，成功后只在本人作品中可见。覆盖 AC-P04 至 AC-P07。

### 场景 P-C：额度、删除和管理

触发三类额度；删除本人作品；管理员查看运行与下架状态。覆盖 AC-P08 至 AC-P10。
