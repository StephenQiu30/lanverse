## 4. 故障场景

- 供应商提交边界崩溃后 reconcile 到唯一终态，不重复计费。
- crawl 积压时 generation 仍按独立并发运行。
- RabbitMQ 重投、MinIO 暂时不可用和审核超时均产生可观察状态。
- live provider 测试前记录最新价格、剩余额度和负责人批准。
