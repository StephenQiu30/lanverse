## 深度安全扫描阻断

使用 Codex Security `deep-security-scan`，目标为本仓库完整工作区。唯一一次启动调用在扫描开始前返回：

> Deep Scan cannot safely start a read-only worker: the parent must provide a managed filesystem permission profile.

当前会话采用 unrestricted 文件系统权限配置，缺少该插件要求的受管文件系统权限档案。没有启动替代扫描、没有生成或封存安全报告，也没有“零发现”结论；扫描 token 用量不可获得。需要在提供受管文件系统权限档案的会话重新发起扫描。账号的 Daybreak 状态为 `not_granted`，这仅影响受保护结果可能是否可展示，并非此次启动失败的原因。
