## 3. 真实集成与浏览器

隔离 HTTP 测试使用生产 `NewBusinessRouter`、本机 PostgreSQL/Redis 和本机 MinIO；前端使用同源 `/api` 转发，不使用 mock 路由。该测试 router 的进程 readiness 使用测试端口，不能推导整套生产 API/Worker/Relay 已运行或所有中间件已健康。

MinIO 测试资产由本轮创建：Go 生成的 160×90 PNG、仓库固定的 H.264 MP4、Go 生成的 PCM WAV；写入、授权预览下载、大小与 SHA-256 检查均使用真实服务。它们是 synthetic 媒体，不能作为真实供应商生成内容证据。测试正常退出会删除本轮创建的三个精确对象；中断恢复也只删除已知测试项目和文件名对应对象。

浏览器测试文件：[canvas.spec.ts](../../frontend/tests/e2e/canvas.spec.ts)。`LV_E2E_PROJECT_ID=<本轮隔离项目UUID> pnpm exec playwright test`：**生产 standalone 构建中 5 项通过，31.3 秒，无跳过**。覆盖真实登录/首次改密、文字/拖动/物理连线/分组/复制/历史/刷新、两页修订冲突、真实对象存储图像显示与视频/音频 `play()`、匿名媒体请求与多选卸载、物理 resize/rename/pan/框选/分组折叠展开、草稿离开保护。未使用 mock 路由。随后源视频悬停租约追加真实播放与移出释放检查，定向 1 项通过（12.8 秒）。

生产装配另行验证：构建产物 `/api` rewrite 指向隔离 Go API；standalone 显式包含 `public` 和静态文件，HTTP 访问 MIT 文本和固定媒体的字节与源文件一致。Dockerfile/Compose 已加入对应 build arg 与 public 拷贝，本地未启动 Docker 环境，镜像门禁由远端 CI 验证。

## 4. 问题修复与回归

- 分组子树：移动/复制包含全部后代，折叠检查祖先关系，禁止循环；复制分配新 UUID 并重建内部边。
- 逆命令：2,001 条边分成两个同请求命令；逆操作超过 100 条时在保存前拒绝，最终图和每条命令均执行界限校验。
- 工作区：会话失效清除门禁，创建期间阻止离开，空名称视为草稿，创建只确认一次；删除冲突读取最新并要求重新确认，不自动重删。
- 媒体：StrictMode 重复挂载原会清空 `src`，先 Red 复现后恢复每次 effect 的授权来源；图片/视频/音频均匿名请求，单选播放器、悬停租约、离屏/隐藏/运动/卸载释放、有界重取。
- 服务端：带 `LastOperationID` 的受保护节点原会响应新值但跳过数据库写入，真实 PostgreSQL 先 Red 复现；现在直接拒绝 8 种直接/间接编辑、revision 不增加，视口仍可更新。
