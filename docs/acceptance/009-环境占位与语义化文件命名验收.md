- 状态：accepted（工程配置与命名规范）

- 对应设计：[项目顶层结构与工程规范](../design/000-项目顶层结构与工程规范.md)

## 1. 验收结果

1. 根 `.env.example`、`.env.production.example`、本机 Git 忽略的 `.env` 和 Compose 服务端环境均包含 `ARK_API_KEY=`；空字符串由 FastAPI Settings 归一化为未配置的可选 `SecretStr`。
2. 占位不进入 `NEXT_PUBLIC_*`、前端包、日志或 Git；没有安装 Ark SDK，没有创建静态能力目录、GenerationRequest、Candidate 或假 Provider 结果。
3. 用户可见文档和 Playwright 文件名不再使用 `S0/S1/S2/S3` 作为主题，统一改为功能语义；正式追踪 ID、切片状态和 `DEV-*` 编号仍保留在文档正文中。
4. Markdown 链接、架构测试、Playwright 显式收集规则和历史验证命令均已切换到新路径；旧文件名引用和带切片编号的目标文件均为零。
