## 结论

本切片完成 Go 公共 API 的运行端点、Event Envelope v2 契约源和旧 Outbox Publisher 的 Topic 隔离。它没有创建 Audit Topic、Consumer Group、AuditRecord 表或 Go 业务 Writer，因此不改变 DB-20、DB-21 和任何业务聚合的当前写入所有权。

## 实现范围

- Go `lanverse-api` 自行响应 `/healthz`、`/readyz`、`/metrics` 与 `/version`，以上请求不转发给 Agent；Readiness 仍真实探测兼容运行时。
- `/metrics` 记录请求数量与耗时，只使用 Method、固定路由模板和状态族，代理请求统一落在 `/` 标签，禁止用户输入形成高基数标签。
- `/version` 返回服务名、构建版本、提交与构建时间；Docker Build Args 通过 Go `ldflags` 注入，默认值明确为开发/未知，不读取 Secret。
- `backend/api/event/event-envelope-v2.schema.json` 是 v2 包络事实源；Go Domain Decoder 拒绝未知字段、v1 消息、非法 UUID/Traceparent、缺少分区键和非对象 Payload，同时保留 JSON number/bool/object 类型。
- Python Outbox 查询必须携带非空 Topic allowlist；当前 Compose Publisher 只允许 `lanverse.io.v1` 与 `lanverse.media.v1`，Schedule Dispatcher 不接收该配置。
