## 4. 业务能力核验

| 当前事实 | 实际缺口及影响 |
| --- | --- |
| 新 TextHarness 有四类任务、来源/覆盖检查、签名、时限、输出上限，结果为 needs_review | 模型结构成功不是正式采纳；跨场披露仍有 blocker，需平台审阅映射 |

| Go 旧 HumanTask、正式分镜 intent 采纳可复用 | 新 Python proposal 仍需固定版本读取、显式转换、ID mapping 和正式 Owner/AcceptanceReceipt 桥 |
