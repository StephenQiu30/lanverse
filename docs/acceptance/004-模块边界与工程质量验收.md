## 4. 强制检查

- Domain 单元测试不启动 PostgreSQL、RabbitMQ、MinIO 或供应商 SDK。
- 模块只通过公开 Port/事件协作，无循环依赖和跨 schema 写入。
- 事件只携带 ID、版本、时间和 trace，不携带 prompt、媒体或 secret。
- Source、Generation、ObjectStore、EventBus、Search 的 fake/真实实现遵守同一契约。
