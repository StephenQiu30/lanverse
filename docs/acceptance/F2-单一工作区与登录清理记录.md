# 单一工作区与登录清理记录

2026-09-30。用户要求先保证当前页面和服务可用，随后明确清理登录功能，不保留兼容处理。设计事实来源为 [BeefTV 引入设计 §4.1](../design/BeefTV能力引入设计.md#41-当前阶段移除登录功能用户指定)。

## 实现与运行

删除前端 `/login`、`components/auth`、身份查询、首次改密、退出入口及认证跳转；项目列表与画布直接读取 Go。删除公开 `/api/auth/*`、密码登录/改密/退出用例、会话认证器、Redis 会话与登录限流、会话期限配置和 Cookie/CSRF 传输规则。Swagger 及客户端由源码与在线 API 重新生成，没有兼容路由、认证模式开关或前端假身份。

Go API 从持久化工作区注入唯一 producer 身份，复用唯一启用组织。原项目/画布命令继续做组织与身份状态检查，保留 Origin、UUID 幂等键、修订、审计与 Outbox。历史迁移、业务数据及内部账号管理命令保留，不清库；固定身份重复读取不会新增或改写，停用状态不会被恢复。当前 API 限于 local 回环监听和浏览器 Origin。

本机使用 PostgreSQL、Redis、Kafka、MinIO、Temporal 的既有服务，前端生产服务器在 `127.0.0.1:3000`，Go API/Worker/Relay 在 8080/8081/8082。进程及日志保存在仓库外 `/tmp/lanverse-local-runtime-20260930/`；配置由进程读取根目录 `.env`，没有复制或记录凭据。
