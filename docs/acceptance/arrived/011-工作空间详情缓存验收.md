## 1. 验收结论

1. `workspace_detail` 是当前唯一登记 namespace。JWT/账号有效性和 PostgreSQL Membership 在任何缓存读取前校验；未授权或跨 Workspace 请求返回 404 且缓存读取次数为零。
2. 缓存投影只包含 Workspace ID、名称、状态和 revision；响应 role 始终来自本次 Membership。key 只含环境、登记 namespace/schema、Workspace UUID、固定 identity 和 revision，不含邮箱、token、正文、URL 或凭据。
3. cold miss 回源 PostgreSQL 后先写不可变 revision 投影，再以 Redis 原子脚本推进 revision 指针；旧 revision 不能覆盖新 revision。更新、归档和恢复只在数据库事务提交后失效并回填，缓存失败不回滚业务事实。
4. TTL 带有界 jitter。miss、过期、namespace 清理、Redis 清库/断连/超时都按 miss 回源；运维可用 `make cache-invalidate CACHE_NAMESPACE=workspace_detail` 精确清理，不执行 `FLUSHDB`。
5. Prometheus 暴露 namespace/operation/result 和耗时；真实指标中不含 Workspace ID。FastAPI lifespan 复用一个 Redis client 并在关闭时释放连接。
