## 真实验证

1. Backend 在全新 PostgreSQL 16.15 与固定摘要 Temporal 上执行 `gofmt`、`go vet ./...`、`go test -count=1 -p 1 ./...`，外部依赖测试不跳过。
2. Agent 执行 Ruff check/format、Pyright 与全部 Pytest；只检查 `agent/app` 和 `agent/tests` 正式边界。
3. Frontend 重新生成 Backend OpenAPI Client，并执行 ESLint、TypeScript、Vitest 与 Next.js 生产构建；生成目录必须无 Diff。
4. 开发/生产 Compose 均在完整必填环境下渲染；Frontend、Backend、Agent 三类镜像从各自 Dockerfile 真实构建并核对运行入口。
5. Delivery Hygiene 拒绝 secret、数据、日志和浏览器报告进入 Git，并保持 Backend/Agent 语言边界。
6. `Required / CI` 必须等 Backend、Agent、Frontend、OpenAPI、Deployment 与 Delivery 全部成功；任一 Job 失败或跳过都不能报告绿色。
