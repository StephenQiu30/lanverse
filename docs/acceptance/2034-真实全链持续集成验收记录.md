## 验收范围

本记录验收当前 `.github/workflows/ci.yml` 是否以可重复、可维护的方式对每个提交执行真实质量门禁。CI 验证 Go Backend、私有 Python Agent Candidate Runtime、Next.js Frontend、Backend OpenAPI 契约、空 PostgreSQL、真实 Temporal、服务 Compose 与三类部署镜像；不在每次提交中重复启动 Kafka、Elasticsearch、Logstash、Kibana 或 MinIO，也不创建临时业务索引。

## 失败证据与修复
