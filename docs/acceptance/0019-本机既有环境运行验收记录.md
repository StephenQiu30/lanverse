## 管理命令与限制

配置位于 `~/Library/LaunchAgents/com.lanverse.<service>.plist`。日常先查看状态和业务就绪再操作；在途模型调用存在时须先按运行合同排空，不能直接重启 Harness/Worker。

```bash
launchctl list | rg 'com.lanverse'
curl --fail http://127.0.0.1:8686/readyz
curl --fail http://127.0.0.1:8687/readyz
curl --fail http://127.0.0.1:8787/readyz
curl --fail http://127.0.0.1:8788/readyz
temporal task-queue describe --task-queue lanverse-creation-text --output json
```

launchd 配置 RunAtLoad、KeepAlive 与 10 秒重启节流；这是当前用户登录域，退出登录后停止，重启机器后需要登录。未宣称无人登录启动、公网 TLS、备份恢复演练或全媒体服务已验收。Native 模式没有 Docker 的媒体 Provider root-key tmpfs 挂载，媒体凭据配置链仍应按其独立部署合同验收，不能以文本服务就绪代替。
