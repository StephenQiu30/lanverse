## 2. 状态推进规则

1. Requirement `reviewed` 只表示可设计，不表示产品负责人已接受；
2. Module Design 和 Slice PRD 同时接受后，对应 Plan 才能进入 `in_progress`；
3. Plan 工作包完成不自动把 Requirement 标为 verified；
4. verified 必须链接真实测试、故障演练、产品验收和外部 Provider/媒体证据；
5. 任何 Requirement 变化先更新本矩阵的受影响 Design/PRD/Plan，再继续实现。
