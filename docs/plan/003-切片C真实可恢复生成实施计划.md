# 切片 C：真实可恢复生成实施计划

> Plan ID：PLAN-C
> PRD：[PRD-C](../prd/003-切片C真实可恢复生成PRD.md)
> Design：M07、M08、M09、M11、M14
> 状态：proposed

## 1. 前置 Gate

切片 A 通过；选定图像/视频 Provider 沙箱，并记录幂等、查询、取消、回调、保留/训练和计量能力；敏感素材政策、单项/项目硬上限和批准职责签认。切片 B 不是前置。

## 2. 工作包顺序

| WP | 工作 | 验证 |
| --- | --- | --- |
| C1 | CapabilityRevision、Prompt compiler 和 Provider-neutral request | Golden 编译可复现 |
| C2 | Route/Preflight、M14 外发披露、M11 estimate | blocker 在外调前发生 |
| C3 | Plan/Item/InputSnapshot、start_now/hold、审批事务 | 冻结、Reservation、Outbox 原子性 |
| C4 | Job/Attempt/Submission/Reconciliation 状态机 | unknown 不盲重试 |
| C5 | 图像 Provider Adapter | 契约/沙箱/失败映射 |

| C9 | Candidate compare、Selection purpose/并发 | 新候选不覆盖主选 |

| C11 | 任务中心、unknown 人工入口、E2E 故障演练 | PRD-C 全场景证据 |

## 3. 故障注入矩阵

提交前/收单后客户端超时、外部 ID 保存前后进程崩溃、回调重复/乱序/伪造、轮询限流、取消未知、下载断线/hash 错、批量成功/失败/unknown 混合、用量迟到、连接撤销。每项验证 Job/Attempt/Usage/Candidate 计数。

## 4. 路由 Gate

本计划不把一个图像+一个视频能力标记为“多模型路由完成”。若进入 PLN-FR-012，新增独立工作包接第二个同类视频 capability，验证硬过滤、选择理由、Prompt 差异、首选不可用和批准集合内 fallback。

## 5. 退出与停止条件

满足 PRD-C 八项退出条件并通过 AC-SYS-002/003、AC-PLN、AC-EXE、AC-MED 和 AC-USG 对应范围。Provider 无法查询未知任务且没有可靠幂等证据时，停止真实上线或限定为人工单次执行，不用自动重试补洞。
