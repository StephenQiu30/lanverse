## 1. 目标与完成定义

通过 REQ-13 §3 的 TC-13-01、TC-13-02、TC-13-03、TC-13-04，满足 DES-16 §8–10 非功能与测试设计。[PLN-02 §3.3](02-项目管理与变更.md) 要求 Red → Green → Refactor、质量门禁、演示与追踪矩阵真实更新；未运行不得报通过。

## 2. 前置条件

已确认分集、LLM 报价与 M1 Agent 骨架可用；过期传播先按 E-31 契约模拟，E-31 完成后重跑联调。Epic 排序及联调验收以 [BACKLOG](../../BACKLOG.md) 为准。待确认项按对应 REQ §4 与 DES 待确认节的默认方案做就绪评审。数据、接口和工作流权威规范见 [DES-02](../design/02-领域与数据模型.md)、[DES-03](../design/03-接口设计.md)、[DES-04](../design/04-工作流与生成操作.md)。

## 4. 实施顺序

1. **Red**：先为原文偏移、台词唯一性、稳定键、版本确认与并发写失败的单元/契约测试，再准备跨边界失败场景。
2. **Green**：E-13-01 → 02 → 03；Agent 04 与前端 05 在契约固定后可并行；最后执行 E-13-06。实施顺序以 [BACKLOG](../../BACKLOG.md) 为准（M2：E-12 → E-13 → E-14；E-31 在 M2 后段实施）；联调项先用契约与模拟，待对方完成后重跑验收。
3. **Refactor**：收敛边界转换、复跑回归，每个任务按 PLN-02 §3 独立评审。

## 5. 验证与验收

- 通用质量门禁按 [PLN-02 §3.3](02-项目管理与变更.md) 完成定义与 [TST-01](../test/01-测试策略.md) 执行；实施时记录实际命令和结果。
- 本功能验证：用 48 句台词、已生成分镜的第 3 场、60 集中第 7 集失败数据执行 TC-13-01～04；核验偏移、台词唯一性、稳定键、单集隔离及 AIQ-01/PERF-05，并注入并发编辑与过期消费（REQ-13 §3；DES-16 §10；TST-02/TST-03）。文档修订阶段未运行功能测试。

## 6. 风险与回退

- LLM 偏移校验失败：保留候选原始输出和失败原因，仅重试该集，不覆盖已确认结构。
- 稳定键错误会误标下游过期：阻止确认有冲突的版本，修正键映射后重算差异，再投递过期事件。
