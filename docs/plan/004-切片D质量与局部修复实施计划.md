## 1. 前置 Gate

切片 C 有真实 Candidate/Selection/Usage 样本；签认首个语义规则、严重度矩阵、允许自动阻塞的确定性规则、QualityRiskAcceptance 职责和人工抽检方案。

## 2. 工作包顺序

| WP | 工作 | 验证 |
| --- | --- | --- |
| D1 | QualityPolicy/Evaluation/Issue/Evidence 状态机 | 未评估不显示通过 |
| D2 | ffprobe/解码/黑帧/静音等技术检查 | Golden 媒体确定结果 |
| D3 | M04 EffectiveScope 和 dependency projection | 可从权威事实重建 |

| D8 | 局部 GenerationPlan/新 Candidate/定向复检 | 未受影响 Shot 不重跑 |
| D9 | 质量页面、证据播放器和 E2E | PRD-D 证据链 |

## 3. 评估数据和指标

数据集包含正确/错误服装、伤痕、地点状态、唯一/消耗道具、相邻动作、不同画幅/编码和时间码。记录 precision/recall 但不以单一分数决定上线；同时记录未评估、规则覆盖、人工驳回和风险接受。

## 4. 故障验证

Evaluator 分片失败/重启、规则升级、输入变更、Impact 计算超时、RepairPlan 过期、修复 Job 失败/unknown、风险接受到期。验证旧证据/主选不被覆盖。

## 5. 退出与停止条件

满足 PRD-D 八项退出条件和 AC-SYS-004/010 对应范围。ImpactReport 不能稳定排除未受影响对象，或评估器无法给出定位证据时，停止自动 RepairPlan，保留人工 Issue，不扩大自动化。
