## 1. 目标与完成定义

完成 [REQ-25](../requirement/25-结果复用与写入边界.md) §3 的 TC-25-01～03，覆盖 [DES-28](../design/28-结果复用与写入边界.md) §1 设计清单及测试设计，满足 [REQ-02](../requirement/02-非功能需求规格.md) REL-02、COST-01。按 [PLN-02](02-项目管理与变更.md) §3.3 留存真实的格式、静态检查、单元/集成、Race、漏洞、契约和验收证据。

## 2. 前置条件

- BACKLOG E-25 前置：E-21；按其里程碑“Epic 实施顺序”推进（[BACKLOG](../../BACKLOG.md)）。
- 联调：无。
- M1 适用底座与本功能测试数据、模型/供应商 P0 结论按 [PLN-01](01-实施路线与交付计划.md) 和 [BACKLOG](../../BACKLOG.md) 就绪。

## 4. 实施顺序

1. **Red**：先为 TC-25-01～03 与 [DES-28](../design/28-结果复用与写入边界.md) 的测试设计写失败的领域、契约、集成和必要的交互用例。
2. **Green**：按任务表建立数据/共享契约，接入用例接口、事件/工作流、Agent（如有）及界面；共享接口只在归属 Epic 实现一次。
3. **Refactor**：收敛依赖，执行质量门禁与故障注入，逐项核对设计清单及验收证据。契约固定后，Agent 适配器与界面可并行。
4. **阶段协调**：按 [BACKLOG](../../BACKLOG.md) 对应里程碑的 Epic 实施顺序推进；本 Epic 无后实施联调项。

## 5. 验证与验收

- 质量门禁：按 [PLN-02](02-项目管理与变更.md) 完成定义与 [TST-01](../test/01-测试策略.md) 执行；保留实际命令、环境、结果和跳过项。
- 本功能专项：指纹等价/不等价、随机种子、跨项目隔离、任务写入边界架构规则；TC-25-01～03。测试数据与预期见 [REQ-25](../requirement/25-结果复用与写入边界.md) §3、[DES-28](../design/28-结果复用与写入边界.md) 测试设计及 [TST-02](../test/02-需求追踪矩阵.md)。

## 6. 风险与回退

- **风险与回退 1**：输入指纹遗漏版本或随机种子导致错误复用：先关闭零费复用入口，按正常报价生成；保留原输出与账本供排查。
- **风险与回退 2**：异步任务覆盖用户参数：限制任务写入字段并以版本测试锁定；发现越界时停止结果回写，保留候选和用户版本供修复。
