## 8. 故障优先执行模板

1. 从 PRD-010 取回当前 PT 的需求叶子、Design 与验收归属，先定义权威事实和允许丢失的技术状态。
2. 先写故障 Red：事务边界退出、重复/乱序、断连、重启、依赖不可用、容量上限和跨空间。
3. 最小实现不得创建第二状态机、通用平台 CRUD、独立微服务或厂商概念泄漏层。
4. 后端契约通过后生成前端 client；页面只展示服务端状态、阻塞与恢复动作。
5. 使用真实 PostgreSQL/RabbitMQ/Redis/MinIO/FFmpeg 契约；mock 只负责确定性单测。
6. 记录故障注入前后业务事实、费用、对象、消息和 trace，再申请产品接受。
