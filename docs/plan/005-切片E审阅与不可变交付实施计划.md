# 切片 E：审阅与不可变交付实施计划

> Plan ID：`PLAN-E`
> 上游：[PRD-E](../prd/005-切片E审阅与不可变交付PRD.md)、M09/M10/M12/M13/M14 Design
> 验收：[Acceptance 规范](../acceptance/README.md)
> 状态：`proposed`

## 1. 交付目标与固定范围

交付从当前主选镜头到内部审阅、修改闭环、基础装配和不可变交付快照的完整链路。审阅针对冻结 ReviewPackage；修改请求进入 Issue/Repair 并由新包重新审阅；Delivery preflight 逐项显示门禁；全部必需输出校验成功后，系统原子发布 Snapshot/Manifest。

本切片不包含外部匿名审片、公开分享链接、高级 NLE、复杂调色/混音或“人工上传成片后补记录”的伪闭环；外部审片留到 F 单独过 Gate。

## 2. 入口 Gate

- 切片 D 为 `verified`，至少一个项目有 10 个以上可用主选镜头及质量/治理依据；
- Selection purpose、内部审阅角色/人数矩阵、撤销规则和修改请求责任人签认；
- Assembly/ExportPreset、审阅 MP4、镜头包、Manifest、字幕格式、音频响度和下载权限签认；
- 23.976/25/29.97 fps、VFR、不同音频采样率、字幕边界、缺失轨道和部分输出失败 Golden 媒体已准备；
- Media Worker、MinIO、渲染工具和可重复执行环境可用，输出 hash/工具版本可记录。

## 4. 时间基与媒体 Golden 策略

- 领域位置以明确 rational time/fps 和媒体版本表达，不用浮点秒作为唯一事实；
- 覆盖 23.976、25、29.97 fps、VFR 输入、不同音频采样率、字幕边界、代理与原件差异；
- 覆盖主文件成功但必需附属文件失败、缺音轨、黑帧和输出 hash 不一致；
- 任一输出差异必须能追溯到输入 Manifest、renderer、preset 和工具版本；
- 评论/字幕/入出点在页面重开、代理重建和重新渲染后不得漂移到另一个内容位置。

## 5. 故障、权限与恢复验证

注入内部 Grant 过期/撤销、成员决定前停用、评论并发、通知失败、渲染阶段崩溃、MinIO 中断、字幕或 Manifest 单项失败、许可在长 Build 中到期、重复 finalize 和下载撤销。通知失败不得回滚评论/决定；partial Build 不得创建 Snapshot；历史 Package/Decision/Snapshot 必须保持可读。

## 7. 退出、停止与回退

十条 PRD-E 验收条件全部为 `passed`，且 Snapshot/Manifest 在重复 finalize、项目后续编辑和下载撤销后仍不可变，E 才可标为 `verified`。时间基不能统一、门禁结论不能冻结/重读、或 Snapshot 可能引用缺失/未校验文件时，停止正式交付，只保留内部预演。

回退可停用新 Build/下载入口和恢复前一制品；已发布 Snapshot、Manifest、ReviewPackage、Decision 和审计不得更新或删除。不得用人工上传成品并手填 Snapshot 冒充平台闭环。
