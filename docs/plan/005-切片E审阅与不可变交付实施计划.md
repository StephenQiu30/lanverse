# 切片 E：审阅与不可变交付实施计划

> Plan ID：PLAN-E
> PRD：[PRD-E](../prd/005-切片E审阅与不可变交付PRD.md)
> Design：M09、M10、M12、M13、M14
> 状态：proposed

## 1. 前置 Gate

Selection purpose、质量/治理例外、Review 批准矩阵、交付组合/ExportPreset、字幕格式、音频响度和下载权限签认；至少一个 10+ Shot 项目具有可用主选。

## 2. 工作包顺序

| WP | 工作 | 验证 |
| --- | --- | --- |
| E1 | ReviewPackage Manifest/Item/状态机 | 终态不回滚，新包不继承批准 |
| E2 | 时间码/区域 Annotation、评论/回复/分派 | 分数帧率和代理重建不漂移 |
| E3 | ReviewDecision/ApprovalPolicy/成员撤销 | 多人角色门槛和并发决定 |
| E4 | 修改请求→M10 Issue/Repair 入口 | 不直接改媒体 |
| E5 | Assembly/Track/Caption/AudioMix 精确时间基 | 重开/重排版本保持 |
| E6 | Delivery Preflight | Selection、Quality、Policy、Review 分别门禁 |
| E7 | Build/Input Manifest/Media Worker/RenderRun | 重启/阶段恢复/独立运行 |
| E8 | 输出校验、Snapshot/Manifest 原子 finalize | partial 无快照，重复 finalize 幂等 |
| E9 | 下载授权/撤销、保留和交付页面 | 快照不变、访问可撤销 |
| E10 | 完整审阅→修复→新审→交付 E2E | AC-SYS-005/006/009 证据 |

## 3. 媒体 Golden 样本

覆盖 23.976/25/29.97 fps、不同音频采样率、VFR 输入、字幕边界、缺音轨/黑帧、代理与原件差异、主文件成功但附属文件失败。输出 hash 差异必须能追到 renderer/preset/输入版本。

## 4. 故障与权限验证

内部审阅会话/授权过期或撤销、通知失败、评论并发、成员在批准时停用、渲染阶段崩溃、对象存储不可用、字幕/Manifest 单项失败、许可在长 Build 中到期、重复 finalize、下载撤销。外部审片链接留到切片 F 验证。

## 5. 退出与停止条件

满足 PRD-E 八项退出条件。若时间基无法统一、门禁结论不能冻结/重读、或 Snapshot 可能引用缺失文件，停止正式交付，仅保留内部预演，不能用人工上传成品冒充平台闭环。
