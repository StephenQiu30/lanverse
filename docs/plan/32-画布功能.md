## 4. 实施与恢复

1. 源核心/设计及合同先同步事实来源，再写核心和边界失败测试；复制源码保留固定路径/许可，不重新手写替代核心。
2. 交互预览只在客户端，结束提交命令；确认后显示已保存/进入历史。网络失败原键查明或重放，409 取最新文档并提示，不静默覆盖配置。
3. parent 必须同文档 group 且无环，world 坐标；组移动批次包含 children，服务端不重复移动；删组解组保留子节点/位置，复制新身份且不继承任务/选定。
4. 当前 Go/前端与本机依赖验证后在正式入口 Demo，保留历史文档恢复和数据演进/回滚证据；缺口接 M1-04/06/07 及 E-10/30/07/08/11/21/24/22 等下一轮合同。
5. 继续真实生成、参考/提升、流水线、Agent、非功能和完整九场景；单次 Demo 不能将完整 MVP 标完成。

## 5. 验收与风险

核心交互映射见迁移设计 §6；完整业务以 REQ-36 §3 / TST-02 为准。格式/静态/类型/构建、Go 适用 vet/lint/Race/vuln、契约生成、真实库与浏览器按 PROJECT/AGENTS 记录，跳过项不报通过。

性能用新引擎 synthetic 和真实媒体分别测 500/800 与2,000节点；记录首屏、运动、播放数、内存来源、设备/浏览器。目标机器/跨设备缺条件写未执行，旧引擎数据不代替。迁移不达标先定位/修复，不能擅自回退成旧外观/备注方案或重建数据库。

## 6. 本次限定实施顺序（2026-10-01）

1. 固定源功能映射与数据合同：仅补核心交互、系统剪贴板、视口/布局、裁剪和授权预览；供应商、Agent、时间轴、持久快照恢复另行交付。
2. 核心交互按失败边界先测试，再接正式 revision/命令和原键重试；真实浏览器覆盖跨标签/刷新与菜单焦点，合成控件测试单列。
3. 本机媒体上传复用 Go 接管/FFmpeg/私有存储，明确人工本地检查声明；同项目去重、幂等回放、失败清理和提交结果不明分别使用真实库与存储验证。
4. 文件选择、拖入与图片粘贴共用上传确认流程；新增节点只保存正式资产 UUID，保存失败重试首次批次，撤销不删除媒体。
5. 启动当前项目并以正式生产入口验证：大文件字节完整性、图片解码、视频/音频播放、完整预览、刷新恢复；只向本轮创建的隔离验收项目写入。
6. 静态/类型/构建、适用 Go 门禁与新鲜在线生成契约收口后提交本地 main；不默认推送或发布。目标机器性能、云审核、真人授权、分片续传与完整产品场景保留未执行边界。
