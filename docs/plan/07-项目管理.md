## 1. 目标与完成定义

通过 REQ-10 §3 的 TC-10-01、TC-10-02、TC-10-03、TC-10-04、TC-10-05、TC-10-06，满足 DES-13 §8–10 非功能与测试设计。[PLN-02 §3.3](02-项目管理与变更.md) 要求 Red → Green → Refactor、门禁、演示与追踪矩阵真实更新；未运行不得报通过。

## 2. 前置条件

M1 项目与风格预设基础数据可用，P0 提供预设样例；预算默认 0 的创建契约先模拟，E-11 完成后重跑实际事务联调。Epic 排序及联调验收以 [BACKLOG](../../BACKLOG.md) 为准。待确认项按对应 REQ §4 与 DES 待确认节的默认方案做就绪评审。数据、接口和工作流权威规范见 [DES-02](../design/02-领域与数据模型.md)、[DES-03](../design/03-接口设计.md)、[DES-04](../design/04-工作流与生成操作.md)。

## 4. 实施顺序

1. **Red**：先为生命周期、规格不可变、概览六阶段计数、进行中任务保护写失败的单元/契约测试，再准备跨边界失败场景。
2. **Green**：E-10-01 → 02 → 03；前端 04可在契约固定后并行；最终运行 E-10-05。实施顺序以 [BACKLOG](../../BACKLOG.md) 为准（M1：E-06 → E-08 → E-10 → E-11）；联调项先用契约与模拟，待对方完成后重跑验收。
3. **Refactor**：收敛边界转换、复跑回归，每个任务按 PLN-02 §3 独立评审。

## 5. 验证与验收

- 通用质量门禁按 [PLN-02 §3.3](02-项目管理与变更.md) 完成定义与 [TST-01](../test/01-测试策略.md) 执行；实施时记录实际命令和结果。
- 本功能验证：用 16:9 国风项目、30 镜头阶段计数、进行中任务和删除第 10 天项目执行 TC-10-01～06；注入归档/删除冲突、清理中断与画幅修改，核验恢复和 PERF-01/03（REQ-10 §3；DES-13 §9；TST-02）。文档修订阶段未运行功能测试。

## 6. 风险与回退

- 清理工作流中断或误清理：到期前保留回收状态和对象，按项目断点续跑并核对审计。
- 概览计数过期：回源重算阶段数据并刷新显示，未修复前不把缓存值作为验收证据。
