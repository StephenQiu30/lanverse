## 1. 目标与完成定义

通过 REQ-10 §3 的 TC-10-01、TC-10-02、TC-10-03、TC-10-04、TC-10-05、TC-10-06，满足 DES-13 §8–10 非功能与测试设计。[PLN-02 §3.3](02-项目管理与变更.md) 要求 Red → Green → Refactor、门禁、演示与追踪矩阵真实更新；未运行不得报通过。

## 2. 前置条件

M1 项目与风格预设基础表可用；P0 预设内容未产出时允许真实空列表，创建可不选预设。预算默认 0 已在 E-10-06 的真实 PostgreSQL 事务中验证；预算调整和生成仍由 E-11 等任务继续验收。Epic 排序及联调验收以 [BACKLOG](../../BACKLOG.md) 为准。待确认项按对应 REQ §4 与 DES 待确认节做就绪评审，默认方案不自动转为已接受需求。数据、接口和工作流权威规范见 [DES-02](../design/02-领域与数据模型.md)、[DES-03](../design/03-接口设计.md)、[DES-04](../design/04-工作流与生成操作.md)。

公开 `/api/projects` 已接入同事务账号/组织授权查询，按名称、状态与删除状态筛选；按更新时间与 ID 倒序分页，游标绑定账号、组织及归一化筛选。回收项目保留原状态并返回 `is_delete`；正式列表仅展示实际安全摘要，不填充未实现的进度、集数或缺失元数据。

内部项目设置修改命令先覆盖名称、描述、风格预设及境外模型开关：按 `expected_revision` 修改，事务重验当前授权、项目可写状态、修订号和预设范围，原子写入项目、审计及变更 Outbox；无实际变化不增加修订或写事件。隔离本机 PostgreSQL Race 测试验证成功、冲突、隔离、拒绝和回滚；默认模型、AIGC 标识样式、公开 PATCH 持久幂等和浏览器验收仍待完成。

E-10-03 已将创建与修改项目事务产生的 `workspace.project_changed.v1` 接入正式 Relay，投影为仅含项目 ID、修订号和变更类型的 `project.updated`；隔离本机 PostgreSQL、Kafka、Redis 的 Race 用例验证真实命令经 Outbox、Relay、审计消费到 Redis Stream、补读和测试授权的 SSE。公开项目 SSE 路由仍待鉴权接线，概览消费者、`project-purge` 和生命周期事件生产方尚未实现，本切片不计为 E-10-03 或 TC-10 完成。

E-10-06 已将列表组件接入正式 `/projects`，支持卡片/语义表格、名称搜索、状态与回收筛选、前后分页；创建表单读取安全组织级预设，未知结果重试保留同次幂等键，失败保留草稿，会话失效停止创建并要求重新登录。真实浏览器验证空列表创建→UUID 画布保存→刷新、390px 创建与真实搜索/状态/表格。概览、设置、归档/恢复与清理仍未接入，不计为 E-10-04 或 TC-10 全量完成。

## 4. 实施顺序

1. **Red**：先为生命周期、规格不可变、概览六阶段计数、进行中任务保护写失败的单元/契约测试，再准备跨边界失败场景。
2. **Green**：E-10-01 → 02 → 03；前端 04可在契约固定后并行；最终运行 E-10-05。实施顺序以 [BACKLOG](../../BACKLOG.md) 为准（M1：E-06 → E-08 → E-10 → E-11）；联调项先用契约与模拟，待对方完成后重跑验收。
3. **Refactor**：收敛边界转换、复跑回归，每个任务按 PLN-02 §3 独立评审。

## 5. 验证与验收

- 通用质量门禁按 [PLN-02 §3.3](02-项目管理与变更.md) 完成定义与 [TST-01](../test/01-测试策略.md) 执行；实施时记录实际命令和结果。
- 本功能验证：用 16:9 国风项目、30 镜头阶段计数、进行中任务和删除第 10 天项目执行 TC-10-01～06；注入归档/删除冲突、清理中断与画幅修改，核验恢复和 PERF-01/03（REQ-10 §3；DES-13 §9；TST-02）。文档修订阶段未运行功能测试。

## 6. 风险与回退

- 清理工作流中断或误清理：到期前保留回收状态和对象，按项目断点续跑并核对审计。
- 概览计数过期：回源重算阶段数据并刷新显示，未修复前不把缓存值作为验收证据。
