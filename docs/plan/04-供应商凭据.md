## 1. 目标与完成定义

完成 REQ-07 §3 的 TC-07-01、TC-07-02、TC-07-03、TC-07-04，满足 DES-10 §8–10 的非功能与测试要求。遵守 [PLN-02 §3.3](02-项目管理与变更.md)：Red → Green → Refactor、相关门禁、真实演示、设计与追踪矩阵同步；未通过的门禁不可计为完成。

## 2. 前置条件

## 4. 实施顺序

1. **Red**：先为单活约束、封装/解封、字段校验、停用边界写失败的单元/契约测试，再准备跨数据库、事件和界面的失败场景。
2. **Green**：E-07-01 → 02 → 03；Agent 04 与前端 05 在契约固定后可并行；最后运行 E-07-06。实施顺序以 [BACKLOG](../../BACKLOG.md) 为准（M1：E-09 → E-06 → E-07 → E-08）；联调项先用契约与模拟，待对方完成后重跑验收。
3. **Refactor**：收敛边界转换、复跑回归，按 PLN-02 §3 独立评审每个任务。

## 5. 验证与验收

- 通用质量门禁按 [PLN-02 §3.3](02-项目管理与变更.md) 完成定义与 [TST-01](../test/01-测试策略.md) 执行；实施时记录实际命令和结果。
- 本功能验证：以方舟、MiniMax 测试账号和无免费接口的模拟适配器执行 TC-07-01～04；注入认证失败、Agent 不可用、凭据停用及在途查询，扫描响应和日志是否泄露凭据（REQ-07 §3；DES-10 §9；TST-02）。文档修订阶段未运行功能测试。

## 6. 风险与回退

- 供应商没有免费测试接口：展示“不支持测试”，保留未测试状态，首次付费生成前仍走报价确认。
- 凭据疑似泄露或停用广播延迟：立即禁止新提交并使缓存失效；已提交任务继续查询，核查旧密钥是否仍被新调用使用。
