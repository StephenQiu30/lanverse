## 4. 实施顺序

1. **Red**：先为 TC-23-01～03 与 [DES-26](../design/26-批量生成.md) 的测试设计写失败的领域、契约、集成和必要的交互用例。
2. **Green**：按任务表建立数据/共享契约，接入用例接口、事件/工作流、Agent（如有）及界面；共享接口只在归属 Epic 实现一次。
3. **Refactor**：收敛依赖，执行质量门禁与故障注入，逐项核对设计清单及验收证据。契约固定后，Agent 适配器与界面可并行。
4. **阶段协调**：按 [BACKLOG](../../BACKLOG.md) 对应里程碑的 Epic 实施顺序推进；本 Epic 无后实施联调项。

## 5. 验证与验收

- 质量门禁：按 [PLN-02](02-项目管理与变更.md) 完成定义与 [TST-01](../test/01-测试策略.md) 执行；保留实际命令、环境、结果和跳过项。
- 本功能专项：300 项上限、每启动 100 子项续写、父子恢复、熔断暂停、取消释放预留；TC-23-01～03。测试数据与预期见 [REQ-23](../requirement/23-批量生成.md) §3、[DES-26](../design/26-批量生成.md) 测试设计及 [TST-02](../test/02-需求追踪矩阵.md)。

## 6. 风险与回退

- **风险与回退 1**：连续供应商错误导致整批浪费：按同类错误阈值暂停未开始项，由用户继续或取消；已开始项继续追踪结算。
- **风险与回退 2**：父工作流重启或取消时丢子项：按持久化批次和子任务恢复；禁止重复提交，未开始项释放预留。
