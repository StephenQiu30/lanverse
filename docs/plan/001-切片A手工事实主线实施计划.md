## 1. 前置 Gate

- 产品负责人接受 PRD-000/A 的试点内容、输入和退出标准；
- M01—M05 最小范围、Python 系统架构和数据迁移策略评审通过；
- 准备一份有授权的 3—5 分钟金标脚本、Fixture 媒体和预期 10—40 镜头范围；
- 开发/测试环境的 PostgreSQL、RabbitMQ 和对象存储可用。

## 3. 测试策略

每个 WP 先写领域/状态 Red 测试，再实现应用和数据库集成。必须使用真实 PostgreSQL 验证唯一约束、RLS、乐观锁和 Outbox；RabbitMQ 至少一次投递下验证重复消费；对象/文档/媒体使用小型授权 Golden 样本。

## 4. 故障与恢复验证

API 在 Outbox 提交后重启、Publisher 发布前后重启、Worker lease 过期、解析部分失败、媒体验证失败、并发批准/重排、成员停用、对象存储短暂不可用。每项保存 Operation、数据库、审计和用户恢复截图/响应。

## 5. 退出与停止条件

满足 PRD-A 七项退出条件并通过 AC-SYS-001/007/008 的 A 范围后关闭。若手工命令语义、跨租户隔离或 Operation 恢复不稳定，停止 B/C；不得让 Agent/真实 Provider 掩盖基础缺陷。
