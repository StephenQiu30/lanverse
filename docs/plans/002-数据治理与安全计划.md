# 数据治理与安全执行计划

## 1. 执行边界

本 Plan 负责政策决策、权限和安全控制，不实现产品页面布局或底层服务拓扑。真实来源/供应商未通过激活门禁时，只运行 fixture/fake。

## 2. 工作包

| ID | 工作包 | 产出 |
| --- | --- | --- |
| G-W01 | 来源准入 | access decision、证据快照、期限、kill switch |
| G-W02 | 内容权利与溯源 | 模板来源、许可、署名、动作级 grant |
| G-W03 | 用户隐私与授权 | owner predicate、审核最小权限、数据最小化 |
| G-W04 | 输入/输出审核 | 成人/违法拒绝、unknown 隔离、审计原因 |
| G-W05 | Fetch/媒体安全 | SSRF、格式/大小、无公网解码、去元数据 |
| G-W06 | suppression/删除 | 立即隐藏、删除任务、receipt、恢复防复活 |
| G-W07 | 外部激活 | SOURCE/PROVIDER/SAFETY/STORAGE 四类记录 |

## 3. Test-first 任务

| ID | Red 约束 | Green 实现 |
| --- | --- | --- |
| G-T01 | 未激活来源仍产生请求 | 来源状态机与 scheduler gate |
| G-T02 | 缺失展示权内容可查询 | action grant 与 publication predicate |
| G-T03 | 跨用户资源可枚举 | owner repository、短时 URL 和 404 策略 |
| G-T04 | 拒绝输入仍调用 provider | 输入审核前置和审计 |
| G-T05 | 拒绝输出可生成作品 | 输出审核、对象不可见和补偿删除 |
| G-T06 | SSRF/redirect 绕过 | allowlist、IP/DNS/每跳校验 |
| G-T07 | 恶意媒体产生 variant | 格式、像素、资源沙箱和 fail-closed |
| G-T08 | 下架后缓存/对象仍可见 | suppression fan-out 和删除 receipt |
| G-T09 | 日志/队列泄露正文或 secret | 序列化白名单和日志过滤 |
| G-T10 | 审核/管理无审计或权限过大 | 专用权限与 append-only audit |

每个 G-T 先提交 `test:`，再以 `impl:` 最小满足；治理策略变化必须更新 fixture 版本和 Acceptance。

## 4. 激活门禁任务

| 门禁 | 必需动作 |
| --- | --- |
| SOURCE-01 | 固定 DiffusionDB revision/checksum，确认访问/保存/展示与负责人 |
| PROVIDER-01 | Seedream API Key、北京区域、最新条款/价格/数据用途、¥700 预算 |
| SAFETY-01 | 中国大陆负责人、成人拒绝、投诉/违法内容 SOP fixture 演练 |
| STORAGE-01 | MinIO license、TLS、bucket policy、备份恢复和删除演练 |

门禁记录与运行配置分离；Design/PRD 接受不能替代启用批准。

## 6. 验证

```text
make test-unit MODULE=governance
make test-integration SPEC=rights,moderation,deletion
make test-security SPEC=ssrf,media,authz,secrets
make test-e2e SPEC=suppression,delete,review
```

需要目标服务未命中证明、对象/索引 receipt、恢复不复活报告、权限矩阵和 secret scan。

## 7. 风险与回滚

- 政策变化：暂停来源/供应商并批量 `rights_pending`。
- 审核不可用：不调用供应商、不发布输出。
- 删除失败：保持 suppression，持续重试并告警。
- 回滚：安全策略只能回到更严格版本；不得为了恢复可用性放宽 fail-closed。
