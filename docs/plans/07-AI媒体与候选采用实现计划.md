# AI媒体与候选采用实现计划

## 1. 目标与边界

交付 text/image/video/tts 统一能力目录、确定性 Mock、批准 Provider Adapter 端口、MinIO 私有媒体登记、GenerationCandidate 和 Adoption，满足 AC-PRD-007 与 AC-MOD-GEN-001～006。前置为 confirmed Storyboard 和 PLAN-05 TaskJob Green。

不实现自动模型 fallback、用户上传、公共对象 URL、整体风格媒体 slot、审美评分或渲染。真实 Provider 凭据不进入仓库；无批准 profile 时对应 Adapter 的真实 smoke 保持阻断，不伪造实现完成。

## 2. 能力与媒体 fixture

确定性 Mock 使用固定种子和输入哈希产出：可解码 PNG、3～8 秒 720×1280 视频、带精确时长 WAV/AAC，以及结构化文本。反例包含批准域外 URL、重定向、错误 MIME、超限字节、损坏文件、零时长、错误画幅、视频时长超过目标±1秒、重复 output slot 和取消后迟到结果。

## 5. 安全、风险与回滚

- Provider/MinIO 凭据只从 shell 或用户显式仓库外配置读取；缺失时只报告变量名。
- LangSmith tracing 强制关闭；网络负向测试拒绝未批准域；Provider 私有响应不进业务表/日志。
- MinIO 测试使用 run_id prefix；清理前枚举并确认只删除本次创建对象。

| 风险 | 预防 | 回滚 |
| --- | --- | --- |
| 同步 MinIO SDK 阻塞事件循环 | 受控线程、并发/超时测试 | 停止 Worker 领取，保留 lease |
| 供应结果格式漂移 | Adapter contract + 技术探测 | Candidate blocked/Task failed，新版本 Adapter 后重试 |
| 采用引用旧输入 | input_hash 和 current 校验 | 返回 412，不改 active Adoption |
| 真实 Provider 未批准 | PLAN-09 前置门禁 | Mock 可完成工程验证，但 Acceptance insufficient |

## 6. Definition of Done

- AC-PRD-007 和 AC-MOD-GEN-001～006 Green，EV-005 包含调用计数、媒体 probe/hash、谱系与采用并发结果。
- `make test-jobs test-integration` 通过四能力确定性 Mock、真实 MinIO 和第 3 镜局部失败场景。
- Candidate/Media/Adoption 不保存永久 URL、secret 或 Provider 原始响应；style 不产生媒体 slot。
- 真实 Adapter 只覆盖已批准配置，未关闭 profile 在 PLAN-09 明确失败而非静默跳过。
