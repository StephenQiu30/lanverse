# 剧本分镜与创作资产实现计划

## 1. 目标与修改边界

交付 confirmed Source→Script draft/confirmed→Asset/Storyboard drafts→联合 confirmed 的纵向切片，满足 AC-PRD-002 和 AC-MOD-STORY-001～006。修改限于 `story_development`、文本 Provider 端口的确定性 Mock、相关 transport/test；Story Feature 统一由 PLAN-09 实现，本计划不实现图片、视频、TTS、Adoption 或 Render。

## 2. 契约 fixture

固定六镜头 fixture 必须包含：至少一个 character/scene/style 资产；有序 Scene；稳定 SpeechLine/voice；6 个稳定 shot_id；每镜 3～8 秒且对齐 24fps；总时长 30～60 秒；每条 SpeechLine 恰属一镜。另准备缺字段、多余字段、截断 JSON、重复 ordinal/ID、越界时长、缺失引用和过期输入反例。

## 5. 风险、回滚与 Definition of Done

| 风险 | 预防 | 回滚 |
| --- | --- | --- |
| AI 输出看似可用但 Schema 不完整 | strict+forbid extra+持久化前复验 | Task failed，新任务；不保存 draft |
| 版本哈希实现分叉 | 生成/保存/确认/消费复用同 contract | 回退应用，历史哈希不重算 |
| 联合确认死锁/半提交 | 固定锁序、单事务、并发测试 | 整体回滚并返回稳定冲突 |
| 消费端暗中覆盖 | ETag/并发 contract test | 返回冲突，由 PLAN-09 刷新/派生 |
