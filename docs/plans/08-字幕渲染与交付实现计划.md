# 字幕渲染与交付实现计划

## 1. 目标与边界

交付 active 视频/TTS Adoption→Subtitle draft/confirmed→RenderSnapshot→Render Task→Delivery→私有下载的完整后端切片，满足 AC-PRD-008 和 AC-MOD-DELIVERY-001～006。

不实现浏览器正式渲染、专业时间线、多语言翻译、自动发布或第二对象存储。FFmpeg/ffprobe 只使用参数数组；源视频音轨必须移除。

## 2. 媒体 fixture 与工具锁

固定六镜头 fixture 提供 6 个已采用视频、若干逐句 TTS、源语言文本和精确 90k ticks。反例覆盖缺视频/TTS、过期 Adoption、Cue 重叠/越镜/舍入错误、视频错误时长、损坏媒体、FFmpeg 超时、上传中断和 ffprobe 规格失败。锁定 FFmpeg/ffprobe 镜像 digest、Noto Sans CJK SC 文件 digest 与 OFL-1.1 许可证。

## 5. 资源、安全、回滚

临时目录按 run_id 隔离并在成功/确定失败后清理；超时强制终止子进程组。下载/上传逐个复核 hash，签名授权不持久化。命令日志只保存脱敏参数摘要，不保存正文/Prompt/签名 URL。

| 风险 | 预防 | 回滚 |
| --- | --- | --- |
| 不同 FFmpeg 产生漂移 | 镜像/tool/font digest + golden probe | 回退兼容 Worker，不重写旧 Delivery |
| Tx1/2/3 留 pending | 每点重放测试 + CAS | 重放同幂等键继续，不建第二 Task |
| 临时文件耗尽 | 预算、预检、finally 清理 | 停止领取，保留 Task/快照后退出 |
| 质检误放行 | ffprobe + 帧/时轴反例 | Delivery failed，不发下载 |

## 6. Definition of Done

- AC-PRD-008 和全部 Delivery Design AC Green，EV-006 保存 ffprobe、SRT、Manifest、hash 与故障差异。
- 固定 fixture 在 120 秒产品目标内产出符合规格 MP4；三件制品均可由 ready Delivery 私有授权读取。
- 任一 Delivery 可反查完整谱系，不含对象 URL；渲染失败不重新调用已成功 AI 任务。
- `make test-jobs test-integration lint typecheck build` 目标范围通过。
