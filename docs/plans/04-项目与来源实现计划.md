# 项目与来源实现计划

## 1. 目标与修改边界

交付 Project/Episode/Source 完整纵向切片，满足 AC-PRD-001 和 AC-MOD-PROJECT-001～006。目标路径限于 `schemas/services/repositories/api/routes/domain` 中按项目与来源命名的文件、对应测试和 OpenAPI 契约；前端工作区统一由 PLAN-09 实现，本计划不实现剧本或生产任务。

## 4. 迁移、风险与回滚

本计划不新增第 21 张表；字段/约束变化必须先更新 DESIGN-06 和根所属表 SQL，再重跑 PLAN-03。无历史应用数据仍禁止破坏性 downgrade。

| 风险 | 预防 | 回滚 |
| --- | --- | --- |
| Unicode 版本随宿主漂移 | 固定 Unicode 15.1 资源与 golden fixture | 回退兼容应用，不改已保存正文/哈希 |
| 并发确认双 current | Episode 行锁 + partial UQ + 故障测试 | 事务失败返回冲突，不自动重试外部请求 |
| 前端误覆盖版本 | 强 ETag/If-Match | 刷新并派生新 draft |
| 日志泄露正文 | 日志捕获负向测试 | 停用受影响日志配置，保留事实 |

## 5. Definition of Done

- AC-PRD-001 与全部 Project Design AC Green，EV-003 记录目标命令、边界 fixture 和并发查询。
- Project/Source Operation 与 OpenAPI 一致，无第二 DTO/URL；日志不含正文/权利细节。
- 新来源只影响兼容投影，任何历史内容和状态不被改写。
- `make test-contract lint typecheck` 目标范围通过，任务 diff 单一且工作区无本任务残留。
