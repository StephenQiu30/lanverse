# 生产任务与恢复产品需求

## 1. 问题、价值与范围

文本、图片、视频、TTS 和渲染可能持续数秒到数分钟，并可能在供应提交、下载或后处理中失败。创作者需要每个生产位置都有独立、可查询、可恢复的 Task，重复操作不重复付费，局部失败不清空成功结果。

范围包含异步受理、Task 状态/进度、取消、系统自动重试、用户重试、Worker 重启恢复、Provider unknown 对账和局部失败；不包含排期队列、优先级 UI、跨项目批处理或人工修改数据库状态。

## 2. 用户故事

| ID | 用户与触发 | 前置条件 | 主流程 | 失败/恢复 | 完成定义 |
| --- | --- | --- | --- | --- | --- |
| US-TASK-001 | 创作者启动一个生成位置 | 输入基线已确认 | 点击生成→3 秒内收到 task_id→在任务/业务页查看状态 | 重复点击/网络重发返回原 Task | 唯一 Task 可持续查询 |
| US-TASK-002 | 创作者看到一个位置失败 | Task 已终态 failed | 查看错误和下一动作→只重试该位置 | 新 Task 引用旧 Task；其他位置保持不变 | 失败位置获得新可判断 Task |
| US-TASK-003 | 创作者请求取消长任务 | Task 非终态 | 发起取消→看到 cancelling→等待服务端收敛 | 供应无法取消时继续对账；迟到结果不采用 | Task 为 cancelled 或已有终态 |
| US-TASK-004 | 操作期间 Worker 重启 | Task 已受理 | 页面继续查询原 task_id→租约过期→系统对账恢复 | 无法证明供应状态时明确 unknown | 120 秒内终态或 unknown，无重复副作用 |

## 3. 状态与用户反馈

| Task 状态 | 用户解释 | 允许动作 |
| --- | --- | --- |
| `queued` | 已受理，等待执行 | 取消、查看 |
| `running` | 正在供应或后处理 | 请求取消、查看阶段 |
| `cancelling` | 取消已请求，结果未定 | 查看，不重复取消 |
| `cancelled` | 已安全收敛为取消 | 必要时创建新 Task |
| `succeeded` | 本 Task 技术执行成功 | 查看输出；不代表已采用/已交付 |
| `failed` | 有确定失败原因 | retryable 时用户重试 |
| `unknown` | 供应是否受理尚不可证明 | 等待对账/人工确认，不盲目重发 |

通信错误不得显示为 Task failed。前端只展示稳定错误码、位置、阶段、retryable 和 next_action。

## 4. 幂等、重试与局部隔离规则

- 一个异步命令只服务一个逻辑目标/usage slot；多项生成只是 Task 集合。
- 同一用户意图复用 Idempotency-Key；同 scope/key/hash 返回原 Task，不同请求复用同键明确冲突。
- 系统自动重试在原 Task 下新增 Attempt；用户重试终态失败新建带 `retry_of_task_id` 的 Task。
- Provider 请求键在外部发送前固定；Worker 恢复先对账，不自动切换 Provider/模型。
- 单镜或单句失败不改变其他 Task、Attempt、Candidate、Adoption 或媒体哈希。
- 取消后的迟到输出可保留用于对账，但必须 blocked 且不可自动采用。

## 5. 非目标

不提供跨项目批任务、可视化 DAG、任意任务优先级、管理员强制改状态、自动跨 Provider fallback、Temporal/Celery 工作流 UI 或永久事件流前端。

## 6. SMART 验收标准

| ID | 可观察行为与阈值 | 事实源、样本/环境与门禁 |
| --- | --- | --- |
| AC-PRD-003 | 同一使用位置的生产命令并发提交 20 次，只形成一个 ProductionTask、一个初始 ProductionAttempt 和一次 Mock 副作用；多项命令不创建 Batch 记录 | 唯一约束、Task/Attempt、Mock 调用日志与 Schema；PLAN-05 集成门禁 |
| AC-PRD-005 | 六镜头 fixture 中第 3 镜头首次失败时其余五个成功；用户只重试第 3 镜头失败位置会新增一个带 `retry_of_task_id` 的 Task 及初始 Attempt，其他 Task、候选和 Adoption 不变 | Task/Attempt/Candidate 差异与调用计数；PLAN-05 恢复门禁 |
| AC-PRD-006 | 在 Provider 已受理、结果落库前终止 Worker，租约过期后重启并用原请求键对账，120 秒内进入终态或明确 `unknown`，不得增加供应副作用 | PostgreSQL TaskJob/Attempt、Mock 对账日志；PLAN-05 故障注入门禁 |
