# PRD 12：画布

执行编号：12；来源需求模块：16。下文06～19指原始需求模块编号，FR/US追踪标识保持原值。

## 1. 概述

在可保存的画布上组织真实节点，完成生图→选图→图生视频→播放和恢复。

本文件是本次进一步拆解的待评审稿，细化用户结果及交付切片，不替代[模块需求](../requirement/16-画布需求.md)中的业务规则。对应[模块Plan](../plan/12-画布.md)；整体顺序与Demo优先级见[执行顺序](../plan/00-执行顺序.md)。未接受的新规则不能作为实施合同。

## 2. 参与者

使用者：制作者。产品负责人确认范围与政策；工程负责人评审Design与可行性；测试负责人验证真实结果。实际承担者待落实，可一人兼任，不虚构姓名或已承诺产能。

## 3. 背景

现有页面固定布局与演示候选未形成节点内容、媒体和生成任务之间的真实关系。

来源是当前模块规格及其第8节页面/源码定位；现有页面和旧后端仅作为现状线索，不能作为新业务合同或已验收证据。

## 4. 目标与完成尺度

在可保存的画布上组织真实节点，完成生图→选图→图生视频→播放和恢复。

本轮成功以接受切片的验收逐条通过为准：用户结果可观察，持久结果可读回，异常/越权有证据，无mock成功。真实外部调用、浏览器和自动化证据分开记录。人员、周期与质量阈值未定，当前不填上线日期、故事点或商业KPI；实施前补测量环境和完成窗口。

## 5. 使用场景

- 作为制作者，我希望创建和移动节点后仍能读回草稿，清楚哪些修改已保存。
- 作为制作者，我希望明确选中图片作为视频输入，再手动提交并播放真实视频。
- 作为制作者，我希望引用真实镜头/设定，并得到可核对建议、导出与待处理入口。

## 6. 价值与范围取舍

本模块是首轮核心入口，提前交付结构/草稿、图片节点、视频节点与明确输入连线；精确提案及验收由Demo PRD/Plan维护。

Agent、配音、导出、全局通知与任意DAG自动执行不纳入首轮。 上述取舍只调整交付顺序，不删除[原始完整范围](../requirement/16-画布需求.md#2-范围与边界)，也不把后续能力标为已完成。

## 7. 解决方案与验收切片

### 用户流程与界面

现有入口和视觉定位见[模块来源](../requirement/16-画布需求.md#8-页面与实现来源)；共享交互遵循[交互需求](../requirement/05-界面与交互需求.md)及[视觉规范](../../DESIGN.md)。本轮不重新设计页面，也不把沿用的Figma链接视为本次核验。涉及画布图片/视频的规则在[Demo PRD](06-画布生图生视频Demo.md)统一维护。

### US-CANVAS-01：保存结构与生成草稿

作为制作者，我希望创建和移动节点后仍能读回草稿，清楚哪些修改已保存。

范围追踪：FR-CANVAS-01～02、FR-CANVAS-04，原始规则见[功能需求](../requirement/16-画布需求.md#3-功能性需求)。

1. 节点/连线/草稿持久。
2. 保存标签来自回执。
3. 冲突/失败保留输入。
4. 适应视口不改节点及业务版本。

### US-CANVAS-02：用节点完成生图与生视频

作为制作者，我希望明确选中图片作为视频输入，再手动提交并播放真实视频。

范围追踪：FR-CANVAS-03～04，原始规则见[功能需求](../requirement/16-画布需求.md#3-功能性需求)。

1. 媒体真实且授权。
2. 图→视频绑定明确候选版本。
3. 使用14冻结任务和费用确认。
4. 结果仅追加且刷新恢复，图片连线不自动收费。

### US-CANVAS-03：接回完整创作工具

作为制作者，我希望引用真实镜头/设定，并得到可核对建议、导出与待处理入口。

范围追踪：FR-CANVAS-03、FR-CANVAS-05～07，原始规则见[功能需求](../requirement/16-画布需求.md#3-功能性需求)。

1. 引用实际版本而非复制历史。
2. 建议明确结果/采用方式。
3. 导出范围与缺媒体处理符合确认格式。
4. 待处理数与跳转来自本项目事实。

### 依赖、假设与质量

- 必要依赖：07项目、08媒体、10模型、14生成；镜头/设定引用随后依赖13/12。
- 尚待决定：允许节点/边类型、删除/撤销、视口保存、选图与连线语义、建议采用、导出和通知规则。
- 功能追踪以以上FR为准；完整质量条件及测试方法见[模块第4节](../requirement/16-画布需求.md#4-非功能性需求)，原始组合场景见[第5节](../requirement/16-画布需求.md#5-验收场景)。拆解不撤销安全、恢复、数据真实性和可访问要求。
- 性能/容量/恢复阈值及运行条件未确定的部分单列，不能报告为质量达标。
