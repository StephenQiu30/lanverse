规则与验收以 [REQ-21](../requirement/21-报价与二次确认.md) 为准，以下为产品摘要。

## 1. 问题与价值

制作者从镜头、批量、画布或 Agent 发起付费生成时，需要先知道各项费用和预算是否足够；输入变化后沿用旧报价会造成意外费用。统一报价、用户二次确认、预算预留与终态结算让每次费用可见且可追踪。对应 PRD-01 §2 的**成本透明、可控性**，横向支撑 S2、S4、S5、S8、S9 的付费步骤；P21、P29、P30 分别约束确认、批量部分失效和 LLM 结算封顶。

## 2. 目标用户与场景

- 在镜头、批量、画布或 Agent 入口查看费用与预算。
- 剔除错误项后明确确认。
- 管理员核查预留释放。

## 3. 范围

- **做（MVP）**：单项与批量报价、输入与参数校验、复用判断、报价有效期、确认、预留、结算、释放、确认审计。
- **不做**：批量执行、任务对账与成本报表由其他功能承担；V2 见 REQ-34。

## 4. 用户体验与流程

1. 从任一付费生成入口点击报价，查看逐项金额、合计、剩余预算、有效期和模型服务区域；境外区域显示数据出境提示。
2. 在对话框中剔除不需要或有错误的项，核对金额后由本人点击“生成（约 ¥X）”确认。
3. 确认后看到“已确认/排队中”等任务状态，任务终态在详情看到实际费用及预留释放。
4. 余额不足时显示差额，可剔除后重报；报价过期或目标/价格变化时说明失效项并重新报价、再次确认；批量仅剔除失效项，其余继续；确认后调度暂不可用时保留已确认状态并等待自动恢复。

## 5. 产品规则

- 所有付费生成必须先报价、后确认；服务端没有任何自动确认参数或配置（REQ-21 R1）
- 确认只能由用户会话发起；Agent 服务令牌等非用户会话调用确认接口返回 403（REQ-21 R2）
- 报价 15 分钟内有效；过期时重新报价并再次要求确认。（REQ-21 R3）
- 确认时重新核对目标、模型与价格；批量中只剔除已失效项，并逐项说明原因。（REQ-21 R4）
- 复用项确认后不再调用供应商，已有结果作为本次产出，费用为零。（REQ-21 R5）
- 批量确认时可剔除不需要的项，剔除项不执行。（REQ-21 R6）
- 预留金额 = 报价；供应商实际费用 = 实际用量 × 报价时价格规则；用户结算金额 = 供应商实际费用，但按 token 计费的 LLM 以预留金额封顶，超出部分由平台承担、单独记账且不计入项目费用与预算（COST-02）；差额释放（REQ-21 R7）
- 任一终态（completed / failed / cancelled / manual 处理后）必须完成结算，残留预留为 0（REQ-21 R8）
- 重复提交同一次报价或确认不会产生重复预留和执行。（REQ-21 R9）
- 报价显示服务区域；境外模型在对话框中显示数据出境提示（REQ-21 R10）
- 非付费操作（上传探测、抽帧、转码）不走本流程（REQ-21 R11）

## 6. 成功标准

- Given 报价已生成 20 分钟，When 用户点击确认，Then 提示报价已过期并重新计算。（[TST-02](../test/02-需求追踪矩阵.md) TC-21-01）
- Given 任意入口发起生成，When 用户未点击确认，Then 不产生任何供应商调用，也不产生预留。（[TST-02](../test/02-需求追踪矩阵.md) TC-21-02）
- Given Agent 建议批量生成 10 个镜头，When 用户未确认，Then 不产生费用；确认后才执行。（[TST-02](../test/02-需求追踪矩阵.md) TC-21-03）
- Given 报价后镜头参数被修改，When 确认，Then 报价作废并提示重新报价。（[TST-02](../test/02-需求追踪矩阵.md) TC-21-04）
- Given 任务结束（任一终态），When 检查账本，Then 该任务不存在未释放的预留。（[TST-02](../test/02-需求追踪矩阵.md) TC-21-05）
- Given 同一 `Idempotency-Key` 的确认请求发送两次，When 检查，Then 只有一笔预留、一个工作流。（[TST-02](../test/02-需求追踪矩阵.md) TC-21-06）

以上为 [REQ-21](../requirement/21-报价与二次确认.md) §3 的 TC-21-01～06；关联质量要求见 [REQ-02](../requirement/02-非功能需求规格.md) PERF-10、REL-02、REL-04、REL-08、COST-02。跟踪 PRD-01 §10 的预估与实际费用偏差及单分钟镜头成本；计费与可靠性阈值以 REQ-02 为准。

## 7. 依赖与风险

- **依赖**：[PRD-05](05-模型注册表与价格.md)、[PRD-07](07-项目管理.md)、[PRD-08](08-项目预算.md)、[PRD-22](22-结果复用与写入边界.md)、[PRD-29](29-成本账本与报表.md)。
- **风险**：并发预算、费用迟到与启动失败可能影响结算可信度。

## 8. 待确认

已决定：批量确认仅剔除变化项并逐项说明，其余继续（PRD-01 P29、REQ-21 R4、DES-24-Q2）；报价有效期为 15 分钟（REQ-21 R3）。报价清理、输出 token 上限来源与配置位置属于 DES-24-Q1/Q3/Q4 技术细节；无其他产品待确认项。
