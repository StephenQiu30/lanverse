# 剧本分镜与创作资产产品需求

## 1. 问题、价值与范围

未经结构化和人工确认的 AI 文本不能直接进入昂贵媒体生产。创作者需要先获得可编辑剧本，再形成角色、场景、整体视觉风格和 6～10 个稳定镜头，最后统一确认一个可追溯生产基线。

范围包含剧本/分镜 AI 提案、版本编辑与派生、资产设定、镜头重排、联合确认和历史查看；不包含自由 Agent 对话、自动采用媒体、复杂时间线编辑或艺术质量评分。

## 2. 用户故事

| ID | 用户与触发 | 前置条件 | 主流程 | 失败/恢复 | 完成定义 |
| --- | --- | --- | --- | --- | --- |
| US-STORY-001 | 创作者希望把故事变成可编辑剧本 | current confirmed Source 存在 | 请求生成→查看 Task→打开剧本提案→编辑→确认 | AI 结构失败可新建 Task；旧来源任务保留 | confirmed Script 含完整场次和语音条目 |
| US-STORY-002 | 创作者希望建立一致角色、场景和风格 | current confirmed Script 存在 | 请求分镜→编辑资产名称/设定→检查引用 | 缺字段或引用失效阻断确认 | 角色/场景/风格资产版本齐全 |
| US-STORY-003 | 创作者希望控制镜头节奏 | 有分镜 draft | 编辑/增加/删除/重排 Shot→检查时长和语音映射→联合确认 | 校验失败定位到具体 Shot/语音；不覆盖旧版本 | confirmed Storyboard 含 6～10 镜、总时长 30～60 秒 |
| US-STORY-004 | 创作者修订已确认内容 | 已有 confirmed Script/Storyboard | 显式派生 draft→编辑→重新确认 | 下游历史不回滚，仅显示 outdated | 新生产只引用新 current confirmed 组合 |

## 3. 内容与交互规则

- AI 输出统一显示“提案”，在用户确认前不得进入媒体生成。
- Script 包含有序场次、动作和稳定 SpeechLine；每条语音有文本、顺序、逻辑 voice_id，对话另有角色。
- Asset 类型只允许角色、场景、整体视觉风格；风格是文字版本，不产生媒体采用位置。
- 每个 Shot 有稳定 ID、顺序、叙事目的、画面提示、动作、3～8 秒时长、资产版本和 SpeechLine 引用。
- Shot 重排不改变稳定 ID；每条 SpeechLine 恰好属于一个 Shot；总时长以 90,000 ticks/s 计算并对齐 24fps。
- `confirmStoryboard` 必须一次确认 ShotSpec 和全部被引用 Asset 版本，不能出现半确认基线。

## 4. 状态与失败

| 状态/场景 | 用户可做 | 系统行为 |
| --- | --- | --- |
| draft | 编辑、保存、确认 | 使用 ETag 防止静默覆盖 |
| confirmed | 查看、用于生产、派生 draft | 内容只读，旧 current 可 supersede |
| superseded | 查看历史 | 不可编辑或复活 |
| AI Schema 无效 | 查看稳定错误 | 不保存可确认提案 |
| 上游 current 已变 | 刷新并重新生成/派生 | 已受理 Task 和历史版本保持不变 |
| 联合确认失败 | 修正具体字段 | 整个确认事务不生效 |

## 5. 非目标

不提供专业编剧多人协作、自由格式 screenplay 导入、无限镜头、镜头级关键帧时间线、资产模型训练或自动决定最终分镜。
