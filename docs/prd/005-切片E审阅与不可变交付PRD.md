# 切片 E：审阅与不可变交付 PRD

> PRD ID：PRD-E
> 上游：切片 C/D；M09、M10、M12、M13、M14
> 状态：proposed

## 1. 用户问题与结果

用户需要让审片人针对确定版本评论和批准，并把批准内容装配为可复现交付。旧评论、决定和快照不能因后续重选、重排或修复而漂移。

## 2. P0 范围

- 冻结 ReviewPackage、内部审片人、时间码/区域评论、修改请求、批准/拒绝；
- 基础画面顺序/裁剪/简单转场、音频放置/音量、基础字幕；
- 审阅 MP4、有序镜头包、Manifest；正式母版预设按 PRD-000 签认；
- Delivery preflight、Build/RenderRun、全部必需输出校验、原子 Snapshot；
- 下载授权和撤销，不含外部渠道自动发布。

外部/非成员审片明确延期到切片 F；切片 E 不提供临时公开链接，也不把内部 reviewer 账号当作外部审片能力。

## 3. 用户旅程

冻结审阅包 → 审片评论/决定 → 修改请求进入 Issue/Repair → 新候选/装配形成新包 → 批准 → 交付预检 → 渲染/验证 → Snapshot/Manifest → 授权下载。

## 4. 页面与决定

审阅播放器决定批准/请求修改/拒绝；装配页决定顺序、入出点、音轨和字幕；交付页决定输出预设、处理 blocker 和发布 Snapshot。高级 NLE 功能明确引导导出素材包。

## 5. 验收与退出

1. 评论在新候选/代理出现后仍指向原媒体和精确时间；
2. 新 ReviewPackage 不继承旧批准；
3. 缺主选、质量/权利/审阅门禁任一未满足不启动正式 Build；
4. 分数帧率下字幕/评论/裁剪重开不漂移；
5. partial/failed Build 不创建 Snapshot；
6. 同 Build 重复 finalize 回读同 Snapshot；
7. Snapshot 可还原全部输入、选择、质量/治理决定、审阅和输出 hash；
8. 后续项目修改不改变旧 Snapshot 或 Manifest。
