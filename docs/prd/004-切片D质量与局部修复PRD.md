# 切片 D：质量与局部修复 PRD

> PRD ID：PRD-D
> 上游：切片 C；M04、M05、M07—M11、M14
> 状态：proposed

## 1. 用户问题与结果

生成候选后，用户需要区分技术损坏、镜头意图偏差和跨镜连续性问题，并只重做必要范围。切片 D 验证影响图、问题证据、RepairPlan 和定向复检，而不是追求一个不可解释的总分。

## 2. P0 范围

- 技术检查：格式、解码、尺寸、时长、黑帧/静音等确定性规则；
- 一个结构化语义检查器：首选人物身份/服装/关键道具一致性；
- 人工 Issue 创建、确认、误报/不适用、分派和 QualityRiskAcceptance；
- M04 EffectiveScope/依赖投影/ImpactReport；
- RepairPlan 显示目标、固定输入、影响、资源和验证范围；
- 只为选定 Shot 创建替代计划，新 Candidate 定向复检。

## 3. 用户旅程

查看检查覆盖 → 打开 Issue 证据 → 决定确认/驳回/风险接受/修复 → 预览影响和资源 → 批准 RepairPlan → 执行局部生成 → 比较新候选 → 复检 → 新审阅准备。

## 4. 风险边界

QualityRiskAcceptance 只处理质量问题；权利/安全仍由 M14 PolicyException。自动评估不能选择候选、批准交付或把未评估显示为通过。修复执行成功不直接关闭 Issue。

## 5. 验收与退出

1. 损坏媒体有确定证据并阻塞对应用途；
2. 人物换装只标记真实范围和引用 Shot；
3. 道具在相邻镜头无原因消失可定位；
4. RepairPlan 不包含未受影响兄弟镜头；
5. 新候选到达后 Issue 必须复检才关闭；
6. 规则/评估器升级保留旧结果并只使相关项 stale；
7. 质量风险、治理例外和审阅批准不能互相代替；
8. 实际重算范围与 ImpactReport 可比较并记录精确率。
