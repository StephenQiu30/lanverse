# 切片 F：团队、画布与组织扩展 PRD

> PRD ID：PRD-F
> 上游：A—E；M01、M06、M12、M14、M15
> 状态：proposed

## 1. 用户问题与结果

核心生产闭环通过后，团队需要细粒度职责、外部审片、空间化接管、组织模板和受控集成。切片 F 扩大协作与复用，但不得复制项目事实或绕过现有命令。

## 2. 按证据启用的能力

| 能力 | 进入 Gate |
| --- | --- |
| 项目角色/临时委派/双人批准 | 已有多人权限冲突和职责需求样本 |
| 外部审片/通知 | E 的内部审阅已稳定，下载/撤销策略签认 |
| 完整画布/团队视图 | B 的最小接管视图证明空间操作显著减少步骤 |
| 组织模板/资产 | 至少两个项目重复同一已批准结构/规则 |
| SSO/SCIM | 企业身份目录成为签约/部署硬条件 |
| API/Webhook | 明确首批客户端、命令、事件和 SLO |
| 私有模型/LoRA | 数据不得外发或明确质量/成本证据 |

没有证据的项保留 proposed，不因归入 F 就同时上线。

## 3. P0 共通规则

- 画布、Agent、列表、API 调用相同 Query/Command；
- 删除画布节点只删除布局；装饰边不参与影响；
- TemplateRelease 只含已批准可发布对象，实例化生成新身份；
- API 客户端可撤销、最小 Scope、幂等和 expected revision；
- Webhook 签名、防重放、版本、重试/死信；
- 私有能力继续经过 M07/M08/M11/M14；扩展无数据库直连和任意代码。

## 4. 验收与退出

1. 画布/列表/API 同命令产生同授权、冲突和领域结果；
2. 删除/移动画布节点不改变领域事实；
3. 成员/客户端/外部链接撤销后新操作立即停止；
4. 模板实例化生成新对象并保留 release 来源，升级只产生迁移 Proposal；
5. API 重复和 Webhook 重放不重复业务动作；
6. 私有能力不能旁路计划、执行、资源和治理；
7. 任何组织级复用不读取另一项目未发布草稿；
8. 每个实际启用能力都有独立采用、故障和安全指标。
