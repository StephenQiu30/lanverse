## 1. 产品决策

F 不是一个“企业功能大包”。项目角色、外部审片、完整画布、模板、SSO/SCIM、API/Webhook 和私有能力分别依据真实需求进入；没有用户样本、权限边界、故障模式和采用指标的能力保持 proposed，不创建占位服务、目录或兼容层。

所有扩展必须复用 A—E 的 Query/Command、权限、幂等、expected revision、资源和治理门禁。画布、模板、外部链接和集成都不能拥有第二份项目事实。

## 2. 能力 Gate 与目标用户

| 能力 | 目标用户 | 进入 Gate | P0 用户结果 |
| --- | --- | --- | --- |
| 项目职责/委派/双人批准 | 组织管理员、制片人 | 已有多人职责冲突样本和撤销 SLA | 权限可解释、可撤销，高风险职责分离 |
| 外部审片/通知 | 制片人、非成员审片人 | E 内部审阅稳定；下载、期限、地域、通知策略签认 | 只访问指定冻结包，撤销后不能扩大访问 |
| 完整画布/团队视图 | 主创、制作操作员 | B 最小视图在至少 3 个高频流程证明显著减少步骤 | 空间操作与列表/API 同事实同命令 |
| 组织模板/资产 | 组织管理员、主创 | 至少两个项目重复同一已批准结构/规则 | 安全发布、预览、实例化新身份和可审查升级 |
| SSO/SCIM | 企业管理员 | 企业 IdP 成为签约/部署硬条件 | 目录同步不改变本地授权和紧急恢复语义 |

| 私有模型/LoRA | 企业管理员、AI 平台负责人 | 数据不能外发或存在明确质量/成本证据与 PoC | 能力准入、健康、撤销且不绕过 M07/M08/M11/M14 |

## 4. 业务规则与失败体验

- 移动、隐藏或删除 Canvas 节点只改变布局；业务删除必须走结构化命令和影响预检。
- TemplateRelease 不包含未发布草稿、凭据、媒体通用访问权或源项目私有身份；实例化不共享 current pointer。
- 外部审片撤销后，每个新请求重新鉴权；不能依赖可独立使用到到期的长期下载 URL 实现“即时撤销”。
- API 与 UI 对同一身份/基线返回相同授权、冲突和结果；Webhook 失败不回滚领域事实。
- SSO/SCIM 冲突、私有能力不健康、Webhook endpoint 故障和第三方限流不得拖垮 A—E 核心交互。
- 扩展不允许任意代码、数据库直连、通配 Tool/凭据或跨 Workspace 查询。

## 5. 每项能力指标

| 能力 | 最低指标 |
| --- | --- |
| 职责/SSO | 授权拒绝、同步冲突、撤销传播、紧急恢复次数 |
| 外部审片 | 授权成功、访问/下载、撤销生效、审阅周转和未授权尝试 |
| 画布 | 目标任务完成率、步骤/时间、错误恢复、键盘路径、布局性能 |
| 模板 | 预览→实例化、被覆盖字段、升级提案接受/拒绝、跨项目拒绝 |
| API/Webhook | 幂等回读、429、投递成功/重试/dead-letter、签名/重放拒绝 |
| 私有能力 | 健康、路由采用、失败隔离、资源/治理拒绝和撤销后新调用 |

## 7. 非目标与退出 Gate

F 不交付公共市场、自动模板升级、任意扩展代码、跨租户模板共享、通用第三方 App 平台或与旧 API 并行的兼容层。每项能力只有在自己的 Gate、相关 `PRD-F-AC-*`、安全/故障/采用指标和回退方式均通过后才能标记完成；F 的其他能力继续保持 `not_run/proposed`，不能用一个能力通过代表整个 F 通过。
