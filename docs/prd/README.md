# AI 视频生产平台 PRD 索引

PRD 按可独立验收的纵向切片组织，不逐模块复述 Requirement。Requirement 定义最终能力合同，Module Design 定义实现边界，PRD 决定某次交付包含哪些用户旅程和 P0 范围。

| 序号 | PRD | 主要结果 | 状态 |
| --- | --- | --- | --- |
| 000 | [首轮试点产品基线](./000-首轮试点产品基线PRD.md) | 用户、规模、权限、格式、指标和发布原则 | proposed |
| 001 | [切片 A：手工事实主线](./001-切片A手工事实主线PRD.md) | 来源到可播放手工预演 | proposed |
| 002 | [切片 B：受限 Agent 提案](./002-切片B受限Agent提案PRD.md) | Agent 首稿与人工逐项接管 | proposed |
| 003 | [切片 C：真实可恢复生成](./003-切片C真实可恢复生成PRD.md) | 冻结计划到真实候选 | proposed |
| 004 | [切片 D：质量与局部修复](./004-切片D质量与局部修复PRD.md) | 问题证据与最小返工 | proposed |
| 005 | [切片 E：审阅与不可变交付](./005-切片E审阅与不可变交付PRD.md) | 冻结审阅、装配与快照 | proposed |
| 006 | [切片 F：团队、画布与组织扩展](./006-切片F团队画布与组织扩展PRD.md) | 多人协作、组织复用和受控集成 | proposed |

每个 PRD 只有在前置退出证据通过、产品负责人接受范围、真实外部条件齐备后才能进入实施。PRD 编号不代表日历月份。
