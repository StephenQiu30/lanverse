## 1. 问题与价值

制作者给双人同框、动作和运镜镜头选好角色造型、场景、视频及音频参考后，若只能把一张图送入模型，就只能反复试提示词，主体外观和表演节奏难以稳定。本功能在报价前展示完整参考与编号，并把全部已确认输入交给支持该能力的模型；候选保留所用版本，便于检查和局部重拍。对应 PRD-01 §1 的**一致性、可控性**，直接服务 S5 全能参考生成镜头；P10 明确全能参考及参考音频不可降级，P21 要求付费前确认。

## 2. 目标用户与场景

- 作为**制作者**，我希望用镜头的参考组合（多角色造型图、场景图、道具图、动作 / 运镜参考视频、参考音频）加镜头参数与画面描述直接生成视频。

典型场景：

- Given 参考组合含角色 A v1、角色 B v1、场景 S v1，When 生成视频，Then 任务输入与片段记录均包含这 3 项及其版本。（TC-28-01）
- Given 双角色同框镜头，When 生成完成，Then 人工抽检两人外观与各自锁定造型一致。（TC-28-02）
- Given 参考组合含运镜参考视频，When 生成完成，Then 按 AIQ-05 评分运镜一致性达标。（TC-28-03）

## 3. 范围

- 做（MVP）：参考组合展开、按模型映射输入、提示词中的参考指代、生成、结果记录参考版本、过期（REQ-28 §1.3）。
- 不做：以 REQ-28 §1.3 的排除项为准；V2 见 [REQ-34](../requirement/34-V2与待定需求池.md)。

## 4. 用户体验与流程

1. 制作者从镜头详情进入视频生成，检查参考组合中的角色、场景、动作视频和音频，以及高亮的“图1 / 视频1 / 音频1”指代和提示词。
2. 选择支持全能参考的模型并查看报价；确认后在任务中心看到进度。完成后在候选卡展开“所用参考”，核对每项版本并决定是否选定。
3. 若参考数量或用途超出模型限制，报价阶段列出不支持的项，用户可改选模型或调整参考后重试；不会悄悄省略。若参考素材失效或供应商不可访问，显示失败原因并允许修复素材后重新报价。若外观或运镜不符，可查看参考证据，保留旧候选并重拍；参考后来改选时，旧候选显示过期。（REQ-28 §2.1–2.4；DES-31 §6）

## 5. 产品规则

- 全部参考及提示词都参加生成；超限在报价阶段拒绝，不静默丢弃（REQ-28 R1）
- 候选保留参考版本，参考更新或改选后旧片段提示过期（REQ-28 R2、R3）
- 指代编号与实际参考顺序一致；提示词由 Go 规则模板组装并允许用户改写，不调用付费提示词 Skill；超长音频可设置起点截取（REQ-28 R4、R5；DES-01 §6.4、DES-05 §5）
- 写实与风格化均须通过验收，不可降级（REQ-28 R6）

## 6. 成功标准

以 [REQ-28](../requirement/28-全能参考生视频.md) §3 与 [TST-02](../test/02-需求追踪矩阵.md) 为准：

- TC-28-01：Given 参考组合含角色 A v1、角色 B v1、场景 S v1，When 生成视频，Then 任务输入与片段记录均包含这 3 项及其版本。
- TC-28-02：Given 双角色同框镜头，When 生成完成，Then 人工抽检两人外观与各自锁定造型一致。
- TC-28-03：Given 参考组合含运镜参考视频，When 生成完成，Then 按 AIQ-05 评分运镜一致性达标。
- TC-28-04：Given 参考组合含参考音频，When 生成完成，Then 按 AIQ-05 评分表演节奏达标，片段记录所用音频版本。
- TC-28-05：Given 写实与风格化项目，When 各执行上述场景，Then 均通过。

相关指标：AIQ-04、AIQ-05；PERF-09。 PRD-01 §10 的生产与质量指标只跟踪，不另设目标。
