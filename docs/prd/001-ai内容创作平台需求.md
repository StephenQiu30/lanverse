# AI 内容创作平台产品需求

## 1. 用户问题与价值

AI 绘画创作者需要跨多个平台寻找提示词、理解参数、切换生成工具并管理结果。Thief 提供连续的“发现灵感 → 做同款/空白创作 → 生成图片 → 管理作品”流程。

爬虫获得的模板只是内容供给；用户真正获得的价值是把灵感直接转化为可管理的图片作品。

## 2. 用户与权限

| 用户 | 产品能力 |
| --- | --- |
| 访客 | 浏览、搜索、筛选和查看公开模板 |
| 邀请创作者 | 登录、做同款、空白创作、查看任务和管理本人作品 |
| 管理员 | 邀请用户、管理来源/任务/额度、审核和下架 |

MVP 不开放自助注册。管理员不能因为角色直接查看用户私有作品；专用安全审核权限另由 PRD-002 约束。

## 3. MVP 范围

P0：

- 首页发现、探索筛选、模板详情、来源与许可展示。
- 管理员邀请账号、登录、退出和会话恢复。
- 模板做同款与空白创作工作台。
- prompt、negative prompt、模型能力与基础参数编辑。
- Seedream 5.0 Lite 图片生成、任务状态、取消和失败反馈。
- 私有作品列表、详情、下载和删除。
- 每人 5 张/日、全站 100 张/日、月度模型费用硬上限 ¥700。
- 来源、采集/生成运行、审核、下架和额度管理入口。

非目标：视频/音频/3D、模型训练、社区发布、评论关注、公开作品分享、支付订阅、移动 App、多租户和任意 URL 通用爬虫。

## 4. 用户故事

| ID | 用户故事 |
| --- | --- |
| P-US-01 | 访客可以按关键词和筛选项找到模板并查看效果、提示词和来源 |
| P-US-02 | 创作者可以从模板进入预填工作台，并看到不兼容参数提示 |
| P-US-03 | 创作者可以从空白工作台配置 prompt 和基础参数 |
| P-US-04 | 创作者提交后立即获得 job ID，并持续看到真实任务状态 |
| P-US-05 | 创作者可以查看、下载和删除自己的作品，且他人不能访问 |
| P-US-06 | 额度不足、输入拒绝、供应商故障和输出拒绝都有明确反馈 |
| P-US-07 | 管理员可以暂停来源/生成、查看运行状态和控制预算 |

## 5. 核心流程

模板创作：

```text
探索 → 模板详情 → 做同款 → 登录/工作台 → 编辑 → 提交
→ 排队/生成 → 输出审核 → 私有作品
```

空白创作：

```text
登录 → 工作台 → 输入/参数 → 提交 → 任务状态 → 私有作品
```

## 6. 产品业务规则

| ID | 规则 |
| --- | --- |
| P-BR-01 | 公开页面只展示当前可发布模板 |
| P-BR-02 | 做同款保留原始提示词；不兼容字段明确提示且不静默丢弃 |
| P-BR-03 | 生成必须登录，同一用户相同幂等键返回同一 job |
| P-BR-04 | 达到用户、全局或月度额度任一上限时拒绝新任务 |
| P-BR-05 | 已接收任务不因随后达到额度而中断，取消按供应商能力 best effort |
| P-BR-06 | 用户作品默认私有，不自动公开、不进入模板库、不用于训练 |
| P-BR-07 | 用户删除后立即从本人页面隐藏，后台异步完成物理删除 |
| P-BR-08 | 任务状态只使用 `queued/running/succeeded/failed/cancelled` 用户态 |

## 7. 产品验收标准

| ID | 标准 |
| --- | --- |
| AC-P01 | 访客无需登录完成首页、搜索、筛选和模板详情路径 |
| AC-P02 | 未登录点击做同款后完成登录并回到已预填工作台 |
| AC-P03 | 做同款预填 prompt 和兼容参数，不兼容字段具有可见提示 |
| AC-P04 | 空白创作和模板创作都能在提交后 2 秒内返回唯一 job ID |
| AC-P05 | 真实 Seedream 任务成功后，图片出现在当前用户作品页 |
| AC-P06 | 排队、运行、成功、失败、取消和审核拒绝都有正确页面状态 |
| AC-P07 | 用户 A 无法访问用户 B 的 draft、job、签名 URL 和作品元数据 |
| AC-P08 | 用户/全局/月度额度达到上限后，新任务被明确拒绝 |
| AC-P09 | 用户删除作品后页面立即不可见，并显示删除处理状态 |
| AC-P10 | 管理员能查看来源、采集/生成运行、额度和下架状态 |

## 8. 产品指标

- 模板详情 → 工作台转化率。
- 生成提交数、成功率、首次结果耗时和失败原因分布。
- 7 日创作者留存、每用户作品数、删除率。
- MVP 可靠性目标：排除主动取消和审核拒绝后生成成功率 ≥95%，任务用户态与后台终态一致率 100%。

增长目标不作为 MVP 发布门禁；先验证完整流程、可靠性和预算控制。

## 9. 依赖与风险

依赖 PRD-002 的治理门禁、PRD-003 的技术功能和 PRD-004 的模块工程约束。主要产品风险为模板效果与 Seedream 不一致、供应商故障、额度耗尽和用户滥用；通过兼容提示、状态反馈、hard cap 和暂停开关控制。

## 10. 发布门禁

AC-P01 至 AC-P10 全部通过；PRD-002/003/004 对应 Acceptance 同时通过；真实来源和生成供应商已激活，否则仅允许内部 fixture/fake 演示。
