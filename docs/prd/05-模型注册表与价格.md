## 1. 问题与价值

制作者把角色图、视频和参考音频组合生成时，不同模型接受的模式、参数和数量上限各不相同；靠人工记忆容易在确认报价后才发现输入不被支持，价格变动也会让费用难以复核。注册表让制作者先看到可用模型及限制，让管理员发布可追溯的能力与价格版本。它支撑 S2/S5 的生成选择、S4 的重拍选择，贡献“可控性”和“成本透明”（PRD-01 §1、§5；P10、P18；REQ-08 §1）。

## 2. 目标用户与场景

- 管理员登记模型，发布能力参数版本和价格版本，再启用。
- 制作者切换模型，参数面板随模型展示支持的字段与限制。
- 管理员调整价格或停用模型，历史已确认任务仍可追溯。

## 3. 范围

- **做（MVP）**：能力字典、模型与价格版本、参数和输入限制、启用停用、按项目筛选可用模型（REQ-08 §1.3）。
- **不做**：以 REQ-08 §1.3 的排除项为准；V2 见 [REQ-34](../requirement/34-V2与待定需求池.md)。

## 4. 用户体验与流程

1. 管理员在“模型注册表”登记模型、配置能力与价格，预览参数表单和版本差异，校验通过后发布并启用；列表显示供应商、区域、状态和生效价格。
2. 制作者在生成面板选模型，看到该模式可用的参数、参考用途及用量上限；填好输入后查看报价。后续管理员发布新价格，不改变已确认任务的版本记录。
3. 参考数量或类型超限时，界面指出具体限制，用户可删减输入或换模型；缺价格规则的模型不能启用。
4. 凭据不可用或模型停用时，选择器说明原因并引导换模型；若表单缓存版本已过期，报价提示模型版本变化并刷新表单后再确认（REQ-08 §2.1–2.4；DES-11 §7）。

## 5. 产品规则

- 模型内容只能发布新版本，已创建任务保留当时版本（REQ-08 R1）。
- 参数组件类型与模式显示、输入用途限制以 REQ-08 R2–R4 为准。
- 报价使用当时生效的价格版本，境外币种按版本化汇率换算（REQ-08 R5–R6）。
- 停用只阻止新报价；发布前校验配置，凭据不可用须在选择器说明（REQ-08 R7–R9）。

## 6. 成功标准

完成 REQ-08 §3 / TC-08-01～05；覆盖免发版上新、输入上限、停用、参数切换、历史价格。扩展性以 REQ-02 EXT-01 验证，报价缓存目标见 REQ-02 PERF-10。

## 7. 依赖与风险

依赖 [PRD-04](04-供应商凭据.md)；供应商适配器能力和实际价格需 P0 核验，配置错误会影响报价（REQ-08 §2.5；DES-11 §10）。

## 8. 待确认

无产品待确认。停用后阻止新报价、历史任务保留版本依据 REQ-08 R1、R7；初始模型与价格取 P0 评测结果（DES-11-Q1），校验格式、汇率录入和缓存方式见 DES-11 §11。
