# PRD 10：生成

执行编号：10；来源需求模块：14。下文06～19指原始需求模块编号，FR/US追踪标识保持原值。

## 1. 概述

用统一合同将冻结输入变为真实图片/视频候选，并控制未知执行与重复收费。

本文件是本次进一步拆解的待评审稿，细化用户结果及交付切片，不替代[模块需求](../requirement/14-生成需求.md)中的业务规则。对应[模块Plan](../plan/10-生成.md)；整体顺序与Demo优先级见[执行顺序](../plan/00-执行顺序.md)。未接受的新规则不能作为实施合同。

## 2. 参与者

使用者：制作者、核对风险任务的管理员。产品负责人确认范围与政策；工程负责人评审Design与可行性；测试负责人验证真实结果。实际承担者待落实，可一人兼任，不虚构姓名或已承诺产能。

## 3. 背景

一次提交、供应商成功、媒体可用和人工采用是不同事实，当前演示将它们混为成功提示。

来源是当前模块规格及其第8节页面/源码定位；现有页面和旧后端仅作为现状线索，不能作为新业务合同或已验收证据。

## 4. 目标与完成尺度

用统一合同将冻结输入变为真实图片/视频候选，并控制未知执行与重复收费。

本轮成功以接受切片的验收逐条通过为准：用户结果可观察，持久结果可读回，异常/越权有证据，无mock成功。真实外部调用、浏览器和自动化证据分开记录。人员、周期与质量阈值未定，当前不填上线日期、故事点或商业KPI；实施前补测量环境和完成窗口。

## 5. 使用场景

- 作为制作者，我希望确认输入和费用后得到可查询任务，避免重复调用和参数漂移。
- 作为制作者，我希望刷新后找到原任务，并打开真实结果。
- 作为制作者，我希望请求结果不明时先查实际执行，避免再次付费。

## 6. 价值与范围取舍

生图和图生视频均为首轮必需，优先与16形成跨模块Demo；详细工作项见Demo Plan，避免按本文件再造一套实现。

批量入口、取消/退款等只在政策明确后加入，不预建报价/支付平台。 上述取舍只调整交付顺序，不删除[原始完整范围](../requirement/14-生成需求.md#2-范围与边界)，也不把后续能力标为已完成。

## 7. 解决方案与验收切片

### 用户流程与界面

现有入口和视觉定位见[模块来源](../requirement/14-生成需求.md#8-页面与实现来源)；共享交互遵循[交互需求](../requirement/05-界面与交互需求.md)及[视觉规范](../../DESIGN.md)。本轮不重新设计页面，也不把沿用的Figma链接视为本次核验。涉及画布图片/视频的规则在[Demo PRD](06-画布生图生视频Demo.md)统一维护。

### US-GEN-01：校验并冻结一次提交

作为制作者，我希望确认输入和费用后得到可查询任务，避免重复调用和参数漂移。

范围追踪：FR-GEN-01～02，原始规则见[功能需求](../requirement/14-生成需求.md#3-功能性需求)。

1. 能力/参考/权限在调用前校验。
2. 必要费用确认绑定本次输入。
3. 同键同输入同任务而异输入冲突。
4. 提交后编辑不改原冻结版本。

### US-GEN-02：追踪状态和真实候选

作为制作者，我希望刷新后找到原任务，并打开真实结果。

范围追踪：FR-GEN-03～04，原始规则见[功能需求](../requirement/14-生成需求.md#3-功能性需求)。

1. 排队/运行/成功/失败/未知/人工可辨。
2. 重启查询同任务。
3. 候选与真实媒体及冻结输入关联。
4. 重复回执不重复发布且不自动选定。

### US-GEN-03：先核对再恢复

作为制作者，我希望请求结果不明时先查实际执行，避免再次付费。

范围追踪：FR-GEN-05，原始规则见[功能需求](../requirement/14-生成需求.md#3-功能性需求)。

1. 已执行丢响应进入unknown。
2. 未知时不直接重提收费。
3. 人工核对有权限及依据。
4. 按接受策略恢复且保留原任务/费用事实。

### 依赖、假设与质量

- 必要依赖：06、07、08、09、10以及有权生成目标；镜头/设定/画布入口各自提供输入。
- 尚待决定：报价/确认/未知费用、供应商核对方式、人工权限、安全重试/取消、媒体就绪/审核和批量确认。
- 功能追踪以以上FR为准；完整质量条件及测试方法见[模块第4节](../requirement/14-生成需求.md#4-非功能性需求)，原始组合场景见[第5节](../requirement/14-生成需求.md#5-验收场景)。拆解不撤销安全、恢复、数据真实性和可访问要求。
- 性能/容量/恢复阈值及运行条件未确定的部分单列，不能报告为质量达标。
