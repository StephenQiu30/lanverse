## 1. 问题与价值

逐镜探索不同参考与生成方案时，制作者在分镜、素材、任务页之间切换会丢失空间关系；另存一套画布业务数据又会造成两处结果不一致。本功能把同一份镜头和素材放在可连线的画布中，报价确认后运行生成，布局跨设备保存，正式选定回写流水线。对应 PRD-01 §1 的**一致性、可控性、效率**，直接服务 S8 画布精修；P9 要求画布与流水线共享数据，P27 要求 MVP 交付，P21 约束生成确认。

## 2. 目标用户与场景

- 作为**制作者**，我希望在无限画布上以节点展示镜头表、镜头、角色、素材与生成节点，并连线与分组。
- 作为**制作者**，我希望在画布上运行生成节点，连线即参考，结果可以“提升”为镜头的正式片段。
- 作为**制作者**，我希望布局自动保存，支持撤销重做、复制粘贴与快捷键，大画布依然流畅。

典型场景：

- Given 在画布上修改镜头 3 的时长，When 切换到流水线视图，Then 镜头 3 时长已更新。（TC-36-01）
- Given 画布生成节点，When 点击运行，Then 弹出报价确认；确认后任务中心出现该任务。（TC-36-02）
- Given 在画布上把一段音频连到镜头 7，When 打开流水线中镜头 7 的参考组合，Then 出现这段音频，用途为“音频”。（TC-36-03）

## 3. 范围

- 做（MVP）：节点类型 × 动作（DES-01 §9.1）、四种连线、布局命令、业务命令转调、生成节点运行、素材预设节点、撤销重做、快照、性能优化（REQ-36 §1.3）。
- 不做：以 REQ-36 §1.3 的排除项为准；V2 见 [REQ-34](../requirement/34-V2与待定需求池.md)。

## 4. 用户体验与流程

1. 制作者从项目进入画布，在左侧节点库添加镜头、角色、素材或生成节点，使用顶部工具栏、小地图和右侧属性面板摆放、分组与编辑；布局自动保存。
2. 将素材连到镜头形成参考，流水线的参考组合同步更新；运行生成节点时先看报价并确认，随后在任务中心跟进，满意的自由生成结果可提升到正式镜头。
3. 撤销可恢复布局及允许的非付费编辑，刷新或换设备后布局仍在。业务对象已删除时节点显示“对象已删除”并可移除；命令冲突时重放未确认的本地布局操作并提示结果；超过 2,000 节点时提示按集拆分；付费生成、选定和确认不提供撤销。（REQ-36 §2.1–2.2；DES-38 §6）

## 5. 产品规则

- 业务节点与流水线共用一份数据；参考连线与参考组合双向一致（REQ-36 R1、R2）
- 自由生成输入和提升结果分别按 input/promote 连线处理，生成仍需报价确认（REQ-36 R3–R5）
- 布局命令校验版本并重放冲突命令；付费生成、选定、确认不可撤销（REQ-36 R6、R7）
- 预设节点可套用参数；500 节点目标不低于 50 fps，同时播放视频不超过 3 个（REQ-36 R8、R9）

## 6. 成功标准

以 [REQ-36](../requirement/36-画布.md) §3 与 [TST-02](../test/02-需求追踪矩阵.md) 为准：

- TC-36-01：Given 在画布上修改镜头 3 的时长，When 切换到流水线视图，Then 镜头 3 时长已更新。
- TC-36-02：Given 画布生成节点，When 点击运行，Then 弹出报价确认；确认后任务中心出现该任务。
- TC-36-03：Given 在画布上把一段音频连到镜头 7，When 打开流水线中镜头 7 的参考组合，Then 出现这段音频，用途为“音频”。
- TC-36-04：Given 调整节点位置后刷新或换设备登录，When 打开画布，Then 布局一致。
- TC-36-05：Given 500 节点的画布，When 平移缩放，Then 帧率 ≥ 50 fps。

相关指标：PERF-06（500 节点 ≥ 50 fps、打开 ≤ 3 秒）；REQ-05 §4.8（两侧修改 2 秒内可见）。 PRD-01 §10 的生产与质量指标只跟踪，不另设目标。
