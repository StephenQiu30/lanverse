# PRD 03：素材

设计入口：[Design 03](../design/03-素材.md)。当前是待评审方案，接受后再按本次闭环细化技术工作项；原始需求与验收标识不变。

执行编号：03；来源需求模块：08。下文06～19指原始需求模块编号，FR/US追踪标识保持原值。

## 1. 概述

使上传参考与生成结果具有真实字节、明确项目归属和可用预览。

本文件是本次进一步拆解的待评审稿，细化用户结果及交付切片，不替代[模块需求](../requirement/08-素材需求.md)中的业务规则。对应[模块Plan](../plan/03-素材.md)；整体顺序与Demo优先级见[执行顺序](../plan/00-执行顺序.md)。未接受的新规则不能作为实施合同。

## 2. 参与者

使用者：制作者。产品负责人确认范围与政策；工程负责人评审Design与可行性；测试负责人验证真实结果。实际承担者待落实，可一人兼任，不虚构姓名或已承诺产能。

## 3. 背景

占位图、扩展名与静态容量不能证明媒体可作为生成输入。

来源是当前模块规格及其第8节页面/源码定位；现有页面和旧后端仅作为现状线索，不能作为新业务合同或已验收证据。

## 4. 目标与完成尺度

使上传参考与生成结果具有真实字节、明确项目归属和可用预览。

本轮成功以接受切片的验收逐条通过为准：用户结果可观察，持久结果可读回，异常/越权有证据，无mock成功。真实外部调用、浏览器和自动化证据分开记录。人员、周期与质量阈值未定，当前不填上线日期、故事点或商业KPI；实施前补测量环境和完成窗口。

## 5. 使用场景

- 作为制作者，我希望上传或打开自己的媒体，确认它确实可用作参考。
- 作为制作者，我希望筛选、建文件夹与收藏后再次找到素材。
- 作为制作者，我希望将素材加入项目或回收条目，保留已引用的创作结果。

## 6. 价值与范围取舍

优先授权媒体存取、真实图/视频元数据、就绪判断和预览；生成候选由14生产，再使用本模块媒体能力。首轮生图无需依赖素材库全套管理。

收藏、文件夹、完整查询与回收不阻塞首轮图片→视频链。 上述取舍只调整交付顺序，不删除[原始完整范围](../requirement/08-素材需求.md#2-范围与边界)，也不把后续能力标为已完成。

## 7. 解决方案与验收切片

### 用户流程与界面

现有入口和视觉定位见[模块来源](../requirement/08-素材需求.md#8-页面与实现来源)；共享交互遵循[交互需求](../requirement/05-界面与交互需求.md)及[视觉规范](../../DESIGN.md)。本轮不重新设计页面，也不把沿用的Figma链接视为本次核验。涉及画布图片/视频的规则在[Demo PRD](06-画布生图生视频Demo.md)统一维护。

### US-ASSET-01：真实上传与预览

作为制作者，我希望上传或打开自己的媒体，确认它确实可用作参考。

范围追踪：FR-ASSET-01、FR-ASSET-04，原始规则见[功能需求](../requirement/08-素材需求.md#3-功能性需求)。

1. 真实字节与探测类型一致。
2. 尺寸/时长可核对。
3. 未就绪/不可用与成功分开。
4. 无权原件拒绝且失败保留安全反馈。

### US-ASSET-02：找到并整理素材

作为制作者，我希望筛选、建文件夹与收藏后再次找到素材。

范围追踪：FR-ASSET-02～03、FR-ASSET-05，原始规则见[功能需求](../requirement/08-素材需求.md#3-功能性需求)。

1. 范围筛选与数量一致。
2. 文件夹刷新保留。
3. 收藏只影响本人。
4. 容量未知不报0且失败不作空列表。

### US-ASSET-03：安全复用与回收

作为制作者，我希望将素材加入项目或回收条目，保留已引用的创作结果。

范围追踪：FR-ASSET-06～07，原始规则见[功能需求](../requirement/08-素材需求.md#3-功能性需求)。

1. 加入项目建立真实授权引用。
2. 无权项目拒绝。
3. 重复加入按确认规则处理。
4. 回收刷新生效且被引用原件/历史保留。

### 依赖、假设与质量

- 必要依赖：06、07；生成媒体入库与14集成，不先等待生成才能验证合法上传。
- 尚待决定：格式/大小上限、审核与就绪、容量总量/引用计量、最近30天时间口径、部分上传保留和重复加入。
- 功能追踪以以上FR为准；完整质量条件及测试方法见[模块第4节](../requirement/08-素材需求.md#4-非功能性需求)，原始组合场景见[第5节](../requirement/08-素材需求.md#5-验收场景)。拆解不撤销安全、恢复、数据真实性和可访问要求。
- 性能/容量/恢复阈值及运行条件未确定的部分单列，不能报告为质量达标。
