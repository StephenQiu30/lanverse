# 数据治理与安全需求

## 1. 目标与适用数据

本 PRD 覆盖两类数据：第三方提示词/示例，以及用户 prompt/生成作品。目标是在不绕过来源规则、不泄露用户数据、不发布不安全内容的前提下支持产品主链。

本文件不是法律意见；真实联网和真实生成必须分别通过运行激活门禁。

## 2. 角色与需求

| 角色 | 需求 |
| --- | --- |
| 访客/创作者 | 只看到有权展示且安全的模板，私有创作不被他人访问 |
| 来源权利人 | 可核验归属并提出下架/删除请求 |
| 安全审核员 | 以最小权限处理隔离内容并留下审计 |
| 运营管理员 | 启停来源/供应商、处理投诉和查看删除进度 |

## 3. 范围

- 来源 ToS、robots、API/书面授权、保存和公开展示动作的独立裁决。
- 第三方内容溯源、许可、署名、采集版本和 hash。
- 用户账号、prompt、任务、作品的 owner 隔离和最小保存。
- Seedream 输入/输出审核及供应商数据边界。
- SSRF、防恶意媒体、MinIO bucket 权限和短时签名 URL。
- suppression、投诉、在线删除、备份防复活和审计。

非目标：自动给出法律结论、采集未知来源、成人内容分级展示、人脸识别、公开用户作品或把用户内容用于训练。

## 4. 治理规则

| ID | 规则 |
| --- | --- |
| G-BR-01 | 来源未具备访问、保存、公开展示三类有效记录时不得联网或发布 |
| G-BR-02 | 来源暂停/许可过期立即停止新任务并隐藏受影响模板 |
| G-BR-03 | 用户 prompt、作品和供应商结果默认私有且不用于训练 |
| G-BR-04 | 成人、违法、未成年人性内容和低置信审核结果 fail-closed |
| G-BR-05 | 生成前审核输入，生成后审核输出；任一失败不产生可见作品 |
| G-BR-06 | 只允许白名单 HTTPS、受限重定向和公共网络地址 |
| G-BR-07 | 只接受 JPEG/PNG/静态 WebP，≤20 MiB、≤40 MP |
| G-BR-08 | 展示衍生图必须移除 EXIF/XMP/GPS，原图不直接签名给浏览器 |
| G-BR-09 | 用户/权利人删除先隐藏，在线对象与索引 24 小时内完成删除 |
| G-BR-10 | RabbitMQ 消息和日志不得包含 prompt、媒体、secret 或长期签名 URL |

## 5. 数据生命周期

第三方内容：

```text
fetched → normalized → rights/safety → published | quarantined | rejected
published → suppressed → deleted
```

用户内容：

```text
draft → input passed → provider → output passed → private work
private work → user deleted → deleted
```

## 6. 治理验收标准

| ID | 标准 |
| --- | --- |
| AC-G01 | 未激活来源不会产生网络请求，激活记录包含条款、动作、期限和负责人 |
| AC-G02 | 每个公开模板可追溯来源 URL、对象 ID、版本、许可、采集时间和 hash |
| AC-G03 | 来源暂停/下架后公共 API 5 分钟内不可见 |
| AC-G04 | 用户 A 无法访问用户 B 的 prompt、job、对象 key、签名 URL 或元数据 |
| AC-G05 | 输入审核失败时供应商调用次数为 0 |
| AC-G06 | 输出审核失败时无 `user_work`、无可见签名 URL，并有审计原因 |
| AC-G07 | SSRF fixtures 均被阻断，目标服务证明未收到请求 |
| AC-G08 | 恶意/超限/不支持媒体全部拒绝，展示文件不含 EXIF/XMP/GPS |
| AC-G09 | 删除后立即隐藏，在线对象/索引 24 小时内有 receipt，恢复不复活 |
| AC-G10 | 日志、队列、错误响应和 Git secret 扫描均无敏感数据 |
| AC-G11 | 审核员和管理员权限最小化，所有治理写操作具有操作者、原因和 trace |
| AC-G12 | DiffusionDB、Seedream、MinIO、安全负责人四类激活门禁均有明确状态 |

## 7. 指标与 SLA

- 公共下架可见性 SLA ≤5 分钟；在线删除 SLA ≤24 小时。
- 越权访问成功数、SSRF 成功数、恶意媒体公开数必须为 0。
- 审核 unknown/timeout 不得自动通过；治理事件和删除 receipt 完整率 100%。

## 8. 风险与边界

来源政策与供应商数据用途可能变化；每次激活记录版本并配置 kill switch。自动检测存在误报/漏报，因此低置信内容隔离，不扩大成人内容范围。备份只恢复到离线 namespace，应用 suppression 后才能上线。

## 9. 发布门禁

AC-G01 至 AC-G12 全部通过；SOURCE-01、PROVIDER-01、SAFETY-01、STORAGE-01 与实际发布范围一致。未通过的外部服务必须保持关闭。
