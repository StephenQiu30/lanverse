## 1. 问题与价值

制作者同时制作多集、多种风格时，散放的镜头和素材难以归到同一作品，也看不清哪集已完成。项目把画幅、风格与生成策略固定在作品入口，并在概览按集显示阶段进度，支撑 S1 的整部剧逐集生产和 S2 的单集推进；归档后仍可查历史。它贡献“效率”和“可控性”（PRD-01 §1、§5；P3、P6、P12；REQ-10 §1）。

## 2. 目标用户与场景

- 制作者创建项目并选画幅、风格类型及预设。
- 制作者在项目概览查看各集阶段完成数。
- 制作者归档、删除或恢复项目，设置默认模型和境外模型开关。

## 3. 范围

- **做（MVP）**：创建、可改字段编辑、列表与概览、归档/恢复、删除/恢复/到期清理、生成策略和标识样式（REQ-10 §1.3）。
- **不做**：以 REQ-10 §1.3 的排除项为准；V2 见 [REQ-34](../requirement/34-V2与待定需求池.md)。

## 4. 用户体验与流程

1. 制作者从项目列表新建作品，填写名称、画幅、风格类型及预设；风格化时选择子风格。创建项目时同步建立默认 0 的预算记录，后续由预算功能调整（DES-13 §2、REQ-11 R1）。进入项目概览后，可看到各集六个阶段的完成数与总数，点击单元格进入对应工作页。
2. 在设置页修改名称、描述、默认模型、境外模型开关等可改项；画幅与风格类型显示为只读，并解释它们与既有素材绑定。
3. 归档后项目仍可浏览、下载，但写入操作提示只读；用户可恢复归档。删除后在回收列表显示剩余恢复期，30 天内可恢复到原状态。
4. 有进行中或待对账任务时，归档/删除会列出阻止项，用户可先处理任务；境外模型关闭时，报价提示不可用并允许换模型，已确认任务继续执行（REQ-10 §2.1–2.4；DES-13 §6）。

## 5. 产品规则

- 名称可重名，以 ID 区分；画幅与风格类型创建后不可改，分辨率固定 1080p（REQ-10 R1–R3；P3、P12）。
- 名称、描述、预设、默认模型、境外开关与标识样式可修改；境外模型默认关闭，关闭不影响已确认任务（REQ-10 R4–R6）。
- 归档只读；进行中任务阻止归档或删除；删除 30 天内可恢复（REQ-10 R7–R9）。
- 概览按集展示六个生产阶段的完成数/总数（REQ-10 R10）。

## 6. 成功标准

完成 REQ-10 §3 / TC-10-01～06；覆盖创建规格、不可改字段、概览计数、进行中任务保护、恢复与境外报价拦截。概览性能以 REQ-02 PERF-01、PERF-03 为准。
