# PRD 08：设定

执行编号：08；来源需求模块：12。下文06～19指原始需求模块编号，FR/US追踪标识保持原值。

## 1. 概述

管理角色、场景、道具与造型参考，使生成引用具有明确版本。

本文件是本次进一步拆解的待评审稿，细化用户结果及交付切片，不替代[模块需求](../requirement/12-设定需求.md)中的业务规则。对应[模块Plan](../plan/08-设定.md)；整体顺序与Demo优先级见[执行顺序](../plan/00-执行顺序.md)。未接受的新规则不能作为实施合同。

## 2. 参与者

使用者：制作者。产品负责人确认范围与政策；工程负责人评审Design与可行性；测试负责人验证真实结果。实际承担者待落实，可一人兼任，不虚构姓名或已承诺产能。

## 3. 背景

展示参考卡片不等于槽位媒体真实、版本已锁定或声音已授权。

来源是当前模块规格及其第8节页面/源码定位；现有页面和旧后端仅作为现状线索，不能作为新业务合同或已验收证据。

## 4. 目标与完成尺度

管理角色、场景、道具与造型参考，使生成引用具有明确版本。

本轮成功以接受切片的验收逐条通过为准：用户结果可观察，持久结果可读回，异常/越权有证据，无mock成功。真实外部调用、浏览器和自动化证据分开记录。人员、周期与质量阈值未定，当前不填上线日期、故事点或商业KPI；实施前补测量环境和完成窗口。

## 5. 使用场景

- 作为制作者，我希望管理设定与造型版本，保留不同对象和历史。
- 作为制作者，我希望选择真实参考并显式锁定，使镜头不被迟到生成改变。
- 作为制作者，我希望试听真实音色并记录真人声音授权，避免使用未声明来源。

## 6. 价值与范围取舍

首轮可用直接图片输入，不必先完成设定集；后续将锁定设定作为同一画布生成合同的参考来源。

先编辑与上传锁定，再接参考生成；声音不进入首轮图片/视频Demo。 上述取舍只调整交付顺序，不删除[原始完整范围](../requirement/12-设定需求.md#2-范围与边界)，也不把后续能力标为已完成。

## 7. 解决方案与验收切片

### 用户流程与界面

现有入口和视觉定位见[模块来源](../requirement/12-设定需求.md#8-页面与实现来源)；共享交互遵循[交互需求](../requirement/05-界面与交互需求.md)及[视觉规范](../../DESIGN.md)。本轮不重新设计页面，也不把沿用的Figma链接视为本次核验。涉及画布图片/视频的规则在[Demo PRD](06-画布生图生视频Demo.md)统一维护。

### US-SETTING-01：建立和查找设定版本

作为制作者，我希望管理设定与造型版本，保留不同对象和历史。

范围追踪：FR-SETTING-01～02，原始规则见[功能需求](../requirement/12-设定需求.md#3-功能性需求)。

1. 分类/筛选与实际引用一致。
2. 名称/别名/造型持久。
3. 同名不自动合并。
4. 版本冲突保留输入且旧版本可辨。

### US-SETTING-02：明确采用槽位参考

作为制作者，我希望选择真实参考并显式锁定，使镜头不被迟到生成改变。

范围追踪：FR-SETTING-03～04，原始规则见[功能需求](../requirement/12-设定需求.md#3-功能性需求)。

1. 四槽位绑定真实授权媒体。
2. 生成仅追加候选。
3. 锁定明确到版本。
4. 新编辑不改旧冻结引用且不可用媒体拒绝。

### US-SETTING-03：声明并试听声音来源

作为制作者，我希望试听真实音色并记录真人声音授权，避免使用未声明来源。

范围追踪：FR-SETTING-05，原始规则见[功能需求](../requirement/12-设定需求.md#3-功能性需求)。

1. 真实可用音频才播放。
2. 声明主体/来源/提交人/时间持久。
3. 未声明真人来源拒绝相关生成。
4. 更换来源后旧声明不适用。

### 依赖、假设与质量

- 必要依赖：07、08；11提供可选抽取来源，参考生成依赖10、14。
- 尚待决定：同名/别名判定、抽取确认、锁定/解除范围与权限、声音声明主体/来源与来源变更。
- 功能追踪以以上FR为准；完整质量条件及测试方法见[模块第4节](../requirement/12-设定需求.md#4-非功能性需求)，原始组合场景见[第5节](../requirement/12-设定需求.md#5-验收场景)。拆解不撤销安全、恢复、数据真实性和可访问要求。
- 性能/容量/恢复阈值及运行条件未确定的部分单列，不能报告为质量达标。
