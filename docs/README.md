# Lanverse 剧本解析文档索引

本目录只记录已经进入实现范围、能够长期维护的产品与工程事实。当前唯一产品主线是“上传整本剧本 → 结构化解析 → 分集 → 人物/场景/任务聚合 → 按集生成并审阅分镜表”。

实现链路按以下顺序维护：

1. [Requirement：剧本解析全流程需求](./requirement/剧本解析全流程需求.md)
2. [Design：剧本解析全流程设计](./design/剧本解析全流程设计.md)
3. [PRD：剧本解析全流程产品定义](./prd/剧本解析全流程PRD.md)
4. [Plan：剧本解析全流程实施计划](./plan/剧本解析全流程实施计划.md)
5. [Acceptance：剧本解析全流程验收标准](./acceptance/剧本解析全流程验收标准.md)

不在本目录保留实施日志、一次性修复方案、旧架构验收证据或尚未进入实现范围的模块设计。Git 历史承担变更追溯。

固定非目标：Go 后端、独立 Agent 服务、独立 Admin 服务、邀请功能、Docker 运行环境、旧接口兼容层和为未来功能预建的空模块。
