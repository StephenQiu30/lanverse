## 3. 接口

```http
POST /api/shots/{id}/versions
{ "expected_revision": 5, "patch": { "generation_mode": "omni_reference", "video_model_key": "ark.seedance-2-pro",
  "references": [ { "role": "subject", "ref_type": "reference_version", "ref_id": "…" },
                  { "role": "subject", "ref_type": "reference_version", "ref_id": "…" },
                  { "role": "scene",   "ref_type": "reference_version", "ref_id": "…" },
                  { "role": "camera",  "ref_type": "media_asset",       "ref_id": "…" },
                  { "role": "audio",   "ref_type": "dialogue_audio",    "ref_id": "…" } ] } }
201 { "version_no": 6, "revision": 6, "validation": { "ok": true, "usage": { "image": [3, 9], "video": [1, 3], "audio": [1, 3] } } }

POST /api/shots/{id}:validate-references   { "video_model_key": "…" }    → 不保存，仅校验
200 { "ok": false, "errors": [ { "seq_no": 4, "code": "input_limit_exceeded", "message": "音频参考最多 3 段" },
                               { "seq_no": 2, "code": "input_not_ready", "message": "素材尚未就绪" } ] }
```

参考选择器数据源：`GET /api/projects/{pid}/characters?episode_id=`（锁定版本）、`GET /api/projects/{pid}/media?kind=video&status=ready`、`GET /api/episodes/{eid}/dialogue?shot_id=`。

## 4. 异步与工作流

无；报价时由命令层展开（DES-04 §报价）。

## 5. 事件与实时

随镜头版本事件发布。

## 6. 界面

参考组合面板（REQ-05 §4.4）：顶部上限条；卡片列表（缩略图 / 波形、名称与版本、用途下拉、“有新版本”提示、移除）；添加菜单（设定集 / 媒体库 / 台词音频 / 上传）；拖拽排序。

## 7. 权限与审计

制作者；随镜头版本留痕。

## 8. 非功能要求

校验 P95 ≤ 200 ms（纯内存计算 + 一次批量查询）。

## 9. 测试设计

校验器的所有规则组合（表驱动单元测试）；前后端校验结果一致性（共用测试向量）。

## 故障约束与专项验证

- 模型切换使参考数量超限：保留组合并标红，停止报价；允许用户减项或换模型。
- 引用版本更新或授权作废：保持原版本可追溯、阻止新报价；提示用户主动升级或替换，不自动改写镜头。
